# Security

This repository is Markdown skills plus small Python tools. If you find a vulnerability in the tools (`tools/`,
`connector/`), or a skill that gives dangerous or wrong instructions that could cause harm, please report it
privately through GitHub: **Security tab → Report a vulnerability**. Do not open a public issue for a tool
vulnerability. For an ordinary wrong or outdated skill, a normal issue or pull request is the right route.

Never put secrets, credentials or personal data in a skill or an issue.
