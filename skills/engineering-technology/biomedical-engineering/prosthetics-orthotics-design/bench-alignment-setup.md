# Bench alignment

**Goal:** assemble the prosthesis so that, when stood on, the load line falls where stability is expected, giving a good starting point for dynamic alignment. Final alignment is by a prosthetist in gait.

## Principles
- A **reference (load) line** is a plumb line dropped through chosen anatomic points; its relation to knee and foot defines stability.
- **Transtibial:** set socket flexion (commonly a few degrees to about 5 degrees to follow the limb), slight adduction as needed, and place the foot so the load line passes through the socket and foot at the intended points; adjust foot position for shoe heel height.
- **Transfemoral:** the load line passes behind the knee centre for stance stability; the knee axis placed relative to the load line sets the stability margin; socket flexion matches residual hip flexion contracture; socket adduction places the knee under the hip.
- Foot rotation (toe out) and step width follow the other foot.

## Steps
1. Mount the socket on the alignment fixture (jig) using the build or component manufacturer's recommended reference positions.
2. Set the height with the shoe on and the pelvis level; leave length adjustable.
3. Check static weight-bearing and loading; verify the knee is stable.
4. Proceed to dynamic alignment: observe gait and adjust.

## Verify
- [ ] Reference points and angles recorded.
- [ ] Static stability confirmed before walking.
- [ ] Settings carried to the definitive prosthesis.
