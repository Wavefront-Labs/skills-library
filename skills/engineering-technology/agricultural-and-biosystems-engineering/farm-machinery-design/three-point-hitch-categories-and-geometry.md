# Three-point hitch categories and geometry

**Goal:** an implement that mounts safely, lifts to working height and holds its working attitude.

## Categories
Hitch categories 1, 2, 3 and 4 (with 3N/4N narrow variants and quick-hitch compatible versions) are defined by ISO 730 and ASABE standards on three-point hitches. Larger categories use larger lower-link pin and ball diameters, and wider spacing. Approximate matches: Cat 1 for small tractors (roughly 20-45 kW), Cat 2 for medium (roughly 40-100 kW), Cat 3 for large row-crop tractors (roughly 80-185 kW), Cat 4 above that. These are indicative; use the standard's dimensional tables for the actual pin sizes, and the tractor and implement manuals for limits.

## Check list
1. Tractor rear hitch category equals implement category; if mixed, use properly rated bushings or adapters rather than improvising.
2. **Lift capacity** at the lower-link ends and at the maximum working distance behind them (manufacturer data), not just at the rear of the lift links; compare with implement weight plus soil load.
3. **Geometry**: lower links level when working, top link angle to give correct implement attitude; mast height changes the instantaneous centre and draft sensitivity.
4. **Sway control**: chains or stabilisers set for field work, loosened or free for headland turns on trailed-type use only as the manual allows.
5. **Draft/position control**: position control for stability in shallow work; draft control for variable resistance, using the lift linkage sensing.
6. PTO-driven implements: check driveline length through the full lift range and hitch geometry.

## Gotchas
- Quick hitch hooks add offset to the implement centre of gravity; re-check front axle load.
- Worn pins and bushes cause hitch play and unsafe unhitching; inspect before use.
- Never stand between tractor and implement while hitching.

## Verify
- [ ] Category and pin sizes match; lift test at full height with implement attached.
- [ ] No driveline bottoming or over-extension across the lift range.
