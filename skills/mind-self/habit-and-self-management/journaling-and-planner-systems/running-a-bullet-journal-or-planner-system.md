# Running a bullet journal or planner system

**Goal:** one trusted place where tasks, events and notes land, reviewed on a rhythm so
nothing important slips — whether that place is a dotted notebook, a printed planner or
an app.

## Core parts (the Bullet Journal method, adaptable to any planner)
1. **Index** — the first pages; list page numbers of collections as you create them.
2. **Future log** — a spread of the next 6–12 months for dated things beyond this month.
3. **Monthly log** — a calendar page (dates down the side, events beside them) plus a
   task page for the month.
4. **Daily log** — dated entries, written as the day happens.
5. **Collections** — pages for a topic: a project, a reading list, a trip, a habit tracker.

## Rapid logging
Short entries with a symbol ("signifier"):
- `•` task  → `×` done, `>` migrated to a later list, `<` scheduled to the future log,
  struck through = no longer relevant
- `○` event
- `–` note
- `*` priority, `!` idea (optional extras)
One line per item. Write the task as an action ("email landlord re: boiler").

## The rhythm
- **Morning (5 min):** new daily heading; pull in today's events and the 1–3 tasks that matter.
- **During the day:** log as things arise — don't let them sit in your head.
- **Evening (5 min):** mark what's done; decide what happens to the rest.
- **Monthly migration (20–30 min):** set up the new month. Go through every open task
  from the previous month and ask *does this still matter?* If yes, rewrite it into the
  new month or schedule it in the future log. If no, strike it. The rewriting friction is
  deliberate — it kills tasks not worth rewriting.
- Many people add a **weekly** spread and review; the official method doesn't require it.

## Habit trackers
A grid of days × habits on a collection page; fill a cell when done. Keep to a few habits
(see `mind-self.habit-and-self-management.self-monitoring.tracking-your-own-behaviour`).

## Digital equivalents
| Paper part | Typical digital version |
|---|---|
| Daily/monthly task logs | Task manager with due dates and "today" view |
| Future log | Calendar plus "someday" list |
| Collections | Notes app pages or project lists |
| Migration | Weekly review of overdue and undated tasks |
Digital wins on reminders, search and recurring tasks; paper wins on focus, deliberate
migration and fewer distractions. A common hybrid: calendar digital, tasks and notes on paper.

## Switching systems without losing things
1. Pick a cut-over date (start of a month).
2. Do a full migration — every open task and future event — into the new system.
3. Keep the old notebook/app read-only for a month; check it once a week.
4. Don't run two live systems in parallel; tasks fall between them.

## Gotchas
- **Decoration creep:** elaborate spreads look great online and consume the time meant
  for doing. Function first; art is optional.
- **Unreviewed systems rot.** A planner you don't open daily becomes a graveyard.
- **Over-planning the day:** list more than ~5 tasks and most will migrate; pick the
  few that matter.
- **One inbox:** if tasks also live in email flags, sticky notes and chat reminders,
  bring them to the planner at the daily review.
- Evidence on journaling for productivity is mostly practitioner experience; benefits
  claimed for well-being journaling come from separate (expressive-writing) research.

## Verify
- [ ] Every task, event and commitment from today is in one system.
- [ ] You run a daily open/close and a monthly migration.
- [ ] Old open tasks are either migrated deliberately or struck — none are just abandoned.
- [ ] You can find any collection in under 30 seconds (index or search).
- [ ] Setup and decoration take less than 10% of your planning time.
