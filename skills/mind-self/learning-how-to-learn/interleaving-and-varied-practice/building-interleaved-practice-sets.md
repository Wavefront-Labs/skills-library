# Building interleaved practice sets

**Goal:** practise so that you can recognise *which* method or category applies — the
skill blocked practice never trains — and so learning transfers to new situations.

## Blocked vs interleaved
- **Blocked:** 20 problems on topic A, then 20 on B, then 20 on C (AAAA BBBB CCCC).
  You know the method before reading the problem. Feels smooth; scores high during practice.
- **Interleaved:** the same 60 problems shuffled (ABCB CACB …). Each problem first
  requires deciding what kind it is. Feels harder; practice scores drop; delayed test
  scores typically rise — in Rohrer & Taylor (2007) a one-week-later maths test was
  roughly double for the interleaved group (63% vs 20%).

## Building an interleaved set
1. **Learn each type once, blocked.** Interleave only after you can do each type in
   isolation; mixing before that is just confusion.
2. **Gather problems from 3–5 related types** that are easy to confuse (different
   integration techniques; past simple vs present perfect; chord types by ear; similar
   bird species).
3. **Shuffle** so no two consecutive items share a type often. Strip headings that give
   away the type ("Section 4.3: substitution").
4. **For each item, first name the type and why**, then solve. That naming step is the
   payoff.
5. **Check and log** misidentifications separately from execution errors.

## Rotation schedules for ongoing study
- Each session: ~⅓ new topic, ~⅔ mixed review of earlier topics.
- Rotate subjects across a study day (e.g. 40 min chemistry, 40 min history, back to
  chemistry) rather than one subject all day — evidence here is thinner than for problem
  interleaving, so treat it as a reasonable default.
- In skills (sport, music, driving), vary conditions: distances, tempos, keys, weather,
  partners. This is "varied practice"; the motor-learning term is contextual interference.

## Contrast pairs
Put the two most confusable items side by side and state the deciding difference:
"Use the chain rule when … ; use the product rule when …". Kornell & Bjork (2008) found
interleaving painting styles helped people identify new paintings by each artist —
because juxtaposition highlights differences.

## When to block instead
- Brand-new, complex material where you can't do a single type yet.
- Very low prior knowledge or high anxiety; get some early wins first.
- Fine-tuning one specific movement (a golf putt) in a single session — block briefly,
  then reintroduce variety.

## Gotchas
- **It feels worse.** Learners consistently rate blocked practice as more effective even
  when they learned more from interleaving. Judge by a test a week later, not by
  in-session fluency.
- Interleaving unrelated topics (maths with French vocab) gives the spacing benefit but
  not the discrimination benefit; the gain is largest for confusable categories.
- Textbooks are almost all blocked — you will need to build mixed sets yourself.
- Effects are strongest in maths and category learning; for other domains the evidence
  is promising but less consistent.

## Verify
- [ ] You can do each type alone before mixing.
- [ ] Your set hides type labels and alternates types.
- [ ] You name the type before solving and log misidentifications.
- [ ] Each session revisits earlier topics, not just the newest.
- [ ] A delayed mixed quiz (a week later) shows you choose methods correctly.
