# Remembering names at introductions

**Goal:** still know someone's name at the end of the evening, next week, and the next
time you meet — without awkwardness.

## Why names vanish
Most of the time the name was **never encoded**. At introductions we're busy with our own
greeting (the "next-in-line" effect: people recall poorly what was said just before their
own turn), the name is said once, quickly, and it's an arbitrary label with no meaning.
Fix attention first; mnemonics second.

## 1. Catch it (attention ritual)
- **Decide in advance** that the name is the one thing you'll capture.
- When the name is said, **look at the face and repeat it** aloud: "Priya — nice to meet you."
- **Didn't hear it? Ask immediately.** "Sorry, was that Priya or Pria?" Asking now is
  normal; asking in an hour is awkward.
- Ask a natural question about it: spelling, origin, "do you go by Rob or Robert?"

## 2. Convert the name to an image
- Some names are already images: Rose, Baker, Hunter, Bell.
- Others need a sound-alike **substitute word**: Priya → "pliers"; Morgan → "more gun";
  Kowalski → "cow-walks-ski"; Ines → "eye-ness".
- Famous namesakes work too: "Martin — like the guitar brand"; "Ada — Ada Lovelace".
- Keep it private and respectful; it's a memory device, not a joke to share.

## 3. Anchor the image to the face
Pick **one distinctive feature** — eyebrows, hairline, glasses, a dimple, ears, jaw, a
smile line (prefer stable features over clothing or hairstyle, which change). Then make
the image act on it: giant *pliers* tweezing Priya's arched eyebrows. Hold it for a
couple of seconds while she's talking.

## 4. Rehearse socially (spaced, in conversation)
- Use the name **once naturally** in the first minute ("So, Priya, how did you…"), once
  more when parting — no more, or it sounds rehearsed.
- **Introduce them to someone else** — the best rehearsal there is.
- Glance around the room every 15–20 minutes and silently name the people you've met.
  This expanding-interval recall is what moves names into longer-term memory.

## 5. Review after the event
- Write names down within a few hours with one note each: feature, context, topic
  discussed ("Priya — eyebrows — logistics, cycling"). A phone contact note works.
- Review the list before the next meeting with that group.
- With permission and where appropriate, attendee lists or work-directory photos help
  later review.

## For teachers, managers and large groups
Use a seating plan or photo roster and test yourself cover-and-recall style; take five
names per session rather than thirty at once.

## Gotchas
- **Thinking about what to say next** instead of listening — the main cause of forgetting.
- **Clothing as the anchor** — gone tomorrow.
- **Overusing the name** to "practise" — sounds salesy.
- **Faking it:** if you forget, say so warmly and ask again; then encode properly.
- Recall of the face is usually much better than of the name; the image link is what
  bridges them.

## Verify
- [ ] You repeated each name aloud at the introduction.
- [ ] Each name has an image and is anchored to a stable facial feature.
- [ ] You used each name naturally at least once and rehearsed silently during the event.
- [ ] You wrote names with one note each within a few hours.
- [ ] At the next meeting, you greet people by name without hesitation.
