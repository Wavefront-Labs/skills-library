# Crafting acronyms, acrostics and rhymes

**Goal:** make a short verbal hook that carries a list, an order or a spelling — for an
exam, a checklist you need under pressure, or teaching others — and make sure it
actually leads back to the facts.

## Pick the right type
| Type | Best for | Example |
|---|---|---|
| **Acronym** (letters spell a word) | Unordered sets where you can reorder freely | HOMES — the Great Lakes (Huron, Ontario, Michigan, Erie, Superior) |
| **Pronounceable letter string** | A fixed order | ROY G BIV — colours of the spectrum |
| **Acrostic** (first letters → a sentence) | A fixed order whose letters don't make a word | Every Good Boy Deserves Fun — notes on the treble-clef lines E G B D F |
| **Rhyme / jingle** | Rules and exceptions | "Thirty days hath September, April, June and November…" |
| **Song / melody** | Longer lists, children, language learning | the alphabet song; lists sung to a tune you know |

## 1. Building an acronym
1. Write the items and their first letters.
2. If order doesn't matter, rearrange to make a real word (HOMES) or a pronounceable one.
3. If no word works, insert a filler letter you'll recognise as filler, or use a
   two-letter cue for a clashing item (e.g. "Me" for Mercury vs "Ma" for Mars).

## 2. Building an acrostic
1. Write the first letters in order.
2. Make a sentence that is **vivid, funny, or personal** — those stick; bland ones don't.
   For the planets, "My Very Educated Mother Just Served Us Nachos" (Pluto dropped since
   its 2006 reclassification).
3. Make it **visualisable** — you can picture the mother serving nachos.
4. Check that each word's first letter maps to only one item in context.

## 3. Building a rhyme or jingle
- Put the key fact at the **end of a line**, on the rhyme — that's the stressed, memorable
  position.
- Keep a steady meter (da-DUM da-DUM); irregular rhythm is hard to recall.
- Borrow a tune you already know for longer material; the melody holds the sequence.

## 4. Test it before relying on it
- **Decode test:** a day later, from the mnemonic alone, can you produce every item
  correctly? If you get "E… elephant?", the cue is too weak; add a second letter or image.
- **Ambiguity test:** do two items share a first letter? Disambiguate now, not in the exam.
- **Speed test:** if decoding takes longer than recalling directly, you've outgrown it.

## Understanding still matters
Verbal mnemonics give **order and cues**, not meaning. Pair them with understanding:
learn what each item is, then use the mnemonic to retrieve the set. Retire the
mnemonic once you know the material directly.

## Gotchas
- **Over-general rules:** "i before e except after c" has many exceptions (*weird*,
  *science*, *their*). A rhyme that's wrong is worse than none — check the rule first.
- **Outdated facts** baked into old mnemonics (the nine-planet versions).
- **Letter collisions** — two "M" planets, two "S" items; add a second letter.
- **Too many mnemonics** for one exam become their own memory load; reserve them for
  lists that resist ordinary learning.
- **Copyright:** sharing your own lyrics set to a well-known tune for teaching is common
  practice, but publishing a recording may raise licensing questions; check before selling
  such material (not legal advice).

## Verify
- [ ] The mnemonic type matches the need (order vs set vs rule).
- [ ] Every item decodes uniquely and correctly from the mnemonic alone after a day.
- [ ] Any rule in a rhyme was checked against real exceptions.
- [ ] You can explain what each item means, not just list it.
