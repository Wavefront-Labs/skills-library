# Drawing a useful mind map

**Goal:** use a radial diagram to get everything out of your head about a topic, see how
the pieces connect, spot what's missing, and turn it into a plan, essay or talk.

## 1. Set up
- **Landscape page, centre start.** Plain paper (A4/A3) or a whiteboard. Space matters:
  a cramped map stops growing.
- **Central topic** in the middle as a word or small drawing, boxed or circled. Keep it a
  noun phrase ("Garden redesign"), not a question.

## 2. Main branches (the first ring)
Draw 4–7 thick branches for the main themes. If you don't know them yet, start with
generic prompts — who, what, when, where, why, how; or problems, resources, people, costs.
Rename them once the real themes appear.

## 3. One keyword per line
Write **one word (or a very short phrase) on each line**, on top of the line. This is the
discipline that makes mind maps different from scattered notes: a single word can sprout
several sub-branches, whereas a sentence is a dead end. "Shade-tolerant plants" →
"shade" with branches "ferns", "hostas", "north wall".

## 4. Grow outward fast
- Work quickly; don't tidy while generating. Jump between branches freely — that's where
  the associative value comes from.
- When one branch dries up, go to the emptiest branch and ask a question of it.
- Lines get thinner as you move out; this keeps hierarchy visible.

## 5. Cross-link and mark
- Draw arrows (or matching colours/symbols) between related items on different branches.
  Cross-links are often where the new ideas are.
- Use a few consistent marks: `!` important, `?` unsure or to research, ✓ decided.

## 6. Hunt for gaps
Step back and look at the *shape*: a thin or empty branch is a gap in your thinking,
research or plan. Ask "what's missing here?" for each main branch. Lopsided maps are
information, not failure.

## 7. Convert to action
Number the main branches in the order you'd present or do them, then write a linear
outline or task list from the map. For an essay: branches → sections, sub-branches →
paragraphs.

## Software or paper?
Paper is fastest for generation and recall; software (XMind, MindMeister, FreeMind,
Miro, Obsidian Canvas and many others — check current features and pricing) is better for
large maps, editing, sharing and export to outlines. Many people sketch on paper, then
rebuild digitally.

## Gotchas
- **Sentences on branches** turn it into a messy list — enforce one keyword.
- **Decoration over thinking:** colour and images help memory a little, but time spent
  drawing is time not thinking. Use them sparingly.
- **Premature hierarchy** — don't fix the main branches before you've generated enough to
  know what they are.
- **Too big to read:** past ~60–80 nodes, split into sub-maps per main branch.
- Claims that mind maps dramatically improve memory over other notes are mixed in the
  research; treat them as an idea and planning tool first.

## Verify
- [ ] The central topic is clear and in the middle.
- [ ] Each line carries one keyword or very short phrase.
- [ ] Every main branch has at least two levels of depth.
- [ ] There are cross-links between branches.
- [ ] You identified at least one gap and either filled it or marked it `?`.
- [ ] The map has been turned into an ordered outline or task list.
