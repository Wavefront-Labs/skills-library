# Tale-type and motif classification

**Goal:** take a narrative you collected or found in an archive and place it correctly in
the international comparative system, so other folklorists can find its relatives —
without flattening what makes your version distinctive.

## 1. Know the two tools and what each indexes
- **ATU index** (Uther 2004, revising Aarne 1910 and Thompson 1928/1961): classifies whole
  **tale types** — recurring plots — with numbers, e.g. ATU 510A *Cinderella*, ATU 333
  *Little Red Riding Hood*, ATU 1000–1199 tales of the stupid ogre. Ranges group genres:
  animal tales (1–299), tales of magic (300–749), religious tales, realistic tales
  (novelle), tales of the stupid ogre, anecdotes and jokes, formula tales (2000–2399).
  *(Range boundaries quoted from memory — confirm against the printed index.)*
- **Thompson Motif-Index**: classifies smaller **motifs** — a single element such as a
  character, object or incident — with letter+number codes, e.g. D (magic), F (marvels),
  K (deceptions). One tale contains many motifs.
- Legends, ballads, riddles and proverbs have their own national or genre catalogues; ATU
  is mainly for folktales. Check for a **national type index** for your tradition — many
  exist and are more precise locally.

## 2. Record the text before classifying it
Classification is only as good as the record. Capture:
- verbatim text (transcribed from audio if oral), language/dialect, and a translation kept
  separate from the original;
- teller (with consent for naming), date, place, audience, occasion, and how the teller
  learned it;
- performance features: openings/closings, formulas, audience interjections, gestures.
The context-and-performance turn in folkloristics (1960s–70s onward) treats these as data,
not decoration.

## 3. Assign the type
1. Summarise the plot in 3–6 neutral sentences, stripping local names.
2. Find candidate types via the index's subject/motif cross-references.
3. Read the full type description and compare episode by episode.
4. If your tale combines episodes from two types (very common), cite both, e.g.
   "ATU 300 + ATU 303", and say which dominates.
5. If it fits partially, write "cf. ATU 480" rather than claiming a match.
6. If nothing fits, say so — a forced match corrupts the comparative record.

## 4. Assign motifs
List the motifs that carry the plot (not every detail). Cite codes with the
motif's wording: "D1421.1 Magic object summons helper" style. *(This example code is
illustrative of format, not checked against the index — verify each code you cite.)*

## 5. Interpret beyond the label
The number is a finding aid, not an analysis. Then ask:
- What does this version change from the type, and why here? (local ecology, religion,
  gender roles, politics)
- Who tells it, to whom, and for what? (teaching, entertainment, warning)
- Structural reading (Propp's 31 functions for Russian wonder tales) can help but was built
  on one corpus — don't treat it as universal.

## 6. Archive it
Deposit the record (audio, transcript, metadata, consent form) with a folklore archive or
institutional repository, using its metadata scheme. Respect restrictions the community or
teller set; some narratives are not for public circulation.

## Gotchas
- ATU superseded AT (Aarne–Thompson); old AT numbers mostly carry over but some types were
  merged, split or renumbered. Cite ATU and note AT where older literature uses it.
- The index is Eurasian-weighted; African, Indigenous American and Oceanic traditions are
  thinly represented, and forcing them into it has been criticised.
- Literary versions (Grimm, Perrault) are not "the original"; they're edited variants.
- Don't confuse a motif with a type: "glass slipper" is a motif; Cinderella is a type.
