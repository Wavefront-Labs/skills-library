# Foley in the box and foley libraries

**Goal:** when there's no stage or budget (TV, docs, indie, pickups after the stage
wrapped), produce foley from libraries that is in sync, varied and perspective-matched
enough that nobody notices it wasn't performed.

## 1. Library you need
- **Footsteps**: per shoe type x surface x pace (walk/run/scuff/stop), many takes each.
  Commercial foley libraries and dedicated footstep libraries cover most combinations.
- **Cloth**: cotton, denim, leather, nylon, wool, in rustles of different lengths.
- **Props**: keys, cups, paper, bags, doors, phones, cutlery - recorded close and dry.
- Metadata searchable in Soundminer or similar: surface, shoe, action, length.

## 2. Cutting feet
- Spot each footfall on the picture frame where the heel lands; cut heel and toe as
  separate events for slow walks.
- **Never** repeat the same step twice in a row; rotate through 8-12 takes, nudge pitch
  (+/- a few cents) and level for variation.
- Match pace: a running character doesn't get walking samples sped up.
- Scuffs, weight shifts and stops matter as much as steps.

## 3. Performing library sounds
- Tools like Krotos Reformer Pro map library sounds to an input signal: perform cloth
  or footsteps by rubbing a mic/contact mic in time with picture; the library sound
  follows your dynamics. Faster and more organic than cutting each event.
- Or record a cheap "guide foley" pass at a desk and replace with library sounds
  aligned to it.

## 4. Matching
- Perspective: EQ (roll off lows/highs) and level for distance; small amount of the
  scene's room reverb (same reverb as the dialogue's fill) to place it.
- Keep foley mono and on the character's position; widen only for groups.
- Lay out tracks like stage foley (FEET per character, MOVES, SPECS) so the mix and
  M&E treat it the same way.

## Gotchas
- Machine-gun effect: identical samples on consecutive steps.
- Library foley recorded in a lively room - it carries the wrong space into every scene.
- Licences: check the library EULA allows use in broadcast/theatrical deliverables.
- Cloth forgotten: dialogue scenes feel dead in the M&E without moves.

## Verify
- [ ] M&E playback with dialogue muted sounds complete (feet, moves, specifics).
- [ ] No sample repeats on consecutive events.
- [ ] Perspective matches picture distance shot to shot.
- [ ] Library licences cover the deliverables.
