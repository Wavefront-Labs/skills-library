# Script breakdown and breakdown sheets

**Goal:** a complete, scene-by-scene inventory of everything the script requires, in a form
that becomes the schedule, the budget and every department's shopping list. Done once,
properly, from the locked draft.

## 1. Prepare the script
- Work from the **locked, scene-numbered production draft**. Breaking down an unlocked
  draft means doing it twice.
- **Measure page eighths**: divide each page into eight horizontal strips; a scene's length
  is counted in eighths (e.g. 2 3/8). Mark the length at the end of each scene. Minimum is
  1/8 even for a one-line scene. Eighths are the universal unit for scheduling how much
  can be shot per day (a drama averages 3-6 pages/day; a TV procedural 7-9).
- Draw a line across the page at every scene heading so scenes are visually separate.

## 2. Line the script (colour code)
Read each scene and underline/highlight every element in its category colour. Standard
(Movie Magic) colours:
| Colour | Category | Colour | Category |
|---|---|---|---|
| Red | Cast (speaking) | Yellow | Extras (atmosphere) |
| Green | Extras (silent bits) | Orange | Stunts |
| Purple | Props | Pink | Vehicles / animals |
| Blue | Special effects (practical) | Circle | Wardrobe |
| Asterisk | Make-up / hair | Brown | Sound / music / playback |
| Box | Set dressing / greenery | Underline (black) | Special equipment (crane, Steadicam, underwater) |
Also tag: VFX, security, additional labour, notes (e.g. "needs rain", "night"). Any item a
department must *bring, build, hire or cast* is an element. Implied elements count: a
scene in a bar implies bar extras, bottles, glassware.

## 3. Number the cast
Assign cast numbers in order of importance (1 = lead) on a cast list. Cast numbers appear
on every sheet, strip and call sheet from now on - never renumber after scheduling starts.

## 4. One breakdown sheet per scene
Header: production title, breakdown page number, scene number(s), script page(s), eighths,
INT/EXT, DAY/NIGHT, set name (from the slug, normalised), location (if known), scene
description (one line: "Marta confronts Dev about the money"), story day. Body: the
elements by category. Footer: notes (stunt coordinator needed, child actor - limited
hours, animal handler, playback).

Group consecutive scenes only if same set, same time, same cast and no element change
(e.g. a phone intercut can be two sheets or one with a note).

## 5. Into the software
Enter sheets in **Movie Magic Scheduling** (or StudioBinder/Celtx/Gorilla). MMS will
import a Final Draft `.fdx` with tags to pre-populate; verify each sheet anyway. Elements
entered consistently (one spelling of "Marta's car") become the strip board's sort keys
and the day-out-of-days.

## 6. Sanity checks before scheduling
- Total eighths = total script pages (within a page).
- Every speaking character has a cast number; every number appears on at least one sheet.
- Story days numbered so wardrobe/continuity can track.
- Flags for the things that drive schedule: children (hours), night exteriors, water,
  animals, stunts, special equipment, weather-dependent scenes.

## Gotchas
- Breaking down the writer's draft and then receiving blue pages - redo the affected sheets
  and keep the old scene numbers (A-scenes, omitted scenes).
- Missing the implied elements (a "crowded train" is 60 extras and a train).
- Set names inconsistent between sheets ("INT. KITCHEN" vs "INT. MARTA'S KITCHEN") - the
  board treats them as different locations.
- Counting a montage as one scene when it needs five locations.

## Verify
- [ ] Every scene has a sheet with eighths, INT/EXT, D/N, set, cast numbers.
- [ ] Sum of eighths matches script length.
- [ ] Each department can pull its list from the sheets without reading the script.
- [ ] Schedule-driving flags marked.
