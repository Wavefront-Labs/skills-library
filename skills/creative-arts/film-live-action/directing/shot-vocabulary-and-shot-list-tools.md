# Shot vocabulary and shot-list tools

**Goal:** a shot list in words everyone on set reads the same way, in a format the
1st AD can time and the DP can light from.

## 1. Shot sizes (standard abbreviations)
| Abbrev | Size | Frame |
|---|---|---|
| EWS / ELS | Extreme wide | Landscape, figures tiny |
| WS / LS | Wide / long | Full figure with environment |
| FS | Full shot | Head to toe |
| MWS / MLS (cowboy) | Medium wide | Knees/mid-thigh up |
| MS | Medium | Waist up |
| MCU | Medium close-up | Chest up |
| CU | Close-up | Head and shoulders/top of chest |
| ECU / BCU | Extreme / big close-up | Eyes, mouth, detail |
| INS | Insert | Object detail |
| 2S / 3S | Two-shot / three-shot | Number of people in frame |
| OTS / OS | Over the shoulder | Foreground shoulder of the other actor |
| POV | Point of view | What the character sees |

## 2. Angles and moves
High / low / eye-level / overhead (top shot) / Dutch; **moves**: pan, tilt, push in /
pull out (dolly), track (lateral), crane up/down, Steadicam, handheld, zoom, rack focus.
Note lens if decided (`MCU MARTA - 50mm - slow push`).

## 3. Shot-list format
Columns: **scene, shot # / set-up letter, size, subject, angle/move, lens, description
(action/dialogue it covers), equipment (dolly/crane), sound (sync/MOS), est. time,
priority (A/B/C)**. Number set-ups the way the script supervisor slates them (`24A`,
`24B`) so lists, slates and logs line up. Group shots by **camera position/lighting
direction**, not script order - that's what gets scheduled.

## 4. Tools
- **Spreadsheet** template (most flexible; share via cloud).
- **Shot Lister** (iOS/Mac): shot lists with time estimates that produce a day schedule
  and track progress live on set.
- **StudioBinder**, **Celtx**: shot lists linked to script breakdown and storyboards.
- **Previs/boards** attached to shots where used.
Export PDF for the crew; the AD needs it by the tech scout to build the day.

## 5. On set
Tick completed shots; mark **priority A** shots (must-haves) so that when time runs out
the AD knows what can be dropped.

## Gotchas
- Personal shorthand nobody else understands.
- Lists in script order - schedule needs camera-direction groupings.
- No priorities; the day ends with essentials unshot.
- Set-up letters that don't match the slate.

## Verify
- [ ] Standard abbreviations used; moves and lens noted where decided.
- [ ] Shots grouped by set-up/lighting direction with time estimates.
- [ ] Priorities marked; set-up letters agreed with script supervisor.
- [ ] Shared with AD and DP before the tech scout.
