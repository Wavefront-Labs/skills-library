# Breakdown reports and department breakdowns

**Goal:** turn the tagged breakdown into the lists every department works from, so
each head of department sees exactly what they must supply, scene by scene.

## 1. Prerequisite: a clean breakdown
Breakdown sheets per scene with elements in standard categories (cast, background,
stunts, vehicles, props, set dressing, wardrobe, make-up/hair, SFX, VFX, animals,
special equipment, music, sound, notes). **Script days** (story chronology: D1, N1, D2)
on every sheet - departments need them for continuity changes.

## 2. Standard reports (Movie Magic Scheduling or equivalent)
- **Element report**: each element with every scene it appears in (e.g. "PROP: revolver
  - sc 3, 17, 44"). Run per category.
- **Breakdown summary / sheets report**: all sheets in script or shooting order.
- **Cast/Element by scene** cross-reference (a grid).
- **Location / set report**: scenes per set with page counts - for location managers.
- **Script day report**: scenes per story day.
In MMS, *Reports* menu; filter by category and sort; export PDF/CSV.

## 3. Department breakdowns
Each department expands the element report into its own working document:
- **Art / set dressing**: per set, dressing list, practicals, graphics, clearances.
- **Props**: hero props with quantities (duplicates for stunts/breakaways), continuity
  notes (blood, damage states).
- **Costume**: per character per **script day** = **change number** ("Marta change 4,
  D3-D4"); duplicates for stunts/blood; background wardrobe.
- **Hair & make-up**: looks per script day, prosthetics, wounds progression, ageing.
- **SFX/VFX**: shot-level lists and methodology; VFX breakdown by shot once boarded.
- **Transport/picture vehicles**, **animals**, **stunts** with rehearsal needs.
Departments return questions to the AD; resolved answers update the master breakdown.

## 4. Keep it current
Every script revision: update affected sheets in the scheduling software (MMS can
import a tagged Final Draft/`.sex` file and update), re-run reports, and **circulate
only changes** with the revision colour noted.

## Gotchas
- Script days missing; costume and make-up continuity breaks.
- Department lists built from an old draft.
- Duplicates (stunt/breakaway props, multiple costumes) not counted.
- Elements named inconsistently ("gun"/"revolver") so reports split.

## Verify
- [ ] Sheets tagged in standard categories with script days.
- [ ] Element, location and script-day reports generated.
- [ ] Each department has its expanded breakdown with change numbers/duplicates.
- [ ] Revision updates re-run and circulated.
