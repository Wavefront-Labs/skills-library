# Budgeting post-production

**Goal:** a post budget built from the post schedule and deliverables list, not a
percentage guess - with enough contingency to survive the cut changing.

## 1. Start from schedule and deliverables
Draft the post calendar first (assembly, director's cut, producer cut, lock, sound,
grade, delivery) and get the **deliverables list** from the sales agent/distributor/
broadcaster - deliverables often cost more than first-time producers expect.

## 2. Accounts and what drives them (post section of a standard chart)
| Account | Cost drivers |
|---|---|
| **Editorial** | Editor + assistant(s) weeks (globals: POST weeks), edit suite and NLE rental, storage, shared server |
| **Post-production sound** | Supervising sound editor, dialogue/FX editors, foley (artist + mixer days), ADR studio days (+ remote ADR), re-recording mix days (premix + final) per format, stems/M&E creation |
| **Music** | Composer package or fee + recording (musicians, studio, union), music supervisor, licensed tracks (sync + master, by territory/term/media) |
| **VFX** | Per-shot bids by complexity (from breakdown), VFX supervisor/producer, contingency 10-20% |
| **Picture finishing** | Conform/online, grade days (SDR, HDR trims), titles and credits, archive restoration, subtitles/captions |
| **Deliverables** | DCP, IMF/ProRes masters, textless, M&E, closed captions, audio description, QC passes (and failure re-QC), LTO archiving |
| **Lab / data** | Dailies, transcodes, cloud review platforms, storage and backup |
| **Legal/clearance in post** | E&O insurance, clearance reports, music cue sheets |

## 3. Quotes and packages
Get **package quotes** from post houses (grade + online + DCP + QC); compare line by line.
Ask what's included: revision rounds, HDR trims, QC re-delivery, storage after delivery.

## 4. Contingency
Post overruns come from: cut not locking (editor extensions), VFX changes after lock,
music clearances, failed QC. Hold **10%** of post (more if VFX-heavy) and protect the
edit-extension weeks.

## Gotchas
- Budgeting the mix but not the M&E and stems.
- Licensed music priced for festival only, then needed for worldwide all-media.
- No QC re-delivery money.
- VFX budgeted as a lump sum with no shot count.

## Verify
- [ ] Post calendar and deliverables list drive every line.
- [ ] Editorial weeks via globals; sound, music, VFX, finishing, deliverables accounts filled.
- [ ] Package quotes compared with inclusions noted.
- [ ] Post contingency held.
