# The director's script notebook

**Goal:** one binder (or tablet file) that holds everything you decided in prep, so
on the day every question - from the actor, the DP, the AD - has an answer you already
thought through.

## 1. Format
- Print the script **single-sided**, one scene per spread where possible, with a
  **blank analysis page facing each script page** (or wide right margin). Three-ring
  binder so revisions slot in by page.
- Digital equivalent: annotate a PDF (iPad + GoodNotes/Notability/ForeDraft/
  Scriptation) with layers for analysis, shots and blocking - Scriptation carries
  notes across revised pages.

## 2. Mark the script page
- **Beat lines**: draw a horizontal line where each beat changes (a new tactic, a new
  piece of information); label the beat with an active verb ("she probes", "he deflects").
- Circle **key lines** and **events** (the moment the scene turns).
- Bracket lines you'd cut if the scene runs long.
- Note **props and continuity** that matter to performance.

## 3. The facing analysis page (per scene)
- **Scene in one sentence** (what changes) and its place in the film's arc.
- For each character: **objective**, **obstacle**, **actions/verbs** per beat, and
  **what they know/ don't know** (Weston's "facts and questions").
- **Images and associations**: references, sounds, music, personal links.
- **Staging idea** (thumbnail floor plan) and **shot ideas** / coverage intent.
- **Questions** to raise with actors in rehearsal.
- **Emotional temperature** at entry and exit, so continuity of performance holds when
  shooting out of order.

## 4. Front sections
Film statement (what it's about, one paragraph), character arcs across the film
(a page per principal with scene-by-scene state), look references, research, the
schedule with day/scene map.

## 5. On the day
Carry a slimmed **day book**: today's scenes with notes, shot list, floor plans,
plus the full binder nearby. Mark circled takes and performance notes at wrap.

## Gotchas
- Notebook so dense you can't find anything on set; use headings and colour.
- Analysing only dialogue; silent scenes need beats too.
- Notes not carried over to revised pages.
- Reading the notebook instead of watching the actors.

## Verify
- [ ] Every scene beat-lined with verbs; turning point circled.
- [ ] Facing page with objectives, obstacles, staging and shot intent per scene.
- [ ] Emotional entry/exit state noted for out-of-order shooting.
- [ ] Revisions integrated; day book prepared for each shooting day.
