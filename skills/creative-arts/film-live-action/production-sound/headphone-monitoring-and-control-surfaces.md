# Headphone monitoring and control surfaces

**Goal:** you hear exactly what you need at every moment - the mix, any single mic, the
return from the boom - and you mix on real faders, not menu knobs.

## 1. Headphones
Closed-back, accurate, comfortable for 12 hours (Sony MDR-7506/ MDR-7510, Sennheiser
HD 25, Audio-Technica M50x). Set a consistent **monitor level** and keep it - your ears
learn the reference.

## 2. Headphone routing presets (Sound Devices 8-Series example)
The recorder offers **headphone presets** (favourites) selectable by a knob/ button:
- **Mix L/R** (what goes to the mix tracks)
- **Pre-fader solo** (**PFL**) of an input - hear a mic before its fader (check a lav
  before opening it).
- **Post-fader solo** / solo-in-place
- **Boom vs lav** comparisons (boom left, lavs right)
- **Return/ camera** monitoring (hop return)
- **MS decode** or other matrices
Configure them in prep so one button gets each view. PFL also by pushing the input's
trim knob or the CL-16's PFL keys.

## 3. Monitoring for others
- **Boom operator**: a wireless return (IEM/IFB) with the mix or their mic + mix; they
  need to hear their own placement.
- **Director/ script supervisor/ video village**: IFB/Comtek feeds with the mix (see
  IFB skill).

## 4. Control surfaces
- **CL-16** (for 888/ Scorpio): 16 linear faders, trims, PFL/solo, arm keys, routing and
  metering on a surface - fader mixing like a console; maps to the recorder's inputs.
- **SD-Remote** (iPad app) for menus/ metering, track names, metadata entry.
- Others: Zoom F8n Pro/F6 with FRC-8, Zaxcom Nova's integrated faders, MIDI controllers.
Configure fader mapping (fader 1 = boom, 2-8 = lavs), gain staging (trim for level, fader
for mix), and save as a scene/ setup file.

## 5. Practice
Mix with eyes on the actors (not the meters); open each lav only when its actor speaks;
check iso tracks are recording pre-fader so post gets full-level signals regardless of
your mix moves.

## Gotchas
- Monitoring post-fader only and missing a noisy lav that's faded down (it's still on the iso).
- Boom op without a return feed - can't judge placement.
- Inconsistent headphone level from day to day.
- Faders mapped differently from yesterday's setup file.

## Verify
- [ ] Headphone presets configured (mix, PFL, boom/lav, return).
- [ ] Return feeds to boom op and IFB to video village.
- [ ] Control surface mapped and setup saved.
- [ ] Iso tracks pre-fader; monitor level consistent.
