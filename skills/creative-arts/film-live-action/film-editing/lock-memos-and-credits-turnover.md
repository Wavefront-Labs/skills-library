# Lock memos and credits turnover

**Goal:** everyone downstream knows exactly which version is locked, what changes
later, and has the exact text for every title and credit.

## 1. Naming the locked cut
- Sequence names: `TITLE_R1_LOCK_v01_2026-10-16` per reel (`R1`-`R6` for features
  in ~20-minute reels) or as one long-play timeline per the post plan.
- Freeze it: duplicate the sequence; the "LOCK" version is never edited - changes go into
  a new version (`LOCK_v02`).

## 2. The lock memo
Send to sound, music, VFX, colour/online, post producer:
- Version names, total running time per reel and overall, frame rate.
- What's delivered (AAFs, EDLs, reference QuickTimes with burn-ins, guide tracks).
- Known pending items (VFX shots still temp, temp music, missing ADR, title cards).
- Contact for questions; date.

## 3. Changes after lock (change lists)
Locks are rarely final. For each later version produce a **change list** (Avid Change List
tool, Resolve/Premiere via EDL comparison, or tools like ChangeList/ Change List Tool)
per reel: event, what moved, frame counts, new/removed material - so sound and music can
conform their sessions. Announce with a memo; increment the version.

## 4. Text list (on-screen text)
A document of every piece of on-screen text in the film: main and end titles, captions
("London, 1987"), signs and graphics added in post, subtitles for foreign dialogue,
inserts like texts/emails. Columns: TC in/out, text exactly as it appears, font/style notes,
burned-in vs subtitle track. Needed for localisation, accessibility and distributors'
deliverables.

## 5. Credits
- Compile a **credits list** from production (deal memos specify credit wording, size and
  placement - guild rules for director, writers, cast billing block).
- Draft main titles and end crawl; send for legal/production sign-off (spellings,
  order, contractual placement, logos, music credits, thank-yous, legal copyright notice).
- Turnover to titles designer/online: approved list, fonts, timings, crawl speed
  (legibility - test at full screen size), and safe areas.

## Gotchas
- Editing the "LOCK" sequence directly.
- Change lists not sent - sound mixes the old cut.
- Spelling errors in credits discovered after DCP.
- Contractual credit placement missed (claims).

## Verify
- [ ] Locked versions named and frozen; lock memo sent.
- [ ] Change lists issued for every post-lock change.
- [ ] Text list complete with TCs and exact text.
- [ ] Credits approved by production/legal before turnover.
