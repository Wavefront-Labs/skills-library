# Choosing the lens package

**Goal:** a package that delivers the film's look, covers the sensor and format, suits
the shooting style and fits the budget - proven by tests before prep ends.

## 1. Primes vs zooms
| | Primes | Zooms |
|---|---|---|
| Speed | Faster (T1.3-T2) | Slower (T2.2-T2.8 typical cine zooms) |
| Size/weight | Small, light per lens | Heavy (large studio zooms 5-7 kg) |
| Workflow | Lens changes take time (1-3 min) | Reframe instantly; ideal for docs, multicam, run-and-gun |
| Look | More choice of character; consistent set | Often cleaner, more clinical; breathing and ramping in cheap zooms |
| Style | Composed, deliberate | Zoom-ins as grammar (70s style), speed on set |
Many features carry a prime set plus 1-2 zooms (e.g. 19-90 or 24-290) for long-lens
work and quick reframes.

## 2. Building the set
- **Focal lengths**: spread for your format - for Super 35, e.g. 18, 25, 32, 40, 50, 75,
  100, 135; for large format (full frame/VV), roughly 1.5x longer for the same angle.
- **Coverage**: check the image circle covers the sensor in the recording mode (open gate
  vs 16:9 crop, anamorphic desqueeze); vignetting appears at the widest focal lengths.
- **Matching**: same series for colour, contrast and flare consistency; mixing series needs
  testing.
- **Mount**: PL / LPL / EF / E; adaptors add risk on heavy lenses.
- **Close focus**: wides often focus to 0.25-0.35 m; diopters for closer.

## 3. Specialty lenses
- **Macro** (e.g. 100 mm macro, 1:1) for inserts and nature detail; deep light needs
  (small apertures at close range), focus on a slider or with micro-rails.
- **Probe lenses** (Laowa 24 mm probe, Innovision): tiny front element for moving
  through miniatures, food, objects; slow (T8-T14), need lots of light.
- **Tilt-shift / swing-shift**: tilt the focal plane for miniature effect or to hold
  focus across a receding plane; shift for perspective control in architecture.
- **Diopters** (split/full), **periscopes**, **lensbabies** for selective-focus character.

## 4. Test
Shoot charts and faces: sharpness, distortion, flare, breathing, colour cast, close focus,
vignetting at each focal length - at the stops you'll use. Project or view on a large
screen. Check rental houses' sets: individual lenses vary.

## Gotchas
- Large-format sensors with S35 lenses: vignetting on wides.
- Slow zooms forcing high ISO at night.
- Specialty lenses arriving on the day with no light budget.
- Breathing zooms used for slow focus racks.

## Verify
- [ ] Prime/zoom balance justified by style and schedule.
- [ ] Coverage confirmed for every lens in the recording mode.
- [ ] Specialty needs listed per scene with light requirements.
- [ ] Lens tests shot and viewed large.
