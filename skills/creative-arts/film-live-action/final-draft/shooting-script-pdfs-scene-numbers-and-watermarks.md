# Shooting-script PDFs: scene numbers, headers and watermarks

**Goal:** every recipient gets a correctly numbered, labelled PDF traceable to them -
so leaks are attributable and nobody works from the wrong draft.

Menu names from Final Draft 12/13; confirm in your version.

## 1. Scene number options
**Production > Scene Numbers...**:
- **Number scenes** with *Keep existing numbers* checked once production has started
  (new scenes get A/B suffixes).
- **Starting number** (rarely not 1; episodic blocks sometimes use episode prefixes,
  e.g. `101` style - agree with the 1st AD).
- **Placement**: left, right or both margins - shooting scripts conventionally show
  **both**. Font matches the scene heading.
- *Omitted* scenes keep their number with `OMITTED`.
Check numbering in the **Navigator** (scene list) before issuing.

## 2. Header and footer
**Document > Header and Footer**: header normally carries the **page number** (right),
plus on production drafts the **draft/colour label and date** ("BLUE REVISION -
16/10/26") - use the inserted fields (*Revision*, *Date*, *Page #*) rather than typed
text so they update. Footer can carry `CONFIDENTIAL - PROPERTY OF <PRODUCTION CO>`.
Header off on page 1 (title page is separate).

## 3. Watermarked PDFs
**File > Save as PDF...** (or Print > PDF): Final Draft offers a **watermark** text
option on PDF output. Use the **recipient's name** (and optionally the date) as the
watermark, one PDF per person: `TITLE_BlueRev_2026-10-16_JSmith.pdf`. Many productions
then distribute through a secure document platform (e.g. Scenechronize or a
studio's watermarking service) that adds per-viewer watermarks and disables download - use it
for cast and outside parties.

## 4. Distribution
- Keep a **distribution log**: recipient, department, draft/colour, date, method.
- Send PDF, never `.fdx`, to non-writers.
- Revised pages: PDF of only the revised pages (*Print/Save Revised Pages*) plus the
  full collated draft to departments that want it.
- Password-protect sensitive PDFs and send the password separately.

## Gotchas
- Scene numbers only on the left; script supervisor and AD expect both sides.
- Typed draft labels in headers that go stale on the next revision.
- One shared watermark ("CONFIDENTIAL") - a leak can't be traced.
- Sending .fdx files that reflow on other machines and break page counts.

## Verify
- [ ] Scene numbers on both sides; existing numbers kept; Navigator checked.
- [ ] Header shows page, draft/colour and date via fields.
- [ ] One watermarked PDF per recipient; distribution log filled.
- [ ] Only PDFs sent outside the writing team.
