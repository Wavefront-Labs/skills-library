# Beat Board, structure lines and the Outline Editor

**Goal:** use Final Draft's own outlining tools so the outline and the script live
in one file and stay linked as you write.

Feature names from Final Draft 12/13; confirm in your version (View menu).

## 1. Beat Board (free-form)
**View > Beat Board** opens an infinite canvas of **beats** (cards with title, body
text, colour). Use it like a corkboard:
- Double-click empty space to create a beat; type title (one line) and body.
- Colour beats by story line; group them spatially into rows per act.
- Zoom out for the whole film; *Structure points*/templates (e.g. Save the Cat, Hero's
  Journey, if provided in your version) can be laid in as guides.
- Images can be dropped onto the board for mood references.

## 2. Outline Editor and structure lines
The **Outline Editor** (View > Outline Editor, shown as a panel above the script) is a
horizontal timeline of rows:
- **Structure lines**: horizontal rows with named sections (Act 1, Act 2A...) whose
  width represents page proportion. Add/rename lines and sections from the panel's
  context menu; use one row for acts and one for sequences.
- **Beats** sit in rows under the structure; drag them from the Beat Board into the
  Outline Editor to commit them to an order.
- Rows can represent story lines (A/B/C) so you see interleaving.

## 3. Beats into the script
Drag a beat from the Outline Editor (or Beat Board) **into the script page**: it
becomes a scene heading/scene with the beat text kept as the scene's summary - the
link persists so the outline and pages stay connected (view the summary in the
Navigator / Scene View). Write the scene under it.

## 4. Keeping them in sync
- After a rewrite, reorder beats in the Outline Editor to reflect the new structure;
  use the Navigator to move scenes in the script itself.
- Delete obsolete beats or move them to a "parked" area of the Beat Board.
- Export: print/PDF the Beat Board or outline for producers.

## Gotchas
- Treating the Beat Board as a second script - beats should be one-sentence events.
- Beats and script diverging after a rewrite; outline becomes misleading.
- Structure line proportions left at defaults that don't match your page targets.
- Older .fdx versions opened in older Final Draft lose Outline Editor data.

## Verify
- [ ] Beat Board organised by act rows and storyline colours.
- [ ] Outline Editor has act and sequence structure lines.
- [ ] Scenes created from beats keep their summaries.
- [ ] Outline reordered after each structural change.
