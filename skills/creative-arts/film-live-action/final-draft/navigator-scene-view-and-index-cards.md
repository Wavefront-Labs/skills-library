# Navigator, Scene View and index cards in Final Draft

**Goal:** treat the script as a set of movable, annotated scenes - find anything in
seconds, reorder safely, and keep summaries and colours as a running outline.

View names from Final Draft 12/13; confirm in your version.

## 1. Navigator
**Tools/View > Navigator** opens a panel with tabs:
- **Scenes**: every scene heading with number, page, length (eighths in some
  versions), colour and **summary**. Click to jump; drag rows to **reorder scenes** in
  the script.
- **Characters**: every speaking character with counts; double-click to find
  occurrences - useful for continuity and casting reports.
- **Notes/ScriptNotes** and **Locations** (depending on version).
Sort/filter to find, e.g., all NIGHT exteriors.

## 2. Scene properties
Each scene has properties (Navigator double-click or **Scene Properties** command):
**Title** (a short name for the scene, separate from the heading), **Summary**,
**Colour**, and in some versions custom fields. Use:
- Summary = the beat/turn in one line - the script becomes self-outlining.
- Colour = story line (A/B/C), POV or status (needs rewrite = red).

## 3. Scene View
**View > Scene View** shows the script as a vertical list of collapsible scenes - read
only the headings + summaries, expand one to edit, drag to reorder. Best for structure
passes on a draft.

## 4. Index Cards view
**View > Index Cards - Script** shows each scene as a card (heading + summary or first
lines) in a grid; drag cards to reorder and the script follows. Set the **number of
cards across** to match acts per row for a corkboard view. Print cards for a physical
board (File > Print with Index Cards view active).

## 5. Practice
- Fill summaries as you write, not after.
- Before a restructure, save a version; drag-reordering can strand transitions and
  `CONTINUOUS` headings - fix headings after moves.
- Use the Characters tab to catch name variants (MARTA vs MARTHA).

## Gotchas
- Reordering in a locked production draft; changes break scene/page locks.
- Summaries left blank so cards show only the first dialogue line.
- `CONTINUOUS` / `LATER` headings no longer true after a move.
- Colours with no agreed legend in a shared script.

## Verify
- [ ] Every scene has a summary and a meaningful colour; legend recorded.
- [ ] Character list checked for name variants.
- [ ] Headings re-checked after any drag-reorder.
- [ ] Version saved before structural moves.
