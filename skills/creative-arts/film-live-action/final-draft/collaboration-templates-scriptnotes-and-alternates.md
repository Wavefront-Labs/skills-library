# Collaboration, templates, ScriptNotes and alternates

**Goal:** several people work on one script without overwriting each other, notes live
inside the file, and line options are kept without cluttering the pages.

Feature names from Final Draft 12/13; confirm in your version. All participants need
compatible versions.

## 1. Templates
Start every script for a show from a **template** (File > New from Template, or save
your own via *Save as Template*): page layout, element styles, act breaks/teaser
structure for TV, header/footer fields, SmartType lists (characters, locations) and
revision set setup. Distribute the `.fdxt` to the room so formats match - mismatched
templates are the main cause of page-count drift between writers.

## 2. Real-time collaboration
Final Draft offers a hosted **collaboration** session (Collaboration menu / button):
the host starts a session and shares the session name/code; collaborators join and
edit live. Practice:
- One **host** owns the master file; save locally at the end of every session.
- Agree who writes which scenes; simultaneous edits to the same paragraph collide.
- Use a voice/video call alongside; the chat is minimal.
- If a session drops, the host's saved file is the master - re-sync from it.
Alternatives for cloud co-writing: WriterDuet (imports/exports `.fdx`), or a shared
`.fdx` on cloud storage with a strict check-out rule (one writer at a time).

## 3. ScriptNotes
Insert a **ScriptNote** (Tools/Insert > ScriptNote) at a point in the text: a coloured
marker with a note body - use for producer notes, questions, research TKs. Notes are
listed in the Navigator; filter by colour (assign a colour per note-giver). They
don't print unless you choose to print notes. Resolve and delete notes rather than
letting them pile up across drafts.

## 4. Alternate dialogue
Select a dialogue block and use **Alternate Dialogue** (Format/Tools > Alternates in
recent versions) to store alternates: a list of versions of the line; the chosen one
shows on the page, others are kept in the file. Use it for joke options, network-safe
versions (broadcast language), or director's choices. Cycle alternates during a table
read to test lines.

## Gotchas
- Writers on different templates; pages reflow on merge.
- Two people editing the same scene in a session.
- ScriptNotes accidentally printed in a distributed PDF.
- Alternates forgotten: the wrong version shipped. Review before locking.

## Verify
- [ ] Show template distributed; every script created from it.
- [ ] Collaboration roles and scene ownership agreed; host saves the master.
- [ ] ScriptNotes colour-coded by giver; cleared before distribution.
- [ ] Alternates reviewed and chosen before production draft.
