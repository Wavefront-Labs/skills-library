# From outline to first-draft pages

**Goal:** a complete draft, start to FADE OUT, in a fixed number of weeks - quality
comes in the rewrite, existence comes now.

## 1. Set the target
A 100-110 page feature at **3 pages/day** five days a week is ~7-8 weeks; professionals
on assignment typically deliver a first draft in 10-12 weeks (WGA step deals often
specify the period). Put the date on the calendar and work back to a daily quota.

## 2. Prepare the outline for drafting
- Number every scene/card. Add a target page count per sequence (act one ~25,
  act two ~55-60, act three ~20-25).
- Next to each scene, the **one thing that must happen** and the **exit line or image**
  if you know it.

## 3. Writing rules for the vomit draft
- **Don't reread** yesterday's pages except the last scene to get back in.
- **Don't revise.** Notes for later go in brackets: `[FIX: motivation unclear]`,
  `[JOKE TK]`, `[RESEARCH: police procedure]`. Search for `[` in the rewrite.
- **Write the scene you're excited about** if the next one is stuck - out-of-order is
  fine, but log what's missing.
- If a scene wants to change the outline, let it, then update the outline cards
  for downstream consequences (one line, not a re-outline).
- Overwrite rather than underwrite - cutting is easier than inventing in rewrite.
- Stop mid-scene when you know what comes next (Hemingway's trick) to start fast tomorrow.

## 4. Track it
Keep a log: date, pages written, page count, scene number reached. Final Draft/Fade In
show page counts; a spreadsheet is enough. Two missed days in a row is the warning sign.

## 5. When stuck
- Write the scene badly in summary prose, bracketed, and move on.
- Go back to the card: what does the character want here, and who is stopping them?
- Change the location - many stuck scenes are in the wrong place.

## 6. Finish
Type FADE OUT on the planned date even if act three is thin. Then put it away for at
least a week before rereading.

## Gotchas
- Polishing act one for a month; the script never reaches act three.
- Abandoning the outline wholesale at page 40 because it feels "too planned".
- Page count balloons to 140 - fine for a vomit draft; note it for the cutting pass.

## Verify
- [ ] Deadline and daily quota set; log kept.
- [ ] Complete draft to FADE OUT; all bracketed notes searchable.
- [ ] Outline updated where the draft deviated.
