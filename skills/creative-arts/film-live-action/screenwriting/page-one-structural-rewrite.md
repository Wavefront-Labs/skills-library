# The structural (page-one) rewrite

**Goal:** a new draft whose story is rebuilt from the foundation, keeping the best of
the old one - not the old draft with scenes shuffled.

## 1. Decide it's structural
Signs the problem is structural, not scene-level: readers can't state what the
protagonist wants; the midpoint changes nothing; act three is solved by coincidence;
notes contradict each other (symptom of a missing spine); the logline no longer
describes the script.

## 2. Reverse outline the current draft
One line per scene: scene #, page, what happens, whose scene, the `+/-` value change,
which plot line. Add page-count per sequence. This is the X-ray - it shows the
40-page act one, the protagonist absent from pages 50-65, the subplot that dies.

## 3. Diagnose and re-conceive
Rewrite the **logline**, the **protagonist's want/need**, the **five pillars**
(catalyst, break into two, midpoint, all is lost, climax) as they *should* be. Often
the fix is upstream: wrong protagonist, wrong inciting incident, goal too passive,
antagonist too weak. Write a one-page new synopsis before touching cards.

## 4. Re-break
New card board from the new synopsis. Mark each card: **KEEP** (old scene works as-is),
**ADAPT** (old scene with a new purpose), **NEW**. Expect 30-60% new on a true page-one.
Don't let a beloved scene survive if it no longer serves; park it in a "lost scenes" file.

## 5. Write clean
Start a **new file** and write from page one, pasting KEEP scenes in and rewriting
ADAPT scenes from scratch with the old one open beside you. Patching inside the old file
leaves seams - mismatched character logic, dead setups.

## 6. Continuity sweep
After the draft: search every character name and key prop for setups and payoffs that
no longer connect; re-read the old reverse outline to confirm nothing essential was lost.

## Gotchas
- Calling a polish a page-one rewrite (or vice versa) - agree scope with producers.
- Keeping the old opening out of loyalty; the new story often starts elsewhere.
- Dead setups and orphaned payoffs from deleted threads.
- Rewriting dialogue first, structure never.

## Verify
- [ ] Reverse outline of the old draft with value changes and page counts.
- [ ] New logline, want/need and five pillars written.
- [ ] Card board marked KEEP/ADAPT/NEW.
- [ ] Draft written in a new file; setup/payoff sweep done.
