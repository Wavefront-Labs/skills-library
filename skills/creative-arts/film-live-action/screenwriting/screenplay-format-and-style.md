# Screenplay format and style

**Goal:** a script whose format is invisible - readers notice format only when it's wrong,
and wrong format is the fastest way to be marked an amateur before page 2.

## 1. The physical standard
- **Courier 12 pt** (or Courier Prime / Final Draft). This is what makes one page ~ one minute.
- US Letter (A4 in the UK/Europe is accepted but Letter is safest for US submissions).
- Margins: left 1.5", right 1", top/bottom 1". Dialogue block ~2.5" from the left, character
  name ~3.7", parenthetical ~3.1". Any screenwriting app sets these; don't fight them.
- Page numbers top right, from page 2. No page number on page 1.
- Title page: title centred about a third down, `Written by` and name beneath, contact or
  agent details bottom left or right. No draft date or "Registered WGA" on a spec.

## 2. Elements
| Element | Rule |
|---|---|
| Scene heading (slugline) | `INT./EXT. LOCATION - DAY/NIGHT`. Caps. Same location = same wording every time. `CONTINUOUS` or `LATER` only when needed. |
| Action | Present tense, lean, max 3-4 lines per paragraph. Capitalise a character's name on **first appearance** only. Caps for important sounds/effects are optional and should be rare. |
| Character cue | Caps, consistent name. Extensions: `(V.O.)` voice-over, `(O.S.)` off-screen but present, `(CONT'D)` when the same speaker continues after action (apps add it automatically). |
| Parenthetical | Lowercase, short, under the cue. Only for an unreadable line or a brief action. |
| Dialogue | No line breaks within a speech unless interrupted by action. |
| Transition | `CUT TO:` is implicit - omit. Use `SMASH CUT TO:`, `MATCH CUT TO:`, `DISSOLVE TO:` only when the transition is the point. `FADE IN:` top, `FADE OUT.` end. |
| Super | `SUPER: "Lagos, 1994"` on its own action line. |

## 3. Common constructions
- **Montage:** `MONTAGE - SARAH TRAINS` as a slug, then short lines each beginning with a dash
  or a mini-slug. End with `END MONTAGE` or just the next full slugline.
- **Intercut (phone calls):** establish both locations with slugs, then `INTERCUT - PHONE CALL`
  (or `INTERCUT AS NEEDED`) and write the dialogue straight through.
- **Flashback:** `INT. KITCHEN - NIGHT (FLASHBACK)` or a `FLASHBACK:` slug; return with
  `BACK TO PRESENT` or a normal slug.
- **Text messages / screens:** a `TEXT ON SCREEN:` or `ON SCREEN:` action line, or format as
  dialogue with the character cue `JESS (TEXT)` - both are accepted; be consistent.
- **Simultaneous dialogue:** dual-dialogue columns (apps support it). Use once or twice per script.
- **Foreign language:** write in English with a parenthetical `(in Spanish)` or a note
  "Dialogue in Spanish is subtitled" after the first instance.

## 4. Spec-script style
- No scene numbers, no camera directions (`CLOSE ON`, `PAN TO`) except as rare emphasis;
  the director decides. Suggest the shot through what you describe.
- No `we see` / `we hear` more than a handful of times. Just describe it.
- No bold/underline in action except for a deliberate, rare effect.
- Keep features 90-120 pages; pilots ~30 (half-hour) or 55-65 (hour). Readers notice 130+.
- "Unfilmables" (what a character thinks) are tolerated in small doses when they help the read.

## 5. Tools
Final Draft (industry default, `.fdx`), Fade In, Highland (Fountain-based), WriterDuet,
Arc Studio, Celtx. Plain-text **Fountain** syntax (`INT. ` starts a slug, caps line is a cue,
`>` forces transitions) converts cleanly to all of them and is good for version control.
Export PDF for submission - never send an editable file unless asked.

## Gotchas
- Inconsistent location names (`INT. BOB'S FLAT` vs `INT. BOB'S APARTMENT`) break breakdowns.
- Orphaned cues at a page bottom (apps handle `(MORE)` / `(CONT'D)` - don't disable it).
- Scene headings for every tiny move within a space - use `LATER` or action lines instead.
- Fancy fonts, colour, images or a cover letter inside the PDF.

## Verify
- [ ] Courier 12, Letter, correct margins; page 1 unnumbered.
- [ ] Every location spelt identically; DAY/NIGHT present on every slug.
- [ ] No camera directions or scene numbers in a spec; `CUT TO:` removed.
- [ ] Page count within range for the format.
