# Synopses for submission

**Goal:** a set of synopses - 50 words, 150 words, one paragraph, one page - that all
tell the same story in the same voice, ready to paste into any competition, fund, lab
or agent submission form without rewriting at midnight before a deadline.

## 1. Write the master first
Start with the **one-page synopsis** (350-500 words). Present tense, third person,
the story in order with the **ending**. Name only the characters who matter (three
or four); everyone else is "her brother", "the detective". Each paragraph covers an
act: setup and inciting incident; complications to the midpoint; escalation to the
crisis; climax and resolution. Include the protagonist's want and what they learn or
lose - funds read for character change, not plot inventory.

## 2. Cut down, don't write up
- **One paragraph (150-200 words)**: keep the inciting incident, the central
  conflict, the crisis choice and the ending; drop subplots.
- **Short synopsis (50-80 words)**: protagonist, goal, obstacle, the turn, the ending
  in one clause. Often indistinguishable from an expanded logline with the ending.
- **Logline (25-35 words)**: no ending.
Keep all versions in one document with word counts; update all of them when the
story changes (an outdated 50-word version in a form contradicts the script).

## 3. Match the voice
A comedy synopsis should be funny once; a horror synopsis should be unsettling by its
final line. Use the film's tone in the prose without jokes that need the picture.
Avoid evaluation ("a hilarious, heartbreaking..."); let the reader conclude it.

## 4. Fit the form
Submission portals (FilmFreeway, Coverfly, broadcaster schemes, national funds) have
hard character limits - count characters, not words, and keep a plain-text version
(no smart quotes, no italics) for pasting. Some ask for "synopsis" meaning the
one-page, others meaning the paragraph; read the guidance and the examples they
publish. If a form asks for a "treatment", send the one-page synopsis only if it
allows that length; otherwise see the treatment skill.

## 5. Check before sending
Read each version aloud; a cold reader should be able to name the protagonist's
problem and the ending from the 150-word version. Spell names identically across the
synopsis, the script's title page and the form.

## Gotchas
- Withholding the ending in a submission synopsis ("...and nothing will be the same").
- Writing the short versions first and padding them into a page - the page reads like a list.
- Character names spelled differently in synopsis and script.
- Evaluative adjectives instead of story.
- A different story in the 50-word and one-page versions after a rewrite.

## Verify
- [ ] Master one-page synopsis with the ending; paragraph and 50-word versions cut from it.
- [ ] Word and character counts recorded; plain-text copies ready.
- [ ] Voice matches the film's genre without evaluation.
- [ ] Cold reader names protagonist, problem and ending from the 150-word version.
