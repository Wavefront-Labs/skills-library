# Rewrite plan and draft management

**Goal:** every note is accounted for, the producer and writer agree on what the next
draft will change before pages are written, and nobody ever asks "which draft is this?".

## 1. Collate the notes
Paste all notes (producer, studio, director, coverage) into one document. Tag each:
**structure, character, scene, dialogue, logic, length, tone**. Group duplicates - three
people saying "act two drags" in different words is one note with weight 3.

## 2. Find the note behind the note
For each group write: what the reader *felt* (confused, bored, unconvinced) and where.
The suggested fix is often wrong; the symptom is almost always right. Mark each:
**Address as asked / Address differently / Discuss / Decline** (with reason).

## 3. Write the rewrite memo (1-3 pages)
1. One paragraph: what this draft is about - the main change in story or character.
2. Bulleted **big changes** (structure, character arcs) with the reason.
3. **Scene-level changes** list.
4. Notes deliberately not taken, with a one-line rationale.
5. Delivery date.
Send it before writing; get explicit sign-off. This prevents "that's not what we
asked for" at delivery and is the professional courtesy expected on paid steps.

## 4. Plan passes
Rewrite in passes, largest first: structure -> character -> scene -> dialogue -> polish.
Re-outline (cards) if structure changes; don't patch pages.

## 5. Draft management
- **File name**: `TITLE_Draft03_2026-10-16_WriterLastname.fdx` - title, number, ISO date.
- **Title page**: draft label and date bottom right/left per convention
  ("Second Draft - 16 October 2026"); producers' drafts may be called "Revised Draft".
- Under WGA contracts a **"draft"** and a **"rewrite"** / **"polish"** are distinct
  steps with different minimums; know which step you're delivering.
- Keep every delivered draft as a PDF in a dated archive; never overwrite. Keep a
  change log (one line per draft).
- Spec drafts sent out: number them only internally; the version on the street should
  just carry a date.

## Gotchas
- Fixing every note literally; the script becomes incoherent.
- Starting pages before the memo is agreed.
- Draft numbers that reset or diverge between writer and producer copies.
- Losing the earlier draft a note-giver now wants back.

## Verify
- [ ] Notes collated, grouped and given a disposition.
- [ ] Memo approved before writing.
- [ ] Passes planned largest to smallest.
- [ ] File naming, title-page label and archived PDFs consistent.
