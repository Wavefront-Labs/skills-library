# Planning a doubling chart

## 1. Build the grid
Rows = characters; columns = scenes (or French scenes — each entrance/exit).
Mark X where a character appears (speaking or silent). A spreadsheet works well.

## 2. Find compatible roles
Two roles can be doubled by one actor only if:
- They never appear in the same scene (no overlapping X).
- There's **enough time between** one role's exit and the other's entrance for
  the costume change (check with costume designer: a basic change might need
  2-3 minutes; a quick change with dressers 30-60 seconds; wigs/make-up longer).
- The actor's casting suits both roles.

## 3. Procedure
1. Sort characters by line count; leads usually don't double.
2. For each remaining actor slot, greedily assign the largest unassigned role,
   then add roles with no overlap and adequate gaps.
3. Count the resulting cast size; iterate (cuts or merged characters may be
   needed — see `creative-arts.theatre.dramaturgy.cutting-shakespeare`).
4. Consider **thematic doubling** (e.g. the same actor as Theseus/Oberon and
   Hippolyta/Titania in *A Midsummer Night's Dream*), which can add meaning.
5. Mark crowd scenes: who is available to fill them?

## 4. Deliver
- Doubling chart (actor → roles) for casting breakdown.
- Updated character-scene grid with actor names for the SM and wardrobe.
- Quick-change list (role A exit → role B entrance, time available) for
  costume.

## Gotchas
- Forgetting silent appearances (attendants, crowd).
- Last-scene curtain calls where doubled actors appear as which character.
- Doubling that confuses audiences (similar costumes, no clear signal).

## Verify
- [ ] No actor appears as two characters in one scene.
- [ ] Every change has a time gap approved by wardrobe.
- [ ] Crowd scenes have enough bodies.
