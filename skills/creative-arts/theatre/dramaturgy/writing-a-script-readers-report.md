# Writing a script reader's report

Literary departments receive large volumes of submissions; readers write reports
so the literary manager can triage. Usually 1-2 pages.

## Report template
1. **Header**: title, writer, agent (if any), date received, page count, cast
   size (M/F/any), settings, running-time estimate, reader name.
2. **Logline** (1-2 sentences): who wants what, against what.
3. **Synopsis** (one or two paragraphs, plot including ending — the report is
   internal).
4. **Assessment**:
   - Voice: is it distinctive? Quote a line or two.
   - Structure: does it build? Where does it sag?
   - Character: are needs clear and active?
   - Theatricality: does it need a stage, or is it a TV/radio script?
   - Originality and urgency: why this play now?
5. **Development needs**: what a dramaturgical process could address.
6. **Fit**: size, scale and programming fit for *this* theatre (studio vs main
   house, audience, mission).
7. **Recommendation**: e.g. *Decline*, *Decline but encourage writer*,
   *Consider (second read)*, *Recommend*. Use the department's categories.

## Practice
- Read the whole script in one sitting where possible; read the first 10 pages
  twice.
- Be fair and specific; reports may be shared with writers in paraphrase.
- Track time: many departments aim for a first response within a stated
  period (often several months).
- Log in the submissions database with status and dates.

## Gotchas
- Plot summary instead of assessment.
- Judging by personal taste rather than the play's own ambitions and the
  theatre's remit.
- Spoiler-free synopses — internal reports need the ending.

## Verify
- [ ] Header, logline, synopsis, assessment, development, fit,
  recommendation present.
- [ ] Specific examples from the text cited.
