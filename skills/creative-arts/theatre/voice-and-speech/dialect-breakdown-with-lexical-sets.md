# Dialect breakdown with lexical sets

## 1. Gather primary sources
- **IDEA** (International Dialects of English Archive, dialectsarchive.com): free
  recordings with transcripts, by region, age and gender; each speaker reads
  "Comma Gets a Cure" and speaks unscripted.
- British Library Sounds (*Accents and Dialects*), BBC Voices, oral-history
  archives, interviews and documentaries. Prefer **real speakers**, matched to
  character's age, class, region, era.
- Avoid learning from actors doing the accent.

## 2. Oral posture ("setting")
Describe the habitual mouth set: tongue position (forward/back,
high/low), lip activity (spread/rounded/lazy), jaw openness, where the voice
"sits" (nasal, pharyngeal, forward). Knight-Thompson calls this the
**oral posture**; nail it first — individual sounds follow.

## 3. Vowel map with lexical sets
Use J.C. Wells' standard lexical sets (*Accents of English*, 1982): KIT, DRESS,
TRAP, LOT, STRUT, FOOT, BATH, CLOTH, NURSE, FLEECE, FACE, PALM, THOUGHT, GOAT,
GOOSE, PRICE, CHOICE, MOUTH, NEAR, SQUARE, START, NORTH, FORCE, CURE, happY,
lettER, commA.
For each set, transcribe the target accent's vowel (IPA) from your recordings,
and note how it differs from your own.

## 4. Consonants
Rhoticity; t-glottalling or flapping; th-fronting (th → f/v); h-dropping;
l-vocalisation (dark l → vowel); r type (tap, trill, approximant); aspiration.

## 5. Prosody
Intonation patterns (e.g. rising terminals), stress timing, speed, pitch
range, characteristic phrases and vocabulary.

## 6. Drill into text
1. Write a one-page breakdown: oral posture, vowel table, consonant list,
   prosody notes, 2-3 reference clips with timestamps.
2. Drill word lists per lexical set, then sentences, then the script.
3. Mark the script with IPA for key words.
4. Record runs; compare to sources; adjust.

## Gotchas
- Learning sound substitutions without the oral posture — sounds "pasted on".
- Over-doing every feature (caricature); real speakers vary.
- Using one source; a single idiolect isn't the dialect.

## Verify
- [ ] Breakdown sheet with posture, vowels, consonants, prosody, sources.
- [ ] Every lexical set filled with a target vowel.
- [ ] Recording of your script compared with source clips.
