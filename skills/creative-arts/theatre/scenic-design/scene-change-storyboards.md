# Scene-change storyboards

A scenic storyboard shows the stage picture for each scene (and key moments within
scenes) in sequence, so the whole team can see how the design moves.

## Procedure
1. List all scenes and key states (a door opens to reveal, a wall flies out).
2. For each state produce a frame:
   - **Photographs of the model** set to that state, shot from a consistent
     audience viewpoint (centre stalls eye height, same lens), with scale figures.
   - Or perspective sketches over a base drawing.
3. Under each frame: scene number, location, time, what's changed from the
   previous frame (flown in/out, trucked on, revolved), and intended **change
   method** (crew, actors, automation, flying) and **target time**.
4. Indicate light quality sketched or noted (night, dawn), to start the
   conversation with the LD.
5. Compile in order (slides/PDF), one or more frames per page.

## Uses
- **Director**: checks the visual story and pacing of transitions.
- **Production manager**: costs automation/flying, crew numbers.
- **Stage management**: basis for the shift plot (see
  `creative-arts.theatre.stage-management.scene-change-shift-plot`).
- **Lighting and video**: states and transitions to light.
- **Company**: model showing on day one.

## Gotchas
- Inconsistent camera angles making changes hard to read.
- Omitting minor props/furniture moves that still need hands.
- Not updating after design changes.

## Verify
- [ ] One frame per scene/state, in sequence.
- [ ] Each frame lists changes, method and target time.
- [ ] Storyboard updated to the final signed-off design.
