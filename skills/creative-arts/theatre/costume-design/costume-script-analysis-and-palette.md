# Costume script analysis and production palette

Rebecca Cunningham (*The Magic Garment*) and Ingham and Covey (*The Costume
Designer's Handbook*) start with the script: costumes tell who characters are,
where they are, and how they change.

## Script analysis
For each character, record:
1. **Given circumstances**: age, class, occupation, region, era, season,
   weather, time of day per scene.
2. **Status and relationships**: who has power; family/group identities
   (uniforms, shared colours).
3. **Personality and arc**: how they see themselves; how they change (a
   costume journey: buttoned-up → loosened).
4. **Textual references** to clothing ("your torn sleeve", "the green
   dress") — must-haves.
5. **Practical requirements**: fights, falls, dancing, quick changes, getting
   wet, blood, pockets for props, climbing.
6. **Scene list** with time passing (do they change clothes overnight?).
Output: a character-by-scene chart (feeds the costume plot).

## Building the palette
1. Start from the director's concept and the set designer's palette (costumes
   must sit on the set and under the lighting).
2. Choose a **production palette**: a limited set of hues, values and
   saturations.
3. Assign **colour stories**: families/groups share colour families; the
   protagonist may be distinct; colour shifts follow character arcs.
4. **Value contrast** matters more than hue at distance: separate characters
   from the set by lightness/darkness.
5. Test swatches against set paint samples under stage lighting (with the LD).
6. Lay out a **line-up** of all characters' renderings per scene to check balance
   and focus.

## Gotchas
- Costumes disappearing against a set of the same value.
- Colour symbolism that's too on-the-nose.
- Practical needs discovered in tech (no pockets, no room for mic packs).

- [ ] Character-by-scene analysis with practical needs.
- [ ] Production palette agreed with set and lighting.
- [ ] Line-up checked for each scene.
