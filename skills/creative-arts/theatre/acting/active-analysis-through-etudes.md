# Active analysis through etudes

Stanislavski's final rehearsal method, transmitted by Maria Knebel (*On the
Active Analysis of Plays and Roles*) and described in Sharon Carnicke's
*Stanislavsky in Focus*. Analysis happens on the feet through improvised
**etudes** rather than round the table.

## Procedure (one cycle per scene)
1. **Read the scene** together once or twice. No memorising.
2. **Short discussion (10 min max):** what is the **event** (what changes),
   what does each character want, what is the main conflict? Note a few key
   facts and key phrases.
3. **Etude 1:** play the scene in your own words, with the given circumstances,
   following the event. Use the space and simple props. Don't try to recall
   lines.
4. **Compare with the text.** Re-read. What happened in the etude that's not in
   the text? What did the text have that you missed (a reversal, a hidden
   intention, a line that now seems essential)?
5. **Etude 2, 3…:** repeat, each time adding the discoveries and more of the
   author's words as they become necessary. Actors naturally start using the
   text because it is the best way to get what they want.
6. **Move to text** when the etude contains the full structure; then learn the
   lines exactly.

## Running it as director
- Keep etudes short (as long as the scene, or shorter).
- Side-coach circumstances, not lines ("it's 3am", "she has the gun").
- After each etude ask *what happened* (events), not *how did it feel*.

## Gotchas
- Etudes turning into comedy or chat: reset the stakes and the event.
- Actors paraphrasing permanently — set a point where text becomes exact.
- Too much discussion before the first etude defeats the method.
- Works poorly for verse unless combined with text work early.

## Verify
- [ ] Each scene's event named before etudes.
- [ ] At least two etude-compare cycles before line learning.
- [ ] Discoveries noted and fed into the next etude.
- [ ] Final etude contains every event of the written scene.
