# Heightening and exploring the game

From the *Upright Citizens Brigade Comedy Improvisation Manual* (Besser, Roberts,
Walsh, 2013), ch. 5-6. Once the first unusual thing is identified (see
`creative-arts.theatre.improv.finding-the-game-of-the-scene`), the scene is
played by two complementary moves.

## Heightening
Make the next instance of the unusual pattern **bigger, more extreme, or with
higher stakes** than the last.
- Example game: a waiter takes every order personally.
  - Instance 1: hurt when the customer orders the salad not the steak.
  - Instance 2: cries over the dressing choice.
  - Instance 3: brings his mother to explain the family's soup.
- Each heighten should be a **new instance** of the same pattern, not a
  repetition.

## Exploring ("if this is true, what else is true?")
Ask: *if this unusual thing is true, what else must be true?* This deepens and
justifies the game:
- "If the waiter takes it personally, he must have cooked the food himself, he
  must know the farmer, he must be in debt to keep the restaurant..."
- Exploring answers **why** (justification) — giving the character a logic so the
  absurdity feels grounded.

## Who does what
- **Unusual character**: commits to the game, justifies their behaviour
  with their logic.
- **Straight/grounded character**: reacts honestly as a reasonable person,
  pointing out what's strange — which frames the game for the audience. Both
  players can heighten.

## Pattern of play
Base reality → unusual thing → frame it (straight man reacts) → heighten →
explore → heighten → edit at a peak laugh or when the game is complete.

## Gotchas
- Introducing a second unrelated unusual thing ("new game") — dilutes.
- Heightening by repetition only.
- Losing the base reality so nothing seems unusual any more.
- Straight character becoming equally crazy too early.

## Verify
- [ ] Each beat is a new, bigger instance of the same pattern.
- [ ] At least one "if this is true" justification given.
- [ ] Base reality still recognisable at the end.
