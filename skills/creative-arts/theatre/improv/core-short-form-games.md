# Core short-form games

Each game is a constraint layered on good scene work. The constraint gives the
audience something to watch for; the scene still needs base reality.

## Scene games
- **Freeze tag**: two players start a scene; anyone calls "Freeze!", tags out a
  player, takes their exact physical position and starts a completely new scene
  justifying the pose. *Works when*: the new scene uses the pose cleverly.
  *Fails when*: players freeze too often or keep the same scene.
- **New choice** ("Ding!"): host rings a bell, the last line must be replaced
  with a new one. *Works*: fast, varied alternatives, then committing to one.
- **Sit-Stand-Lie (Levels)**: three players; at all times one must sit, one
  stand, one lie; changes must be justified.
- **Half-life**: same scene in 60, 30, 15, 7, 3 seconds. *Works*: keep key
  beats, get physical.
- **Emotional rollercoaster**: host calls emotions; scene continues with the new
  emotion.

## Guessing games
- **Party quirks**: host (guesser) at a party; guests have secret quirks
  (from audience) shown through behaviour; host guesses. *Works*: guests give
  escalating clues, not instant giveaways.
- **Interrogation / Late for work / Press conference**: one player guesses a
  scenario from others' clues.

## Verbal games
- **Story-story (Conducted story)**: players tell a story; the conductor points
  and players switch mid-sentence, sometimes mid-word. Out if they hesitate.
- **Expert double / Expert interview**: one player is the "expert", another
  interviews; variants with two people as one expert (each speaking alternate
  words).
- **One-word story / Alphabet** (each line starts with the next letter).

## Craft rules for all
- Even in a game, establish who-what-where.
- Commit physically; big choices read better.
- Don't sacrifice the partner for the gag.
- Keep games short (2-4 minutes).

## Gotchas
- Using a game's gimmick as a substitute for scene work.
- Guessing games where clues are too obscure for the audience to enjoy.
- Over-explaining rules.

## Verify
- [ ] Each game's rule explainable in one sentence.
- [ ] Base reality established within the game.
- [ ] Games run 2-4 minutes and end on a peak.
