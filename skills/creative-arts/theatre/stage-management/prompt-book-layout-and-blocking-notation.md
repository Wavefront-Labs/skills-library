# Prompt-book layout and blocking notation

The **prompt book** (UK: "the book"; US: also "production book"/"calling script")
is the authoritative record of the production: text, blocking, cues and paperwork.

## Layout (ring binder)
Tabs, in a typical order:
1. Contact sheet and company list.
2. Schedules (rehearsal, production, tech).
3. Script with blocking (interleaved).
4. Scene breakdown / character-scene chart.
5. Props lists; set/shift plot; costume plot reference.
6. Ground plans and model photos.
7. Rehearsal reports and production meeting minutes.
8. Show reports; running plots; fight/intimacy notation.
9. Risk assessments; emergency procedures; show-stop text.

## Interleaved script
- Script page on one side (often hole-punched with a reinforced margin), blank page
  facing it for blocking.
- Number each moment of blocking in the script (1, 2, 3...) at the exact word,
  and write the matching notation with the same number on the facing page.
- Include a **small ground-plan thumbnail** on blocking pages where the stage
  picture is complex; mark positions with character initials.

## Standard abbreviations
- Areas: **US/DS/SR/SL/C** (upstage, downstage, stage right, stage left, centre),
  combined **DSR, USL** etc. Stage right/left are the actor's right/left facing
  the audience.
- Movement: **X** = cross ("H X DSL" = Hamlet crosses downstage left); **→** for
  direction; **ent** / **ex**; **sit**, **rise**, **kn** (kneel), **tn** (turn).
- Characters: initials or first letters (consistent and listed in the book).
- Furniture and props: named or numbered (from the ground plan).
- Use pencil; blocking changes daily.

## Maintenance
- Update immediately when blocking changes; erase old notation.
- Copy/scan the book weekly; keep a backup at a separate location.
- After freeze, produce a clean final copy (archive copy for remounts/tours).

## Gotchas
- Blocking written in the script margin only — illegible later.
- Inconsistent abbreviations between DSM and ASMs covering the book.
- No backup — losing the book loses the show.

## Verify
- [ ] Book tabs complete and current.
- [ ] Every blocking moment numbered in script and notation.
- [ ] Weekly backup taken.
