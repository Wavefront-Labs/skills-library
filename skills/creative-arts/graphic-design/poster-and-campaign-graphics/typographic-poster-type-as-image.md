# Typographic poster (type as image)

**Goal:** a poster with no photograph where the letterforms carry the concept and the message is still readable.

## 1. Start from one idea
Write the message and the single feeling or metaphor behind it ("sold out" = letters crammed against the edge; "echo" = a repeated, fading word). If you cannot state the idea in a sentence, the layout will be decoration.

## 2. Choose the typographic device
- **Scale contrast:** one word huge, the rest small. The biggest element is the image; keep a clear jump between levels rather than many similar sizes.
- **Cropping:** let a very large letter bleed off the edge; keep enough of each letter that the word is still recognisable.
- **Repetition, rotation, stacking:** set one word in a tight stack with minimal leading, or run it vertically. Rotating by 90 degrees is usually safer than arbitrary angles.
- **Letter-as-shape:** use a counter, bowl or stem as a frame, window or mask for other content.
- **Weight and colour only:** two weights of one family plus one accent colour often outperform mixing typefaces.

## 3. Build it
1. Pick a face with strong, simple forms at display size (a grotesque, a heavy serif, or a condensed sans). Check the licence allows the intended use.
2. Set the headline first, at the size that fills the format, then place secondary text on the same grid (see `creative-arts.graphic-design.poster-and-campaign-graphics.poster-hierarchy-at-distance`).
3. In Illustrator or InDesign use **Type > Create Outlines** only on a duplicate when you need to distort, crop or mask the letters; keep a live-text version.
4. Tighten or loosen tracking by eye at display size; large type usually needs negative tracking and manual kerning of problem pairs.
5. Keep the information (date, place, URL) in a separate, quiet block with generous space around it.

## Failure modes
- Everything expressive, nothing readable: if the key words cannot be read in a few seconds, reduce the effect.
- Stretching letters distorts the design; scale proportionally or choose a face that is already condensed or extended.
- Too many ideas: pick one device and apply it consistently.

## Self-check
View a thumbnail from across a room: the headline reads first, then one secondary line, then details. Print at least a reduced proof to judge real contrast.
