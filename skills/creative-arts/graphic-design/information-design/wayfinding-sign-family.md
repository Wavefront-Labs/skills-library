# Wayfinding: the sign family

**Goal:** a small, consistent set of sign types that gets people from arrival to destination
without asking, placed at the decision points where they are needed.

## The sign types (SEGD practice)
| Type | Job | Examples |
|---|---|---|
| **Identification** | "You are here / this is X" | room signs, building names, entrance markers |
| **Directional** | "X is that way" | blade signs, overhead directories, floor arrows |
| **Orientation** | "Here is the whole place" | you-are-here maps, directories, lift-lobby floor lists |
| **Regulatory / statutory** | rules, safety | fire exit, no entry, accessibility notices (legal requirements) |
| **Interpretive** | explain and inform | heritage panels, exhibit labels |

## Process
1. **Circulation analysis:** walk every route from each arrival point (car park, transit, main
   door) to key destinations. Mark **decision points** (junctions, lift lobbies, stair landings).
2. **Destination hierarchy:** primary (reception, wards, gates), secondary, tertiary. Primary
   destinations appear on directionals from the arrival point; others appear progressively.
3. **Nomenclature:** one name per destination everywhere (signs, maps, website, staff speech).
   This is often the hardest and most valuable part.
4. **Sign type family:** design each type's size, mounting (wall, projecting, suspended,
   freestanding), layout grid, type sizes, arrow placement rules, colours, pictograms.
5. **Location plan and message schedule** (see that skill) place each sign and record its text.

## Graphic system rules
- One wayfinding typeface with open apertures and clear numerals (Frutiger, Transport, Clearview,
  Inter, Source Sans); see the sign legibility skill for letter heights.
- **Arrows:** one arrow design; arrow on the side it points (left arrow left-aligned); order
  messages straight ahead first, then left, then right (or by distance).
- Colour coding by zone helps only when it is reinforced everywhere and also coded by text -
  never rely on colour alone.
- High contrast (LRV difference >= 70% is common practice; ADA requires non-glare finish and
  dark-on-light or light-on-dark).

## Gotchas
- Too many signs = no signs; consolidate messages at the decision point.
- Signs designed at a desk fail in place: mock up at full size on site.
- Statutory signs (fire, safety) follow local regulations and ISO 7010, not brand style.

## Verify
- [ ] Every decision point on key routes has the information needed there and only there.
- [ ] Nomenclature identical on signs, maps and digital.
- [ ] Full-size mock-ups tested on site at real viewing distances.
