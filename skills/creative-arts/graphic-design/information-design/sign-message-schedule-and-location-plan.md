# Message schedule and location plan

**Goal:** a precise list and map that the fabricator and installer can build from, and that the client can approve line by line.

## 1. Survey and decision points
- Walk the site (or study plans) from each arrival point to each destination, listing **decision points** where a person has to choose a direction.
- Group destinations by importance and by audience (visitors, staff, service), then decide the information hierarchy.

## 2. Sign types
Define a small set of **sign types** (for example A: freestanding directory, B: directional wall sign, C: room identification, D: regulatory) with dimensions, materials, mounting and typography on a type sheet. Re-use types across the site.

## 3. Message schedule
A table with one row per sign, with at least:
- Sign ID (unique, linked to the plan), sign type, location description.
- Face copy per side: line by line text, arrows and pictograms with exact wording and capitalisation.
- Mounting height and orientation, illumination, quantity.
- Status and revision (approved, to revise) and notes.
Keep it in a spreadsheet or database, with revisions dated, so counts and copy are controlled in one place. Check wording for consistency (same names for destinations everywhere).

## 4. Location plan
- Mark each sign ID on the floor or site plan with a symbol that shows type and facing direction.
- Use layers or colours by type; include a legend and a revision date. Add elevation sketches for wall-mounted signs where height is important.

## 5. Review
- Walk the plan: from each arrival point, can you reach every key destination by following signs only?
- Check ordering and arrow logic at every decision point, and remove repetition.
- Get client approval of the message schedule before artwork, and sign off on a mock-up before fabrication.
- Accessibility requirements (see `creative-arts.graphic-design.information-design.ada-and-tactile-braille-signs`) are verified at this stage.

## Failure modes
- Same destination named differently on different signs.
- Plans that do not match the schedule (a revision on one only).
- Arrow ambiguity at junctions.
