# Feature openers and departments

**Goal:** feature openers that make each long story feel special, and department pages that look the
same every issue so readers navigate by habit.

## Feature opener spread
- Elements: **image** (often full bleed on one page or across the spread), **headline**, **standfirst**,
  byline and photo credit, and the **text start** with a drop cap or bold lead-in.
- One dominant entry point (image or a typographic headline). The headline and image should work as a pair:
  headline completes or twists the image's meaning.
- Text start visible on the opener: readers should not have to turn the page to find where to begin.
- Vary openers from story to story (image-led, type-led, illustration-led) within the type system.
- Continuation spreads drop back to the standard grid with secondary entry points (subheads, pull quotes).

## Departments (recurring sections)
- Fixed templates on parent pages: section header or tab (name, colour, folio style), grid, standard
  elements (product shots with price lines, short reviews with star ratings, Q&A layouts).
- Content changes each issue, structure does not. Build paragraph, object and table styles so editors can
  fill them quickly, ideally in InCopy.
- Section colour coding helps navigation; keep palette limited and consistent with the brand.

## Openers vs departments
| | Feature opener | Department |
|---|---|---|
| Layout | bespoke each issue | fixed template |
| Image | commissioned, big | supplied, small to medium |
| Type | display headline, can be expressive | standard heads |
| Goal | surprise | familiarity |

## Gotchas
- Openers with no text start force a page turn; many readers never do.
- Department templates drifting issue to issue (one-off tweaks) erode recognition; update the template, not
  the page.
- Photo credits and captions forgotten on openers: put credit slots in the template.

## Verify
- [ ] Each opener shows headline, standfirst, credit and the text start.
- [ ] Department pages match their templates in a side-by-side check with the last issue.
