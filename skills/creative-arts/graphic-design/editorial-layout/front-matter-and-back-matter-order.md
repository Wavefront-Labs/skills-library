# Front matter and back matter order

**Goal:** prelims and end matter in the conventional order, on the right sides, so the book looks
professionally published (Chicago Manual of Style, chapter 1).

## Front matter (prelims), typical order
| Page | Element | Side |
|---|---|---|
| i | Half title (title only) | recto |
| ii | Series title, list of other works, or frontispiece (or blank) | verso |
| iii | **Title page** (title, subtitle, author, publisher) | recto |
| iv | **Copyright page** (copyright notice, edition, ISBN, CIP data, printer, credits) | verso |
| v | Dedication (and epigraph) | recto |
| | (Blank verso) | |
| | **Contents** | recto |
| | List of illustrations, tables | recto start |
| | Foreword (by someone else), Preface (author), Acknowledgments, Introduction (if not part of text) | each starts recto |
- Front matter uses **lower-case roman** folios, counted from the half title, often not printed on display
  pages (half title, title, copyright, dedication, part titles).
- Main text starts on **page 1, a recto**, with arabic numerals.

## Back matter, typical order
Appendixes, Chronology, Abbreviations, **Notes** (endnotes), Glossary, **Bibliography** or References,
List of contributors, Illustration credits, **Index**, colophon (optional, describes type and printing).
Major sections start on a recto in formal books; many trade books allow verso starts to save pages.

## Design notes
- Display pages (half title, title) use the book's display type system, not a separate style.
- Copyright page in small type (often 7-8 pt), flush left or centred, bottom of page.
- Contents: align page numbers right (tab with leader or none); show only the levels readers need.
- Running heads are omitted on display pages and chapter openers.

## Gotchas
- Page count must fit signatures; prelims often absorb or release blank pages to make it fit.
- The copyright page's ISBN and CIP data must match the publisher's records exactly.
- Changing roman page counts after the index is made shifts nothing (arabic starts at 1), but changing the
  main text start side does: keep page 1 recto.

## Verify
- [ ] Each element is on the conventional side; page 1 is a recto.
- [ ] Folios: roman in front matter, arabic from page 1, suppressed on display pages.
