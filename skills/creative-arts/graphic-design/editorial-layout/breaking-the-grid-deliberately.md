# Deliberately breaking the grid

**Goal:** moments of surprise and energy in a publication that look designed, not accidental, because the
underlying grid is otherwise obeyed (Timothy Samara, Making and Breaking the Grid).

## When a break is earned
- Openers, covers, section dividers and climactic features: pacing calls for a change.
- Content demands it: a panoramic image, a quote that is the story, a long list or timeline.
- Never in the body of continuous reading text, captions or tables.

## Moves that read as intentional
- **Bleed:** image runs off one or more edges, while its other edges stay on grid lines.
- **Cross the gutter:** an image or headline spans the spread's central fold (check binding: avoid faces and
  key words in the gutter; allow creep in perfect-bound books).
- **Scale jump:** one element dramatically larger than the grid's modules (huge numeral, cropped letter).
- **Overlap:** headline overlapping an image edge, aligned to at least one grid line.
- **Rotation:** type at 90 degrees along an edge, baseline on a column line.
- **Margin intrusion:** a pull quote hanging into the outer margin, aligned to the margin edge.
- Use **one** break per spread; anchor at least two edges of the breaking element to the grid.

## Process
1. Lay out the spread on the grid first.
2. Identify the one element that should break and how (bleed, overlap, scale).
3. Keep every other element on the grid; strengthen alignment elsewhere so the contrast reads.
4. Check that reading order is still obvious (entry point, then text start).

## Gotchas
- Breaking because the content does not fit is not a design decision; edit or re-plan the page.
- Text over busy images loses contrast; check legibility and add scrims if needed.
- Gutter crossings misalign between printer spreads in saddle-stitched work; leave tolerance.

## Verify
- [ ] The break can be explained in one sentence (what it emphasises).
- [ ] All other elements align to the grid; the breaking element still touches grid lines.
