# Final file delivery specs

**Goal:** the client or printer can use the artwork immediately without asking for fixes.

## 1. Confirm the spec before starting
Ask for the **final size** (with bleed and safe area), **colour mode** (RGB for screen, CMYK for print, or a named profile), **resolution** (commonly 300 ppi at final size for print, 72-150 ppi for screen use as specified), **file format**, **deadline** and **who receives** the files. Put them in the brief or contract.

## 2. What to deliver
- **Flattened final:** TIFF (print, lossless), PNG (screen, transparency), or JPEG (small previews); PDF where requested.
- **Layered source** only if the contract includes it: PSD for raster, AI for vector. Many illustrators retain the source and licence only the final; agree that in writing.
- **Vector artwork:** outline type (Illustrator: Type > Create Outlines on a copy) or supply the fonts if licences allow; embed or link images and package them.
- **Transparent version** (PNG or PDF) for use on different backgrounds if asked.
- Spot colours and special inks only as the print spec requires.

## 3. Colour handling
- Work in a defined profile; convert at the end with a stated rendering intent and check saturated colours that shift on conversion to CMYK (soft proof in Photoshop: View > Proof Setup).
- Embed profile if the client asks; label the delivered profile in the file name or notes.

## 4. Naming and packaging
- Consistent names: client_project_description_v01_final-size_mode (for example `acme_cover_front_v02_3000x4500_cmyk.tif`).
- Zip with a short readme: sizes, profiles, fonts or typefaces used, usage rights summary.
- Deliver by a shared link with expiry; confirm receipt.

## 5. Usage record
Record the licence granted (use, medium, region, term, exclusivity) in the invoice. Seek legal advice if usage terms are complex.

## Self-check
Open each delivered file fresh: dimensions, mode, profile, transparency and fonts match the spec.
