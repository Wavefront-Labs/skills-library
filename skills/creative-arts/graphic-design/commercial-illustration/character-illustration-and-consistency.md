# Character illustration and consistency

**Goal:** a character that is distinctive and looks like the same person or creature in every picture.

## 1. Brief and exploration
- Define personality, role, age, setting and audience; write three adjectives.
- Explore silhouettes first (fill shapes black): a good character reads from silhouette alone.
- **Shape language:** circles read as friendly and soft, squares as stable or stubborn, triangles as dynamic or sharp; combine deliberately.

## 2. Construction
- Build from simple volumes: head, torso, pelvis as spheres, cylinders or boxes; set **proportions** in head units (for example a stylised child at 3-4 heads tall, a heroic adult at 7-8) and keep to them.
- Fix distinctive features: eye style, nose, hair silhouette, costume shapes, recurring props. Keep the number of distinctive features small.
- Decide line style (weight, taper, outline colour) and rendering (flat, cel shading, textured).

## 3. Model sheet
Create one master sheet containing:
- **Turnaround:** front, three-quarter, side and back at the same scale with guidelines for eyes, shoulders, hem and feet.
- **Expressions:** a set (neutral, happy, sad, angry, surprised, thinking).
- **Poses** showing action and a few common gestures.
- **Colour palette** swatches with values (hex or CMYK) and a **size comparison** with other characters or objects.
- Notes on construction and dos and don'ts.

## 4. Staying consistent in production
- Keep the model sheet next to the canvas; trace or reference the head construction rather than redrawing from memory.
- Use a **template file** with layers for sketch, line, colour and a locked guideline layer; store the palette as swatches.
- Compare thumbnails of your latest image with the sheet side by side.
- For vector, keep a master character in Illustrator and build poses by editing a copy.

## Failure modes
- Features that drift (eye spacing, head size).
- Costume details that change between images.
- Complexity that the style cannot repeat quickly.
