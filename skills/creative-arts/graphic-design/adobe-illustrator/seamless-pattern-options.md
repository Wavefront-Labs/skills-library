# Seamless patterns with Pattern Options

## Create
1. Select motif artwork, Object > Pattern > **Make**. Enters Pattern Editing Mode, swatch added.
2. **Pattern Options** panel:
   - **Tile Type**: Grid, Brick by Row, Brick by Column (offset 1/2 typical), Hex by Column/Row.
   - Width/Height or **Size Tile to Art** with H/V spacing.
   - Move Tile with Art.
   - **Overlap**: which motifs sit on top at tile edges.
   - Copies: 3x3, 5x5 preview; Dim Copies.
3. Place motifs so they cross tile edges - Illustrator repeats them across the seam automatically.
4. Done (top bar) saves the swatch.

## Editing and applying
- Double-click the swatch to edit.
- Apply as a fill. Scale the pattern independently: Object > Transform > Scale with only
  **Transform Patterns** ticked (or the `~` key while dragging with the Selection tool).
- Preferences > General > Transform Pattern Tiles controls default behaviour.

## Avoiding visible repeats
- Vary rotation and size; avoid one dominant motif creating a "line" across the repeat.
- Check at 5x5 copies zoomed out: tangents and gaps show up as stripes.

## Delivery (textiles, wrapping)
- Supply the tile as artwork + pattern swatch, tile dimensions in mm, repeat type (half-drop = brick by column).
- Expand patterns (Object > Expand) for some print workflows; flat tile PNG/TIFF for digital textile printers at the required ppi.

## Verify
- [ ] No seams or gaps at tile edges at 5x5 preview and in Outline view.
