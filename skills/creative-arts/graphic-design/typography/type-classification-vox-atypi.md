# Type classification (Vox-ATypI and practical sans categories)

**Goal:** name what you see in a typeface precisely enough to brief, search for, substitute and pair type.

## Serif classes (Vox-ATypI, adopted by ATypI in 1962; British Standard BS 2961)
| Class | Look | Examples |
|---|---|---|
| **Humanist** (Venetian) | Diagonal stress, low contrast, slanted e bar, heavy bracketed serifs | Jenson, Centaur |
| **Garalde** (old style) | Diagonal stress, more contrast, level e bar | Garamond, Bembo, Sabon |
| **Transitional** (réale) | Near-vertical stress, sharper contrast, wider | Baskerville, Times |
| **Didone** (modern) | Vertical stress, extreme contrast, hairline unbracketed serifs, ball terminals | Bodoni, Didot |
| **Mechanistic** (slab) | Heavy square serifs, low contrast | Rockwell, Clarendon (bracketed) |
| **Lineal** (sans) | No serifs (split below) | |
| **Glyphic**, **Script**, **Graphic**, **Blackletter**, **Gaelic** | Incised, connected, display, broken | Trajan, Snell Roundhand, Fraktur |

## Sans subclasses (the lineal split used in practice)
- **Grotesque** (19th c.): some contrast, odd quirks, often a double-storey g. Akzidenz-Grotesk, Franklin Gothic.
- **Neo-grotesque:** even, closed apertures, horizontal terminals. Helvetica, Univers.
- **Geometric:** circle, square, triangle construction; single-storey a in many. Futura, Avenir.
- **Humanist sans:** pen-based proportions, open apertures, more legible at small sizes and on screens.
  Gill Sans, Frutiger, Myriad.

## How to read a face (checklist)
1. **Stress axis:** draw a line through the thinnest parts of the o; diagonal = humanist/garalde.
2. **Contrast** thick-to-thin.
3. **Serifs:** bracketed, unbracketed, slab, none.
4. **Apertures:** open (c, e, a open) vs closed.
5. **Terminals:** ball, sheared, horizontal.
6. **x-height** relative to cap height.

## Using it
- Briefing: "humanist sans, open apertures, large x-height" finds legible UI faces quickly.
- Pairing: contrast classes (Garalde text with a humanist sans) or share structure (Frutiger with
  Minion: both humanist).
- Substitution: when a font is not licensed, stay inside the class and match x-height.

## Gotchas
- Classification is descriptive; many modern faces mix traits. The 2021 ATypI vote de-adopted Vox-ATypI
  as its official system; it remains the shared vocabulary.
- Retail font sites use their own categories; search with traits, not only class names.
