# Recording conservation data in a collections management system

**Goal:** searchable, durable records linked to each object.

## What to record
- Condition checks (date, examiner, rating) linked to the object record.
- Treatments (proposal, report, materials, dates, conservator).
- Environmental and handling notes, hazards (for example pesticide or radioactive) and special storage.
- Images and documents attached or linked by persistent path.

## Practices
1. Use the system's conservation or condition module if it has one (for example TMS, EMu, CollectiveAccess, PastPerfect or similar); otherwise define fields that map to Spectrum procedures.
2. Use controlled vocabularies for materials and techniques, such as the Getty Art and Architecture Thesaurus, and local picklists for condition terms (see `condition-terminology-rating-and-report-templates`).
3. Assign unique identifiers to each record and image; never reuse them.
4. Restrict editing by role; keep an audit trail.
5. Back up the database and the image store; test restores.
6. Keep paper records scanned and linked.

## Verify
- [ ] Every treatment has a linked report and images.
- [ ] Vocabularies consistent.
- [ ] Backups and restores tested.

## Professional note
General guidance only, not a treatment recommendation for a specific object. Work on heritage objects needs the judgement of a qualified conservator, working to the AIC Code of Ethics and Guidelines for Practice (or the ECCO / Icon equivalent) and the owner's consent; test, document and prefer the minimum intervention. Check current safety data sheets and local regulations for every material named.
