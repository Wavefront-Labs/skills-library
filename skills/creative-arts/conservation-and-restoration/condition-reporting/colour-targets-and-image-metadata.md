# Colour targets and image metadata

**Goal:** images whose colour can be trusted, and files that can be found and understood later.

## Colour
1. Photograph a colour target (such as an X-Rite ColorChecker, or targets recommended in FADGI guidelines) in the same light as the object, at the start of each session or setup.
2. Shoot raw, with consistent exposure, white balance set or corrected.
3. Create or apply a camera profile or correction from the target in the raw processor.
4. Convert to a standard working space (commonly sRGB or Adobe RGB for derivatives) and embed an ICC profile.
5. Check results on a calibrated monitor.

## Files and metadata
1. Use a naming convention with the accession number, view and sequence; no spaces, no reuse.
2. Keep an unaltered master (raw or TIFF) and derivatives.
3. Embed or sidecar metadata (IPTC, XMP): title, ID, creator, date, rights, view, equipment, lighting and conservator.
4. Keep a log linking images to the object record.
5. Back up.

## Verify
- [ ] Target in frame, profile applied.
- [ ] File names and metadata consistent.
- [ ] Masters archived separately from derivatives.

## Professional note
General guidance only, not a treatment recommendation for a specific object. Work on heritage objects needs the judgement of a qualified conservator, working to the AIC Code of Ethics and Guidelines for Practice (or the ECCO / Icon equivalent) and the owner's consent; test, document and prefer the minimum intervention. Check current safety data sheets and local regulations for every material named.
