# Reflectance transformation imaging (RTI)

**Goal:** record a surface so it can be relit interactively on screen, showing relief, tool marks, and subtle changes.

## Principle
A fixed camera records a set of images while a light moves to different directions. Software combines them into a file in which the lighting can be changed.

## Highlight RTI capture
1. Fix the camera on a copy stand or tripod, parallel to the surface; focus and set manual exposure.
2. Place one or two black reflective spheres in the frame near the object, in the same focal plane.
3. Use a single light source at a constant distance; take images with the light at many angles (commonly dozens, such as 30 to 60), covering the hemisphere above the surface.
4. Keep camera, object and spheres still throughout.
5. Include a scale.

## Processing
1. Use tools such as RTIBuilder and RTIViewer (free from Cultural Heritage Imaging) or other software.
2. The software finds the light direction from the highlight on each sphere and computes surface data in formats such as PTM or HSH.
3. View, tune enhancement (specular, diffuse), and record views.

## Cautions
- Moving objects or shifting spheres ruin the data.
- Heat from light on fragile surfaces: use low-heat sources.
- Archive raw images with the processed file.

## Verify
- [ ] All images sharp and aligned.
- [ ] Spheres show clear highlights.
- [ ] Source files archived.

## Professional note
General guidance only, not a treatment recommendation for a specific object. Work on heritage objects needs the judgement of a qualified conservator, working to the AIC Code of Ethics and Guidelines for Practice (or the ECCO / Icon equivalent) and the owner's consent; test, document and prefer the minimum intervention. Check current safety data sheets and local regulations for every material named.
