# Security fixings, hanging height and large-format installation

**Goal:** safe, secure and consistent hanging.

## Fixings
- Use fixings rated for the work's weight with a safety margin, into a suitable wall or support; check the wall (studs, blockwork, plasterboard anchors).
- Common methods: two or more wall hangers per work, French cleats for heavy frames, mirror plates or Z-clips, and security screws or bolts that need a special tool.
- Fix the artwork to the wall or hang with hardware that prevents lifting off; use tamper-proof fasteners in public spaces.
- Never hang from the wire alone for valuable or heavy works.

## Height and layout
- A widely used convention puts the centre of the work at about 145 to 150 cm (57 to 60 inches) above the floor; adjust for the room, the visitors, and group arrangements.
- Plan the layout with a floor plan or paper templates; measure and mark with a level and laser; keep consistent spacing.

## Large-format installation
1. Check the weight and the wall's load capacity; consult an engineer when unsure.
2. Use suitable lifting aids and enough people; use a hoist or lift when needed.
3. Mark fixing points exactly; test the fixings before hanging.
4. Hang with controlled lowering; check level and security after hanging.
5. Record fixings used in the install report.

## Verify
- [ ] Fixings rated and tested.
- [ ] Height and level checked.
- [ ] Install report kept.

## Professional note
General guidance only, not a treatment recommendation for a specific object. Work on heritage objects needs the judgement of a qualified conservator, working to the AIC Code of Ethics and Guidelines for Practice (or the ECCO / Icon equivalent) and the owner's consent; test, document and prefer the minimum intervention. Check current safety data sheets and local regulations for every material named.
