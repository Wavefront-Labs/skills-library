# Planning and tracking a collection move

**Goal:** move collections without loss or damage, with a reliable record.

## Planning
1. Define scope: what is moving, where from and to, and why (building, storage change, renovation).
2. Measure and assess: object numbers, sizes, weights, condition and special needs; prepare the destination (see `re-org-storage-reorganisation`).
3. Set the schedule with phases, team roles, equipment, and risk plans; consider emergency response (see `writing-an-emergency-plan`).
4. Prepare objects: condition checks, stabilisation, packing (see `packing-for-an-internal-move`).
5. Train the team, with rules for handling and recording.

## Tracking
- Give each object a unique ID and a location code; use barcodes or RFID tags where resources allow, or a paper log.
- Record each step: removed, packed, in transit, received, shelved.
- Scan or tick at both ends; resolve discrepancies the same day.
- Keep records both on site and backed up.

## Post-move audit
1. Compare the register with objects actually in each location.
2. Investigate missing or misplaced items; correct the database.
3. Record any damage found and take action.
4. Review the move: what worked, what failed, lessons.

## Verify
- [ ] Every object has an ID and recorded location after the move.
- [ ] Discrepancies cleared.
- [ ] Review report written.

## Professional note
General guidance only, not a treatment recommendation for a specific object. Work on heritage objects needs the judgement of a qualified conservator, working to the AIC Code of Ethics and Guidelines for Practice (or the ECCO / Icon equivalent) and the owner's consent; test, document and prefer the minimum intervention. Check current safety data sheets and local regulations for every material named.
