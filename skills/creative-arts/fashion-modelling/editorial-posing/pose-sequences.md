# Pose sequences

**Goal:** a personal library of flows you can run on any set.

## Technique
- Build a sequence by choosing a **start position**, then a series of transitions that each change one or two elements (for example front stance, weight back, turn to three-quarter, hand to collar, look away).
- Practise **continuous movement** from one pose to the next so the photographer can shoot between positions and catch transitional frames.
- Keep three or four sequences for standing, one seated, one walking and one close-up, and rotate through them.
- Adapt on the day: shorten or reverse a sequence if the light, set or garment makes some positions unusable.
- Note which sequences suit a skirt, a jacket or trousers; garments change what is possible.

## Check
Run a sequence in a mirror and confirm each pose reads cleanly and the transitions do not hide the garment.
