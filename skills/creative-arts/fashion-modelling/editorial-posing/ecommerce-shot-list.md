# Ecommerce shot list

**Context:** e-commerce shoots often capture many looks per day against a standard shot list set by the retailer or brand.

## Typical list (brand specifications vary, so get theirs)
- **Front**, full length and sometimes cropped.
- **Three-quarter** or **side**.
- **Back.**
- **Detail** shots (collar, cuff, pocket, closures, texture).
- **Movement** frame (walking, turning, hem swing), if asked.
- **Alternate styling** (open or closed jacket, sleeves up or down).

## Technique
- Ask for the list at the start of the day and for look-specific changes.
- Hold each position **cleanly** and return to the same marks for consistency.
- Check the garment for creases and drape before each position, not after.
- Keep your face and hair **identical across looks**, except as styling directs.
- Note any special positions a brand requires, such as a standard hand placement.
