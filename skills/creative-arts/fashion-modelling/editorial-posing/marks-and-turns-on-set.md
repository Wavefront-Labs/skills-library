# Marks and turns on set

**Goal:** every image lines up with the last without the photographer re-lighting.

## Technique
- Marks are usually **tape on the floor** for your feet. Learn the foot position and the direction you face on each mark.
- Practise **one clean turn** between marks (usually on the ball of the foot) so the garment stays settled and you do not drift.
- Place both feet **exactly on the mark**. A few centimetres can change distance to camera and focus.
- Keep the **same distance** from backdrop and light; stepping forward shifts exposure and shadow.
- Use a **quick reset** after each position: weight, posture, hands, then face.
- If the mark looks wrong, say so; an assistant can adjust it.

## Check
Compare successive looks: same height in frame, same shadow positions, same foot placement.
