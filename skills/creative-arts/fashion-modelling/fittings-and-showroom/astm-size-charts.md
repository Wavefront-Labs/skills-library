# Astm size charts

**Context:** ASTM International publishes standard tables of body measurements for apparel sizing, including those listed in the coverage spec: ASTM D5585 and D6240. Check which table applies to which group, because the tables cover different groups and are revised.

## How to use them
- **Treat them as a reference,** not a rule. Brands usually develop their own **fit blocks and size charts** with their customer in mind.
- **Compare your measurements** with the relevant table to see where you sit relative to the standard sizes (for example whether you are close to a standard base size).
- **Read the table:** it lists body dimensions for each size (bust, waist, hip and others). Note what each point is and the measurement units.
- **Ask the brand** whether it uses an ASTM table, ISO 8559 or its own chart, and what size it fits on you.
- Clothes labels, vanity sizing and regional differences mean that **the same number can fit differently** between brands.
