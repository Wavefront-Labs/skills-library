# Importing, exporting and organising brushes in Procreate

**Goal:** manage a custom brush library safely. Procreate brushes are `.brush` files (single) and `.brushset` files (a set).

## Import
1. Open the Brush Library and tap **+** (top right) to create a new brush, or the **Import** option in the same area to load a file.
2. Pick the `.brush` or `.brushset` from Files, iCloud Drive or another source. Tapping the file in the Files app or in an email can also open it in Procreate.
3. The brush or set appears in the library. Check any grain or texture bundled with it renders correctly.
4. Only import brushes from sources you trust and whose licence allows use; commercial sets often have personal or commercial licence terms.

## Export
- Swipe left on a **brush** and tap **Share** for a `.brush` file; on a **set** name, swipe left and Share for a `.brushset`.
- Save to Files or a computer. Do this for all custom brushes as a second backup (`creative-arts.visual-art.procreate.gallery-stacks-and-backup`).

## Organise
- Create your own set with **+** at the top of the set list and drag brushes between sets, or long-press and drag.
- Reorder sets by dragging; duplicate a brush by swiping left before editing; delete via swipe left.
- Keep a single "favourites" set at the top for daily brushes.

## Gotchas
- Deleting a set deletes every brush in it; export first.
- Brushes imported from other apps (for example Photoshop `.abr`) need conversion or import support; Procreate's native format is its own, and unconfirmed conversions may lose settings.
- Large sets with many high-resolution grains slow the library.

## Verify
- [ ] An exported `.brushset` re-imports on a second device with the same brushes.
- [ ] The favourites set sits at top and survives a restart.
