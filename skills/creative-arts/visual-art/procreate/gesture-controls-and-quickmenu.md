# Gesture controls and QuickMenu

**Goal:** work in Procreate with minimal menu-diving, following the Procreate
Handbook's Gestures and QuickMenu pages. Gesture names follow recent versions;
check the Handbook if your version differs.

## Core gestures
| Gesture | Action |
|---------|--------|
| Two-finger tap | Undo (hold for rapid undo) |
| Three-finger tap | Redo |
| Pinch / spread | Zoom; quick pinch snaps canvas to fit |
| Two-finger twist | Rotate canvas |
| Three-finger scrub | Clear layer |
| Three-finger swipe down | Copy & Paste menu |
| Four-finger tap | Toggle full-screen interface |
| Touch-and-hold with finger on canvas | Eyedropper (default) |
| Touch-and-hold after a stroke | QuickShape (perfects the shape) |

## Customising (Actions > Prefs > Gesture controls)
- Panels for **Paint, Smudge, Erase, Assisted Drawing, Eyedropper, QuickMenu,
  Full screen, Clear layer, Copy & Paste, Layer select**, and **General**.
- Typical setup:
  - Disable "touch" painting (Paint with finger off) so palms and fingers never paint.
  - Eyedropper on "□ + Apple Pencil" (hold the square button on the sidebar and tap)
    or touch-and-hold with a short delay.
  - QuickMenu on a gesture you will remember (e.g. "□ touch" or a three-finger
    tap if not used).
- Set **delay** times so gestures do not trigger accidentally.

## QuickMenu
- A radial menu of six actions (e.g. new layer, flip canvas horizontally, merge
  down, clear, select, a favourite brush). Long-press a slot to change its action.
- Create multiple QuickMenus for different tasks (sketching, colouring).

## Gotchas
- Accidental clear layer from a three-finger scrub: disable it if it bites you.
- Finger painting enabled: smudges appear from resting hands.

## Verify
- [ ] Undo/redo, zoom, rotate gestures in muscle memory.
- [ ] Eyedropper and QuickMenu assigned to comfortable gestures.
- [ ] Finger painting disabled if using Apple Pencil only.
