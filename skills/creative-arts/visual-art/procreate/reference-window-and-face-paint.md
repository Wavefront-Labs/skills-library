# Reference window and Face tab in Procreate

**Goal:** work from reference without leaving the canvas.

## Steps
1. **Actions > Canvas > Reference** to open the Reference window (Handbook, Canvas section).
2. Choose a tab: **Canvas** (a live copy of the artwork, for checking the whole picture at small size while zoomed in), **Image** (import a photo from the Photos library or Files), or **Face** (a face-oriented reference tab; see below).
3. Drag the window around, resize it with the corner handle, and pinch inside it to zoom the reference.
4. Use the **Eyedropper** by touch-and-holding a colour in the reference to sample it into your colour (check the eyedropper gesture in `creative-arts.visual-art.procreate.eyedropper-and-colour-history`).
5. Tap the window's close or Done control to dismiss it. The reference does not become part of the file layers.

## Face tab
- Intended for face reference and painting on a face model; what it requires (for example a device with a front camera or a depth camera) and the exact behaviour in your Procreate version are unconfirmed here. Read the Handbook entry for Reference before relying on it.

## Gotchas
- Reference images are stored with the artwork's reference but are not layers and may be lost if the file is exported to other formats.
- Copyrighted reference is fine for study but copying it into finished work is a licensing matter.
- On small iPad screens, the floating window covers canvas; park it in a corner.

## Verify
- [ ] The Canvas tab updates live as you paint.
- [ ] A sampled colour from the Image tab matches the reference closely.
