# Procreate palettes and swatches

**Goal:** keep the colours for each project in Procreate palettes you can reuse
and share (Procreate Handbook, Colors: Palettes).

## Creating palettes
1. Colours panel > **Palettes** tab > **+**.
2. Options: **Create new palette** (empty), **New from Camera** (samples colours live
   from the camera), **New from File** / **New from Photos** (extracts a palette from
   an image).
3. Rename by tapping the title. Palettes hold 30 swatches.

## Swatches
- **Add**: choose a colour, tap an empty swatch slot.
- **Delete / set**: touch and hold a swatch for options.
- Reorder by dragging (in the palette's compact or card view).
- Mark a palette **Set as default** so it appears in the compact view of every
  colour mode (bottom of Disc/Classic/Harmony).

## Import / export
- Share a palette (swipe left on it > Share) as a **.swatches** file.
- Import .swatches by opening the file into Procreate (Files app, AirDrop) or
  dragging it in.
- Adobe **.ase** palettes (Swatch Exchange from Illustrator/Photoshop) can be
  imported the same way in recent versions (check your version).

## Use cases
- A project palette per illustration series for consistency.
- A limited palette (see gamut mapping): save only allowed colours.
- Brand palettes via hex values entered in Value mode, then saved as swatches.

## Gotchas
- Palette from photo picks dominant colours, not necessarily the useful ones;
  edit afterwards.
- Swatch colours are stored in the canvas's profile context; sRGB vs P3 canvases can
  look different.

## Verify
- [ ] Project palette created and set as default during the project.
- [ ] Shared/imported palettes open correctly.
