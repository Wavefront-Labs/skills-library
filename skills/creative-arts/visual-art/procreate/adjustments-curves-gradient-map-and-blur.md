# Adjustments in Procreate: curves, gradient map and blur

**Goal:** correct and stylise colour and focus. Open **Adjustments (magic wand)** and pick a tool. Listed items follow the Handbook; names vary by version.

## Applying
- Choose **Layer** to apply to the whole layer, or **Pencil** to apply by painting the effect with the Pencil; slide a finger across the canvas to set the amount.
- Adjustments are **destructive** to the layer pixels, so duplicate the layer first, or apply to a copy and compare.

## Key tools
- **Curves:** an RGB curve plus separate Red, Green and Blue curves, and a Gamma view. Drag points to set contrast: an S shape adds contrast; lift the black point for a faded look.
- **Gradient Map:** maps the tonal range of the layer to a gradient; use a three-stop dark-to-light gradient to give a painting a unified colour mood.
- **Colour Balance, Hue/Saturation/Brightness, Recolor:** shift colours globally or in shadows, midtones and highlights.
- **Blur:** Gaussian, Motion and Perspective. Use Gaussian on a duplicate layer for glow or depth of field, and Motion for speed.

## Workflow
1. Duplicate the layer to be adjusted.
2. Apply Gradient Map and set the layer blend mode and opacity (for example Colour or Soft Light) so it tints rather than replaces.
3. Compare with the original by toggling visibility.

## Gotchas
- Blur on a layer applies to its edges and transparency; fill empty edges first or use a selection.
- Curves destroy data when pushed hard; avoid stacking several strong Curves moves.
- Apply Pencil mode adjustments at moderate pressure; they build up.

## Verify
- [ ] The adjusted layer sits above an untouched duplicate for quick comparison.
- [ ] Tones still show detail in shadows and highlights.
