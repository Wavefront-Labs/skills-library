# Multi-block colour relief registration

Each colour has its own block, so the edition is not fixed in advance (unlike reduction).

## Key block
1. Cut a **key block** with the main line work or darkest structure.
2. All blocks must be **exactly the same size** with square corners (or carry registration marks/kento cut into the same positions).

## Transferring the key to colour blocks
- **Offset (transfer) proof**: ink the key block, print it on a smooth non-absorbent sheet (acetate, mylar or a smooth paper), then immediately place the wet print face down onto a fresh block in the jig and burnish - the image transfers in register.
- Dust the wet offset with talc or chalk to stop smudging.
- Mark on each colour block the areas for that colour; carve away the rest.

## Registration methods
- **Jig with corner stops**: blocks drop into a fixed recess; paper is placed against stops or onto pins.
- **Pin and tab**: tabs taped to paper; registration pins on the jig bed. Very repeatable.
- **Kento** (Japanese): an L-shaped corner notch and a straight side notch cut into each block; paper is laid into these by hand.

## Printing order
- Usually light to dark, key block last (it crisps up edges), or key first if colours are transparent overlays. Proof the sequence on newsprint.
- Overprinting two transparent colours makes a third - plan overlaps deliberately.
- Let oil inks set between colours, or print wet-on-wet only with care.

## Gotchas
- Plywood and lino can move with humidity; keep blocks and paper in the same room for a day.
- Paper that shrinks or stretches between colours misregisters - use a stable paper, or dampen consistently.
- Thin slivers between colours (trapping): make colour areas overlap slightly under the key line.

## Verify
- [ ] Offset proof registers on each colour block.
- [ ] Proof sequence printed on newsprint.
- [ ] Paper and blocks acclimatised.
