# Memory drawing training

**Goal:** draw convincingly from memory and imagination by training recall
systematically. Horace Lecoq de Boisbaudran's *The Training of the Memory in Art*
(1847-1876), which taught Rodin and Fantin-Latour, sets out the method.

## Core cycle
1. **Study** the subject for a fixed time (start with 1-3 minutes), analysing
   actively: proportions, angles, the big shapes, what is unusual.
2. **Hide** it.
3. **Draw** it fully from memory.
4. **Compare** with the original; note specific errors.
5. **Repeat** study with attention on those errors, and draw again.

## Progression
1. Simple 2D shapes and line drawings (a master's contour drawing).
2. Simple objects: a cup, a shoe, a chair.
3. Faces and features from photos or casts.
4. Full figures in poses; then models who move.
5. Scenes: draw at home the street you sketched that day.

## Active looking strategies
- Name proportions ("the head fits 2.5 times in the torso").
- Remember the silhouette and the light-shadow shape, not details.
- Make a quick mental gesture line; trace it in the air.
- Use your own drawing vocabulary (construction boxes, cylinders) as storage.

## Daily use
- After a life drawing session, draw one pose from memory at home.
- Gurney recommends watching people and drawing them later in the sketchbook.

## Gotchas
- Passive staring: memory needs analysis during study.
- Skipping comparison: you will reinforce errors.
- Jumping to complex scenes too early; build up gradually.

## Verify
- [ ] Each memory drawing is compared and errors are written down.
- [ ] Error notes shorten over successive attempts.
