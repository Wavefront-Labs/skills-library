# Premixing colour strings

**Goal:** before painting, mix rows ("strings") of a colour in even value steps,
so painting becomes a choice of value and temperature rather than a new mixture
for every stroke. Systematised by Frank Reilly (Art Students League) from
Munsell; still taught at some ateliers.

## A string
- A single hue/chroma family in **value steps**, e.g. 9 steps from value 2 (dark)
  to value 9 (light), each step visually equal.
- Common strings: a neutral grey string (black + white), a flesh string
  (red/yellow/white-based), and a shadow string (flesh string greyed or cooled),
  plus strings for the background and costume.

## Mixing a string
1. Mix the **middle value** (5) first, matching hue and chroma to the target
   (check against a value scale with a palette knife).
2. Mix the lightest and darkest needed steps.
3. Fill the steps between by combining neighbours, checking each against the value
   scale: equal visual steps.
4. Lay them in a row on the palette, light to dark; label if needed.
5. Make enough for the session; oil strings keep a day or two (longer under cling
   film or in the freezer).

## Painting with strings
- Each stroke picks a value from the string; temperature shifts come from mixing
  adjacent strings (a touch of the shadow string to cool a halftone).
- Strings enforce value control and harmony; deviations should be deliberate.

## Gotchas
- Steps unequal: transitions on the form jump.
- Strings too saturated or uniform: painting looks mechanical. Allow some variation
  from them as you go.
- Lightening with white alone changes hue and chroma: compensate with a touch of
  the original colour or a warmer pigment.

## Verify
- [ ] Each string steps evenly in value against a scale.
- [ ] The middle value matches the target colour.
