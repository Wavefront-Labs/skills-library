# Release agents and mould keys

## Release by material pair
| Mould | Cast / next layer | Release |
|---|---|---|
| Plaster | Plaster | Soft soap (potash soap) worked in, sponged off, repeated until it beads; or a thin oil/stearine mix |
| Plaster | Resin, wax | Seal plaster first (shellac, then wax or PVA), then release |
| Silicone | Silicone (second mould half) | **Always** release: petroleum jelly thinned in mineral spirits, or a silicone-to-silicone release (e.g. Smooth-On Ease Release 205 / Mann 200 depending on maker guidance). Silicone bonds to silicone otherwise |
| Silicone | Resin, plaster, wax, concrete | Usually none; a light release extends mould life with polyurethane and polyester resins |
| Fibreglass / GRP mould | Polyester or epoxy | Paste wax (multiple buffed coats) then PVA film |
| Urethane rubber | Most things | Release required (urethane sticks to much) |

## Parting lines
- Follow the **high point** of the form (the widest outline when viewed from the pull direction) so neither side has undercuts.
- On figures, run seams over shoulders, along the side of the arm, behind ears - where cleanup won't show.
- Fewer pieces = fewer seams, but each piece must pull straight off.

## Keys
- **Natches/keys** are bumps and matching hollows on the mating face: cut cone-shaped hollows with a coin or key-cutter in plaster, or press marbles into clay walls for silicone.
- Asymmetric pattern (or a "this way up" shape) so pieces can only go back one way.
- For glove moulds, external rubber keys lock the rubber to the jacket.
- Pour spouts and vents go at the lowest and highest points of the cast orientation.

## Gotchas
- **Wax and petroleum jelly** soften fine detail if applied heavily - thin it and buff.
- **Silicone-based release sprays** can stop paint adhering to the cast later; wash casts with detergent or use a paintable release.
- **Mixing release chemistries** (e.g. silicone spray on a platinum mould) can cause inhibition.

## Verify
- [ ] Release chosen for this specific mould/cast pair, and tested on scrap.
- [ ] Pieces register with no rocking.
- [ ] Spout and vents placed for the pour orientation.
