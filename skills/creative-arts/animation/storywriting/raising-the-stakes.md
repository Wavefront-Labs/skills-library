# Raising stakes

Goal: the audience knows what will be lost if the hero fails, and it matters to them.

## 1. Define the stakes (Coats, rule 16)
- Ask: What happens if the hero doesn't succeed? Stack the odds against them.
- Personal stakes beat abstract ones: "the world ends" matters less than "she loses her brother".
  Tie global stakes to a personal loss.
- Stakes must be shown, not only said: show what the hero has, then threaten it.

## 2. Raising them
| Method | Example |
|---|---|
| Add a clock | it must be done before sunrise |
| Increase cost | failure now also hurts a friend |
| Remove resources | allies leave, tools break |
| Raise from personal to public | the secret becomes known to everyone |
| Make it irreversible | there's no going back |
| Internal stakes | success requires facing the flaw |
Raise at the midpoint and at all-is-lost at minimum.

## 3. Credibility
- Stakes the audience believes will happen: show the consequence happening to someone else first.
- Avoid repeating the same threat at the same level.

## Verify
- [ ] Stakes written as "if X fails, Y is lost".
- [ ] Personal stakes linked to any global stakes.
- [ ] Stakes rise at the midpoint and the low point.
