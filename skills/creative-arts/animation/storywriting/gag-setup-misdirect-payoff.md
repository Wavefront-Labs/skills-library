# Gag setup, misdirect and payoff

Goal: visual gags that land because the audience is led to expect one thing and gets another.

## 1. Anatomy
1. **Setup**: establish the situation and an expectation (the character reaches for the door handle).
2. **Misdirect**: guide attention or expectation one way (we expect it to be locked).
3. **Payoff**: the unexpected but logical result (the whole door falls off).
4. **Reaction**: the character's response often gets the second laugh.

## 2. Patterns
- **Rule of three**: establish, confirm, break (two expected results, the third surprises).
- **Reversal**: the opposite of the expected happens.
- **Exaggeration**: the result is far bigger than expected.
- **Literalisation**: a figure of speech taken literally.
- **Delayed reaction**: the character doesn't notice at first.

## 3. Disney story-gag practice (Illusion of Life)
- Gags should grow out of character and situation; random gags stop the story.
- Story artists pitched gags on boards; the best were kept if they supported the story's mood.

## 4. Boarding gags
- Clear staging: the audience must see the setup clearly before the payoff.
- One idea per panel; hold the payoff long enough; timing beats in the animatic.

## Verify
- [ ] Setup clear before the payoff.
- [ ] Payoff surprising but logical.
- [ ] Reaction beat considered.
