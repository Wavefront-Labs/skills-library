# Scene beats and objectives

Goal: scenes that are active, with each moment a change in behaviour.

## 1. Objectives
- Every character in a scene wants something from it (objective), linked to their overall want.
- Objectives must clash for conflict.
- Write them as active verbs: "to get Dad to say yes", "to stop her from leaving".

## 2. Beats
- A beat (McKee) is an exchange of behaviour in action/reaction. Each new tactic = a new beat.
- Tactics escalate: ask, charm, bargain, guilt, threaten, plead.
- When a tactic fails, the character changes tactic (a new beat). Beats build toward the turning point.

## 3. Writing method
1. Write the scene's value and turning point.
2. Write each character's objective.
3. List beats: tactic A -> reaction -> tactic B ... -> turn.
4. Make sure each beat is different; cut repeated beats.

## 4. Uses downstream
- Board artists and animators stage beats as acting changes; mark beat changes in the script.
- Timing: beat count gives a sense of scene length.

## Verify
- [ ] Objectives written as active verbs.
- [ ] Beat list shows escalating tactics.
- [ ] Turning point reached through beats.
