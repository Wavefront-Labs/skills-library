# Wordless storytelling

Goal: a story that reads in any language because every beat is shown.

## 1. Write for the eye
- Write action lines as visible events, not thoughts: not "she misses her father" but "she holds his hat,
  sets it on the empty chair".
- Each beat: a clear action and a clear reaction.

## 2. Tools
| Tool | Use |
|---|---|
| Pantomime | broad, clear poses and gestures; one idea per pose |
| Props | objects carry meaning (a photo, a gift, an empty chair) |
| Staging | silhouettes and composition clarify relationships |
| Repetition with variation | routine shown, then changed |
| Sound and music | emotion, timing, comedy beats; sound effects as dialogue |
| Graphic signs | notes, drawings, screens (sparingly) |

## 3. Structure
- Keep stories simple; one want, few characters.
- Establish the routine (the "every day") so changes are readable.
- Use reaction shots to tell the audience what to feel.

## 4. Test
- Watch the animatic with the sound off: can viewers retell the story? Then with music only.

## Verify
- [ ] Every story beat visible as action.
- [ ] Animatic understood with sound off.
- [ ] Props and repetition carry key meaning.
