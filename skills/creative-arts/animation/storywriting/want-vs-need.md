# Want vs need

Goal: a character arc with a built-in engine: chasing the want forces the character to face the need.

## 1. Definitions
- **Want**: the conscious, external, visible goal - win the race, get home, be accepted by the group.
  It drives the plot and gives scenes objectives.
- **Need**: what the character must learn or become to be whole - trust others, accept loss, value
  themselves. Usually unconscious at the start; it carries the theme.

## 2. Put them in conflict
- The best arcs make the want and need pull against each other: pursuing the want in the old way makes the
  need harder to reach.
- Typical endings:
  - Gets the need, gives up the want (sacrifice; most family animation).
  - Gets both, but the want in a changed form.
  - Gets the want, loses the need (tragic or ironic ending).

## 3. Map it to structure
| Beat | Want/need |
|---|---|
| Setup | want stated; need hinted (theme stated) |
| Act two | chasing the want; B story presses the need |
| All is lost | the want fails or is hollow |
| Finale | the character acts from the need |

## 4. Write it down
- "[Character] wants [external goal] but needs [inner change]; these conflict because [reason]."

## Verify
- [ ] Want is visible and could be photographed.
- [ ] Need is internal and tied to the theme.
- [ ] The sentence shows how they conflict.
- [ ] The climax shows which one wins.
