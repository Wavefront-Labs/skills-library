# Story spine exercise

Goal: a fast skeleton that tests whether a story has cause and effect, used for brainstorming and diagnosing.

## 1. The spine (Kenn Adams; Pixar rule 4)
- **Once upon a time** ... (the world and hero)
- **Every day** ... (the routine, the status quo)
- **One day** ... (the event that breaks the routine)
- **Because of that** ... (consequence)
- **Because of that** ... (consequence - repeat as needed)
- **Until finally** ... (the climax)
- **And ever since then** ... (the new normal; the moral)

## 2. How to use it
- Write a spine in five minutes per idea; generate several for one premise and compare.
- Keep "because of that" strictly causal; if a line works with "and then", the chain is weak.
- Use it for each sequence or episode too.
- In groups, take turns adding lines (improv origin); it trains causal thinking.

## 3. Diagnose with it
- Can you write the spine of your current draft? Missing "every day" = no status quo; missing "ever since then"
  = no change.
- Compare the spine's "every day" to its "ever since then": they should differ.

## Verify
- [ ] All spine lines written.
- [ ] Each "because of that" is causal.
- [ ] "Ever since then" shows change from "every day".
