# A / B / C plot episode structure

Goal: an episode with a main story and lighter stories that support it and pace the half hour.

## 1. Proportions (22-minute episode)
| Plot | Share of beats | Carrier |
|---|---|---|
| A | about 50-60% | the lead; the episode's main problem |
| B | about 25-35% | a supporting lead; theme echo or contrast |
| C (runner) | 3-6 short beats | a minor character or running gag |
11-minute episodes usually have an A plot only, sometimes a small runner.

## 2. Intercutting
- Alternate scenes so each plot rests while the other advances; enter each scene late.
- Act breaks land on A-plot turns; B plot may also turn at the same break for extra punch.
- Avoid two scenes in a row of the B plot unless it's climaxing.

## 3. Thematic link
- B and C plots echo or argue the theme of the A plot from a different angle (same lesson in a different
  context, or the opposite outcome).
- Best endings collide plots: the B or C plot's payoff resolves or complicates the A plot.

## 4. Breaking method
- Break the A plot first on the board, then the B plot, then weave; mark each scene card with A/B/C.

## Verify
- [ ] Beat share roughly matches the table.
- [ ] Plots alternate with no long gaps.
- [ ] Plots linked thematically and ideally collide.
