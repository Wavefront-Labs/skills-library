# Economy of setup in shorts

Goal: the audience understands who, where and what is wanted within seconds, so the short can spend its time
on the story.

## 1. Tools
| Need | Fast way |
|---|---|
| Who the character is | design, costume, a defining action (the want in a gesture) |
| Where/when | one establishing shot with a specific detail |
| The want | show the character trying for it in the first action |
| The rules of the world | demonstrate one rule visually, early |
| Mood/genre | colour, music, first image |

## 2. Shortcuts
- **Archetypes**: an old man, a lonely robot, a lost child - understood instantly; give one twist.
- **Show the routine** in a 3-5 shot montage when "every day" matters.
- **Combine** introductions: the first shot sets world, character and want at once.

## 3. Cut ruthlessly
- Remove any shot that doesn't set up something paid off later.
- No title cards explaining backstory unless they are part of the style.

## 4. Test
- Show the first 30 seconds to someone; ask who the character is and what they want.

## Verify
- [ ] Want visible within the first 30-45 seconds.
- [ ] Every setup shot pays off later.
- [ ] Cold viewer can name the want.
