# Scene story values and turning points

Goal: every scene changes something that matters, so no scene is a non-event.

## 1. Story values (McKee)
- A **value** is a binary human quality that can change charge: alive/dead, love/hate, freedom/slavery,
  truth/lie, courage/cowardice, loyalty/betrayal, wisdom/stupidity, hope/despair.
- Each scene is a unit of change: the value-charge at the start differs from the end (+ to -, - to +,
  + to ++, - to --).
- A scene where the charge does not change is a **non-event**: cut it or rewrite it.

## 2. Turning points
- The change happens at a turning point, through **action** (someone does something) or **revelation**
  (something is learned).
- Prefer turning points that combine both and surprise (the gap between expectation and result).
- Turns create surprise, curiosity, insight and a new direction.

## 3. Scene analysis method
1. Identify the value(s) at stake.
2. Note the charge at entry and exit.
3. Find the turning point and how it happens.
4. Break the scene into beats (action/reaction pairs) and check they build toward the turn.

## 4. Sequence and act level
- Scenes build sequences (moderate change), sequences build acts (major reversal). Alternate charges
  across scenes to avoid monotony (+ + + reads flat).

## Verify
- [ ] Each scene has a named value and entry/exit charge that differ.
- [ ] Turning point identified as action or revelation.
- [ ] No three consecutive scenes with the same charge movement.
