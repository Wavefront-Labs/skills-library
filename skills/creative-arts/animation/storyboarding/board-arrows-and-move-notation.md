# Board arrows and move notation

Goal: panels that any layout artist, animator or editor can read without asking.

## Arrows
- **Character/object action arrows**: drawn inside the panel along the path of motion, usually
  flat, filled or outlined arrows, showing direction (and with a curve for arcs). Keep them
  outside the character's silhouette.
- **Camera move arrows**: drawn from the start frame rectangle to the end frame rectangle,
  often in a distinct color (red) or as thin arrows from the corners.
- **3D arrows** (drawn in perspective) show movement toward or away from camera.

## Frame rectangles
- For pans and trucks, draw the full area with start and end frame boxes, labelled "A" and "B"
  or "start/end".
- For a move within a single panel, the arrow connects the boxes.

## Common text shorthand
| Abbreviation | Meaning |
|---|---|
| CUT / CUT TO | hard cut |
| DISS / X-DISS | dissolve |
| FI / FO | fade in / fade out |
| PAN L/R, TILT U/D | camera rotation |
| TRUCK IN/OUT, DOLLY | camera move |
| OS / O.S. | off-screen (dialogue or sound) |
| VO / V.O. | voice-over |
| BG / FG / MG / OL / UL | background, foreground, midground, overlay, underlay |
| SFX | sound effect |
| CONT'D | action continues into next panel |

## Placement
- Dialogue and action notes in the fields below the panel (Storyboard Pro: Action Notes,
  Dialogue, Notes fields per panel).
- Arrows on a separate layer so revisions can toggle them.

## Failure modes
- Same arrow style for camera and character moves - layout cannot tell them apart.
- Arrows covering faces.
- Unlabelled frame rectangles.

## Verify
- [ ] Camera arrows and action arrows visually distinct.
- [ ] Every move has start/end frames.
- [ ] Shorthand consistent with the production's convention sheet.
