# Match cuts

Goal: a cut that joins two different shots through a shared element so the transition feels
inevitable and adds meaning (2001's bone-to-satellite cut is the textbook example).

## Kinds
1. **Graphic match**: similar shape, position and size in frame (a round clock face -> the full moon).
2. **Action/movement match**: a motion begins in one shot and continues in another place/time
   (a door slammed -> a different door opening).
3. **Sound match**: the same or similar sound bridges (a scream -> a train whistle).
4. **Idea/metaphorical match**: two images linked by meaning (a character's tears -> rain).

## Boarding method
1. Identify the transition need (time jump, location change, thematic link).
2. Choose the matching element and place it at the **same screen position and size** in both
   panels (overlay the two panels to check).
3. Match motion direction and speed for action matches.
4. Note "MATCH CUT" with the element named.

## Uses in animation
- Animation can design matches precisely because everything is drawn - common in montages and
  time-passage sequences (Up's marriage montage uses graphic matches).

## Failure modes
- Element in different screen positions: the match does not register.
- Match cut used for a trivial transition (feels like a gimmick).
- Too many in a row.

## Verify
- [ ] Overlaid panels: matching element aligns in position and size.
- [ ] Motion direction continues across action matches.
- [ ] The match carries meaning or bridges a jump.
