# On-model enough for boards

Goal: the right level of drawing finish for the production stage - recognisable and readable,
never slower than needed.

## Levels
| Stage | On-model requirement |
|---|---|
| Feature story (pitch boards) | loose, gestural; character identifiable; acting clarity over likeness |
| Feature reels (revised) | cleaner, but still rough; key expressions accurate |
| TV boards (especially 2D, overseas production) | close to on-model, clean line, poses usable as layout and key references |
| Previs/animatic for CG | moderate; poses and staging matter, details do not |

## How to stay recognisable fast
- Learn each character's **key identifiers**: head shape, hair silhouette, eye spacing, size
  relationship, costume shape.
- Keep a model sheet pinned beside the boarding canvas.
- Maintain **size relationships** between characters (a line-up reference).
- Draw expressions from the character's own expression sheet range.

## TV specifics
- Boards often go to overseas studios as the main layout reference - scale, perspective, and
  poses must be usable; accurate character size and props matter.
- Revisionists clean up panels to the show's standard.

## Failure modes
- Feature story artists over-rendering (slower iteration, emotional attachment to panels).
- TV boards too loose for the overseas studio to interpret.
- Characters changing size between panels.

## Verify
- [ ] Finish level matches the stage and production type.
- [ ] Characters identifiable at a glance in every panel.
- [ ] Size relationships consistent.
