# Sequence planning and shot count

Goal: board a sequence that is producible - the shot count and complexity match the runtime
and budget.

## Numbers to know
- **Average shot length (ASL)**: modern features often 3-6 s; fast action lower (2-3 s); slow drama
  higher. TV animation episodes often run ~3-5 s ASL.
- Shot count = runtime / ASL. A 3-minute sequence at 4 s ASL is about 45 shots.
- Each new setup (camera angle + BG) costs layout, BG painting/modeling, lighting.

## Method
1. Get the sequence's target runtime (from script pages and reel).
2. Estimate shot count from the intended pace.
3. Plan **setups**: list the camera setups; reuse them for multiple shots (a dialogue scene may be
   3-4 setups covering 20 shots).
4. Flag expensive elements: crowds, FX, water, complex camera moves, new locations.
5. Board within the plan; if the board exceeds it, decide with the director what to simplify.

## Trade-offs
- Fewer, longer shots with more acting vs more shots with cutting.
- New location vs reusing a set.
- Action set pieces budgeted separately.

## Failure modes
- Boards that need twice the budgeted shots.
- Every shot a new setup.
- Discovering expensive FX late.

## Verify
- [ ] Planned shot count and actual board shot count within ~10-20 %.
- [ ] Setup list exists and is reused.
- [ ] Expensive elements flagged to production.
