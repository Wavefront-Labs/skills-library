# Visual intensity graph

Goal: a one-page plan connecting story structure to visual structure. Block's method: graph
story intensity over time, then plan each visual component's contrast/affinity to follow it.

## Step 1 - story graph
- X axis: time (sequences or minutes). Y axis: intensity (0-10).
- Mark exposition, conflict build, climax, resolution. Most stories rise in a sawtooth
  toward a climax near the end.

## Step 2 - component graphs
Under the story graph, add rows for each component:
| Component | Low intensity (affinity) | High intensity (contrast) |
|---|---|---|
| Space | flat | deep |
| Line/shape | horizontals, circles | diagonals, triangles |
| Tone | low contrast | high contrast |
| Color | narrow palette, desaturated | complementary contrast, saturated |
| Movement | continuous direction, slow | opposing, fast, toward camera |
| Rhythm | regular, slow cutting | irregular, fast cutting |

## Step 3 - apply
- Board and color script against the graph.
- Save maximum contrast for the climax; deliberately reduce before it so the rise is felt.
- Some components can run counter to the story for irony (a bright, calm-looking scene of horror).

## Failure modes
- Everything at maximum all the time.
- Visual climax in the wrong place (a spectacular midpoint, a flat ending).
- Graph made but not shared with layout, color and lighting.

## Verify
- [ ] Story and component graphs exist on one page.
- [ ] Boards and color script follow the graph.
- [ ] Peak visual contrast coincides with the story climax.
