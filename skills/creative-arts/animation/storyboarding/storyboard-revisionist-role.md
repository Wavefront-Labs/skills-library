# Storyboard revisionist role

Goal: apply notes to existing boards quickly and invisibly. Storyboard revisionist is a
distinct Animation Guild classification and a common entry route into story.

## Tasks
- Implement director, showrunner, network/legal (standards and practices) notes.
- Redraw panels to fix continuity, staging and model issues.
- Add panels for script changes after recording.
- Clean up rough panels to the show's standard.
- Update dialogue to match the final record.

## Method
1. Read every note; map each to panel numbers before drawing.
2. Match the original artist's drawing style, staging conventions and BG treatment.
3. Check continuity before and after each changed panel.
4. Mark changed panels (a colored dot, a "REV" tag, or revision date in the panel field) so
   editorial and production see what changed.
5. Update the animatic or flag changes to the editor.

## Standards and practices notes
- Common categories: imitable dangerous behaviour, violence, product logos, unsafe practices
  (e.g. seatbelts, helmets in kids' shows). Follow the network's written guidelines.

## Failure modes
- Fixing a note on one panel and breaking continuity in the next.
- Style mismatch that makes revised panels obvious.
- Unmarked changes that editorial misses.

## Verify
- [ ] Every note has a corresponding change or a logged reason for no change.
- [ ] Revised panels marked.
- [ ] Continuity checked around each change.
