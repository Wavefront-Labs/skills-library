# Panel value grouping

Goal: panels that read instantly because values are organised into a few large shapes, not
scattered tones. Framed Ink devotes its central chapters to this.

## Method
1. **Limit values**: 3 (light, mid, dark) for most boards, up to 4-5 for key moments.
2. **Group**: connect areas of the same value into large shapes (the whole background dark, the
   characters mid, the window light).
3. **Separate the subject**: put the subject in a value that contrasts with what is behind it -
   dark against light (silhouette) or light against dark (spotlight).
4. **Light logic**: decide the light source and let shadows unify shapes rather than outline them.
5. **Mood**: low-key (mostly dark) for menace and drama; high-key (mostly light) for comedy and openness.

## Tools in boarding software
- Use a few fixed grey swatches (e.g. 20 %, 50 %, 80 %) rather than picking new greys per panel.
- Separate layers for line, flat values and shadows so revisions are fast.

## Failure modes
- Every object outlined with its own mid-grey: muddy, nothing reads.
- Subject the same value as the background.
- Value schemes that change randomly panel to panel within one scene.

## Verify
- [ ] Panel converted to 3 values still reads.
- [ ] Subject contrasts with its immediate background.
- [ ] Value scheme consistent within a scene, changing with mood across scenes.
