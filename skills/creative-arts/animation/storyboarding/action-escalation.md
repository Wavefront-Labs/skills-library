# Action escalation

Goal: action that builds instead of repeating. An action sequence is a mini-story with
progressive complications (McKee) and a rising visual intensity curve (Block).

## Levers
1. **Stakes**: what can be lost increases (personal safety -> a friend -> the city).
2. **Complications**: each section adds a new problem (weapon lost, injury, time limit).
3. **Environment**: the space becomes more dangerous or confined.
4. **Visual intensity**: shorter shots, more contrast, more diagonals, closer framing, more camera
   movement (Block's intensity components).
5. **Character**: the hero must use a new skill or make a choice - the climax tests character.

## Structure
- Setup (goal and threat clear) -> first engagement -> complication -> reversal (hero loses
  ground) -> lowest point -> turn (new idea/choice) -> climax -> resolution beat.
- Pauses between rises let intensity climb again from a lower point (a sawtooth curve).

## Method
1. Write the sequence's question (Will they escape?).
2. List complications in increasing order of difficulty.
3. Plot intensity per beat (a quick graph) and board to match.

## Failure modes
- Flat intensity (non-stop action at one level) - the audience tires.
- Climax smaller than earlier set-pieces.
- Complications unrelated to character.

## Verify
- [ ] Intensity graph rises overall with pauses.
- [ ] Each section adds a new complication.
- [ ] Climax resolves the sequence's question through a character choice.
