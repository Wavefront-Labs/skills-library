# Zoom vs dolly

Goal: know which move you are asking for, because they look and feel different.

## Differences
| | Zoom | Dolly |
|---|---|---|
| What changes | focal length | camera position |
| Perspective | unchanged (just magnified) | changes; near objects grow faster than far |
| Parallax | none | yes |
| Feel | observational, artificial, TV/documentary, "crash zoom" comedy | immersive, physical, cinematic |

In flat 2D, a "truck" is technically a zoom (no parallax) unless multiplane layers are used.

## Dolly zoom (vertigo / "zolly")
- Dolly in while zooming out (or the reverse) so the subject stays the same size while the
  background stretches or compresses.
- Dolly in + zoom out: background appears to recede - realisation, dread (Jaws beach shot).
- Dolly out + zoom in: background looms closer - vertigo, being overwhelmed.
- CG: animate camera distance and focal length together so subject size is constant:
  subject size ~ focal_length / distance; keep focal_length / distance constant.

## Boarding notes
- Write "ZOOM" or "DOLLY" explicitly; never just "move in".
- For dolly zoom, draw start and end frames with the subject the same size and the background
  changed.

## Failure modes
- Asking for a zoom when you want immersive movement (feels cheap).
- Dolly zoom used casually - it is a strong effect for a single moment.
- Crash zooms in a grounded drama (tone break).

## Verify
- [ ] Move type stated in the panel notes.
- [ ] Dolly zoom frames show constant subject size.
- [ ] Move feel matches the scene's tone.
