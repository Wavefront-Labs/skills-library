# Frame entrances and exits

Goal: movement between shots that is continuous and readable.

## Rules
1. **Direction continuity**: a character exiting frame right enters the next shot from frame
   left (moving the same screen direction).
2. **Clean frame options**: starting a shot on an empty frame and letting the character enter, or
   holding after they exit, gives editorial flexibility and compresses time (they can appear
   elsewhere in the next shot).
3. **Exit completely** before cutting if you will cut to them in a different place; cut while
   they are still in frame if the next shot continues the same motion (cut on action).
4. **Depth entrances**: entering from behind camera (into the foreground) or from deep
   background - strong for reveals and threats.
5. **Entrances as reveals**: time the entrance on a beat (a character interrupts the line).

## Boarding
- Show direction arrows; note "ENTERS L", "EXITS R", "CLEAN FRAME".
- Show the first panel with the empty frame if it is part of the shot.

## Failure modes
- Exit right, enter right - direction flip.
- Cutting away mid-exit, then showing the character elsewhere immediately (jarring).
- Entrances on unimportant moments that steal focus.

## Verify
- [ ] Screen direction consistent across exits/entrances.
- [ ] Clean frames noted where needed.
- [ ] Entrance timing supports the scene's beats.
