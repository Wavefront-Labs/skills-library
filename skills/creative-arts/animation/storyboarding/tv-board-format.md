# TV board format

Goal: episode boards that work as the primary production document for layout and animation,
often executed by a different (overseas) studio.

## Page and panel format
- Usually 3 panels per page (landscape) or 6-8 per page (portrait sheets), with fields below
  each panel: Action notes, Dialogue, Slug/notes (camera, SFX, timing).
- Header: show, episode number and title, page number, sequence/scene.
- Panels in the show's aspect ratio with safe areas.

## What the production studio needs
1. **Clear poses** at key moments (they will key from them).
2. **BG callouts**: which BG (new or reuse with ID), camera framing, pans with start/end.
3. **Props and FX** indicated and named (consistent with the show's design lists).
4. **Character sizes** correct relative to BG.
5. **Mouth/expression cues** for key acting.
6. **Camera notes**: pans, trucks, shakes, transitions, with timing hints.

## Process context
- TV boards often go thumbnail -> rough -> clean, with director/showrunner passes; then an
  animatic for timing; then a "sheet timing" pass and shipping.
- Revisionists handle notes after the main board artist moves on.

## Delivery checklist
- Every scene and panel numbered; dialogue matches the latest script/record.
- New designs flagged (characters, props, BGs that need design).
- Files exported in the format the studio requests (PDF board + per-panel images + project file).

## Failure modes
- Missing BG callouts - the studio invents BGs.
- Dialogue in boards out of date with the record.
- Unclear camera moves.

## Verify
- [ ] Every panel has action/dialogue/notes completed where needed.
- [ ] BG and new-design callouts complete.
- [ ] Dialogue matches the recorded script.
