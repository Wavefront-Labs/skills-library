# Dissolves, wipes and fades

Goal: use transitions as punctuation - each implies something different about time and tone.

## Meanings
| Transition | Implies | Typical length at 24 fps |
|---|---|---|
| Cut | continuous or immediate | 0 |
| Dissolve | time passing, dreamy link, memory | 12-48 frames |
| Fade out/in (to black) | end of a section, big time jump | 12-36 frames each |
| Fade to white | death, revelation, dream | 12-36 |
| Wipe | playful jump, retro style (Star Wars) | 8-24 |
| Iris in/out | cartoon ending, focus on a detail | 12-24 |

## Boarding
- Draw both panels (outgoing and incoming) and mark "DISS" (or "X-DISS"), "FO/FI", "WIPE L-R"
  between them, with duration.
- Design the two images for the dissolve: the overlap is visible for its whole length, so
  compositions should not clash (a face dissolving into a landscape where the eyes sit on
  something meaningful).
- For wipes, specify direction and edge (soft/hard, shaped).

## Animation timing
- Both shots need extra frames (handles) covering the dissolve's length.
- A slow dissolve over animation costs double animation for that length.

## Failure modes
- Dissolves between shots in the same continuous time (confusing).
- Overusing wipes or irises in a tonally grounded film.
- Forgetting handles - editorial cannot make the dissolve.

## Verify
- [ ] Each transition matches its intended meaning.
- [ ] Durations noted.
- [ ] Animation handles planned for overlaps.
