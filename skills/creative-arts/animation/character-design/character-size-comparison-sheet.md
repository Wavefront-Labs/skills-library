# Character size comparison sheet

Goal: one reference that settles "how big is X next to Y" for every department.

## Contents
- All principal characters standing in neutral pose, front or 3/4, on one ground line.
- Horizontal height lines across the sheet every head unit of a reference character
  (or in real units: feet/metres).
- Key props and a door/chair at scale, so layouts can check fit.
- Optional second row: characters in their most common pose (sitting, on all fours) if that
  changes relative height.

## Method
1. Choose the reference character (usually the lead) and its height in real units.
2. Scale every other character from their turnaround to that unit; do not eyeball.
3. Place on one baseline with even spacing; label name and height.
4. Draw height lines and the reference prop.
5. Check eyelines: who looks up at whom in a two-shot? Note the angles.
6. Version it and pin it in the layout and animation briefs; update when a design changes.

## Failure modes
- Scaling from different drawings with inconsistent poses (one slouched, one upright).
- Leaving out non-human characters and props, which drift worst.
- Not updating after redesigns; layouts follow the stale sheet.

## Verify
- [ ] Every character measured from its turnaround.
- [ ] Height lines and a scale prop present.
- [ ] Sheet version matches current model sheets.
