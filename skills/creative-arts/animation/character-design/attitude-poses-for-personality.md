# Attitude poses for personality

Goal: a sheet of 6-10 poses showing how this character stands, sits and gestures when
nothing special is happening, so every animator acts them the same way.

## What goes on the sheet
- **Default stance**: weight distribution, foot placement, shoulder set, head tilt.
- **Habitual gestures**: hands in pockets, arms folded, finger-wagging, hair twirl.
- **Emotional extremes in body form**: confident vs defeated version of the stance.
- **Signature move**: the one gesture fans would imitate.
- **Contrasts**: how they react differently from another character in the same situation.

## Method
1. List 5 adjectives for the character; pick body-language signals for each (open vs
   closed posture, chest forward vs back, wide vs narrow stance).
2. Draw the default stance at 3/4 with a clear line of action.
3. Draw gestures as thumbnails first; keep the 6-10 strongest.
4. Label each pose with the attitude it shows ("bluffing", "secretly scared").
5. Pin the sheet alongside the turnaround; animators reference it in blocking.

## Failure modes
- Attitude sheet that is just generic action poses (run, jump) - says nothing about who they are.
- Default stance symmetrical and neutral.
- Poses contradicting the written personality.

## Verify
- [ ] Every pose labelled with an attitude.
- [ ] Default stance has asymmetry and weight.
- [ ] Cold viewer guesses the adjectives from the sheet.
