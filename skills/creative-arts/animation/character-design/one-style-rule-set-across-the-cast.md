# One style rule set across the cast

Goal: characters by different designers that look like they belong in the same frame.

## What the rules cover
- **Eyes**: construction (dot, oval with pupil, anime highlights), lash rules, highlight shape.
- **Hands**: number of fingers, knuckle treatment, nail detail or none.
- **Line**: weight range, taper, inner-line vs outline weight, line colour.
- **Shape vocabulary**: corner radius, how angular the most angular character may be.
- **Proportion range**: min/max head count across the cast.
- **Detail density**: max number of folds, accessories, patterns.
- **Colour**: saturation ceiling, shadow treatment (one tone, two tones), skin palette.

## Method
1. Extract rules from the lead's approved design: write each as a measurable sentence
   ("eyes are vertical ovals, pupil 40% of eye height, one round highlight upper left").
2. Put rules and do/don't examples on one style page.
3. Redraw every supporting character against the page; mark violations.
4. Allow deliberate exceptions only with a story reason (an alien drawn in another style).
5. Re-run the check when new characters are added mid-series.

## Failure modes
- Rules stated as adjectives ("appealing", "clean") instead of measurable traits.
- A guest designer's character with five-finger realistic hands in a four-finger show.
- Detail creep in late-added characters.

## Verify
- [ ] Rules page exists with measurable rules.
- [ ] Every cast member checked and violations resolved.
- [ ] Exceptions documented with their reason.
