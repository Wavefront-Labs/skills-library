# Exaggerating proportions for personality

Goal: proportion that tells the audience who someone is before they move. Caricature
principle: find the defining trait and push it; normalise the rest.

## Trait to proportion mappings
| Trait | Push |
|---|---|
| Strength, bully | huge chest/shoulders, small head, short legs |
| Intellect, nerd | large cranium, thin neck, narrow shoulders |
| Greed, gluttony | big belly or jaw, small eyes |
| Nobility, arrogance | long neck, long nose, upright tall torso |
| Timidity | small body, big eyes, hunched narrow shoulders |
| Speed | long legs, light upper body |

## Method
1. Write the trait in one word.
2. Draw a neutral version of the character at the show canon.
3. Produce 4-6 variants pushing different proportions by 25%, 50%, 100%.
4. Line them up and pick the one that reads the trait fastest to a cold viewer.
5. Pull back any second exaggeration; two competing pushes look like errors.
6. Check that the exaggeration survives the turnaround (big chin in profile, big belly
   in front view).

## Failure modes
- Exaggerating everything: no hierarchy, chaos.
- Stereotypes that read as offensive caricature of real groups; exaggerate personality,
  not ethnicity.
- Push only visible in one angle.

## Verify
- [ ] One dominant exaggeration tied to a written trait.
- [ ] Cold viewer names the trait from the silhouette.
- [ ] Exaggeration holds in all turnaround views.
