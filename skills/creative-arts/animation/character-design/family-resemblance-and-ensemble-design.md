# Family resemblance and ensemble design

Goal: characters who visibly belong together (a family, a team, a species, a faction)
while each stays individual.

## Shared vs individual traits
- **Shared (inherited)**: one or two strong features - nose shape, eye shape, hair colour,
  ear form, colour palette, costume motif. Pick features that survive at distance.
- **Individual**: proportion, age, posture, silhouette breaker, accessory.
- Age progression: children carry the parent's feature in softer, smaller form; elders
  carry it exaggerated (sagged, enlarged nose/ears).

## Method
1. Design the founding member (or the parent) first.
2. Choose 1-2 inheritable features and list them on the sheet.
3. Design each member by keeping those features and varying everything else using
   the cast-contrast axes.
4. For factions/teams, add a shared costume or colour system (uniform accent colour,
   insignia shape).
5. Line them up and test both ways: do they read as related? Can each be named?

## Failure modes
- Clones: family members who differ only in size.
- No shared trait: audience cannot tell who is related without dialogue.
- Shared traits too subtle to read at medium shot.

## Verify
- [ ] Inherited features listed and present on every member.
- [ ] Each member passes the individual-silhouette test.
- [ ] Cold viewer groups the family correctly.
