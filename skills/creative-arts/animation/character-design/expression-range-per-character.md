# Expression range per character

Goal: an expression sheet that says not only what the face can do, but what this
character would do - range limits and signature faces.

## What to define
- **Baseline**: resting face (a stoic baseline differs from a grumpy one).
- **Range ceiling**: how far the extremes go (a reserved butler never goes full
  cartoon take; a sidekick always does).
- **Missing emotions**: what they hide (shows fear as anger, never cries on screen).
- **Signature expressions**: 2-3 faces unique to them (smirk, eye-roll, one raised brow).
- **Tells**: involuntary leaks when they lie or suppress emotion.

## Method
1. Start from the six basic emotions; draw each at the character's natural intensity.
2. Add 4-6 nuanced blends (smug, wistful, sheepish).
3. Draw the extremes and mark the ceiling with a red line - "do not exceed".
4. Draw the signature expressions and the tells.
5. Compare with other cast members' sheets: the same emotion should look different
   per character.

## Failure modes
- Every character emoting identically - interchangeable faces.
- No ceiling: animators push a restrained character into broad mugging.
- Signature expression overused until it loses meaning.

## Verify
- [ ] Baseline, ceiling, signatures and tells on the sheet.
- [ ] Same emotion differs visibly between two characters.
- [ ] Ceiling respected in sample shots.
