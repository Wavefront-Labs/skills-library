# Big-medium-small size variety

Goal: no two major shapes in a design the same size. Bancroft's variety rule: a
big shape, a medium shape and a small shape give contrast and a visual hierarchy.

## Method
1. List the main masses: head, torso, hips, legs, hands, feet, hair, key accessory.
2. Rank them: which is BIG, which MEDIUM, which SMALL? There should be a clear
   winner (big torso, medium head, small legs for a strongman; big head,
   medium body, small feet for a child).
3. Apply the same rule within each part: in the face, big eyes / medium nose /
   small mouth (or big jaw / medium nose / small eyes for a brute).
4. Vary spacing too: distances between features should differ (eyes close, eyes to
   mouth far), not be evenly spaced.
5. Overlay the design with rough bounding shapes; if two are near-equal, push one.

## Typical mappings
| Character | Big | Medium | Small |
|---|---|---|---|
| Strongman | chest/shoulders | head | legs |
| Child | head | torso | limbs |
| Elder | nose/ears | body | eyes |
| Elegant villain | height/legs | torso | head |

## Failure modes
- Equal-size head and torso, equal-length arms and legs: stiff and generic.
- Variety in the silhouette but evenly spaced facial features - the face is the first
  place the eye goes.
- Random variety unrelated to personality.

## Verify
- [ ] Clear big/medium/small ranking for body and for face.
- [ ] Feature spacing varies.
- [ ] The ranking expresses the personality brief.
