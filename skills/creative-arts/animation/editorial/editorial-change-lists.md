# Editorial change lists

**Goal:** after any edit change to a locked or partially locked sequence, each department knows exactly which
shots changed and how, before they waste work on the old cut.

## What a change list contains

| Change | Fields |
|---|---|
| Trimmed / extended | shot, old cut range, new cut range, head/tail delta in frames |
| Omitted | shot, status OMIT (keep the number retired) |
| New shot | new ID (e.g. sh015), frame count, turnover package |
| Re-ordered | old and new position |
| Speed change / retime | shot, ratio, frames affected |
| Audio change | lines moved, new dialogue takes |

## Generate it by diffing timelines

Export the old and new cuts (OTIO/EDL/XML) and compare by shot name:
```python
import opentimelineio as otio
def shots(path, fps=24):
    tl = otio.adapters.read_from_file(path)
    return {c.name: (otio.opentime.to_frames(c.source_range.start_time, fps),
                     otio.opentime.to_frames(c.source_range.duration, fps))
            for c in tl.tracks[0].each_clip()}
old, new = shots("sq020_v011.otio"), shots("sq020_v012.otio")
for s in sorted(old.keys() | new.keys()):
    if s not in new: print(s, "OMITTED")
    elif s not in old: print(s, "NEW", new[s])
    elif old[s] != new[s]:
        (os_, od), (ns, nd) = old[s], new[s]
        print(s, f"head {ns-os_:+d}  tail {(ns+nd)-(os_+od):+d}  len {od}->{nd}")
```
`source_range` is the used portion of each shot's media (relative to the shot's own frames), so head/tail
deltas show exactly how much of the shot was added or removed.

## Distribution

- Publish as a versioned document (`sq020_changelist_v012.pdf/csv`) and update tracker frame ranges for each
  shot automatically.
- Flag shots already in animation or lighting: extensions need more animation; trims may waste work.
- Send updated turnover packages for changed shots only.

## Gotchas

- Shots renamed in the NLE break diffing; enforce clip names = shot IDs.
- Extensions beyond handles need new animation; within handles, lighting may only need to re-render.

## Verify

Apply the change list to the old shot list: the result equals the new cut's breakdown (sum of frames matches
the new sequence length).
