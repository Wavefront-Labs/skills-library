# Prop orthographics and callouts

Goal: a model-ready prop sheet that leaves no question about shape, size or how it works.

## 1. Views
- Front, side and top as minimum; back and underside if the camera sees them; a 3/4 perspective view
  for appeal.
- Draw views on a shared grid so features line up across views (project lines between them).
- Same scale for every view; state the scale and total dimensions in real units.

## 2. Callouts
- **Detail views**: enlarged circles for small features (hinges, engravings, buttons) at 2-4x.
- **Section views** where the inside matters (a box lid thickness, a hollow handle).
- **Material notes**: wood type, metal finish, worn areas, with swatch references.
- **Moving parts**: range of motion arcs, pivot points, open and closed states.
- **Hand interaction**: where hands grip; check scale against the character's hand on the model sheet.

## 3. Clarity
- Line weight: heavier outline, lighter internal detail; no rendering on orthos beyond flat tone.
- Label every callout with a number and short note; no paragraphs.

## 4. Check
- Build a quick blockout (or ask modeling for one) from the orthos and compare; discrepancies between
  views show up immediately.

## Verify
- [ ] Views aligned on a grid at one scale with dimensions.
- [ ] Moving parts show pivots and range.
- [ ] Scale checked against the character's hand.
