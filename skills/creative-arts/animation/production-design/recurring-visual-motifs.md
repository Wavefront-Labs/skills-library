# Recurring visual motif

Goal: a visual idea the audience absorbs without noticing, that makes the world feel authored and echoes the theme.

## 1. Derive the motif from the theme
- Write the theme as a sentence (from the story team). Ask what shape or object embodies its two sides.
  Examples: circles (family, wholeness) vs broken arcs; cages/grids (control) vs open horizons;
  a recurring object (a key, a lantern) that gains meaning.
- Prefer a **shape or pattern** over a symbol; shapes can live in architecture, props and costumes at many scales.

## 2. Build the system
| Scale | Where the motif lives |
|---|---|
| World | architecture silhouettes, window shapes, city plan |
| Set | furniture forms, floor patterns, framing elements |
| Prop | handles, emblems, hero prop shape |
| Costume | seams, buttons, collar shapes, prints |
| Graphics | logos, signage, title design |

## 3. Make it change
- Plan how the motif evolves with the arc: fragmented to complete, rigid to organic, absent then present.
- Mark on the color script or sequence list where the motif appears strongly, weakly, transformed.

## 4. Keep it subtle
- If the audience notices the motif on first viewing, it is probably too loud, unless it is a plot object.
- Avoid putting it in every frame; frequency rises toward key story moments.

## Verify
- [ ] Motif written as theme -> shape with a reason.
- [ ] Usage table across world, set, prop, costume.
- [ ] Planned evolution mapped to sequences.
