# Painting backgrounds in a show style

Goal: a team of painters produces backgrounds that look like one artist painted them.

## 1. Start from masters
- The art director paints or approves 3-5 **master BGs** per location covering the main lighting states.
- A **style sheet** lists: palette per location, value range, brush set, edge rules, texture overlay,
  how much detail per depth plane, line treatment.

## 2. Paint order
1. Layout drawing on top (line layer, matched to the field and camera).
2. Flat value/colour blocks per plane (sky, far, mid, near, overlays separate).
3. Light and shadow shapes following the sequence key.
4. Texture and detail, densest in the midground focal areas.
5. Atmosphere and final colour adjustments; compare to master side by side.

## 3. Consistency rules
- Sample colours from the master or palette file, not by eye.
- Use the show brush set only; same canvas resolution and texture overlay scale.
- Keep layers per depth plane for parallax and compositing.

## 4. Review
- Review BGs as a sequence strip, not singly.
- Composite a character colour model over each BG before approval.

## Verify
- [ ] Master BG and style sheet referenced.
- [ ] Layers separated by plane.
- [ ] Character test composite approved.
