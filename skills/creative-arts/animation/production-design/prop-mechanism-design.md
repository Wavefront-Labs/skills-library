# Functional mechanisms and plausibility

Goal: a gadget, tool or contraption that looks like it works, so the audience believes what it does.

## 1. Start from function
- Write what the prop does and the sequence of states (closed -> unlocking -> open).
- Choose real mechanisms: hinge, slide, gear train, cam, lever, spring, ratchet, telescoping tube.
  Look at real objects that do the same job.

## 2. Make the mechanism visible
- Show pivots (bolt heads, rivets), guides, and where force goes. Unexplained motion reads as magic.
- Parts that move need clearance; parts that bear load need thickness.
- Moving parts get a contrasting material or colour so the motion reads.

## 3. Design for the rig and animation
- Each moving part rotates around one clear pivot or slides on one axis; avoid parts that must deform
  unless designed as flexible (springs, cloth, rubber).
- Draw the extreme positions; check no parts intersect through the full range.
- Note which motions are rigged vs which are swapped models (states).

## 4. Stylisation
- Simplify the number of parts but keep the logic; three gears that mesh read better than twelve.
- Cartoon cheats are fine (a spring that stretches too far) when they serve a gag, and noted.

## Verify
- [ ] State sequence drawn.
- [ ] Each moving part has a visible pivot or guide.
- [ ] Extreme positions drawn and collision-free.
