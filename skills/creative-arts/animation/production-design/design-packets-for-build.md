# Design packets for build departments

Goal: a modeler or BG painter can build the asset correctly from the packet alone.

## 1. Packet contents
- **Hero illustration**: the approved design in context, lit in the show style.
- **Orthographic views**: front, side, back, top as needed, same scale, aligned on a grid.
- **Scale reference**: a human figure or measured height; key dimensions in real units.
- **Callouts**: materials, construction details, moving parts, details at 2-4x magnification.
- **Colour and material**: colour model/swatches for each material plus texture references.
- **Variants**: damaged, night, open/closed, different dressing states.
- **Usage notes**: which shots, camera distance, which parts are hero vs never seen (don't build the back
  if the camera never goes there).
- **Story notes**: what the asset must communicate, and anything it must do (open, fold, break).

## 2. Format
- One PDF or board per asset with the asset ID and version on every page; source files attached.
- Use the same template for every asset so departments know where to look.

## 3. Handoff
- Kickoff review with the builder; record questions as packet changes, not side conversations.
- Builder's first blockout returns for a quick design check before detail work.

## Verify
- [ ] Orthos aligned at one scale with dimensions.
- [ ] Materials and colour specified.
- [ ] Hero vs unseen areas marked.
- [ ] Blockout checked against packet before detailing.
