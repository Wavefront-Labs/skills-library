# Color script thumbnails from boards

Goal: a strip of small paintings, one per beat, made fast enough to redo whenever the reel changes.

## 1. Choose the panels
1. Watch the current story reel; pull one representative panel per story beat (not per shot) -
   typically one per 20-60 seconds of screen time: 40-120 thumbs for a feature, 8-20 for an 11-min episode.
2. Prefer the panel with the widest view of the space and the main character's emotional pose.
3. Export at board aspect ratio and drop them in order onto a grid canvas (rows = sequences).

## 2. Paint at stamp size
- Thumbnail at roughly 2-3 cm wide (about 150-250 px). Small size forces big shapes.
- **Value pass first**: 3-4 values per thumb, flat fills over the board drawing on a multiply layer.
- **Colour pass**: a colour or overlay layer on top, one dominant hue plus one accent per thumb.
- No details, no characters beyond silhouettes; the light direction must read.
- Time box: 5-10 minutes per thumb. If it takes longer you are illustrating, not scripting.

## 3. Read the strip
- Zoom out until each thumb is about 1 cm; the arc should read as a rhythm of dark/light and warm/cool.
- Flip to greyscale to check the value arc separately from hue.
- Mark beats that look the same as their neighbours but should feel different.

## 4. Keep it alive
- Name thumbs by sequence and beat (`seq04_b03`) so changes to the reel map to the strip.
- When a sequence is re-boarded, re-pull panels for that row only.

## Verify
- [ ] Every story beat has one thumb; order matches the latest reel.
- [ ] Greyscale view shows a clear value rhythm.
- [ ] Each thumb has one dominant hue and at most one accent.
