# Actionable visual feedback

Goal: notes that move a frame toward the target in one revision.

## 1. Note structure
**Goal -> problem -> direction.**
"The eye should land on Mia (goal). The bright window behind her pulls focus (problem). Drop the window
two value steps and warm her key light (direction)."

## 2. Use variables, not adjectives
- Replace "make it pop" with value, saturation, hue, temperature, edge, size, position, detail density.
- Quantify where possible: "two value steps", "half the size", "move her onto the left third".

## 3. Prioritise
- Order notes: story read, composition and value, colour, then detail. Fixing detail before value wastes time.
- At most three must-fix notes per version; the rest go on a "later" list.

## 4. Separate taste from the target
- Tie each note to the bible or the story goal. If it is a preference, say so and let the artist choose.
- Ask what the artist was going for before rewriting it; the miss may be a briefing problem.

## 5. Delivery
- Say specifically what works first ("the silhouette reads at thumbnail") so it is kept.
- Pair verbal notes with a draw-over and write them in the tracker; spoken-only notes get lost.

## Verify
- [ ] Every note names a variable and a direction.
- [ ] No more than three must-fix notes per round.
- [ ] Notes are written in the tracker against the version.
