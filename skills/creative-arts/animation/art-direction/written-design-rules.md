# Written design rules

Goal: the style is a set of rules anyone can check, not a mood only the art director carries in their head.

## 1. Rules must be testable
Weak: "The world feels whimsical." Testable: "Verticals lean 3-7 degrees; no two adjacent verticals lean the
same way." A reviewer must be able to say pass or fail from the frame.

## 2. Categories to cover
- **Shape**: dominant primitive (circle/square/triangle) per location or faction; big-medium-small ratios.
- **Line**: line weight in px at delivery resolution, taper, line colour (black vs coloured line).
- **Perspective**: allowed types (1/2/3-point, curvilinear), horizon conventions.
- **Detail density**: where detail is allowed (focal areas) and where shapes stay flat.
- **Texture**: grain size, brush or material source, how much shows on characters vs BG.
- **Colour**: palette reference, saturation ceiling, shadow derivation rule.
- **Lighting**: hard or soft shadow edges, number of light tones on characters.
- **Exceptions**: rules that break for story reasons (the villain's lair is all triangles).

## 3. Format
- Numbered rules, each with a one-line reason and a picture (link to the do/don't sheet).
- Keep it to 2-4 pages; long bibles are not read.

## 4. Use the rules
- Reviews quote rule numbers ("breaks R12").
- A rule that keeps getting broken is either unclear or wrong; revise it.

## Verify
- [ ] Each rule is pass/fail checkable on a single frame.
- [ ] Each rule has an image and a reason.
- [ ] Reviews reference rule numbers.
