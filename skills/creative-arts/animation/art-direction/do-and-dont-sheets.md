# Do and don't sheets

Goal: new artists and vendors can hit the style in their first week because the common mistakes are shown,
not described.

## 1. Collect the mistakes first
- Gather real off-style work from reviews, tests and early outsourcing. The best "don't" examples are
  mistakes people actually made.
- Group them by category: shape, line, proportion, colour, rendering, texture, lighting, staging.

## 2. Layout of each sheet
- One topic per sheet. Left = DO (green tick), right = DON'T (red cross).
- Same subject, same angle in both so only the rule changes.
- One-line rule under each pair, phrased as an instruction: "Corners are rounded at 1/8 of the shorter
  side", "Shadows are one flat tone, never gradients".
- Annotate the specific difference with arrows; avoid paragraphs.

## 3. Coverage checklist for a series
- Characters: proportions, line weight, mouth shapes, hands, expressions out of range.
- Environments: perspective rules (e.g. no three-point), straight vs wobbly lines, texture density.
- Colour: saturation ceiling, forbidden hues, shadow colour rules.
- Rendering: edge treatment, highlight shapes, gradient use.
- Staging: tangents, eyelines, crowded silhouettes.

## 4. Maintain
- Version the sheets with the art bible; add a new pair every time the same note is given three times.

## Verify
- [ ] Each pair isolates one rule.
- [ ] Rule text is an instruction under 15 words.
- [ ] Sheets sourced from real review mistakes.
