# Notan and value grouping

Goal: a strong light-dark design underneath every painting. Notan (Japanese "light-dark")
reduces an image to two values so the big shape pattern can be judged.

## Principles
- **Group, do not scatter**: link darks into a few large connected shapes and lights into others.
  Scattered small spots read as noise.
- **Unequal areas**: one value dominates (e.g. 70/30); 50/50 splits feel static.
- **Focal contrast**: put the sharpest light-dark meeting at the focal point.
- **Shape quality**: interesting, varied shapes with interlocking edges beat simple bands.
- **Value grouping beyond two**: after notan, group into 3-4 values (light, light-mid,
  dark-mid, dark); each object belongs to one group in the composition, not its own range.

## Method
1. Make 2-value thumbnails (black marker or threshold layer in Photoshop/Krita).
2. Try 4-6 arrangements; choose the one that reads the story at a glance.
3. Expand to 3-4 values, assigning each area to a group.
4. Check characters: they should sit as a light on dark or dark on light shape.
5. Keep the notan visible as a thumbnail beside the final paint and check against it.

## Failure modes
- Values assigned object by object, creating a patchwork.
- Character values same as the background group behind them.
- Equal-area split with no dominant value.

## Verify
- [ ] Two-value version reads the story.
- [ ] Dominant value covers most of the frame.
- [ ] Focal point at the strongest contrast edge.
