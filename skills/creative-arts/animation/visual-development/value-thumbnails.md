# Value thumbnails (3-5 values)

Goal: solve composition and light in small greyscale studies before spending time on
colour and detail.

## Setup
- Size: about 5-8 cm wide (or 200-400 px), at the final aspect ratio.
- Palette: 3 values (light, mid, dark) or up to 5 (add light-mid and dark-mid). Make swatches
  first and pick only from them - no in-between greys.
- Time: 2-5 minutes each.

## Method
1. Frame the aspect ratio rectangle.
2. Block the big shapes with the mid value; place darks; pull lights out last.
3. Make 6-12 variations: change light direction, camera height, value of the sky, which
   plane is darkest.
4. Pick the strongest read; mark the focal point.
5. Optionally scale it up as the underpainting/value key for the colour painting; check
   the colour version in greyscale against it.

## What to judge
- Is the focal point at the highest contrast?
- Do the planes (FG, MG, BG) separate?
- Does the light tell the mood (high-key, low-key)?
- Does the image read at thumbnail size?

## Failure modes
- Detailing inside thumbnails.
- Using too many values; the structure disappears.
- Colour version drifting away from the approved value thumbnail.

## Verify
- [ ] Fixed 3-5 value palette used.
- [ ] Multiple variations explored.
- [ ] Final colour checked in greyscale against the thumbnail.
