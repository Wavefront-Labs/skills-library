# keyframe-types

Goal: a readable timeline, with keys vs breakdowns vs holds visible at a glance, so blocking, splining and review are faster.

## Types (Dope Sheet, select keys, R or Key > Keyframe Type)

- **Keyframe** (white/yellow diamond): normal keyframe.
- **Breakdown** (small cyan diamond): for example transitions between key poses.
- **Moving Hold** (dark gray/orange diamond): a key that adds a small amount of motion around a holding pose; the Dope Sheet also shows a bar between them.
- **Extreme** (big pink diamond): an extreme state, or any other purpose.
- **Jitter** (tiny green diamond): a filler or baked key, for keying on ones, or any other purpose.
- **Generated** (dark diamond): a key generated by a tool (for example Copy Global Transform: Fix to Camera). It tells Blender and add-ons that such keys are safe to remove and re-generate, so do not mark hand-made animation with it.
- **New Keyframe Type** in the Keying popover (Timeline/animation editor footer) sets the type given to newly inserted keys, so you can key breakdowns directly.
- Dope Sheet Select > **Select by Type** selects all keys that share the type of the currently selected keys.

## Workflow uses

- Blocking: key poses as Keyframe, extremes as Extreme, breakdowns as Breakdown, so reviewers can read structure without scrubbing.
- Select by type from Python when needed: iterate `fcurve.keyframe_points` and test `kp.type` (for example `'BREAKDOWN'`).

## Gotchas

- Types are visual metadata; they do not change interpolation. Interpolation differences are shown separately (a green line between keys marks custom interpolation; the handle shape shows the handle type).
- Grease Pencil frames also have keyframe types; see `gp-keyframe-types`.

## Verify

The Dope Sheet shows the expected mix of diamond sizes and colours per pose.
