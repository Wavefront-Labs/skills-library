# Tie-down drawings

Goal: the stage between rough animation and final cleanup. The rough keys capture motion and
acting but drift off-model; tie-downs "tie down" the drawing to the model sheet while keeping
the rough's action. In the Animation Guild classifications this falls to key assistants /
assistant animators.

## Inputs
- Rough animation (approved pencil test).
- Model sheets, construction sheets, color models.
- Animator's timing charts.

## Method
1. **Overlay the rough** on a new layer at reduced opacity.
2. **Build construction** on the rough's gesture: masses, centre lines, eye line - in correct
   proportion from the model sheet.
3. **Keep the action**: line of action, silhouette, arcs and the animator's exaggeration must
   survive. If the model conflicts with an intentional squash/stretch, keep the stretch with
   volume preserved.
4. **Tie the details**: features, costume lines, hair shapes placed consistently on the
   construction.
5. **Do keys and breakdowns first**, then flip them in order to check volume and arcs before
   inbetweening.
6. **Charts and numbering** preserved; note any changes for the animator.

## Failure modes
- Tie-downs that "fix" the acting - straightening a deliberate pose.
- Volume drift between consecutive tie-downs (check by flipping).
- Costume details popping location between keys.

## Verify
- [ ] Rolling/flipping keys: volumes and details consistent.
- [ ] Silhouettes match the rough's.
- [ ] Model sheet comparison passes for proportions.
