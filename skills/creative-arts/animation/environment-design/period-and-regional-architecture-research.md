# Period and regional architecture research

Goal: sets that feel specific to a time and place (1950s suburb, Edo-period town,
Moroccan medina) because they are stylized from real forms, not invented from memory.

## Sources
- Historic building surveys and photo archives (e.g. US Library of Congress HABS/HAER,
  national heritage registers, museum collections).
- Architectural style guides and pattern books of the period (catalogue homes, builder manuals).
- Period photographs and films; old postcards; street-level imagery for regional variety.
- Field trips: sketching and photographing on site (materials, weathering, light).

## What to collect
- Massing and roof forms; window and door proportions; ornament vocabulary.
- Materials and how they age (adobe, timber, brick bond patterns, stone).
- Street furniture, signage, lighting, vehicles of the era.
- Interior fittings: switches, fixtures, furniture, appliances.
- Climate-driven features (eaves, shutters, courtyards).

## Method
1. Define the exact era range and region from the script.
2. Build a reference board grouped by category; label each image with source and date.
3. Extract the 5-10 defining features that make the period readable.
4. Stylize those features using the show's set style rules; drop the rest.
5. Flag anachronisms in review (a 1970s outlet in a 1940s kitchen).

## Failure modes
- Generic "old" mixing several centuries and countries.
- Copying a single reference so closely it becomes a recognisable real building (rights issue).
- Research without a stylization step: realistic details clashing with the show style.

## Verify
- [ ] Era and region defined.
- [ ] Labelled reference board with defining features listed.
- [ ] Anachronism check done in review.
