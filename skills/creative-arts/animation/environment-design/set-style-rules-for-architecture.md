# Set style rules for architecture

Goal: a short rule set that makes every building, interior and prop look like the same
world, whoever draws it (the "UPA flat" look, the leaning Dr. Seuss town, the
straight-line rigour of The Incredibles' mid-century sets).

## Rules to define
- **Verticals**: true vertical, or deliberately leaning/tapering (buildings narrower at the top,
  walls tilted inward). State the angle range (e.g. lean 2-5 degrees, never mirrored).
- **Corners**: sharp, rounded (radius as a fraction of the wall), chamfered.
- **Line quality**: ruled lines, wobbly hand lines, broken lines.
- **Simplification**: what gets drawn (window frames yes, mullions no; brick suggested by
  3 bricks per wall area).
- **Proportion push**: doors taller and narrower than real, windows oversized, etc.
- **Perspective treatment**: true linear perspective, flattened/frontal, or forced.
- **Texture**: flat colour, dry brush, gouache texture, none.

## Method
1. Pull 3-5 approved key BGs; extract rules as measurable statements.
2. Draw a rule sheet: a simple building, a door, a window, an interior corner and a
   staircase, each in the show style with the rule written beside it.
3. Add do/don't pairs for the commonest mistakes.
4. Test: have another artist design a new building from the sheet alone.
5. Revise after the first episode/sequence and freeze.

## Failure modes
- Rules expressed as mood words ("whimsical") rather than angles and counts.
- Lean applied randomly in all directions; reads as error, not style.
- Interiors drawn in a different style from exteriors.

## Verify
- [ ] Rule sheet with measurable statements.
- [ ] New-building test passes.
- [ ] Interiors and exteriors share rules.
