# Outlining with scene and sequel — causality from big beats to scenes

**Goal:** an outline where every event causes the next, the big turning points land
at roughly the right places, and individual scenes alternate action and reaction so
the pace breathes.

## 1. Start with the spine
Write three sentences:
1. **Who wants what?** (protagonist and concrete goal)
2. **What stands in the way?** (antagonist or force, and why it matters)
3. **What's at stake if they fail?**
If you can't write these, more outlining won't help yet.

## 2. Anchor the big beats
Most Western commercial structures (three-act, beat sheets like Save the Cat, the
"hero's journey") share roughly these turning points. Approximate positions as % of length:
| Beat | Approx. position | Function |
|---|---|---|
| Opening / setup | 0–10% | Normal world, character, want, flaw |
| **Inciting incident** | ~10–15% | Event that disrupts and poses the story question |
| End of act 1 / commitment | ~20–25% | Protagonist commits; no going back |
| **Midpoint** | ~50% | Major reversal or revelation; shifts from reacting to acting (or false victory/defeat) |
| Crisis / "all is lost" | ~75% | Lowest point; the plan fails |
| **Climax** | ~85–95% | Decisive confrontation; protagonist acts on what they learned |
| Resolution | last few % | New normal |
Positions are guides for pacing, not formulas. Literary fiction and non-Western
traditions often use other shapes (e.g. kishōtenketsu, a four-part structure built on
contrast rather than conflict).

## 3. Connect with "but" and "therefore"
List events in order. Between each pair write **but** (complication) or **therefore**
(consequence). If you find "and then", the events are merely sequential — rework so
one causes the next. (This test is widely attributed to the creators of *South Park*.)
Also check: each major turn should come from a character's **choice** at least as
often as from coincidence. Coincidence may start trouble, rarely resolve it.

## 4. Pace scenes with scene and sequel
A model from Dwight V. Swain's *Techniques of the Selling Writer*:
- **Scene** (action unit): **Goal** (what the POV character wants now) → **Conflict**
  (opposition) → **Disaster** (they fail, or succeed at a cost, or things get worse).
  Ending a scene on "yes, it all worked" kills momentum.
- **Sequel** (reaction unit): **Reaction** (emotional response) → **Dilemma** (options,
  all bad) → **Decision** (new goal), which launches the next scene.
Use sequels to control pace: compress them to a line in action stretches, expand them
for emotional beats. Too many full sequels in a row = slow; none = exhausting.

## 5. Build the outline
1. Spine sentences.
2. Big beats as one line each.
3. Fill in a **scene list** between beats: one line per scene with POV, goal, conflict,
   disaster/outcome. Index cards or a spreadsheet make reordering easy (Scrivener's
   corkboard too — see creative-arts.literary-writing.scrivener.compile-to-manuscript-format).
4. Run the but/therefore test across the whole list.
5. Check subplots: each should touch the main plot at a beat (often complicating it
   at the midpoint or climax).

## Gotchas
- **Formula visible:** readers sense paint-by-numbers beats; hit them through character choices.
- **Passive protagonist:** if events happen *to* them through the midpoint, the outline
  needs more decisions.
- **Climax solved by someone else** or by luck feels cheated.
- **Outline rigidity:** deviate when drafting reveals something better, then update the outline.
- Percentages and beat names vary between books and teachers; treat them as approximations.

## Verify
- [ ] Spine sentences: want, obstacle, stakes.
- [ ] Inciting incident, midpoint, crisis and climax placed and described.
- [ ] Every event linked to the next with but/therefore; no "and then".
- [ ] Each scene line has goal, conflict and a non-clean outcome.
- [ ] Climax is resolved by the protagonist's own choice.
