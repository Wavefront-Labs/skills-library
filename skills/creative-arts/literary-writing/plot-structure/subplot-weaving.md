# Weaving subplots

**Goal:** secondary storylines that deepen the main plot instead of distracting from it.
A subplot is a smaller arc (beginning, complication, resolution) carried by the
protagonist or a secondary character.

## What each subplot must do (at least one)
- **Pressure the main plot:** the romance makes the mission harder; the family crisis
  costs time.
- **Mirror or contrast the theme:** a side character faces the same choice and chooses
  differently (often showing the cost the protagonist avoids).
- **Supply something the climax needs:** an ally, a skill, a realisation.
Save the Cat's "B story" is usually the relationship subplot that carries the theme.

## Procedure
1. List candidate subplots in one line each: who, want, outcome.
2. For each, write how it **intersects** the main plot (at least twice: once in the
   middle, once near the climax). No intersection = separate story; cut or merge.
3. Build a **scene grid**: rows = scenes/chapters, columns = plot threads; colour each
   scene by thread (index cards, spreadsheet, or Scrivener labels).
4. Check spacing: a thread absent for more than about a fifth of the book will be
   forgotten; a thread in every scene may be the real main plot.
5. Resolve subplots **before or inside the climax**, usually in ascending importance;
   only the main plot's resolution should come last.

## Typical counts
- Short novel: 1-2 subplots; long commercial or epic novel: several, each with its
  own viewpoint character in multi-POV books.

## Gotchas
- Subplots that resolve after the main climax drain the ending.
- Subplot conflicts unrelated to the theme feel like filler.
- Subplot characters with more vivid wants than the protagonist pull focus.

## Verify
- [ ] Each subplot has a mini-arc and intersects the main plot at least twice.
- [ ] Scene grid shows no thread vanishing for long stretches.
- [ ] All subplots resolved by the end of the climax sequence.
