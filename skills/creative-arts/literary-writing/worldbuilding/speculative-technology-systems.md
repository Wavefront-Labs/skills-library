# Speculative technology systems

**Goal:** invented technology (FTL drives, AI, gene editing, uploading) that behaves like
a coherent system with rules, limits and consequences — the SF counterpart of a magic
system. Darko Suvin's term **novum** names the new element that distinguishes an SF world;
Clarke's third law ("any sufficiently advanced technology is indistinguishable from magic")
reminds you that unexplained tech reads as soft magic.

## Specify each novum
1. **Capability:** what it does, at what scale, how fast.
2. **Limits:** energy, range, failure rates, maintenance, scarcity of materials.
3. **Cost and access:** who can afford it; who controls it.
4. **Interface:** how people use it day to day (and how it breaks).
5. **Origin and age:** new tech disrupts; old tech is infrastructure and invisible.

## Trace consequences
- **Second-order effects:** cheap teleportation ends airlines, changes cities, enables new
  crimes, alters war. Pick the ones your story touches.
- **Social adaptation:** laws, slang, etiquette, class divisions, religion's response.
- **The "why not" test:** for each plot problem, why doesn't the tech fix it? Limits and
  costs must answer.

## Keep it consistent
- Limit the number of big novums; each one multiplies consequences.
- Keep a tech bible: rules, every on-page use, chapter references.
- Don't upgrade capabilities mid-book without a visible cause.

## Writing it on the page
- Characters treat familiar tech as ordinary; explain through use, not lecture.
- Neologisms sparingly; context makes meaning clear.

## Gotchas
- Tech as wallpaper: transformative tech with no social effect.
- Convenient inconsistency (scanners detect everything except the plot's secret).

## Verify
- [ ] Each novum has capability, limits, cost and interface defined.
- [ ] Second-order consequences listed for those the story touches.
- [ ] Every plot problem has a limit-based answer to "why not use the tech?".
