# Researching agents and building an agent list

**Goal:** a list of 40-100 legitimate agents who actively represent your category and
genre, queried in batches so you can learn from the response rate.

## Sources
- **QueryTracker** — agent profiles, genres, response times, user-reported data.
- **Publishers Marketplace** (paid) — deal reports: who sold what, to whom, recently.
  The strongest evidence an agent sells your genre.
- **Manuscript Wish List** (manuscriptwishlist.com, #MSWL) — what agents say they want.
- **Agency websites** — the authoritative source for current submission guidelines and
  whether the agent is open to queries.
- **Acknowledgements pages** of comparable recent books — authors thank their agents.

## Vetting
- Legitimate agents earn commission on sales only. The Association of American Literary
  Agents (AALA, formerly AAR) Canon of Ethics prohibits charging reading fees.
- Red flags: reading or "evaluation" fees, referrals to a paid editing service, no
  verifiable sales, solicitation out of the blue. Check Writer Beware.
- Confirm the agent is actively building a list (recent deals, open to queries).

## Build the list (spreadsheet)
Columns: agent, agency, genres, open/closed, guidelines (pages, synopsis, form/email),
personalisation note, date queried, response, request type, follow-up date.

Rules:
- One agent per agency at a time unless the agency's guidelines say otherwise; a pass
  from one often means a pass from the agency.
- Tier: A (perfect fit, strong sales), B, C — but mix tiers in each batch so early
  feedback isn't only from dream agents.

## Querying in batches
1. Send 8-12 queries.
2. Wait 4-8 weeks (or each agent's stated response window; many say "no response means no").
3. Evaluate: zero requests after ~20 queries points at the query or premise; requests but
   no offers points at the pages.
4. Revise, then send the next batch.

## Verify
- [ ] Every agent on the list represents your exact category (adult/YA/MG) and genre.
- [ ] Every agent verified fee-free with recent sales.
- [ ] Guidelines recorded per agent and followed.
- [ ] Batch results logged before the next batch goes out.
