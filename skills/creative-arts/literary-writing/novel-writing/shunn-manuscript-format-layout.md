# Standard manuscript format layout

**Goal:** a submission file that looks like every other professional manuscript, so
nothing distracts from the writing. William Shunn's "Proper Manuscript Format" guides
(novel and short story; classic and modern versions) are the most widely cited
reference. Always follow an agent's or publisher's own guidelines where they differ.

## Page setup (Word: Layout/Format menus)
- Letter (US) or A4; **1 inch (2.5 cm) margins** all round.
- **Font:** 12 pt Times New Roman (modern) or Courier/Courier New (classic); one font throughout.
- **Double-spaced**, left-aligned (ragged right), **no extra space between paragraphs**
  (Paragraph > Spacing Before/After = 0).
- **First-line indent 0.5 in** via paragraph settings — not tabs or spaces.
- Italics as italics (modern) — classic format uses underlining.

## First page / title page (novel)
- Top left: legal name, address, phone, email (and agent details if represented).
- Top right: approximate word count (rounded, e.g., "about 92,000 words").
- Centred about halfway down: TITLE, then "by" and the byline (pen name if used).
- Shunn's novel format places the title on a separate cover page; the first chapter
  starts on the next page. Story format puts the title block on page one above the text.

## Header (every page after the first)
`Surname / SHORT TITLE / page number`, right-aligned, in the header area. Use Word's
Different First Page so the title page has no header.

## Chapters and breaks
- Start each chapter on a **new page** (Insert > Page Break or "Page break before" in
  the chapter heading style), chapter heading about a third of the way down.
- Scene breaks: a **centred `#`** on its own line (not a blank line).
- Shunn's novel format ends with "END" centred after the last line (common practice;
  check guidelines).

## Gotchas
- Fancy fonts, colours, headers with images.
- Using blank lines between paragraphs and also indenting.
- Using spaces/tabs for indents (breaks conversion).
- Forgetting to update the header's short title.

## Verify
- [ ] Margins, font, spacing and indent set via styles.
- [ ] Contact block and word count on first page.
- [ ] Header shows surname / short title / page number from page 2.
- [ ] Chapters start on new pages; scene breaks marked with `#`.
