# Publishing on Amazon KDP

**Goal:** a correctly configured Kindle ebook and paperback on Amazon, with a
deliberate choice about exclusivity. Policies change — confirm figures in KDP Help
before publishing.

## Setup sequence (per format: Kindle eBook, Paperback, Hardcover)
1. **Details:** language, title/subtitle (must match the cover), series name and number,
   author (pen name allowed), description, publishing rights, primary audience, up to 7
   keyword boxes, categories (see `book-metadata-and-bisac-categories`).
2. **Content:**
   - Ebook: upload EPUB, DOCX or KPF (Kindle Create). Choose DRM (cannot be changed later).
     ISBN optional (Amazon assigns an ASIN).
   - Paperback: get a free KDP ISBN (imprint shows "Independently published", usable only
     on KDP) or enter your own; choose trim, paper (white/cream), bleed, cover finish;
     upload interior PDF and full-wrap cover PDF (see `print-interior-and-cover-specs`).
   - Use the **online previewer** and fix every flagged issue.
3. **Pricing:** territories, royalty plan, list prices.

## Royalties (check current terms)
- Ebook **70%** option requires a list price within the band Amazon sets (historically
  $2.99-$9.99 in the US) and deducts a per-MB delivery fee; outside it, **35%**.
- Paperback: 60% of list price on Amazon marketplaces **minus printing cost**;
  Expanded Distribution pays less (40% minus printing) and requires a higher price.
- Use the KDP pricing calculator in the paperback pricing page to see printing cost.

## KDP Select (ebook only)
- 90-day auto-renewing **exclusivity**: the ebook may not be sold or given away
  elsewhere (print and audio are unaffected).
- Benefits: Kindle Unlimited page-read income, Kindle Countdown Deals or free-book
  promotion days.
- Trade-off: wide distribution (Apple, Kobo, Google, libraries) vs KU income. Untick
  auto-renew if you plan to go wide at the period end.

## Pre-orders
- Ebook pre-orders can be set up well before release with a final file deadline a few
  days before; missing it can cost pre-order privileges. Paperback pre-order options are more limited.

## Before publishing
- Order a **proof copy** of the paperback; check margins, spine text, colour.
- Link formats so they appear on one product page (usually automatic when titles/authors match).
- Set up Author Central / author page.

## Gotchas
- Title or author on cover differs from metadata -> rejection.
- Keywords stuffed with other authors' names or trademarked terms violate guidelines.
- Using KDP's free ISBN then wanting IngramSpark distribution with the same ISBN — not allowed.
- Enrolling in Select while the ebook is still live on another store.

## Verify
- [ ] Previewer shows no errors; proof copy approved.
- [ ] Royalty option and price consistent with the plan.
- [ ] Select enrolment decision deliberate; auto-renew set accordingly.
- [ ] All formats linked on one product page after publication.
