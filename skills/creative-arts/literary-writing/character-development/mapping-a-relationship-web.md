# Mapping a relationship web

**Goal:** see the ensemble as a network of relationships, each carrying tension, so
every scene with two characters has something live between them.

## Build the map
1. Write each major character's name as a node (on paper or a diagramming tool).
2. Draw a line for every pair that interacts. On each line write:
   - **What each wants from the other** (often different).
   - **The tension** (rivalry, debt, secret, attraction, resentment, dependency).
   - **Power balance** (who holds more, and why).
3. Mark pairs with no line or no tension.

## Read the map
- **Dead pairs:** two characters who share scenes but want nothing from each other —
  scenes between them will be flat. Add a tension or keep them apart.
- **Hub overload:** if every line runs through the protagonist, the world feels thin;
  give secondary characters relationships with each other.
- **Triangles** generate drama (two people competing for the third's loyalty, love or
  approval); look for them or create one.
- **Secrets on lines**: a secret one character keeps from another is a time bomb.

## Plan the shifts
Make a second map for the end of the book. Compare: which alliances broke, which
enemies allied, who gained power. Each change needs a scene that causes it; add those
scenes to the outline.

## Gotchas
- Mapping only affection lines; conflict is what drives scenes.
- Too many characters to track (if the map is unreadable, the book may be too) — see
  `merging-characters`.

## Verify
- [ ] Every pair that shares a scene has a want and a tension on its line.
- [ ] At least one triangle or secret in play.
- [ ] Start and end maps differ, and each change has a causing scene.
