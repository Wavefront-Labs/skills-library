# Stage fright and recovering from slips

**Goal:** perform with nerves under control, and handle mistakes so the audience
barely notices.

## Before
- **Learn the story as images and beats, not words** (the story-map method in
  `creative-arts.literary-writing.oral-storytelling.shaping-a-story-for-telling-aloud`).
  Word-for-word memorisation is fragile: lose a word, lose the place.
- **Know the first and last lines cold.** A secure start calms you; a secure end lets you land.
- Rehearse aloud in varied conditions (standing, to a friend, with distractions).
- Visit or picture the room; check the mic.

## Right before
- **Slow breathing:** exhale longer than you inhale (e.g., in 4 counts, out 6-8)
  for a minute or two; it calms the stress response.
- Shake out hands and shoulders; release jaw.
- Reframe arousal as excitement; the physical symptoms are the same.
- Find one friendly face in the first row.

## When it goes wrong
| Slip | Recovery |
|---|---|
| Go blank | Pause (it looks deliberate), breathe, repeat the last line you said, or ask yourself "what did the character see next?" — return to the image |
| Skipped a beat | Weave it in later: "What I hadn't told you was..." / in folktales, "Now, earlier that day..." |
| Wrong name or detail | Correct lightly and move on, or let it stand if it doesn't matter |
| Interruption (phone, noise) | Acknowledge briefly if huge, then repeat the last line and continue |
| Laughed at the wrong place | Smile, wait, continue |
The audience doesn't know the script. Most slips are invisible if you don't signal them
with apologies or grimaces.

## Gotchas
- Apologising ("Sorry, I lost my place") — draws attention.
- Speeding up to get it over with.
- Over-preparing word-for-word the night before.

## Verify
- [ ] First and last lines known cold.
- [ ] Story can be told from the beat map in a different wording each time.
- [ ] Recovery lines rehearsed for a skipped beat.
