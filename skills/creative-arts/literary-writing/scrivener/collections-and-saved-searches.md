# Collections and saved searches

**Goal:** group documents outside the binder hierarchy — without moving them — for
focused work: one character's scenes, everything needing revision, a beta reader's packet.

## Show collections
**View > Collections > Show Collections** (Scrivener 3): collection tabs appear above the
binder. The **Binder** tab is always first; **Search Results** appears after searches.

## Standard collections (hand-picked)
1. Select documents in the binder.
2. Use the **+** in the collections header (or Documents/Add to Collection menu) to
   create a new collection with them; name and colour it.
3. Drag more documents onto the tab later. Removing from a collection doesn't delete
   the document.
Uses: "Beta packet 1", "Scenes to cut?", "Chapter 12 rewrite set".

## Saved-search collections (update automatically)
1. Run a project search (toolbar search; choose scope options: title, text, notes,
   keywords, metadata, label, status...).
2. From the search options menu, choose **Save Search** (saved as a collection with a
   search icon).
3. It re-runs whenever you select it — always current.
Uses: "Status = First Draft", "Keyword: Ben", "Text contains TODO", "Label = Timeline B".

## Working with a collection
- Select the collection; select all its documents; view as **Scrivenings** to read them
  as one continuous text (e.g., every Ben scene in order for a voice pass) — edits go
  straight to the originals.
- Use the corkboard/outliner on the collection.
- Order within a standard collection is independent of the binder; saved searches follow
  binder order.

## Gotchas
- Confusing collections with folders: deleting a collection doesn't delete documents, but
  deleting a *document* while in a collection view moves it to Trash.
- Overly broad text searches catching notes and research — set search scope.

## Verify
- [ ] Collections visible and named for current tasks.
- [ ] At least one saved search tracks a revision state.
- [ ] Scrivenings view of a collection used for a continuity or voice pass.
