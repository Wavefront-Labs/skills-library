# Document templates

**Goal:** reusable documents (character profile, setting sheet, scene planning card,
interview notes) that you stamp out with one command, so every entry has the same fields.
Scrivener 3; the Novel project template already includes a Template Sheets folder with
Character and Setting sketches.

## Create a template folder
1. Create a folder (outside Draft), e.g., "Templates".
2. Select it and choose **Project > Set Selection as Template Folder**. Its icon changes.
3. Add documents inside it: each is a template. Write the fields as headings or a table:
   ```
   Name:
   Role in story:
   Want / Fear / Need:
   Wound:
   Speech profile:
   Physical tells:
   Arc (start -> end):
   ```
   Give each template a custom icon if you like (Documents > Change Icon).

## Use a template
- **Project > New From Template** (or the Add button's dropdown) > choose the template.
  The new document is created at the selected binder location.
- Templates can also carry Label, Status, Keywords and metadata defaults — set them on the
  template document.

## Default new document per folder
- For a folder (e.g., "Characters"), you can set a **default template** for new
  documents created inside it (Inspector/Documents options for the folder, depending on
  version), so pressing Add creates a character sheet automatically.

## Good templates to make
- Character sketch (see `creative-arts.literary-writing.character-development.character-backstory-and-profile`).
- Setting sketch (sensory details, history, who goes there).
- Scene card: goal, conflict, outcome/disaster, turn, POV, story date.
- Research source note: citation, URL, key quotes, used in chapter.

## Gotchas
- Templates inside the Draft folder get compiled — keep them outside.
- Changing a template doesn't update documents already created from it.

## Verify
- [ ] Templates folder designated (icon changed).
- [ ] At least character, setting and scene templates exist.
- [ ] New From Template creates documents in the right place with default metadata.
