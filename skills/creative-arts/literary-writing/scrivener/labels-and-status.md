# Labels and status in Scrivener

**Goal:** use Scrivener's two built-in metadata fields to see the shape and progress of
a book at a glance. Every document has one **Label** (colour-coded) and one **Status**
(text). Menu names below follow Scrivener 3; macOS and Windows differ slightly — check
the user manual for your version.

## Decide what each field means
- **Label** — something you want to *see as colour*: POV character, plotline/timeline,
  act, or scene type. Pick one dimension per project.
- **Status** — workflow stage: To Do, First Draft, Revised Draft, Final Draft, Done
  (defaults), or your own (Needs Research, Cut?, Beta Notes).

## Customise
1. **Project > Project Settings > Label** (and **Status**): rename the field itself
   (e.g., rename "Label" to "POV"), add/remove/reorder values, set colours.
2. Set a **default** value for new documents.

## Assign
- Inspector > **Metadata** pane (or the bottom of the inspector), outliner columns, or
  right-click a binder item > Label / Status. Select many items and set at once.

## Display
- **View > Use Label Color In** > Binder, Index Cards, Outliner rows, Icons — turn on what helps.
- Corkboard: label colour as pins or card tint; **status stamps** across index cards
  (corkboard options/appearance settings).
- Outliner: add **Label** and **Status** columns; click column header to sort.

## Use
- Spot imbalance: corkboard of all scenes coloured by POV shows if one character
  vanishes for 50 pages.
- Revision passes: filter/sort by Status; use a **saved search** collection
  "Status = Revised Draft" (see `collections-and-saved-searches`).
- Compile: in the compile contents you can filter what's included (e.g., exclude
  documents with a status like "Cut?") — check the compile filter options in your version.

## Gotchas
- Mixing dimensions in one field (some labels are POVs, others are plotlines) — use
  custom metadata or keywords for the second dimension (see `custom-metadata-fields`).
- Too many colours to read; 4-8 values is practical.
