# Scrivenings mode

**Goal:** read and edit a run of scenes as if they were one document, while keeping them as separate binder items. Menu names below follow Scrivener 3; shortcuts and exact labels differ between the Mac and Windows editions and by version, so confirm in the app's Help or the official user guide.

## Steps
1. **Select several documents** in the binder (Shift or Ctrl/Cmd click), or select a folder and choose the Scrivenings view (View > Scrivenings, or the toolbar's view icon). Selecting a folder shows everything inside it as one text in Scrivenings mode.
2. The editor shows the text with a thin **separator** between documents; you can edit across them. Each piece stays a separate document and an edit goes to the original.
3. **Use it to**: read a chapter for flow, run a continuity pass, search and replace within a section, cut across scene boundaries.
4. **Combine with collections** (`creative-arts.literary-writing.scrivener.collections-and-saved-searches`): select a collection and view it in Scrivenings to read every scene of one character in order.
5. **Adjust the separators** in the application preferences (the Editing options include how Scrivenings separators are shown) if you want them subtler.
6. **Split or merge** while there: place the cursor and use Documents > Split; select documents and use Documents > Merge to permanently join them. Merge cannot be easily undone, so take a snapshot first (`creative-arts.literary-writing.scrivener.snapshots-compare-and-restore`).

## Gotchas
- Scrivenings of a very large selection can be slow; work in chapters.
- In Scrivenings, the Inspector shows metadata for the document where the cursor is, which can confuse.
- Do not confuse Scrivenings mode with Composition mode (`creative-arts.literary-writing.scrivener.composition-mode`), which is the distraction-free view.

## Verify
- [ ] Selected folder displays as one continuous text.
- [ ] Edits are in the correct source documents.
- [ ] Snapshots exist before any merge.
