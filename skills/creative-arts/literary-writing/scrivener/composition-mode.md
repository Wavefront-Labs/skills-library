# Composition mode

**Goal:** a full-screen, distraction-free writing surface that still gives you access to
notes and targets when needed. Scrivener 3 (macOS and Windows); shortcuts vary — check
**View > Composition Mode** (or **Enter Composition Mode**) in your version.

## Enter and exit
- Select a document (or several — Composition Mode shows them as Scrivenings) and
  choose **View > Enter Composition Mode** (toolbar button also available).
- **Esc** exits back to the main window.

## Control strip (move the mouse to the bottom edge)
- **Paper width** and **paper position** (left/centre/right).
- **Background**: colour or an image (set in the appearance preferences/settings).
- **Background fade** / paper opacity.
- **Keywords**, **Inspector** HUD (floating panel with synopsis, notes, metadata),
  **go to** another document, word count display, and target progress.
- Text zoom.

## Useful settings
- **Typewriter scrolling** (Format or View menu > Typewriter Scrolling): keeps the line
  you're typing at a fixed height on screen — easier on the neck for long sessions.
- Editor appearance in Composition Mode can differ from the main editor (Preferences/Options
  > Appearance > Composition) — e.g., larger font, different text colour, paper colour.
- Pair with the session target (see `project-and-session-targets`).

## Workflow tips
- Put the scene's synopsis or notes in the Inspector HUD before entering so you can
  glance at the plan.
- Use it for drafting; use the normal editor/outliner for structural work.

## Gotchas
- Accidentally editing several documents when you entered with a multiple selection —
  Composition Mode shows them stitched together.
- Theme/appearance changes in Composition only affect that mode — not your compiled output.

## Verify
- [ ] Composition Mode configured with comfortable paper width and font.
- [ ] Inspector HUD and target visible on demand.
- [ ] Typewriter scrolling on if preferred.
