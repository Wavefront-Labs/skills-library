# Keywords in Scrivener

**Goal:** tag scenes with multiple values (unlike Label/Status, a document can have many
keywords) — typically every character present, locations, objects, motifs and plot
threads — then find and filter by them. Scrivener 3; check menu names for your platform.

## Set up the keyword list
- **Project > Keywords...** opens the Project Keywords panel (a project-wide list).
  Add keywords, nest them hierarchically (Characters > Anna, Ben; Places > Harbour),
  and assign colours.
- Plan a consistent vocabulary before tagging (one name per character, not
  "Anna"/"Annie").

## Assign
- Inspector > **Metadata** (keywords section): click **+** and type, or drag keywords
  from the Project Keywords panel onto documents in the binder/corkboard/outliner.
- Select multiple documents and drag a keyword to tag them all.

## See them
- Corkboard: keyword colours show as chips on index cards (enable in corkboard options).
- Outliner: add a **Keywords** column.

## Find and filter
- Project search (magnifier in the toolbar) — set the search scope to **Keywords** and
  search a keyword to list every tagged document.
- In the Project Keywords panel, select a keyword and use its search button to find documents.
- Save the search as a collection (see `collections-and-saved-searches`) — e.g., "All
  scenes with Ben" — to read them in sequence in Scrivenings for a continuity pass.

## Uses
- Character continuity: read every scene a character appears in, in order.
- Motif tracking: tag every appearance of a symbol (see
  `creative-arts.literary-writing.prose-style.symbol-and-motif`).
- Research: tag research documents with the chapters they support.

## Gotchas
- Inconsistent keyword spelling creates duplicates; edit in the Project Keywords panel to merge/rename.
- Keywords don't compile into the manuscript; they're for organisation only.

## Verify
- [ ] Keyword list planned and created in the Project Keywords panel.
- [ ] Every scene tagged with characters present.
- [ ] Keyword search returns the expected scenes.
