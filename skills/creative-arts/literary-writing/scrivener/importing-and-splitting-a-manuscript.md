# Importing and splitting a manuscript

**Goal:** move an existing draft into Scrivener as separate binder documents, ready for corkboard and reordering work. Menu names below follow Scrivener 3; shortcuts and exact labels differ between the Mac and Windows editions and by version, so confirm in the app's Help or the official user guide.

## Steps
1. **Prepare the source file.** In Word or another editor, mark scene or chapter breaks consistently with a unique separator that does not appear in normal text (for example a line containing only `###`, or use Heading styles). Save as `.docx` or `.rtf`; keep a backup of the original.
2. **Import.** Use File > Import > Import and Split (Mac and Windows versions both offer a split-on-separator import) and choose the file. Enter the separator string and choose whether to remove the separator text from the result. Alternatively use File > Import > Files for a single unsplit document.
3. **Check what you got.** Imported files typically land in the binder as documents; move them into Draft and create the folder structure you want.
4. **Split after the fact.** In any document, place the cursor and use the Documents > Split commands (at selection, at cursor) to cut a document in two; use Documents > Merge to join documents.
5. **Titles.** Rename the new documents; if separators held chapter titles, use the option to keep them as titles if the import offers it, or copy them in by hand.
6. **Formatting check.** Imported styles can bring odd fonts and spacing; select all in the editor and use Format > Convert to Default Formatting (or the equivalent) to match your project style, then confirm compile will set final format.
7. **Verify scene counts** against your source and word count in Project Statistics.

## Gotchas
- A separator that appears in the text splits it in the wrong places; pick something unlikely.
- Footnotes and comments may import with limited fidelity; review them.
- Track changes in the source are best resolved before import.

## Verify
- [ ] Scene and chapter count equal the source.
- [ ] No stray separators left in text.
- [ ] Word count of imported material matches the original within a small margin.
