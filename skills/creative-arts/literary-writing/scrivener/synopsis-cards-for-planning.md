# Synopsis cards

**Goal:** give every binder document a short summary that is visible on the corkboard and outliner, so you can plan and reorder from summaries. Menu names below follow Scrivener 3; shortcuts and exact labels differ between the Mac and Windows editions and by version, so confirm in the app's Help or the official user guide.

## Where the synopsis lives
Each document has a **synopsis** (index card text) shown on the corkboard card and editable in the Inspector's Synopsis pane, separate from the document's text. Folders have synopses too.

## Writing a good card
1. **One or two sentences**, in present tense, covering: who wants what, what happens, how it turns. "Mara hides the letter; her brother finds it and takes it to their father."
2. **Include the change**: what is different at the end of the scene.
3. **Keep length consistent** so the corkboard reads evenly.
4. **Add the title** as a short label, not a summary.

## Starting from an existing draft
Scrivener can generate a synopsis from the document's text (in the Documents menu or by the Synopsis pane's controls; the exact command differs by version), usually taking the opening lines. Treat that as a placeholder and rewrite each into a true summary.

## Using them
- **Corkboard** (View > Corkboard): drag cards to reorder documents; the order follows into the binder for the normal corkboard.
- **Outliner** (View > Outliner): synopsis appears as a column; add label, status and custom metadata columns.
- Use labels and status colours for point of view, timeline or revision state (`creative-arts.literary-writing.scrivener.labels-and-status`).
- Print or compile a synopsis outline for an editor or agent through Compile or File > Print options.

## Verify
- [ ] Every scene has a card showing change as well as event.
- [ ] Read all the cards in sequence: they should tell the plot.
