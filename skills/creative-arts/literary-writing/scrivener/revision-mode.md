# Revision mode

**Goal:** mark text you add or change in a pass, in a colour, so you can see how much a pass touched and what is new. Menu names below follow Scrivener 3; shortcuts and exact labels differ between the Mac and Windows editions and by version, so confirm in the app's Help or the official user guide.

## How it works
Turn on **Format > Revision Mode** and choose a revision level (Scrivener offers several, commonly five, each with its own colour; you can see and rename them in the Revision options or project settings). While Revision Mode is on, new typing and edited text take the colour of the active level. Turning it off stops marking; existing marks remain.

## Steps
1. Pick a level per pass: for example Level 1 for the structural rewrite, Level 2 for the dialogue pass, Level 3 for the editor's changes.
2. Enable Revision Mode, edit as usual.
3. **Review**: scroll or use Scrivenings (`creative-arts.literary-writing.scrivener.scrivenings-mode`) to see coloured text across scenes; the colour density shows which chapters changed most.
4. **Clear marks** for a level or all (Format > Revision > Remove Revision Marks, or the menu's equivalent) when a pass is accepted, so the next pass starts clean.
5. **Compile**: revision colours can be shown in some outputs for an editor or printed review draft, and should be disabled for final output. Check Compile's revision options.

## Compared with snapshots
Revision Mode shows where and how much you changed, in the text itself; it does not store the earlier wording. Use snapshots for that (`creative-arts.literary-writing.scrivener.snapshots-compare-and-restore`).

## Gotchas
- Forgetting to switch Revision Mode off colours unrelated edits.
- Pasted text takes the current level colour.
- Compile with revision colour left on yields coloured final output.

## Verify
- [ ] Each pass has its own level.
- [ ] Marks cleared when accepted.
- [ ] Final compile shows no revision colours.
