# Taking and comparing snapshots

**Goal:** keep restorable versions of individual documents, and see exactly what changed between a snapshot and the present. Menu names below follow Scrivener 3; shortcuts and exact labels differ between the Mac and Windows editions and by version, so confirm in the app's Help or the official user guide.

## Take a snapshot
1. Select the document.
2. **Documents > Snapshots > Take Snapshot** (or with a title, to label it "before cutting dream scene"). A snapshot is a stored copy of the document's text and, in Scrivener 3, can include more than the raw text.
3. Snapshots live per document; view them in the Inspector's **Snapshots** tab. A multi-document snapshot is taken by selecting several documents first.
4. Take a snapshot **before**: heavy cutting, merging documents, a pass of search-and-replace, handing to an editor, or importing revisions.

## Compare
1. Open the Inspector's Snapshots pane and select the snapshot.
2. Use **Compare** (Snapshots button or the Documents > Snapshots > Compare with Current Version command) to show the differences between the snapshot and current text.
3. Read the comparison: insertions and deletions are marked by colour or styling, so you can find what you removed or added in a session. Use it to check an editor's revisions against yours.
4. The display is a diff of text, not a merge tool; copy back what you want by hand.

## Restore
- **Roll Back** replaces the current text with the snapshot; take a new snapshot of the current text first, so you can go back again.
- Or copy specific sentences from the snapshot into the current document.

## Housekeeping
- Snapshots add to project size and are included in backups; delete obsolete ones in the Snapshots pane.
- Use clear titles and dates.
- Snapshots are not a substitute for backups (`creative-arts.literary-writing.scrivener.automatic-backups-and-restoring`).

## Verify
- [ ] A snapshot exists before each large revision.
- [ ] A compare view shows differences correctly.
- [ ] You practised a roll back on a test document.
