# Project and session targets

**Goal:** turn a manuscript goal into a daily number Scrivener tracks for you, and see
progress per chapter. Scrivener 3; check menu names and shortcuts for your platform.

## Draft and session targets
1. **Project > Project Targets** opens the targets window: a **Draft** (manuscript)
   target and a **Session** target, each with a progress bar.
2. Set the **Draft target** (e.g., 90,000 words).
3. Open **Options** in the targets window:
   - **Deadline** date; **writing days** (e.g., Mon-Fri) and whether to count today;
   - let Scrivener **calculate the session target automatically** from words remaining
     ÷ writing days left;
   - when the session count **resets** (e.g., at midnight or when the project opens);
   - whether text in documents excluded from compile counts;
   - whether to show a notification when the target is reached.
4. Keep the window open (it can float) while writing.

## Document targets
- Each document can have its own target: the target/bullseye icon in the editor footer
  (bottom of the editor) — set words (or characters) for a chapter or scene.
- Outliner: add **Target**, **Progress** and **Total Words** columns to see each
  chapter's progress bar.

## Practices
- For NaNoWriMo-style goals: 50,000 words, deadline 30 November, all days writing ->
  session target ≈ 1,667/day, recalculating as you fall behind or ahead.
- Exclude notes/research from counts (they're outside Draft by default).
- During revision, a negative target ("cut to 95k") can be tracked by watching total
  words against the draft target.

## Gotchas
- Session count resetting unexpectedly when the project closes — check the reset option.
- Counting words written then deleted: session counts net change by default in some
  settings — check whether "allow negatives" is set as you expect.
- Pasting large chunks inflates session counts.

- [ ] Session target auto-calculated and visible while writing.
