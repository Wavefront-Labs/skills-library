# Split editor and Quick Reference panels

**Goal:** see the draft and a second document together without losing your place. Menu names below follow Scrivener 3; shortcuts and exact labels differ between the Mac and Windows editions and by version, so confirm in the app's Help or the official user guide.

## Split the editor
1. **View > Layout > Split Editor** (Horizontal or Vertical in the submenu). Two editors appear; the active editor is the one you last clicked.
2. Clicking a binder item loads it into the active editor, so click inside the editor you want to change first.
3. Use one pane for the scene, the other for notes, a research PDF, a character sheet, or an earlier scene to check continuity.
4. **Lock** or link behaviour: the editor header has a control to keep a pane from changing when you click the binder, if your version has it. Check the header controls.
5. Close the split with the same menu.

## Copyholder
A **copyholder** is a pane on one side of the split used as a reference document, which can load a document and be navigated independently from the editor; it is Scrivener's version of a lectern for reference. Verify the exact control in your version.

## Quick Reference panels
- **Navigate > Quick Reference > Open Quick Reference** (or the document's context menu) opens a floating panel with a document. Panels can stay on top while you work in the main window, and several can be open.
- Good for **a scene you are quoting**, a **style sheet** or a **character sheet**.
- Panels are editable and show the document's own text.

## Bookmarks
Document bookmarks link from a document to others (Inspector > Bookmarks); a bookmark can be viewed in the Inspector pane or opened in a Quick Reference panel, which is ideal for pulling a source straight beside a scene. Project bookmarks are available from every document.

## Verify
- [ ] Two panes show the intended documents.
- [ ] A Quick Reference panel opens a bookmark source.
- [ ] You know which editor pane is active before you click the binder.
