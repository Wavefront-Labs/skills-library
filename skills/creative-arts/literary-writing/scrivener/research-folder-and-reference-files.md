# Research folder and reference files

**Goal:** keep everything you need in the project, searchable and next to the draft, without it appearing in the output. Menu names below follow Scrivener 3; shortcuts and exact labels differ between the Mac and Windows editions and by version, so confirm in the app's Help or the official user guide.

## What can go in
- **PDFs, images, audio, video** imported as files (File > Import > Files, or drag from the file system).
- **Web pages** captured as web archives or PDFs (File > Import > Web Page).
- **Text notes** you write: character sheets, setting notes, timelines, interview transcripts.
- Folders of related items (Characters, Places, Sources, Interviews).

## Steps
1. Create sub-folders inside Research for categories.
2. Import files; they are copied into the project (check the import dialogue options if you prefer links, which exist for some media to avoid project bloat).
3. Rename items with clear titles; add keywords and labels for search (`creative-arts.literary-writing.scrivener.scrivener-keywords`).
4. **View beside the draft**: split the editor (`creative-arts.literary-writing.scrivener.split-editor-and-quick-reference-panels`), or open an item in a Quick Reference panel.
5. Use **bookmarks** (document bookmarks and project bookmarks in the Inspector) to link a scene to its source material.
6. **Search** with scope set to include Research, or limit it to the Draft.

## Keep it out of compile
Items in Research are not compiled by default, but check Compile settings if you have moved items in or out of Draft.

## Gotchas
- Large video or audio files bloat the project and backups and can slow syncing; use links or keep files outside.
- Web captures preserve a snapshot, not a live page; save the URL in the note for provenance.
- Copyright: keep source material for personal reference; quotation in the book follows `creative-arts.literary-writing.creative-nonfiction.permissions-and-fair-use-for-quotations`.

## Verify
- [ ] Research items are organised in named sub-folders.
- [ ] A quick-reference view opens a source beside the draft.
- [ ] Compile output contains none of the Research material.
