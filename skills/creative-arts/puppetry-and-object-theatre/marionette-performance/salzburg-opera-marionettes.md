# Salzburg opera marionettes

**Goal:** know how an opera is staged with marionettes.

## Overview
- Founded by Anton Aicher in 1913, the company stages **operas** (especially Mozart) and ballets with marionettes about 60-90 cm tall.
- Scores are usually **recorded**, and the singers are not seen; the performance is a matching of puppets to a pre-recorded soundtrack.

## Technique
- Operators stand on a **high bridge** and work figures with wooden controls, each with many strings.
- Rehearsal uses **cue sheets** and counts so the moves land on musical beats.
- Stage set and lighting are miniature versions of opera design.

## Lessons
- Precise **timing and discipline** matter more than speed.
- Rehearse each figure's movement set independent of the others, then assemble.

## Check
You can describe the staging method and identify the problems of syncing a marionette to a sung line.
