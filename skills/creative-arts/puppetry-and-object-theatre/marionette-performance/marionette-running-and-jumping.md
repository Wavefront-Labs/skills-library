# Marionette running and jumping

**Goal:** energetic travel without tangles.

## Run
- Increase **rocking speed** and shorten the sway; lean the control a little forward.
- Give the figure a brief **airborne** moment by lifting the control slightly between steps, then landing.
- Keep arms swinging by small hand-string movements.

## Jump
- Bend the knees (slack strings), then **lift the control** sharply and lower with a settle.
- For a hop onto a step, practise with a spare figure.

## Safety for strings
- Move smoothly; abrupt lifts snap strings.
- Check strings after each performance.

## Check
The run reads as faster than the walk, with clear landing weight.
