# The dissecting skeleton

**Goal:** a skeleton that falls apart and reforms.

## Mechanism
- A **jointed skeleton** with each bone hung by its own string or by pairs; hands, skull and ribs may separate.
- Hooks or loops hold the limbs to the main body.

## Routine
- Start with a slow dance, then bones rattle loose one by one, the figure collapses in a pile, then reassembles.
- Each separation is a distinct **beat**.

## Tips
- Make a **string chart** and label each string.
- Practise the reassembly sequence.

## Check
The collapse and rebuild work in a single smooth sequence.
