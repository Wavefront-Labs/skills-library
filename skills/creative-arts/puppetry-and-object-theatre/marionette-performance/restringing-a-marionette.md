# Restringing a marionette

**Goal:** a figure that hangs level and works first time.

## Steps
1. Photograph the existing stringing and note each string's route.
2. Remove and **replace one string at a time**, labelling them.
3. Tie to the figure with a **clove or fixed knot** plus a drop of glue; thread through the control with a loop.
4. Hang the figure from the control and check **balance** (head level, shoulders level, feet touching).
5. Trim ends and re-check string lengths.

## Tips
- Keep spares of the same material.
- Use **eyes or screws** on the figure where possible.

## Check
The figure hangs straight with all strings equally taut, and each string moves the correct part.
