# Picking up hand strings

**Goal:** clean arm gestures without tangling.

## Method
- Hand strings run from the wrists to a **hook or paddle** on the control. With the free hand, lift the hand string with one or two fingers and pull the arm up or out.
- Keep the **other fingers on the control** to hold balance.
- Release by **returning the string to the hook** slowly.

## Gestures
- Wave, reach, hold a prop, clasp.
- Hold hand strings **slightly slack** at rest so arms hang naturally.

## Faults
- Pulling strings across others and tangling.
- Lifting the hand without a matching shoulder movement.

## Check
The figure can wave and then drop its arm cleanly without the strings crossing.
