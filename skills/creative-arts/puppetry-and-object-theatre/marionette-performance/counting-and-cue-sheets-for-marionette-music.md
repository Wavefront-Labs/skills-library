# Counting and cue sheets for marionette music

**Goal:** every operator knows what to do and when.

## Sheet layout
- Columns: **time or bar**, figure, action, string, note.
- Add **warnings** one bar before each cue.

## Use
- Distribute to every operator; run with the music.
- A stage manager **calls** key cues.

## Check
Operators rehearse the show without a missed cue.
