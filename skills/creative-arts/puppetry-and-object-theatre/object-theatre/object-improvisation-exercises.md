# Object improvisation exercises

**Goal:** a repertoire of exercises that produce material.

## Exercises
- **One object, three minutes:** discover what it can do and what it wants.
- **Pair:** two objects meet; one wants something.
- **Transform:** an object changes use midway.
- **Silent story:** tell a story without words.

## Method
- Work in **small groups**, short rounds, then show and discuss.
- Capture promising moments on **video** and in notes.

## Check
Each round yields at least one repeatable moment.
