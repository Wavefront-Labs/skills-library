# Object dramaturgy and narrative structure

**Goal:** a clear shape for a show built from objects.

## Dramaturgy
- Set **rules** early (what objects can do, who the performer is).
- Use **repetition and variation** to build humour and meaning.
- Provide a **want, obstacle, change** for the main object.

## Narrative shapes
- Journey, meeting, loss and return, transformation.
- Keep stories short and visual; **cut words** that duplicate the images.

## Check
A one-paragraph summary captures the want, obstacle and ending.
