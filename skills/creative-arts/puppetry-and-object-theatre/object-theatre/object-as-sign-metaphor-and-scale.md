# Object as sign metaphor and scale

**Goal:** objects that carry a clear meaning and then change it on purpose.

## Principles
- An object **stands for** something (a spoon is a boat, a hat is a house). State the meaning clearly early.
- A single object may later **change meaning** to create wit or poignancy.
- **Scale shifts** (a hand seen as a giant, a model as a town) show power, smallness or memory.

## Methods
- Use **close-up** actions to show scale: lift a small figure beside a large object.
- Keep metaphors simple and consistent.

## Check
Viewers can say what each object stands for at each moment.
