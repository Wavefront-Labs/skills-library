# Giving objects breath and focus

**Goal:** an everyday object that appears to breathe and look.

## Breath
- Give the object a **slow rise and fall** on the performer's own breath, small and constant; avoid wobble.
- Let the breath **change with feeling**: quicker for fear, slower for sleep.

## Focus
- Choose the object's **eyes**: the point that faces the target (a handle, a gap, a label). Turn that point toward what the object looks at.
- Look first, move second; hold the look for a beat.

## Waking
- Start from stillness, add breath, then a slow head-turn, then focus on something.

## Check
Observers say the object is alive or watching before it does anything else.
