# Scale and set pieces on the table

**Goal:** a table that works as a world.

## Choices
- Match **puppet size** to the table so the figure reads from the audience; typical tabletop figures are 50-100 cm.
- Use **simple objects** as scenery (a box for a house, a cloth for a river).
- Keep objects **low** so operators can reach the figures.

## Practice
- Place scenery so the puppets have a clear pathway.
- Change scale by shifting the scene (a big hand, a tiny model) for effect.

## Check
Objects on the table support the story without blocking sightlines.
