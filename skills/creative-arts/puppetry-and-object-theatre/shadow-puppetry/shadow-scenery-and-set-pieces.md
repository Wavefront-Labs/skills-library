# Shadow scenery and set pieces

**Goal:** scenery that supports the figures.

## Materials
- Card, thin plastic or leather cut-outs; translucent paper for light areas.

## Mounting
- Fix scenery to **rods or frames** at the screen so it stays sharp.
- Use **layers** at different distances to give depth.
- Use **tabs and slots** so pieces slot into a base.

## Storage
- Store flat in a labelled folder with a running order.

## Check
Scenery contrasts with figures and changes quickly.
