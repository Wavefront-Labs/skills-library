# Puppet get in set up and strike

**Goal:** repeatable get-in under an hour.

## Plan
- **Load order:** stage and frame first, lights and sound second, puppets and props last.
- Label cases with contents and set-up order.
- Use a **checklist** for each stage: build, mask, light, sound, puppets, props.

## Set-up
- Build the stage, then test **masking and sightlines**.
- Rig lights, run a cue check and a sound check.
- Lay out puppets and props by scene.

## Strike
- **Reverse order**; repair damage before packing.
- Count puppets and props back in; clear the space.

## Check
Time every get-in; aim to cut five minutes after each venue.
