# Bag types and proportions

**Goal:** choose the bag type and size that fits the customer's use and body, and get
proportions right before patterning.

## Types and typical dimensions (W x H x D, cm)
| Type | Typical size | Strap/handle drop |
|---|---|---|
| **Tote / shopper** | 35-45 x 30-38 x 12-18 | Shoulder: 22-28 cm |
| **Satchel** | 28-35 x 22-28 x 10-14 | Top handle 8-12 cm + long strap |
| **Crossbody** | 18-25 x 13-18 x 5-8 | Strap 110-130 cm adjustable |
| **Clutch** | 25-30 x 13-18 x 2-5 | None or wristlet |
| **Bucket** | 20-28 base dia/width x 25-30 H | Shoulder or crossbody |
| **Baguette / shoulder** | 25-28 x 13-15 x 5-7 | Short strap 20-25 cm drop |
| **Hobo** | 35-45 wide, slouchy | 20-25 cm |
| **Backpack** | 28-32 x 38-45 x 12-15 | Adjustable straps |
| **Belt bag** | 18-22 x 12-14 x 5-7 | Adjustable belt |

## Proportion rules
- **Strap drop** (top of handle to top of bag) decides where the bag sits: under the arm
  (shoulder), at the hip (crossbody), carried in hand (top handle 8-12 cm).
- Large bags read best with structured bases; small bags with slender straps.
- Check the bag against the body: photograph a cardboard mock-up on a fit model.
- Laptop totes need internal dimensions for target device (e.g. 13-14 in laptop ~33 x 23 cm).

## Gotchas
- Shoulder drop under ~20 cm doesn't fit over a coat.
- Deep gussets on small bags look boxy.
- Weight of hardware changes how a small bag hangs.

## Verify
- [ ] Mock-up photographed on a body.
- [ ] Strap drop measured over a coat.
- [ ] Dimensions on spec sheet as W x H x D.
