# Scarves and soft accessories

**Goal:** a range of scarves, wraps and soft accessories with clear formats, materials and finishes.

## Formats (cm)
| Format | Size |
|---|---|
| Bandana / neckerchief | 50-55 square |
| Small silk square | 70 x 70 |
| Classic silk square | 90 x 90 |
| Shawl square | 130-140 square |
| Skinny scarf | 15 x 150 |
| Oblong scarf | 30-70 x 180-200 |
| Stole / wrap | 70 x 200 |
| Snood / infinity | loop 60-80 circumference x 25-35 |

## Materials
- Silk twill (12-16 momme for squares), chiffon, crepe de chine, modal, cashmere, merino,
  wool-silk, cotton voile, lambswool.
- Woven (jacquard, check, herringbone) vs knitted (rib, fisherman) vs printed.

## Finishes
- **Hand-rolled hem** (silk squares): small rolled edge stitched by hand, rolled toward the
  print face.
- Machine-rolled or overlocked hem.
- **Fringe** (twisted or plain) on wovens; specify length (5-10 cm).
- **Blanket stitch** edging; brushed finishes for warmth.

## Range and merchandising
- Prints coordinate with the RTW collection; offer core colours plus seasonal prints.
- Packaging: folded square boxes for silk; bands for woven scarves; hangtags with care.

## Gotchas
- Brushed and loose knits pill; test.
- Light silk shows print through to the back; check reverse.
- Care labels on small items: sew-in label in a corner or printed.

## Verify
- [ ] Formats chosen and dimensions spec'd.
- [ ] Finish (hem/fringe) specified.
- [ ] Care label attached.
