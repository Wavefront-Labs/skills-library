# Dimensional change (shrinkage) testing

**Goal:** know how much a fabric or garment shrinks in home laundering before patterns are
cut, and specify limits for bulk.

## Standards
- **AATCC 135**: dimensional changes of fabrics after home laundering.
- **AATCC 150**: same for garments.
- **ISO 6330** (domestic washing and drying procedures) with **ISO 5077** (determining
  dimensional change) and ISO 3759 (preparation, marking and measuring).

## Procedure (in-house screening version)
1. Cut a specimen at least 50 x 50 cm (fabric); condition it.
2. Mark **benchmarks**: three pairs of marks 25-50 cm apart in length (warp) and width
   (weft) with indelible ink.
3. Measure each distance precisely (original length A).
4. Launder per the care label (temperature, cycle), dry per the label (tumble/line/flat);
   typically 3 cycles for a stable result.
5. Condition and re-measure (B).
6. **Dimensional change % = (B - A) / A x 100** (negative = shrinkage).
For certification, send to an accredited lab using the full standard.

## Limits (typical brand standards, set your own)
- Wovens: about +/-3% length and width.
- Knits: about -5% length, -5% width (tees often allowed a bit more).
- Garment-dyed or washed products: tested after the wash process.

## Using the results
- Pattern compensation for garment-washed products (enlarge patterns by the shrinkage).
- Choose pre-shrunk (sanforized, compacted) fabrics for cotton.
- Care label must reflect tested conditions.

## Gotchas
- Testing only one cycle underestimates progressive shrinkage.
- Fusible interlinings shrink differently from the shell (bubbling); test assemblies.
- Measuring wet or unconditioned fabric gives false results.

## Verify
- [ ] Benchmarks measured before and after per the standard.
- [ ] Results within brand limits in both directions.
- [ ] Care label and pattern compensation updated.
