# Screen separations and trapping

**Goal:** split artwork into one opaque positive per colour so the printer can make screens
that register and do not leave gaps.

## Separations
1. Reduce artwork to the agreed colour count first (see reducing colours skill).
2. Create one layer/channel per colour; each must be 100% black (opaque) where that colour
   prints. In Photoshop use spot channels; in Illustrator use spot swatches and output separations.
3. Name each film/colour with the Pantone or lab dip reference and print order.
4. Add registration marks and the repeat boundary (for rotary) on every film.

## Trapping
- Trap = deliberate overlap where two colours meet so slight misregistration does not show
  the ground. Typical traps on textiles are larger than paper: 0.25-1 mm depending on fabric
  and machine; ask the printer.
- Spread the lighter colour under the darker (darker colour defines the edge).
- **Fall-on (overprint):** two transparent colours printed over each other create a third;
  plan these to save a screen.
- Knockouts: where a light colour sits on a dark one with opaque ink, knock out the dark.

## Halftones and mesh
- Halftones on textiles: coarse (20-65 lpi) depending on fabric; fine dots fill in on rough cloth.
- Mesh counts: lower mesh (e.g. 43-77 threads/cm) for heavy deposits on knits; higher for fine detail.

## Rotary specifics
- Rotary repeat height fixed by screen circumference (commonly 640 mm, also 820, 914, 1018 mm);
  the design repeat must divide into it.

## Gotchas
- Zero traps leave white slivers on fabric.
- Too many fall-ons make colour unpredictable on dyed grounds.
- Fine lines under ~0.3 mm may not hold on coarse mesh.

## Verify
- [ ] One named film per colour with print order.
- [ ] Traps agreed with the printer.
- [ ] Repeat fits the screen size.
