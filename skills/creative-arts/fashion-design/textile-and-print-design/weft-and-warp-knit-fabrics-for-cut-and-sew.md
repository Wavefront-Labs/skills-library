# Weft and warp knit fabrics for cut-and-sew

**Goal:** choose the right knitted yardage for cut-and-sew garments and spec it properly.

## Weft knits (circular or flat machines; loops run across)
| Fabric | Character | Uses |
|---|---|---|
| Single jersey | Light, curls at edges, ladders | T-shirts, linings |
| Rib (1x1, 2x2) | High widthways stretch and recovery | Cuffs, necks, fitted tops |
| Interlock | Double-faced, stable, does not curl | Polos, babywear |
| Ponte / double knit | Firm, structured | Trousers, dresses, jackets |
| French terry / fleece | Loops or brushed back | Sweatshirts |
| Piqué | Textured, breathable | Polo shirts |

## Warp knits (loops run lengthwise; made on tricot or raschel machines)
| Fabric | Character | Uses |
|---|---|---|
| Tricot | Smooth, runs-resistant, stable | Lingerie, linings, swim |
| Raschel | Open, lace and mesh | Lace, nets |
| Powernet | High-power stretch | Shapewear, panels |
| Spacer mesh | 3D, cushioned | Sportswear, footwear |

## Spec when buying
- Gauge or cut, gsm, width (often open-width or tubular), content, stretch % both ways and recovery.
- Spirality (twist) after washing for single jersey: tolerance typically under ~5%.
- Shrinkage (AATCC 135 / ISO 6330 + 5077).

## Gotchas
- Single jersey side seams twist if spirality is high; test washed garments.
- Tubular jersey has a crease line; cut avoiding it or buy open-width.
- Warp knits stretch less lengthwise; check direction of greatest stretch before cutting.

## Verify
- [ ] Structure suits garment stretch needs.
- [ ] Spirality and shrinkage tested.
- [ ] Stretch direction marked on the pattern grainline.
