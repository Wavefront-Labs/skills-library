# Print repeats and colourways

**Goal:** turn a motif drawing into a production-ready repeating print with several
colourways, at a scale that reads correctly on the garment, in a file the printer can use.

## 1. Choose the repeat structure
- **Block (straight/full-drop):** tile side by side. Simplest; most likely to show
  obvious rows and columns.
- **Half-drop:** each column shifted down by half the tile height. Breaks horizontal
  lines; the standard choice for allover florals.
- **Brick:** each row shifted sideways by half. Horizontal equivalent of half-drop.
- **Mirror/turnover:** tiles flipped — good for symmetrical, damask-like looks.
- **Placement / engineered prints** are not repeats: designed to the pattern piece
  (e.g. a border along a hem). Get the pattern pieces before designing these.

## 2. Tile size and the printer's limits
- Ask the mill/printer for **maximum repeat size and printable width before you start.**
  Rotary screen has a fixed circumference (a commonly cited size is 64 cm, but confirm —
  machines vary); digital printing is more flexible but has a max width and DPI.
- Common file spec for digital: tile at final size, 150–300 dpi, RGB or the printer's
  required profile — ask, specs differ.
- Screen printing needs **separations**: one layer per ink colour, flat colour only, a
  fixed count (often budgeted at 4–8 screens). Gradients need halftones or a different
  method.

## 3. Build a seamless tile (Photoshop/Illustrator method)
1. Draw motifs on a canvas at the tile size.
2. Photoshop: *Filter › Other › Offset* by half width and half height (wrap around)
   to bring the edges to the centre; fill the gaps; offset back. Illustrator: use the
   *Pattern Options* panel (Object › Pattern › Make) and choose Grid, Brick or Hex tile
   types with a live preview.
3. Repeat until no seam is visible at 400% zoom.
4. Tile it 4×4 and look from across the room: **hunt for "tracks"** — accidental lines,
   clusters and holes that only appear when repeated. Move or rotate motifs to break them.

## 4. Scale on the body
Print a 1:1 test strip and hold it against a body or drape it on the stand. Rules of thumb:
small ditsy prints read as texture from a few metres away; large motifs get cut by seams and
darts and land in unflattering places (bust, crotch) — check on the actual pattern pieces.
Check pattern matching at CF, pockets and side seams costs fabric; decide early whether
the print must match.

## 5. Colourways
- Build the design with indexed colours (named swatches or one layer per colour) so a
  colourway is a swap, not a repaint.
- Make 3–5 colourways: one hero matching the collection's colour story, one dark, one
  light/neutral, one commercial "safe" one.
- Keep value contrast consistent between colourways or the motif hierarchy changes.
  Check by converting each to greyscale.
- Specify colours with a physical standard (e.g. Pantone TCX cotton swatches or the
  mill's lab-dip system). Screen colour is not a standard; approve **lab dips / strike-offs**
  in daylight-balanced viewing light before bulk.

## Gotchas
- Designing in a canvas that is not an exact divisor of the printer's repeat — the
  printer will rescale and break your seams.
- Fine lines below the process minimum disappear (ask for minimum line weight).
- Print on knit stretches; check scale on the worn, stretched fabric.
- Metamerism: a colour that matches under shop light can mismatch outdoors.

## Verify
- [ ] Repeat type chosen on purpose; tile meets printer size/width/DPI spec.
- [ ] No visible seams or tracks in a 4×4 tile at viewing distance.
- [ ] Scale tested at 1:1 on body or stand.
- [ ] At least three colourways, greyscale-checked for consistent contrast.
- [ ] Colour standards and strike-off approval step agreed with the printer.
