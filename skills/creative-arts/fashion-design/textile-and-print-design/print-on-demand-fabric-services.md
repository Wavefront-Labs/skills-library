# Print-on-demand fabric services

**Goal:** get printed fabric for samples, small runs or makers without screens or MOQs.

## Services
- Spoonflower and similar (Contrado, Bags of Love, local digital bureaus). They print from your
  file onto a menu of base fabrics, usually in reactive, pigment or sublimation inks depending on
  base.

## File setup (check the service's current spec)
- Typical: RGB JPG/PNG/TIFF at 150 dpi at final size; repeat tile seamless. Choose repeat type
  (basic, half-drop, half-brick, mirror, centred) in the upload tool.
- Set print width to the fabric's printable width; border/engineered designs need full-width files.
- Name colours with the service's colour map/colour guide hex codes for predictable results.

## Workflow
1. Order the service's **colour map/colour guide** on your target base; pick hex codes from it.
2. Order test swatches (8 x 8 in/20 x 20 cm type) on 2-3 bases.
3. Wash test swatches as the garment would be washed.
4. Order yardage; allow production lead time plus shipping.

## Choosing base
- Same design prints differently by base: sublimation-polyester bases are brighter than
  pigment-cotton bases. Order swatches on the actual base.
- Check weight (gsm), width and content stated by the service.

## IP and privacy
- Most services offer private vs for-sale designs; keep unreleased collection prints private.

## Gotchas
- Monitor colours are not what prints; use the colour guide.
- Scale set wrong in the upload tool changes motif size.
- Not production-grade for large runs: cost per metre is high and lots vary.

## Verify
- [ ] Swatch approved on the chosen base.
- [ ] Repeat tiles seamlessly in the preview.
- [ ] Design set private until launch.
