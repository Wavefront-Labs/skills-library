# Shoe size systems and grading

**Goal:** label, convert and grade footwear sizes correctly across markets.

## Systems
| System | Unit | Notes |
|---|---|---|
| **EU (Paris point)** | 2/3 cm (6.67 mm) per size | Based on last length |
| **UK** | barleycorn 1/3 in (8.47 mm) per size | Child and adult scales; half sizes |
| **US** | same increment as UK, offset | Men's US approx UK + 1; women's US approx UK + 2 (varies by brand) |
| **Mondopoint** (ISO 9407) | foot length and width in mm | Ski boots, military; most accurate |
| **Japan / China** | foot length in cm or mm | e.g. 26.5 |

## Conversions
- Size charts vary by brand because they convert from **last length**, not foot length. Build
  your own chart from your last and test with feet.
- Never rely on generic online tables for production labelling; use the factory's chart for
  your last.

## Widths
- UK fittings (E, F, G, H) and US (A, B, C, D, E, EE): each step usually ~5-6 mm ball girth.

## Grading
- Lasts grade in length by size step and in girth (typical: length 6.67 mm per Paris point,
  ball girth about 4-5 mm per size).
- Soles: mould per size or per **size pair** (e.g. one mould for 38/39); heels often per group.
- Uppers: graded patterns per size from the base (often 37 women, 42 men).

## Gotchas
- Using one sole for a size group means toe/heel overhang varies; check extremes.
- Half sizes need separate lasts and often sole moulds; cost.
- Unisex sizing labels confuse; state both men's and women's sizes explicitly.

## Verify
- [ ] Size chart built from the brand's own last.
- [ ] Extreme sizes fit-trialled.
- [ ] Sole mould size groupings confirmed.
