# Last modification and toe shape

**Goal:** get a last that delivers the new look without breaking fit, by knowing what can be
modified and how to brief the last maker.

## What a last maker can change
- **Toe shape and extension:** round, almond, square, pointed, chisel. Extension beyond the
  foot is added length (pointed toes can add 2-4 cm); the fitting area stays the same.
- **Toe spring:** height of the toe tip above ground; more spring helps roll-off on stiff soles.
- **Heel height and pitch:** changing heel height on an existing last requires adjusting
  the seat angle and toe spring; usually > 10-15 mm change means a new last series.
- **Girths:** ball, waist, instep girth (in mm); widths (e.g. UK F, G; US B, D) by girth steps.
- **Feather line and bottom shape** for different sole constructions.

## Brief
- Base last reference (maker and model), target changes in mm, reference shoe or toe sketch at
  1:1 in side and top view, heel height, construction method.
- Approve a **sample last** (often in wood or 3D-printed/milled plastic), then fit trial shoes
  before grading.

## Toe shape and fit
- Pointed toes must start tapering **after** the toe joints, not on them; the extra length
  goes past the toes.
- Square toes need toe box height to clear the big toe.

## Gotchas
- Small toe changes alter the vamp line and upper patterns; re-pattern.
- Modifying only the base size and grading proportionally distorts toe shapes on large sizes.
- 3D last software (e.g. Delcam/Autodesk, Lastmaker, Romans CAD) helps but approve physically.

## Verify
- [ ] Fit trial in base size before grading.
- [ ] Changes recorded in mm against the base last.
- [ ] Upper pattern updated.
