# Tuck, miss and lace structures

**Goal:** use the three non-knit needle actions to create texture, width and openwork.

## Needle actions
- **Knit:** needle takes yarn and casts off old loop.
- **Tuck:** needle takes yarn but keeps the old loop; loops accumulate, giving bumps and width.
- **Miss (float/slip):** needle does not take yarn; yarn floats behind.

## Tuck structures
- **Full cardigan (fisherman rib):** tuck on alternate needles on both beds each course; bulky,
  wide, soft. Widthways spread ~30-50% vs 1x1 rib.
- **Half cardigan (half fisherman):** tuck on one bed only, alternate courses; asymmetric texture.
- Tuck stitches make fabric **wider and shorter**; tuck lace (tuck on several courses) makes
  openwork-like holes.
- Limit: usually 2-4 tucks stacked before loops break or fabric jams.

## Miss structures
- Floats make fabric **narrower** and less stretchy; used in slip-stitch colourwork and in
  jacquard backings.
- Float length limit: about 5-7 needles at 12 gg before snagging; shorter on finer gauges.

## Transfer lace
- Loop transferred to the adjacent needle, leaving an empty needle = eyelet. Combined patterns
  create lace; transfers slow the machine and add cost.

## Charting
- Use the machine's symbols (Shima Seiki SDS-ONE APEX / Stoll M1plus) or a generic chart with
  colour codes per action; give the factory a swatch plus chart.

## Gotchas
- Mixing tuck and plain areas produces different widths; garment edges flare.
- Tuck patterns increase yarn consumption (10-30%).

## Verify
- [ ] Swatch measured for width/length change.
- [ ] Float lengths within limit.
- [ ] Chart and swatch sent together.
