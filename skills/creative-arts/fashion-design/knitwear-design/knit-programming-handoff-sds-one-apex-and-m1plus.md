# Knit programming handoff (SDS-ONE APEX, M1plus)

**Goal:** give the knit programmer everything they need to turn the design into a machine
program first time, and use their simulation to check before knitting.

## The systems
- **Shima Seiki SDS-ONE APEX** (APEX3/APEX4): design, knit simulation (realistic virtual
  samples), and programming for Shima machines incl. WHOLEGARMENT.
- **Stoll M1plus** (now part of Karl Mayer group, with Stoll knit programming): pattern
  programming and simulation for Stoll flat machines.
- Programmers in the factory or a sampling studio do the programming; designers rarely
  program fully, but must speak the language.

## Send
- Technical flat (front/back), measurements (finished), gauge and machine type if known.
- Structure chart: needle actions per area (knit front/back, tuck, miss, transfer), colour codes
  per yarn feeder, with a legend matching the yarn list.
- Yarn list: count, ends, colour references, feeder allocation.
- Shaping: fully fashioned marks, necklines, armhole shaping, rib heights.
- Swatch (physical) of the intended stitch with stitch density (wales/courses per cm).
- Finishing recipe (affects knit size).

## Use the simulation
- Ask for a **virtual sample** (APEX knit simulation or M1plus simulation): check colour
  proportions, pattern placement and scale before sampling.
- Approve the program image; comments go back to the programmer per area.

## Gotchas
- Charts drawn without knowing gauge produce motifs the wrong size; chart in stitches at the gauge.
- Colour codes not matched to feeders cause wrong colour placement.
- Machine limits (feeders, transfers per row) can force simplification; ask early.

## Verify
- [ ] Charts in stitches at target gauge.
- [ ] Yarn and colour codes consistent across chart and yarn list.
- [ ] Virtual sample reviewed before first knit.
