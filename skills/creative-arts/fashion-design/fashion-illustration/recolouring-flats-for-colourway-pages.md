# Recolouring flats for colourway pages

## Prepare the flat
1. Build the flat with closed shapes filled separately: body, contrast panels, trims, stitching.
2. Fill with **global swatches** named by role (`Body`, `Contrast`, `Trim`, `Stitch`).
   Editing a global swatch updates every object using it.
3. Keep stitching and shading on their own layers so they can follow or ignore recolouring.

## Recolour
- **Edit > Edit Colors > Recolor Artwork**: map current colours to a palette. Load the
  season palette as a colour group (or a Pantone FHI library from Swatch Libraries > Color Books).
- Use the Assign view to control which old colour maps to which new; keep tonal stitching
  linked to the body colour.
- Save each result as a colour group so colourways stay reproducible.
- Fast method for many flats: duplicate the artboard, then edit the global swatch values per artboard.

## Colourway page
- The same flat repeated at the same size per colourway; front only unless the back changes.
- Under each: colourway name, Pantone TCX/TPG code, fabric reference and colour code.
- Print colourways: clip the recoloured print swatch into the body shape.

## Gotchas
- Non-global swatches and gradients recolour unpredictably.
- Screen colour isn't the approval standard; codes are. Approve with lab dips.
- Recolour print artwork separately from the flat, then place.

## Verify
- [ ] Every fill uses a named global swatch.
- [ ] Codes printed with every colourway.
- [ ] Flat scale identical across the page.
