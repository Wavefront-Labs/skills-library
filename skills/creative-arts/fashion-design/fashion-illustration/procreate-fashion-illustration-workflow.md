# Procreate fashion illustration workflow

## Canvas
- Portrait A4 or A3 at **300 DPI** (A4 = 2480 x 3508 px). Larger canvases reduce the
  maximum layer count (Procreate limits layers by canvas size and device memory).
- Insert the croquis template as a photo, set layer opacity 30-40%, lock it (swipe left > Lock).

## Layers
Croquis (locked), rough sketch (low opacity), ink, skin, garment flat colours (one layer
per garment), shadows (Multiply, clipping mask), highlights (Add/Screen), background.
Set the ink layer as **Reference** so ColorDrop fills colour layers below without gaps.

## Inking
- Studio Pen or Technical Pen; raise **StreamLine** in Brush Studio > Stabilisation for
  smooth curves.
- Pressure gives line-weight variation; rotate the canvas instead of your wrist.

## Colour
- ColorDrop flat colour into reference areas; drag left/right while holding to set Threshold.
- **Alpha Lock** to paint inside a layer, **Clipping Mask** to keep shadows/prints editable.
- Prints: insert the swatch, clip it to the garment layer, Transform > Warp to follow the body.
- Recolour: Adjustments > Hue, Saturation, Brightness on the garment layer.

## Export
- Share > PNG (flat, keeps transparency) or PSD (layers for Photoshop finishing).
- Time-lapse replay export suits portfolio and social posts.

## Gotchas
- Layer limit hit mid-illustration: merge shadow layers or work at A4.
- ColorDrop leaking: ink lines not closed; close gaps or lower the threshold.
- Back up .procreate files to Files/cloud; they live inside the app.

## Verify
- [ ] Canvas 300 DPI at output size.
- [ ] Ink on its own layer set as Reference.
- [ ] Shadows and prints on clipping masks, not merged.
