# Group and lineup illustration

## Lineup (technical presentation)
- All figures on **one croquis scale and one ground line**, evenly spaced, front walking
  or static poses. Purpose: compare silhouettes, colour flow and proportion.
- Order by colour flow and silhouette rhythm, matching the planned runway order.
- Number looks under each figure; flats and swatches can sit beneath.

## Group illustration (mood and narrative)
1. Thumbnail the composition first; 3-7 figures read best.
2. **Overlap** figures slightly to unify the group; vary depth (back figures smaller,
   placed higher) for space.
3. Vary poses (front, 3/4, back, walking) so different garment views appear, but keep
   one dominant figure as the focal point.
4. Figures on the same plane share an eye line.
5. Unify with one light direction, the same media and a shared background tone.

## Gotchas
- Figures at different scales on a lineup suggest different sizes.
- Overlap that hides key design details; overlap only plain areas.
- Identical poses read as a pattern, not a group.

## Verify
- [ ] Common ground line and scale (lineup) or consistent perspective (group).
- [ ] Each look's key detail visible.
- [ ] Order follows the collection's colour/silhouette story.
