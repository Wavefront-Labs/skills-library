# Flats and colourway range board

**Purpose:** show the whole range on one page/board so merchandisers, buyers and the design
team can check balance: category mix, price ladder, colour spread, repetition.

## Layout
1. Grid by **category** (outerwear, jackets, tops, bottoms, dresses, knit) in rows, or by
   delivery/drop in columns.
2. All flats at **one scale**, front views, aligned on a common baseline.
3. Under each flat: style number, name, fabric, target price, and colourway chips with codes.
4. Header: season, collection name, delivery, palette strip.
5. Mark carryover vs new, key items, and items still in development.

## Checks the board enables
- Category counts against the line plan.
- Colour distribution: each colour appears across enough categories to build outfits.
- Price ladder: good/better/best spread per category.
- Silhouette repetition or gaps.

## Tools
Illustrator artboards (A3/tabloid landscape), InDesign for multi-page books, or PLM range
boards; export to PDF for review.

## Gotchas
- Mixed scales (a coat drawn smaller to fit) mislead on proportion.
- Colour chips sampled from screen; use approved standard codes.
- Out-of-date boards: version and date every page.

## Verify
- [ ] Consistent scale and baseline.
- [ ] Every style has number, fabric and colourways.
- [ ] Board totals reconcile with the line plan.
