# Illustration board layout and hierarchy

**Goal:** a board that reads in seconds: what the collection is, what the key looks are,
what they're made of.

## Elements
Hero illustration(s), supporting figures, technical flats (front/back), fabric swatches,
colour palette, title and short concept text, optional mood image.

## Hierarchy
1. One focal element (largest, highest contrast): the hero look.
2. Secondary: other looks at a consistent smaller scale.
3. Tertiary: flats, swatches, palette, text.
Eye path usually top-left to bottom-right (Western reading); place the hero off-centre.

## Grid and spacing
- Use a column grid (e.g. 6 or 12 columns on A3 landscape) and consistent margins
  (15-20 mm).
- Align flats and swatches along grid lines; equal gutters.
- Leave white space; boards fail by crowding more than by emptiness.

## Typography
- One or two typefaces; title large, body 9-12 pt for print.
- Labels near the elements they describe; same style throughout the portfolio.

## Output
- Build in InDesign (or Illustrator) with linked images; illustrations scanned at 300-600 dpi.
- Print: PDF/X-1a or high-quality print PDF, CMYK, 3 mm bleed if full-bleed.
- Screen: RGB PDF/JPG; check colour on a calibrated monitor.

## Gotchas
- Mixing figure scales on one board confuses the read.
- Swatches glued on physical boards must be the same set as the digital file.
- Text-heavy boards don't get read; 30-60 words maximum.

## Verify
- [ ] Clear focal point and consistent scale.
- [ ] Elements aligned to a grid with margins.
- [ ] Correct colour mode and resolution for output.
