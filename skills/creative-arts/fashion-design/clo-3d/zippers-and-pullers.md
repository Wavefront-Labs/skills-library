# Zippers and pullers in CLO

**Goal:** zips that look right (teeth, tape, puller) and behave correctly in simulation.

## Creating
1. Select the **Zipper** tool (3D window in most versions).
2. Click along the edge of the first side from start to end (double-click to finish), then
   along the opposite side in the same direction. CLO creates the zip connecting both.
3. The zipper appears with default tape, teeth and puller.

## Properties (select zipper in Object Browser or 3D)
- **Teeth type**: coil, metal, plastic moulded (Vislon-style); size (e.g. #3, #5, #8).
- **Tape width** and colour; teeth colour; puller and slider shape from library or OBJ.
- **Open/close state**: slide position (open the zip partially for styling).
- Invisible zipper option where available.

## Placement realism
- Align zips with the real placement: centre front, side seam invisible zips, pockets.
- Topstitch around the zip (see topstitch skill) for realism.
- For separating (open-end) jackets, zip both sides; for closed-end, end at the stop.

## Simulation tips
- Zips are stiff; on soft fabrics they can wave - add interlining/fusible or strengthen the
  edge pattern.
- Too-coarse particle distance on the zip edge causes jagged tape.
- Zip lengths unequal between sides twist the garment.

## Gotchas
- Drawing sides in opposite directions twists the zip.
- High-detail metal teeth increase render time; use lower settings for previews.

## Verify
- [ ] Teeth type, size and colours match the BOM.
- [ ] Zip runs straight without waving.
- [ ] Slide position set for the intended styling.
