# Fit model selection and base size

**Goal:** fit all samples on a body that exactly represents the base size of the brand
chart, so production fits the customer.

## Choose the base size
- Middle of the sales size curve (often UK 10-12 / US 6-8 / EU 38-40 for womenswear
  misses; M for letter-sized lines).
- Same base size for the whole line so fits are consistent.

## Choose the fit model
- Measure candidates: height, bust/chest, waist, high hip, low hip, inside leg,
  shoulder, neck, arm length, back length.
- Accept within about +/-1 cm on key dimensions of the chart's base size; posture and
  proportion matter as much as numbers.
- Not a runway model: fit models represent customers.
- Keep a **fit model log**: measurements each month (bodies change), notes on posture.

## Fit model and form
- Match a dress form (padded) to the fit model so pre-fits on the form are reliable.
- In 3D, build the base avatar to the fit model's measurements.

## Session practice
- Fit model wears consistent underwear/shoes per category.
- Fit with the same model across the season; record any changes.
- For size sets, use graded fit models or check key sizes (smallest, base, largest).

## Gotchas
- Changing fit models mid-season shifts the fit of the whole line.
- A fit model between sizes leads to "fixes" that move the base off the chart.
- Fitting only the base size misses grading problems at the extremes.

## Verify
- [ ] Fit model measurements logged within tolerance of the base size.
- [ ] Form and avatar matched to the fit model.
- [ ] Extreme sizes checked before bulk.
