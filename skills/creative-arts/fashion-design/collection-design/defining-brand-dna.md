# Defining and protecting brand DNA

**Goal:** a written set of design codes that make the brand recognisable without the
logo, and rules for which codes must appear every season.

## Find the codes (audit)
1. Lay out the last 4-6 seasons' best sellers and best press images.
2. List repeated elements under: **silhouette**, **detail** (a pocket, a seam, a
   closure), **material**, **colour**, **print/pattern**, **hardware**, **attitude/styling**.
3. Mark which repeat in both sales and press: these are the core codes.
Examples (public): Chanel tweed jacket with chain-weighted hem and braid trim;
Burberry check and trench details; Bottega Veneta intrecciato weave.

## Write the DNA document
- 5-8 codes, each with a photo, a one-line definition and its fixed parameters
  (e.g. "contrast topstitch, 6 mm from edge, 3.5 stitches/cm, tonal thread only").
- Classify: **always** (every season), **rotating** (some seasons), **retired**.
- Evolution rules: what may change (scale, colour, material) and what may not.

## Use it in each season
- At line review, check every category has at least one "always" code.
- Signature pieces (carryover) get yearly refresh in fabric/colour only.

## Gotchas
- Too many codes = none; brands are remembered for few things.
- Changing a code because a designer is bored loses customers; change in measured steps.
- Protect distinctive codes with design registration or trademark where possible.

## Verify
- [ ] 5-8 codes documented with parameters and images.
- [ ] Each code is classified always/rotating/retired.
- [ ] Line review checklist includes a DNA check.
