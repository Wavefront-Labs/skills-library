# Zero-waste pattern design

**Goal:** a garment whose pattern pieces use the whole width and length of the fabric
with (near) zero offcuts. Conventional cutting typically wastes around 15% of fabric.

## Principles (Rissanen and McQuillan, *Zero Waste Fashion Design*)
- Design **with** the pattern, not before it: the layout shapes the garment.
- Start from the fabric: width (e.g. 140 cm), length budget, selvedge use.
- Use the leftover shapes as functional parts (pockets, facings, ties, gussets, collars).

## Methods
1. **Jigsaw/tessellation**: draw the full fabric rectangle at scale (1:5); place main
   pieces; reshape adjacent edges so they nest; leftovers become small parts.
2. **Geometric cutting**: rectangles, squares and triangles (kimono, kurta, Holly
   McQuillan's "make/use" systems). Shape comes from folds, pleats, draping.
3. **Subtraction cutting** and tucks/pleats to absorb excess instead of cutting it away.
4. **Full-width trousers/skirts** where gores are cut as interlocking trapezes.

## Process
- Work at 1:5 or 1:4 in paper, then full scale; toile in calico the full width.
- Iterate: a design change moves several pieces; check the whole layout every time.
- Grading is hard: each size may need its own layout; plan width use per size or use
  adjustable elements (pleats, ties).

## Gotchas
- Zero-waste for one size can waste in others.
- Selvedges and fabric flaws reduce usable width; measure the real fabric.
- Industrial markers already achieve 80-90% efficiency; claims need comparison.

## Verify
- [ ] Layout drawn at scale on the real fabric width.
- [ ] Waste measured (area of offcuts / total) and recorded.
- [ ] Toile made from the full layout confirms the design.
