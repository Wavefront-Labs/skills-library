# Building a garment cost sheet (FOB and landed)

**Goal:** know what a style really costs delivered to your warehouse, so pricing and
design decisions are made on facts.

## Cost sheet lines
| Line | How to get it |
|---|---|
| Fabric | Consumption (m per garment from the marker, incl. wastage ~3-5%) x price/m |
| Lining/interlining/pocketing | Same method |
| Trims | Buttons, zips, labels, thread, hangtags, packaging: unit price x qty |
| CMT (cut, make, trim) | Factory quote from the sample and tech pack |
| Wash/print/embroidery | Per-unit quotes |
| Testing/compliance | Per style or allocated |
| Factory overhead and profit | Usually included in FOB quote |
| **FOB** | Price at the origin port, loaded (Incoterm FOB) |
| Freight | Sea/air per unit (cbm or kg based) |
| Duty | HS code duty rate x customs value |
| Insurance, clearance, fees | Broker, port, inland transport |
| **Landed cost** | FOB + freight + duty + fees |

## Steps
1. Get marker consumption from the pattern room or factory (not a guess).
2. Request FOB quotes from 2-3 factories with the same tech pack.
3. Classify the HS code (e.g. by fibre and construction: knitted vs woven changes duty) and
   look up the rate in the destination tariff (US HTS, EU TARIC, UK Trade Tariff).
4. Add freight per unit and fees; compute landed cost.
5. Record currency and exchange rate used.

## Incoterms
FOB (buyer pays from port of loading), CIF (seller pays freight and insurance to
destination port), DDP (seller delivers duty paid). Compare quotes on the same term.

## Gotchas
- Knitted vs woven and fibre content can change duty a lot; design choices affect cost.
- Sample-room consumption is higher than production markers; re-check at bulk.
- Small orders get surcharges (below MOQ); cost at real quantities.

## Verify
- [ ] Consumption from a marker, not an estimate.
- [ ] HS code and duty source recorded.
- [ ] FOB and landed cost both shown with currency and Incoterm.
