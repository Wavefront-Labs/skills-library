# Running a fit session and writing fit comments

**Goal:** a 15-30 minute fit per style that ends with precise, measurable comments the
factory can apply without guessing.

## Before
- Measure the sample flat against the spec; mark out-of-tolerance POMs in red.
- Prepare: pins, tape measure, chalk, camera, previous comments, flats, fabric info.
- Fit model in the right base layers and shoes.

## During
1. Look at the garment on the body from front, side, back at 2-3 m.
2. Check balance (side seams vertical, hem level, CF/CB on body centre).
3. Check fit at: neck, shoulders, chest, armhole, sleeve, waist, hip, seat, length.
4. Movement: arms forward/up, sit, squat, walk; note pulling, gaping, riding up.
5. Read wrinkles: drag lines point toward the problem (tight areas pull, excess folds).
6. Pin corrections; measure the change with the tape (e.g. "pin out 1 cm at CB neck tapering to 0").
7. Photograph each view with pins in.

## Comments format
Numbered, one per issue, each with:
- Location and POM code,
- Observation ("back neck stands away 1 cm"),
- Action with measurement ("reduce back neck width 0.5 cm each side; new spec 17 cm"),
- Whether it applies to all sizes (grade) or base only.
Update the spec sheet and revision log in the same session.

## Gotchas
- Vague comments ("make it more relaxed") produce random changes.
- Correcting fit and design in one comment confuses the factory; separate them.
- Fitting in a sample fabric that differs from bulk hides real behaviour.

## Verify
- [ ] Every comment has a POM, measurement and action.
- [ ] Photos attached for every view.
- [ ] Spec and revision log updated after the session.
