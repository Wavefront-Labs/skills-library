# Colour flow across deliveries

**Goal:** each delivery (drop) looks complete on the floor and also mixes with the
previous drop, so customers can combine purchases and the store transitions smoothly.

## Plan it on a calendar
1. List deliveries (e.g. AW: Aug transition, Sep, Oct, Nov holiday; SS: Jan resort, Feb,
   Mar, Apr, May summer).
2. For each, assign 4-6 palette colours. Overlap **at least 2 colours** with the previous
   and next delivery.
3. Neutrals run through all drops; seasonal colours enter and exit; holiday drop may
   add metallics or a festive accent.
4. Match colour to weather: transition drops keep summer neutrals with first autumn colours.

## Example (AW)
| Drop | Colours |
|---|---|
| Aug | ecru, camel, sage, rust |
| Sep | camel, rust, chocolate, navy |
| Oct | chocolate, navy, burgundy, grey melange |
| Nov | navy, burgundy, black, silver accent |

## Check with the line plan
Each drop needs tops and bottoms and an outer layer in compatible colours, or the drop
can't be sold as outfits.

## Gotchas
- Production delays shuffle deliveries; a drop that relies on a delayed colour
  becomes orphaned. Keep neutrals as the safety net.
- Wholesale accounts may receive drops out of order; each should still work alone.

## Verify
- [ ] Each drop has 4-6 colours with at least 2 overlapping neighbours.
- [ ] Each drop forms complete outfits.
- [ ] Neutrals run through the whole season.
