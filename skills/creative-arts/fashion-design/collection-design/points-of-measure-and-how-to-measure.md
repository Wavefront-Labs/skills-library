# Points of measure and how-to-measure

**Goal:** a measurement spec that every factory measures the same way, so samples can be
checked objectively.

## Core POMs (woven top example)
| Code | POM | How to measure |
|---|---|---|
| A | Body length from HPS | From high point shoulder (where shoulder seam meets collar) straight down to hem |
| B | Chest width | 2.5 cm below armhole, edge to edge, garment flat (half chest) |
| C | Waist width | At narrowest point / specified distance from HPS |
| D | Hem width | Straight across at hem, edge to edge |
| E | Across shoulder | Shoulder point to shoulder point |
| F | Sleeve length | From shoulder point (or CB neck for raglan) to cuff edge |
| G | Bicep | 2.5 cm below armhole, perpendicular to sleeve fold |
| H | Cuff opening | Relaxed, edge to edge |
| I | Neck width | Seam to seam at HPS |
| J | Front neck drop | From HPS line down to CF neck seam |
Bottoms: waist (relaxed/extended), high hip, low hip, front/back rise, inseam,
thigh, knee, leg opening.

## Rules
- State **flat (half) vs circumference** for each.
- Specify **relaxed vs extended** for elastic waists and knits.
- Measure along the garment line or straight - state which (curved armholes!).
- Include a **how-to-measure diagram** per POM on the spec sheet.
- Tolerances per POM: tighter on small dimensions (neck +/-0.5 cm) than large (length
  +/-1-1.5 cm). Set them before sampling.

## Gotchas
- HPS vs CB neck confusion changes body length by 1-2 cm or more.
- Measuring curved seams straight vs along curve gives different numbers.
- Knits measured stretched vs relaxed vary widely; lay flat without tension.

## Verify
- [ ] Every POM has code, definition, diagram and tolerance.
- [ ] Flat vs circumference and relaxed vs extended stated.
- [ ] A second person measures a sample and gets results within tolerance.
