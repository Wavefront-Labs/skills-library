# Composing a moodboard that edits

**Goal:** one board that a pattern cutter, stylist or buyer can read in 10 seconds and
understand the mood, palette, materials and attitude of the collection.

## Selection
- Start from 60-100 research images; select **8-15**. Every image must add something new
  (silhouette, texture, colour, attitude, setting). Two images saying the same thing: keep one.
- Choose **one hero image**, the strongest single expression of the concept.
- Include at least one image for each: silhouette/shape, texture/material, colour, character.
- Add 3-6 physical swatches or colour chips if it is a physical board.

## Layout
- Hero image largest (roughly a quarter to a third of the board), placed off-centre.
- Group by visual rhyme (colours, lines) so the eye flows; avoid an even grid of equal images.
- Leave white/neutral space (15-25%); a crammed board reads as unedited.
- Title + 3-5 mood words, small and clean. Colour strip along an edge or bottom.
- A3 or A2 landscape for physical; 1920x1080 or A3 PDF for digital.

## Test
- Cover the title; ask someone to describe the mood in three words. If they match yours,
  it works.
- Remove each image in turn; if nothing is lost, it goes.

## Gotchas
- Pure runway images make the board a copy of other designers.
- Low-resolution web images pixelate in print; check at 100% before printing.
- Too many colours in images dilute the palette; use image colour consistent with the story.

## Verify
- [ ] 8-15 images, one clear hero.
- [ ] Silhouette, texture, colour and character all represented.
- [ ] Three-word test matches your mood words.
