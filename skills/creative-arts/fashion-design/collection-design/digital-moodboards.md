# Digital moodboards and the Pinterest-to-board workflow

**Goal:** collect widely online but present a curated, high-resolution, sourced board
that can be printed or shared with a team.

## 1. Collect
- **Pinterest**: one secret board per project, sections per theme (silhouette, colour,
  texture, character). Pin from the original source page when possible so the link survives.
- **Are.na**: better for mixed media (text, links, PDFs) and less algorithmic noise.
- Save originals to a project folder too; boards and links disappear.

## 2. Curate
Options:
- **Milanote**: drag images, notes, colour swatches; free-form canvas; export PDF/PNG.
- **Figma**: frames at A3 (1191x842 pt) or 1920x1080; components for colour chips;
  shareable for comments.
- **InDesign/Illustrator**: best for print; place linked images, check effective PPI.
Same editing rules as a physical board: 8-15 images, one hero, white space.

## 3. Resolution and colour
- For A3 print at 300 PPI you need ~4960x3508 px for full-bleed; an image filling a
  quarter needs ~2480x1754 px. Pinterest thumbnails rarely suffice; find the original.
- Colour chips: use Pantone TCX references with sRGB approximations, labelled
  "screen approximation".

## 4. Share
- Export PDF (print) and a 2000 px wide JPG/PNG (screen).
- Keep a source list (image, URL, credit) as a second page.

## Gotchas
- Screenshots of Pinterest pins = low resolution and lost credit.
- Shared live boards get edited by others; export a dated version at each review.

## Verify
- [ ] Every image is at least 150 effective PPI at print size (300 preferred).
- [ ] Source list accompanies the board.
- [ ] A dated export exists for each review.
