# Cohesion checks across looks

**Goal:** confirm that every look belongs to the same collection, through shared threads
rather than sameness.

## Threads to check (build a table: looks as columns, threads as rows)
| Thread | Question |
|---|---|
| Silhouette | Do looks use the same 2-3 silhouette families? |
| Fabric | Does each fabric appear in 2+ looks? |
| Colour | Does each colour appear in 2+ looks? |
| Signature detail | Is the key detail (a seam, a closure, a pocket) in most looks? |
| Finishing | Same edge finishes, stitch type, hardware family? |
| Styling | Shared footwear, hair, accessories, layering logic? |
Fill each cell with a mark; a look with few marks is an outsider.

## Fix outsiders
- Add a shared detail or fabric instead of cutting immediately.
- Move it to a different story or drop.
- Cut if it fights the concept.

## Variety check (the opposite risk)
Each look needs at least one difference: silhouette, length, layer count, colour or texture.
If two looks differ only in colour, consider merging into one style with two colourways.

## Gotchas
- One-offs (fabrics used once) cost money and break cohesion; aim for every fabric in 2+ looks.
- Too much cohesion becomes repetition; the audience stops looking.

## Verify
- [ ] Thread table complete for every look.
- [ ] Every fabric and colour appears in at least two looks (or is a deliberate accent).
- [ ] Every look has a clear difference from its neighbours.
