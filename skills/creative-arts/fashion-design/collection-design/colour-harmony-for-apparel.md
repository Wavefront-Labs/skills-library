# Colour harmony and contrast for apparel

**Goal:** combine colours within looks and across the collection so they read as
designed, using value and saturation as much as hue.

## Schemes
- **Tonal / monochrome**: one hue in several values and textures (cream wool, ecru linen,
  stone suede). Elegant; texture carries interest.
- **Analogous**: neighbours on the wheel (rust, ochre, olive). Calm, warm or cool.
- **Complementary**: opposites (navy + orange, green + red). High energy; usually one
  dominant and one small accent.
- **Split complementary / triadic**: more complex; use one dominant colour.
- **Neutral + accent**: the commercial default.

## Value and saturation
- Value contrast (light vs dark) reads from further away than hue contrast. Check
  in greyscale (photo desaturated): if all looks merge, add value contrast.
- Muted and saturated colours together: the saturated one dominates; size it down.
- **Proportion rule of thumb**: roughly 60/30/10 dominant/secondary/accent per look.

## Colour blocking
Place blocks along style lines (seams) so colour shapes the body: darker at sides
narrows; light at shoulders widens. Contrast at the waist cuts height.

## Skin tones
Test palette colours against a range of skin tones (swatch next to models or photos);
colours very close to skin value can wash out near the face; place them away from the
face or add a contrast collar/neckline.

## Gotchas
- Screen judgments of harmony fail in fabric; textures change perceived colour.
- Equal-sized complementary blocks vibrate; let one dominate.

## Verify
- [ ] Each look has a stated scheme and dominant colour.
- [ ] Greyscale check done for value contrast.
- [ ] Palette tested near the face on several skin tones.
