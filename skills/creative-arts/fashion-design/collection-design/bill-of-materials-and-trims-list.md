# Bill of materials and trims list

**Goal:** a complete list of what goes into the garment so the factory can source and
cost it, and nothing is substituted without approval.

## Columns
| Column | Example |
|---|---|
| Component type | Shell fabric / lining / interlining / trim / label / packaging |
| Description | 2-hole corozo button, 24 L, matte |
| Supplier | e.g. YKK, Avery Dennison, mill name |
| Supplier ref/article | Supplier code |
| Colour / colour code | Per colourway (or reference the colourway page) |
| Size / dimensions | 24 L; #5 coil zip, 18 cm closed-end |
| Placement | CF placket x6, cuffs x2, spare x1 |
| Quantity per garment | 9 |
| Unit of measure | pcs / m / cm |
| Unit price | For costing |
| Status | Approved / pending / sampled |

## Do not forget
Thread (type, ticket, colour per seam), fusibles (weight, where), elastic, tapes (stay
tape on shoulder, neck), shoulder pads, drawcord and tips, eyelets, hangtag and string,
size label, care/content label, brand label, barcode sticker, polybag with warning,
hanger, tissue, carton marks.

## Rules
- One row per component per placement if colour differs by placement.
- Spare buttons listed (often 1 per size of button).
- Nominate suppliers for brand trims; allow factory sourcing only for stated generic items.

## Gotchas
- Missing thread colour: factories pick "matching", which rarely matches.
- Custom trims have long lead times and MOQs; start them at design stage.
- BOM and flats out of sync after changes: update both in the same revision.

## Verify
- [ ] Every visible and hidden component listed.
- [ ] Supplier refs and colours per colourway specified.
- [ ] BOM total quantities match the flats callouts.
