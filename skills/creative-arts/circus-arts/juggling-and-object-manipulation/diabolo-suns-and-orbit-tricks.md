# Diabolo suns and orbit tricks

Suns and orbit tricks send the diabolo around in circular paths: around the body, around a stick, or between the hands. Names vary between communities, so confirm the exact trick with a video reference (the Library of Juggling, https://libraryofjuggling.com, has many diabolo entries) before teaching it.

## Prerequisites
- Stable acceleration and control.
- Throw and catch on the string.

## General method
1. Start with the diabolo at a high spin.
2. Choose a circular path (for example around one stick or around the body).
3. Move the sticks in a smooth circle so that the string keeps the diabolo on its path without a tilt.
4. Keep a continuous string tension throughout the circle.

## Learning order
1. Small, slow circles near the string.
2. Larger circles, both directions.
3. Return from the circle to a normal stance on the string, checking spin each time.
4. Combine with an acceleration pause at the end.

## Faults
- Dropping spin: add acceleration before the trick.
- Tilt at the end of the orbit: re-centre before the catch.
- Letting the string tangle on the stick: keep the string clear; use a longer string if needed.

## Safety
Orbits can bring the diabolo close to your head; keep clear of faces and check the surroundings.

## Verify
- [ ] 10 clean orbit tricks with a controlled return to the string.
