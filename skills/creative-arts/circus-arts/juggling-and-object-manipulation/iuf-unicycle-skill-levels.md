# IUF unicycle skill levels as a training ladder

The IUF publishes a numbered ladder of skill levels for unicyclists, from basic riding to advanced trick riding. National federations and clubs run level tests and badges based on it. Exact requirements are revised over time, so always download the current document from the IUF site (https://www.iuf.org) or your national federation; this skill does not reproduce requirements because I cannot confirm the current list from memory.

## How the levels are organised
- Each level lists a short set of skills (mounts, riding, turning, idling, hopping, one-foot riding, backward riding, and so on) with a measurable criterion for each.
- Early levels cover mounting, riding straight, turning, stopping and idling; later levels move into one-foot and hopping skills, then more advanced movements.
- A rider passes a level by completing every skill in the list in a witnessed test.

## Using them for training
1. Download the current level sheet; photograph or print it and tick off skills you can already do.
2. Choose the lowest level with an unticked skill; train only the missing skills (two or three at a time).
3. Film attempts so you can compare against the criterion (distance, count, time).
4. Test with an examiner (club coach, federation official) when every skill in the level is repeatable.

## Coaching tips
- Group children by level, not by age.
- Keep one confirmed skill in each session so riders end on success.
- Record the level result in the rider's log with the date and examiner.

## Verify
- [ ] You have the current IUF or national-federation level sheet, not an old forum copy.
- [ ] Each ticked skill was witnessed by someone other than the rider.
