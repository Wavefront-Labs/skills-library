# Reading siteswap ladder and causal diagrams

**Goal:** turn a siteswap into a picture you can read at a glance, and use causal
diagrams to learn tricks and passing patterns faster.

## Ladder diagram
- Two horizontal rails: top = right hand, bottom = left hand.
- Beats marked along the rails, alternating hands (R on beat 0, L on beat 1, ...).
- Each throw is an arc from its throw beat to the beat it is caught/thrown again
  (number of beats = the siteswap digit).
- Odd throws arc between rails (cross), even throws stay on the same rail.
- One continuous line traced through arcs = one object's path.
Use: see where each ball goes, count objects (number of separate paths), spot collisions
(two arcs landing on the same beat).

## Causal diagram
- Same rails, but an arrow goes from each throw to the throw it **causes**: the throw
  you must make to free the hand for the incoming object.
- In a 3-ball cascade, each throw causes the next throw from the other hand two beats
  later.
- In tricks, arrows show which throw "makes room" for which - e.g. in 441 the 1 is
  forced by the incoming 4.
Use: causal diagrams are the standard for **passing** patterns, where the question is
"when I throw this, what must I throw next?".

## Practice
- Draw 3, 441, 531 and 4 as ladders by hand.
- Draw the causal diagram for a 3-count passing pattern.
- Check your drawings in Juggling Lab, which animates siteswaps.

## Gotchas
- Different authors put the left hand on top; check the legend.
- Causal diagrams omit holds (2s) as arrows; they look like gaps.

## Verify
- [ ] From a ladder, you can say how many objects a pattern uses.
- [ ] From a causal diagram, you can say which throw follows a given catch.
