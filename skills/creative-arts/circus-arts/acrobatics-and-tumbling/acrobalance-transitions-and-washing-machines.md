# Acrobalance transitions and washing machines

**Goal:** move between partner balances without breaking contact or rhythm, including
"washing machines": repeating cycles of transitions that return to the start.

## Transition principles
- **Always have a support**: at least one solid contact (foot on hip, hand in hand)
  during the change; never release two at once.
- **Grip handovers** happen when weight is lowest (e.g. at the bottom of a swing).
- **Flyer leads with intention**, base follows; agree which.
- Breath and counts: transitions that work on "1-2-and-3" are reliable; ad lib ones fail.

## Building a washing machine
1. Choose 2-3 positions both partners hold easily (e.g. front bird, throne, folded leaf).
2. Find the shortest path between each pair; practise each link alone.
3. Chain links; return to the start position to close the loop.
4. Repeat the cycle 3 times without pause before adding speed.

## Spotting
Spotter tracks the flyer's centre of mass, especially when the flyer rotates around the
base's feet. Most falls happen mid-transition, not in the static poses.

## Faults
- Rushing a transition before the base re-stacks legs: collapse.
- Flyer going limp mid-turn.
- Hidden grip changes the base does not expect: say them aloud while learning.

## Verify
- [ ] Each link done in isolation 5 times cleanly.
- [ ] Full cycle 3 times continuous, no extra steps or resets.
- [ ] Both partners can call every grip change.
