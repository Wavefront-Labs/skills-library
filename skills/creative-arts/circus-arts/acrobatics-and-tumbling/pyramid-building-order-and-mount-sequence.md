# Pyramid building order and mount sequence

**Goal:** a pyramid is built in a fixed order with each person taking a known path and
known holds. Order and paths are planned before the first rehearsal.

> Coach-led. Any pyramid over two levels has spotters on the top performers.

## Building order
1. Bases set first (outside to inside or as designed).
2. Middles mount in a set order, usually from the centre out.
3. Tops mount last.

## Mount paths
- Each mount uses a defined step: base's thigh, hip, shoulder; or a throw.
- Steps are on bones and muscles that can take load (thigh near the hip, shoulder near
  the neck), never on joints like the knee or the lower back.

## Holds
- Defined holds for each connection: hand-to-hand, calf grips, wrist grips.

## Checks between levels
- Each level confirms "set" before the next mounts.
- Spotters say "go".

## Faults
- Mounting before the level below is stable.
- Steps on the middle of the base's back.

## Verify
- [ ] Written build sheet with order, paths and holds.
- [ ] Each mount rehearsed separately.
