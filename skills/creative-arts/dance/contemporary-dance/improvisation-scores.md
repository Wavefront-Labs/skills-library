# Improvisation scores

**Goal:** structure improvisation with a score - a set of instructions that limit and
focus choices - so a group can improvise coherently in class or performance.

## Elements of a score
| Element | Example |
|---|---|
| **Space** | a taped square; only move along straight lines; one dancer centre at a time |
| **Time** | 10 minutes; phases of 2 minutes; stillness every time the music stops |
| **Roles** | mover, witness, caller; entering and exiting from the edge |
| **Material** | only use a learned phrase, fragmented; only floor movement |
| **Relationship** | copy, contrast, ignore; always be in contact with someone |
| **Calls** | spoken commands like "pause", "replay", "reverse" (Tuning Scores) |
| **Ending** | when everyone is still for 10 seconds; a bell; a set time |

## Known scores
- **Underscore (Nancy Stark Smith):** a long-form score with phases (arriving, small dance,
  expanding, the dance, closing) for contact/improvisation practice.
- **Tuning Scores (Lisa Nelson):** dancers and viewers use calls (e.g. "pause", "end",
  "replace") to tune what is seen.

## Designing your own
1. Decide the purpose (exploration, composition, performance).
2. Choose 2-4 rules; more limits produce more focus but less freedom.
3. Test with the group, observe, adjust.
4. Write the score clearly so it can be repeated.

## Faults and fixes
| Fault | Fix |
|---|---|
| Score too complex | reduce to the essential rules |
| Dancers ignore rules | restate and side-coach briefly |
| No clear ending | define the ending condition |

## Verify
- [ ] Score written with space, time, roles and ending.
- [ ] Group runs it twice with recognisably different but coherent results.
- [ ] Observers can identify the rules from watching.
