# Canon construction

**Goal:** use canon - the same material performed by dancers starting at different times -
to create texture and momentum in group work.

## Types
| Type | How it works |
|---|---|
| **Simple canon** | dancers start the same phrase one after another at a fixed delay (e.g. 2 counts) |
| **Cumulative canon** | dancers join in one by one and continue until all are moving |
| **Ripple/cascade** | a single movement passes quickly along a line (delay of 1 count or less) |
| **Simultaneous canon** | all start together but at different points of the phrase |
| **Round** | like a musical round - each dancer repeats the phrase several times |

## Design choices
- **Delay:** short delays (1 count) make ripples; long delays (4-8) make overlapping phrases.
- **Spacing:** a line across the stage (ripple reads left to right), a diagonal, or a cluster.
- **Order:** start with the dancer the audience sees first, or opposite for surprise.
- **Ending:** all finish in unison (dancers who started later cut material), or end one by one.

## Method
1. Make the phrase work in unison first.
2. Decide the type, delay and order; map who starts on which count.
3. Rehearse with counts out loud; film from the front to check readability.

## Verify
- [ ] Canon is readable as canon from the audience view.
- [ ] Each dancer knows their start count and how to end.
- [ ] Ending clean (unison finish or staggered by design).
