# Motif manipulation devices

**Goal:** generate a whole section from a short motif by applying systematic changes, so
the dance has unity (same source) and variety (different versions).

## Devices
| Device | What it means |
|---|---|
| **Repetition** | exact repeat - establishes the motif |
| **Retrograde** | perform it backwards, like rewinding video |
| **Inversion** | upside down or mirrored (high becomes low, right becomes left) |
| **Augmentation** | bigger in size or slower in time |
| **Diminution** | smaller or faster |
| **Fragmentation** | use only part of it |
| **Instrumentation** | perform it with a different body part |
| **Change of level/plane/direction** | same motif on the floor, facing upstage, in the sagittal plane |
| **Change of dynamics** | sustained instead of sudden, light instead of strong |
| **Embellishment** | add detail (a hand flick, a head turn) |
| **Additive/accumulation** | add one move each repetition |
| **Change of relationship** | in canon, in contrast, mirrored by a partner |

## Method
1. Create a 4-8 count motif with a clear identity.
2. Apply 2-3 devices to make versions A1, A2, A3.
3. Combine versions into a phrase or section; keep the original visible early on.
4. Distribute versions among dancers for group texture.

## Tips
- Don't apply every device; choose those that support the intent.
- Audiences recognise a motif after about three appearances - repeat it enough.

## Verify
- [ ] Original motif and at least three named variations recorded.
- [ ] Section built from the variations, original still recognisable.
- [ ] Devices chosen match the intention.
