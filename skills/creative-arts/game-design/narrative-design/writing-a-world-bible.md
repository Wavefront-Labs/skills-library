# Writing a world bible

**Goal:** one canonical reference so every writer, artist, designer and localiser makes
the same world, and contradictions are caught before they ship.

## Sections
1. **Premise and tone** (one page): what the world is about thematically, tone words,
   reference touchstones, what this world is NOT.
2. **Rules of the world**: physics, magic or technology limits and costs. Write each rule
   with its cost and its exceptions; rules without costs break plots.
3. **Timeline**: dated key events, with what the average person believes vs what is true.
4. **Geography**: map, regions with climate, economy, culture, and one sensory line each.
5. **Factions**: goal, method, resources, leader, relationship to each other faction
   (a relationship matrix), what they want from the player.
6. **Characters**: profile for each named character (role, want, need, voice sample,
   relationships, status by chapter).
7. **Culture**: religion, customs, naming conventions per culture, slang list.
8. **Glossary**: every proper noun with spelling, pronunciation and one-line definition.
9. **Style guide**: capitalisation, number formats, dialect rules, banned words or anachronisms.
10. **Open questions**: things deliberately undecided, so nobody invents them ad hoc.

## Practice
- **Need-to-know rule:** write what the game uses plus one layer beneath; a 400-page
  bible no one reads is worse than 40 pages everyone does.
- Mark each fact as `canon`, `draft`, or `secret` (true but never revealed yet).
- Keep it in a wiki with page owners and a change log; announce canon changes in one channel.
- Link each entry to where it appears in the game (quest ids, level names) for QA.

## Gotchas
- Naming conventions per culture prevent the "random fantasy syllables" look; write the
  phonetic rules, not just examples.
- Retcons are cheap before VO and expensive after; freeze canon before recording.
- Localisers need pronunciation and gender for every name.

## Verify
- [ ] Every proper noun in the script exists in the glossary.
- [ ] Each world rule lists cost and exceptions.
- [ ] Canon changes logged with date and owner.
