# Roll20 virtual tabletop

**Goal:** a smooth online session on Roll20, with maps, tokens and character sheets prepared in advance.

## Setup
1. **Create a game** and choose a character sheet template that matches your system, or a custom sheet if you need one. Invite players with the game link.
2. **Build pages** (maps) with the grid set to match your system's units. Upload map art at a size that matches the grid; check resolution so images stay sharp.
3. **Use layers:** map and background layer for scenery, token layer for creatures and items, and GM layer for hidden things.
4. **Create tokens** with the token tools; link them to character sheets so bars and names are consistent. Set default tokens so new copies behave the same.
5. **Lighting and fog:** use the lighting features (dynamic lighting, which is the vision-and-light system) for line of sight and darkness; it is easier with prepared walls and light sources. Features and plan limits change over time, so confirm in the current Roll20 help.
6. **Macros and rolls:** write macros for repeated rolls; use the chat's dice syntax (for example /r 1d20+5) and roll templates supplied by the sheet.
7. **Handouts and journal:** store handouts, lore, and images; share them with specific players.
8. **Audio and video:** use the built-in options or an external call.

## Plans
Roll20 has free and paid tiers; some features (such as API scripts, the Mod scripting system) are limited to paid subscribers. Confirm the current feature list on the website before building around one.

## Gotchas
- Large images slow the session; compress and test before play.
- Players' browser setups vary; test with one player first.
- Keep a backup of your maps and notes outside the platform.

## Verify
- [ ] Grid matches the map art.
- [ ] Token and sheet links tested with a dummy player.
- [ ] Handouts and visibility set per player.
