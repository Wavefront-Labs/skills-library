# Script change tools

**Goal:** give any player a way to edit the story in real time, using familiar playback controls.

Script Change is an RPG safety toolkit by Beau Jágr. It borrows video-playback controls as metaphors (for example pause, rewind and fast-forward) so players can ask the group to adjust the scene. I have not re-checked the exact set of buttons against the original document, so confirm the details in the published toolkit before teaching it.

## Procedure
1. **Introduce it in session zero** with a short explanation and an example.
2. **Explain the main controls** in plain language:
   - **Pause:** stop to check in, discuss, or take a break.
   - **Rewind:** go back and redo or replay a moment differently.
   - **Fast-forward:** skip ahead past a scene or content with a summary.
   Add the remaining controls from the original toolkit as you choose.
3. **Make it low-friction:** anyone can use it at any time, with a word or a hand signal; no justification needed.
4. **Respond immediately and kindly:** the GM and players say thanks and make the change.
5. **After the break,** return to play with a new direction; if needed, talk privately later.
6. **Pair with other tools** such as lines and veils or the X-card (see the ttrpg-consent-checklist skill).
7. **Review after sessions:** ask whether the tool is working and whether anyone wants adjustments.

## Gotchas
- A tool nobody uses may signal social pressure; the facilitator should model using it.
- Do not interrogate a player who invokes it.
- Script change is for editing the story, not for fixing interpersonal conflict.

## Verify
- [ ] Tool introduced with examples.
- [ ] Anyone can invoke it without justification.
- [ ] Group response practised and non-judgemental.
