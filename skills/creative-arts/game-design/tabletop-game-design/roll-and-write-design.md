# Roll-and-write design

**Goal:** a game where everyone uses the same dice or cards and the sheet turns them into
different, satisfying decisions.

## Structure options
| Choice | Example |
|---|---|
| Shared roll, all use it | Qwixx (active player has extra options) |
| Active player picks, others take leftovers | Ganz schoen clever's silver platter |
| Flip a card, all use it | Welcome To..., Cartographers (flip-and-write) |
| Draw shapes / routes | Railroad Ink (route dice), Cartographers (polyomino shapes) |

Shared input means 1 or 100 players take the same time; that scalability is the genre's main selling point.

## The sheet is the engine
1. **Tracks with escalating rewards** (cross off left to right; reaching a box gives a
   bonus). Qwixx's rows must ascend or descend, so early choices close options.
2. **Combo chains:** crossing a box triggers another mark elsewhere (Ganz schoen clever).
   Players love chains; tune so a typical game has a few and an expert game many.
3. **Scarcity of boxes** is the timer: the game ends when a track fills or after N rounds.
4. **Penalty boxes** for passing protect against stalling.
5. Layout: read order left to right, top to bottom; group by colour; leave space for
   pencil marks (boxes at least 7-8 mm).

## Procedure
1. Pick the input (dice faces, cards) and write its distribution; 2d6 sums peak at 7.
2. Sketch the sheet on paper, play 10 solo games, mark which boxes never get used.
3. Remove or re-cost dead boxes; move overused rewards later.
4. Add one interaction point (first to complete a goal scores more, others less).
5. Test at 1, 2 and max players for downtime and tie frequency.

## Gotchas
- Pure multiplayer solitaire: add shared goals or leftover-dice choices for some interaction.
- Too many bonus chains make turns slow to resolve; cap chain length or make chains visible.
- Laminated sheets need dry-erase-friendly box sizes and contrast.

## Verify
- [ ] Every box used in at least some test games.
- [ ] Turn time roughly constant across player counts.
- [ ] Printable sheet tested in black-and-white.
