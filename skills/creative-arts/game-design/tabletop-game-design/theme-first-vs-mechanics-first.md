# Theme-first vs mechanics-first

**Goal:** a board game where theme and mechanics support each other, whichever one you
started from.

The *Kobold Guide to Board Game Design* includes essays debating theme vs mechanics as
a starting point; both routes produce successful games.

## Two routes
| Route | Process | Risk |
|---|---|---|
| Theme-first | start from a subject ("running a 1920s airline"); ask what decisions people in that world make; design mechanics to model them | over-simulation, too many rules for realism |
| Mechanics-first | start from a mechanism or interaction ("bidding with your own workers"); find a theme that explains it | pasted-on theme that adds nothing |

## Integration test
For each core action, ask: **does the theme explain why this action exists and what it
does?**
| Action | Thematic explanation | Integrated? |
|---|---|---|
| place worker on market | your foreman hires labour there | yes |
| trade 3 cubes for 1 VP | ? | no - find a reason or change the action |
A rules teach that can be told entirely as the theme ("you buy planes, open routes,
and passengers fly them") indicates strong integration.

## Techniques
1. **Name actions with theme verbs** (not "gain 2 blue", but "harvest").
2. **Components carry theme** (shapes, art, tokens that look like what they are).
3. **Theme predicts rules:** players can guess rules from the fiction ("of course fuel
   runs out").
4. **Cut thematically odd rules** or find a mechanism that fits better.
5. For abstract games, theme can be light; decide deliberately (see abstract strategy
   design) rather than half-theming.

## Gotchas
- Theme can mislead: if fiction suggests a rule that doesn't exist, players will play it
  wrong. Align or explain.
- Some markets and audiences favour strong theme; others are happy with abstracted
  euros. Know the audience.

## Verify
- [ ] Route chosen and stated.
- [ ] Integration table for core actions.
- [ ] Rules teach can be delivered in theme language.
- [ ] Playtesters guess at least some rules from the fiction.
