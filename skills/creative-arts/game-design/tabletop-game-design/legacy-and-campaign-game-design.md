# Legacy and campaign games

**Goal:** a game that changes permanently across sessions (Risk Legacy 2011 by Rob Daviau,
Pandemic Legacy, Gloomhaven, Charterstone) so the group's history becomes the story.

## Persistence tools
| Tool | Example use |
|---|---|
| Stickers on board / cards | a city becomes fortified, a character gains a scar |
| Destroying components | tear up a card when it is lost forever |
| Sealed boxes / envelopes | open when a condition triggers ("Open when the third city falls") |
| Campaign sheet / log | track unlocks, scores, decisions between sessions |
| Writing on components | name a character, record a victory |

## Design procedure
1. **Write the campaign arc**: number of sessions (Pandemic Legacy season 1 is 12-24
   games), act structure, and the reveals that turn each act.
2. **Base game must work alone**: session 1 has to be a complete, good game.
3. **Each session changes something visible** and permanent; players should leave
   session 3 with a different board than they started.
4. **Triggers for sealed content** are conditional, not only scheduled; groups who
   struggle see different reveals.
5. **Catch-up across sessions**: the losing player gets a benefit next game (Risk Legacy
   gives losers a one-time bonus), or difficulty adjusts to win/loss (Pandemic Legacy adds
   funding after losses).
6. **Save and reset between sessions:** design the box storage so state survives setup;
   a session recap card or log speeds restarts.
7. **After the campaign:** state what the box becomes (a unique replayable game, a
   reset pack for sale, a scrapbook).

## Writing and production
- Spoiler management: number every sealed item, list contents in a private manifest, and
  playtest with fresh groups for each act; one group can only experience reveals once.
- Plan many independent playtest groups; legacy testing is the costly part.

## Gotchas
- Absent players: allow drop-in players or AI stand-ins without breaking story.
- A sealed item opened early by mistake needs an instruction ("put it back, it will not matter").
- Permanent decisions that can lock a group into a lost campaign need a recovery rule.

## Verify
- [ ] Session 1 is complete and fun alone.
- [ ] Every session produces a visible permanent change.
- [ ] Losing groups have a catch-up path.
- [ ] Each act tested by groups who had not seen it.
