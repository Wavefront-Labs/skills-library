# Character creation systems

**Goal:** players finish creation with a character they care about, that is competent at
the game's core activity, in a time that fits the game's use.

## Methods
| Method | Example | Trade-off |
|---|---|---|
| Random rolls | D&D 4d6-drop-lowest, OSR 3d6 in order | fast, surprising; unequal characters |
| Point-buy | D&D 5e point buy (27 points), GURPS | balanced, slow, optimisation |
| Standard array | D&D 15,14,13,12,10,8 | fast and fair, less personal |
| Class / archetype | D&D classes | clear niches |
| Playbooks | Powered by the Apocalypse (Apocalypse World, Masks) | 10-15 min, strong genre identity |
| Lifepath | Traveller, Cyberpunk RED | backstory generated with stats; Traveller can kill you in creation |
| Freeform descriptors | Fate aspects | expressive, needs GM judgement |

## Design procedure
1. **Set the time budget**: one-shot or convention games need under 20 minutes or pregens;
   campaigns can afford an hour.
2. **Guarantee competence** at the core activity: every character can contribute in the
   game's main scenes (fight, investigate, talk), even if not equally.
3. **Niche protection**: each archetype has something only it does well.
4. **Build hooks into creation**: questions ("Who here saved your life?"), bonds, and
   relationships give the GM material (PbtA playbooks do this explicitly).
5. **Order of steps**: concept first, then numbers, so players do not min-max into a concept.
6. **Write a one-page creation summary** and a worked example.
7. **Pregenerated characters** for one-shots with backstory hooks to each other.

## Testing
- Time ten new players through creation; note where they stall (usually choosing from
  long lists: spells, feats, gear).
- Check for trap options (choices that look fine but are weak); remove or fix them.
- Compare characters built by optimisers vs casual players; the gap should not ruin play.

## Gotchas
- Long equipment lists are the most common creation bottleneck; offer kits.
- Random generation with high stakes stats can make a player hate their character; offer a safety net (swap two stats, reroll if total too low).
- Too many interdependent choices force a rules read before play.

## Verify
- [ ] New players finish within the time budget.
- [ ] Every archetype can act in each core scene type.
- [ ] Creation produces at least one hook per character.
