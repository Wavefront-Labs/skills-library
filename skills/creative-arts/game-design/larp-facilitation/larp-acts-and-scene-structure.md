# Larp acts and scene structure

**Goal:** a game with a shape: players know where it starts, it escalates, and it can end well inside the available time.

## Procedure
1. **Set the length and rhythm.** One-evening games run a few hours; weekend games span many; mark mandatory off-game breaks (meals, sleep, safety check-ins).
2. **Divide into acts** with clear purposes, for example:
   - Act 1: introductions, relationships, stakes.
   - Act 2: complications, conflicts, secrets revealed.
   - Act 3: climax and consequences.
   - Epilogue: closing scenes before debrief.
3. **Write scene triggers:** timed or event-based prompts (a message arrives, the lights change, a visitor appears) that move play between acts. Put them in the run sheet (see larp-runsheet-and-timeline).
4. **Design scenes players want:** give characters reasons to meet, decide, or confront. Make sure every character has a thread that reaches a climax.
5. **Control the end:** specify the ending trigger (a final vote, a time call, a ritual) and a safe wind-down so intense scenes do not stop abruptly.
6. **Add flex:** build slack in the schedule for delays; mark optional scenes that can be cut.
7. **Brief players** on the structure (what the acts are, what triggers exist, how it ends) unless secrecy is part of the design.
8. **Test with a rehearsal or table-read** to measure real timing.

## Gotchas
- Climaxes scheduled with no escalation feel flat.
- Open-ended games without a closing ritual leave players in a limbo; always include an end.
- Do not let plot triggers override player agency; give players a way to resist.

## Verify
- [ ] Acts and ending defined with triggers.
- [ ] Each character has a path to the climax.
- [ ] Timing tested.
