# Constraint-based ideation

**Goal:** many distinct concepts in a short session, steered by constraints so they are
not variations on the last game you played, then a disciplined cut to 1-3 to prototype.

Schell (2nd ed.) ch7 and Fullerton ch6 both make the point: constraints are not the enemy of
creativity; a blank page produces clones. The problem statement itself is the first
constraint.

## 1. State the problem as constraints
Write what you *must* satisfy before generating ideas: platform, session length, player
count, budget, team skills, audience, deadline. Schell: "state the problem" (Lens of the
Problem Statement) widens the solution space because it separates the real need from an
assumed solution.

## 2. Generate with forcing constraints
Pick one or two per round, 10 minutes per round, quantity over quality:
| Constraint type | Example prompts |
|---|---|
| Verb-first | one verb only (push, swap, trade, hide, rewind) |
| Input | one button; tilt only; voice; no hands on the screen |
| Component | 18 cards only; one die; a single sheet of paper |
| Inversion | take a genre and flip a rule (horror where you are the monster) |
| Theme collision | random noun + random genre (bakery + survival) |
| Removal | a shooter with no shooting; a racing game with no steering |
| Real experience | a mundane activity made into a loop (sorting mail) |
Random-card decks (oblique strategies, jam theme generators) help break habits.

## 3. Write each idea as one line
`[verb] in [context] where [twist]`. No elaboration during generation; elaboration kills
volume.

## 4. Filter
1. Remove ideas that violate the problem constraints.
2. Dot-vote (each person 3 votes) on "I want to play this".
3. For the top 5, write the essential experience and the riskiest question.
4. Pick 1-3 whose riskiest question can be answered by a cheap prototype this week.

## Gotchas
- **Judging during generation** collapses output to safe ideas; separate the phases.
- **Subconscious incubation is real** (Schell discusses this): a second short session the
  next day often beats a single long one.
- Do not "keep" an idea by attaching it to the winner; Frankenstein concepts lack a core.

## Verify
- [ ] Constraints written before generation.
- [ ] 30+ one-line ideas in under an hour.
- [ ] Shortlist each has an essential experience and a riskiest question.
- [ ] 1-3 selected with a prototype planned (see `creative-arts.game-design.systems-and-mechanics.risk-driven-prototypes`).
