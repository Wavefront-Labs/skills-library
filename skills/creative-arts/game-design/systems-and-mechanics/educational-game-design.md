# Educational game design

**Goal:** a game where playing well *is* learning the target material, with evidence
that the learning happened.

Schell (2nd ed.) ch32 (Games Transform Their Players) discusses transformational games. Koster's
*A Theory of Fun* argues fun is the experience of learning patterns, which makes games
natural learning tools when the pattern being mastered is the target knowledge.

## Procedure
1. **Write learning objectives** in observable terms (e.g. "given a food web, predict
   the effect of removing one species"). Use a taxonomy such as Bloom's to pitch the
   level (remember, understand, apply, analyse...).
2. **Find the core mechanic that embodies the objective.** The skill the player
   practises to win must be the target skill. This is often called *intrinsic
   integration* (Habgood and Ainsworth's research found intrinsically integrated
   designs outperformed extrinsic ones in their maths game study).
3. **Avoid "chocolate-covered broccoli"** - quiz questions bolted onto an unrelated game
   (answer 5 questions to get a turn). Learners feel the quiz is the price of play.
4. **Feedback that explains:** failures should show *why* (consequence visible in the
   system), not just "wrong".
5. **Plan assessment:** pre/post tests, in-game performance data mapped to objectives
   (stealth assessment), teacher dashboards if classroom use.
6. **Context of use:** classroom sessions are short (often 20-40 minutes), with
   setup time; design session length and save/resume accordingly. Teachers need
   guides and alignment to curriculum standards.
7. **Playtest with learners and educators**, separately.

## Gotchas
- Making it "fun" by adding unrelated rewards competes with the learning for attention.
- Overly accurate simulations can be too complex; abstract to the objective.
- Measure learning, not just engagement; an enjoyable game can teach nothing.

## Verify
- [ ] Observable learning objectives written.
- [ ] Core mechanic practises the target skill (mapping documented).
- [ ] Pre/post or in-game assessment plan exists.
- [ ] Session length fits the intended setting.
