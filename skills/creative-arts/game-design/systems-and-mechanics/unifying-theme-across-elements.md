# Unifying theme across elements

**Goal:** every element of the game (rules, fiction, art, sound, interface, tech choices)
reinforces one theme, so the experience feels intentional and memorable.

Schell (2nd ed.) ch6 distinguishes a *theme* (what the game is ultimately about, e.g. "the
fragility of trust") from a *setting* (pirates, space). Settings are interchangeable;
themes give coherence.

## Procedure
1. **State the theme as an idea, not a setting.** Test: could you set the same theme in
   two different settings? "Survival through cooperation" works in a lifeboat or on Mars.
2. **Run the Lens of Unification** across the elemental tetrad:
   | Element | Current choice | Reinforces theme? | Change |
   |---|---|---|---|
   | Mechanics | shared resource pool | yes | - |
   | Story | lone-hero ending | no, contradicts | ensemble ending |
   | Aesthetics | warm palette for shared spaces | yes | - |
   | Technology | async multiplayer | weak | add shared ghost markers |
3. **Look for resonance** (Lens of Resonance): what about the theme feels powerful or
   personal to you and the audience? Themes that touch something true (fear of loss,
   desire to belong) carry further than clever ones.
4. **Make the rules say it.** The strongest theming is mechanical: in a game about
   scarcity, inventory pressure is the theme, not a backdrop.
5. **Prune contradictions.** A single contradicting element (cheerful music in a game
   about grief) can undo the rest; list and resolve them.

## Gotchas
- **Pasted-on theme:** if you can swap the setting and no rule changes, the theme is
  decoration. That is fine for some abstract games, but then do not claim the theme as a
  selling point.
- **Theme by text only:** an intro crawl about loyalty with mechanics rewarding betrayal
  produces ludonarrative dissonance (see
  `creative-arts.game-design.narrative-design.ludonarrative-harmony`).
- Theme does not need to be stated to the player; it needs to be felt. Over-explaining
  is a smell.

## Verify
- [ ] Theme written as an idea that survives a setting swap.
- [ ] Tetrad table completed; every "no" has a planned change or an accepted reason.
- [ ] At least one core mechanic expresses the theme directly.
- [ ] Playtesters, unprompted, describe the game in words close to the theme.
