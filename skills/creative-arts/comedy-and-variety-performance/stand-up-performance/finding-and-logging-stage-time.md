# Finding and logging stage time

**Goal:** as many good sets as you can reach, and a record of them.

## Finding it
- Search local listings, social media and venue pages for open mics and new-act nights. Ask other comics.
- Go regularly to a few, get known by the hosts.
- Aim for variety: small pubs, big rooms, comedy nights, non-comedy-specific audiences.
- Create your own opportunity; see `running-your-own-open-mic`.

## Logging
Use a spreadsheet or notebook, one row per set:
- date, venue, host, audience size, set length, material used, laugh rating, notes.
- Track the order of your set and which bits were new.

## Using the log
- Spot patterns: which room types suit you; which hosts book you again.
- Count sets per month; target a number and aim to increase it.
- Plan your new-material nights.

## Gotchas
- Relying on one room.
- Over-gigging without reviewing; see `post-set-review`.

## Verify
- [ ] Log updated within a day of each gig.
