# Post-set review

**Goal:** improve from every gig.

## Process
1. Immediately after, jot three things that worked and three that did not, while memory is fresh.
2. Within a day, listen to the recording; see `recording-sets-and-mapping-laughs`.
3. Classify each problem: material (the joke), delivery (timing, pace), room (size, mix, sound), or state (nerves, tiredness).
4. Decide one or two changes to test at the next gig.
5. Update the joke file; see `filing-and-versioning-jokes`.

## After a bad set
- Wait a day before judging; shame distorts memory.
- Find the best minute of the set and the reason for it.
- Talk to a trusted peer.

## After a good set
- Check what worked so you can repeat it; success hides errors too.

## Gotchas
- Changing too many things at once.
- Skipping the review because it hurts.
