# The turn or second game

**Goal:** refresh a sketch that has established its game and needs new energy.

## What it is
A moment, usually after the game has been heightened a few times, where the situation changes: a new fact is revealed, a character changes sides, or the game flips so a different pattern starts.

## Types
- **Reveal**: new information recontextualises the previous beats.
- **Role reversal**: the straight character takes on the game, or the odd one becomes normal.
- **Escalation of scope**: the game spreads from one person to a whole group.
- **Second game**: a related but separate pattern takes over and is heightened briefly.

## Writing it
1. Mark where the first game starts to feel predictable.
2. Brainstorm turns that grow out of the first game.
3. Choose one that connects back to the original premise.
4. Keep it short; a second game should not outlast the first.

## Gotchas
- A turn that does not connect to the premise feels like a separate sketch.
- Adding a turn to a sketch that is already short; it may only need an ending.

## Verify
- [ ] The turn is surprising but inevitable in hindsight.
