# Beat sheets for sketches

**Goal:** a one-page plan so you can see the shape before writing dialogue.

## Template
1. **Premise** in one line.
2. **Base reality** (who, where, want) and the first unusual thing.
3. **Game** stated as "if this is true, what else is true?"
4. **Beats** 1-5: one line each, in order of escalation.
5. **Turn** (optional): a change of direction; see `the-turn-or-second-game`.
6. **Ending**: button, reversal, or blackout; see `finding-and-heightening-the-game-of-the-sketch`.
7. **Runtime estimate**: allow roughly a minute per page of script as a rough guide; check against your format.

## Use
- Share the beat sheet in the room before scripting to get quick feedback.
- Rewrite the sheet when the draft changes; keep it as the source of truth.

## Gotchas
- A sheet with beats that are the same joke.
- Writing the script before the ending is known.

## Verify
- [ ] Each beat is distinct, the ending is chosen, and the runtime is within target.
