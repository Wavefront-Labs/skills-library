# Finding and heightening the game of the sketch

**Goal:** write sketches that are about one funny idea, escalate it clearly, and end
before the audience gets ahead of you; then stage them so the game reads in a live room
or on screen.

## 1. The vocabulary (improv-derived, widely used in sketch rooms)
- **Base reality:** the normal world the sketch starts in (a dentist's office, a job
  interview). Establish it fast and clearly — who, where, what's happening.
- **First unusual thing:** the moment something breaks the expected pattern ("The dentist
  treats every tooth like it has a personality").
- **The game:** the repeatable pattern of that unusual thing. If you can state it as
  "If this is true, what else is true?", you've found it.
- **Heightening:** each beat plays the game again, bigger or in a new direction.
- **Straight character:** the person who reacts as the audience would; they give the
  game its contrast. Without them, nothing is unusual.

## 2. Writing process
1. **Premise in one line.** "A job interview where the candidate interviews the company
   like a hostage negotiator." If you can't say it in one line, it's two sketches.
2. **List 10+ heightening beats** (moves). Sort them from small to big.
3. **Choose 3–5 beats** with clear progression. Each must be a *new* expression of the
   game, not the same joke louder.
4. **Write the base reality quickly** (aim to reach the first unusual thing within the
   first ~30 seconds / half page).
5. **Find the ending:** a **button** (a final line that tops the game), a **reversal**
   (the straight character joins in or the game flips), or a **blackout** (lights cut on a
   punch). Avoid "and then they all leave".
6. **Cut.** Live sketches commonly run 2–5 minutes; screen sketches often shorter.
   *Norms differ by show; check the format.*

## 3. Character sketches
Built around a character's defining want or trait rather than a situation. Same
engine: establish the character's normal, show the trait in a small way, heighten across
different situations or scenes (recurring characters thrive on this).

## 4. Table reads and the room
- Read aloud with performers; mark where laughs happen.
- A useful note is specific: "beat 3 repeats beat 2", not "make it funnier".
- If the room is ahead of the sketch by beat 3, the game was too obvious — skip beats or
  add a twist.

## 5. Performing sketches
- **Commit to the reality.** Play the absurd thing as completely normal for the character.
- **Straight characters stay straight** — breaking (laughing) undercuts the game.
- Clear staging: the audience must see the face delivering the key line; cheat out.
- Props and costume establish base reality instantly; one strong signifier beats many.
- Hit the blackout line cleanly and freeze; the tech cue is on that word.

## Gotchas
- Two games in one sketch: the audience doesn't know which to follow. Pick one.
- Heightening by volume or swearing only; escalation must be in the idea.
- Long, cute setup before the first unusual thing.
- Every character is weird: no contrast, no laughs.
- No ending: sketches that fizzle hurt the next sketch in the running order.

## Verify
- [ ] You can state the game in one sentence.
- [ ] The first unusual thing arrives within ~30 s.
- [ ] Each beat is a distinct heightening, not a repeat.
- [ ] There is a clear straight character.
- [ ] The sketch ends on a button, reversal or blackout, under the target runtime.
