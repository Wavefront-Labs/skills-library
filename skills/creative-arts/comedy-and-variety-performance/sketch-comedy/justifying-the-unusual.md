# Justifying the unusual

**Goal:** make the audience believe the absurd world follows its own rules.

## Technique
- Characters should act as if the unusual thing is normal. Justification comes from character want or world logic, not from stopping to explain.
- Ask: why would this person do this, now, in this place? The answer gives specificity to the lines.
- Keep the justification consistent: once a rule is established, each new beat must obey it or break it knowingly.

## Methods
1. **Backstory in a line**: a character mentions a prior event that explains the oddity.
2. **Shared logic**: all characters accept it.
3. **Personal want**: the character has a self-interested reason to act oddly.

## Cautions
- Over-explaining kills the joke; a short justification is enough.
- Justifying every detail drains the surprise.
- Do not justify with "it was a dream" or "they are crazy" unless the sketch's game is that.

## Test
Read the sketch aloud and note every point where the audience may ask "why". Add or remove a line to answer only those.

## Verify
- [ ] Each beat obeys a rule you can state in a sentence.
