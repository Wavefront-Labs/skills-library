# Prop comedy

**Goal:** a bit where an object does the comedy.

## Choosing
- Select an object the audience recognises quickly and that offers several uses.
- Make it visible from the back of the room.

## Process
1. List ordinary uses and then misuses.
2. Choose a game: the object misbehaves, the performer misuses it, or it substitutes for something else.
3. Establish the rules in the first beat; heighten with variations.
4. Plan handling: grip, timing, and reset.
5. Add a surprise: the object does something unexpected at the end.

## Practicalities
- Test props for reliability and noise; carry spares.
- Safety: sharp edges, hot items, fragile objects, and slippery liquids.
- Resets between shows.

## Delivery
- Build rhythm through repetition then variation.
- Use the face to show the character's thought about the object.

## Gotchas
- Too many props; one at a time is clearer.

## Verify
- [ ] The prop is visible, the game is clear in the first 20 seconds, and the reset is quick.
