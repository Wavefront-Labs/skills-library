# Rehearsing a sketch show

**Goal:** a clean, funny show that survives the stage.

## Schedule
1. **Table read**: hear the script; mark laughs and cuts.
2. **Blocking**: stage each piece; make sure faces are seen.
3. **Run**: each piece several times, then in order.
4. **Tech**: lights, sound, props, costume changes.
5. **Dress and previews**.

## Props
- List per sketch; pre-set and label.
- Use one strong prop to establish base reality.
- Check items are safe, quiet and durable.

## Costume changes
- Plan the order so quick changes are minimised.
- Use simple pieces (a hat, a jacket) to signal characters.
- Mark change locations and helpers.
- Rehearse changes with timing; aim to keep them within the transition time.

## Notes
- Take notes after every run: timing, sightlines, tech.

## Gotchas
- Leaving props to the last rehearsal.
- Not rehearsing the changes.

## Verify
- [ ] The show runs in order with all props and changes at tempo.
