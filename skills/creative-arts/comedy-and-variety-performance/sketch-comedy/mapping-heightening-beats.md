# Mapping heightening beats

**Goal:** a beat ladder with a clear shape, written down before drafting.

## Procedure
1. State the game in one line; see `finding-and-heightening-the-game-of-the-sketch`.
2. Brainstorm 10-15 expressions of the game (moves) without ordering.
3. Rate each by size (small, medium, large, absurd).
4. Choose 3-5 moves that change in kind or stakes, not only volume.
5. Order small to large; put the funniest or most surprising last, or reserve it for the turn.
6. Write one line per beat on a card; check each differs from the last in how it plays the game.

## Beat checks
- Does each beat increase the cost to a character (embarrassment, stakes, relationship)?
- Is one beat explicit about the rules (a character states the logic) and the others implicit?
- Does the reaction of the straight character escalate along with the game?

## Gotchas
- Two beats that are really the same joke in different words.
- A final beat that is quieter than the one before it.

## Verify
- [ ] The ladder reads as an escalation when you read only the beat lines.
