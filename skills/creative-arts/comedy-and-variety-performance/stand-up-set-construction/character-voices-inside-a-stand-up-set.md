# Character voices inside a set

**Goal:** use other people's voices as a tool, not a distraction.

## Choosing characters
- Prefer people you can describe in one word and one physical detail (the disappointed parent, the over-keen waiter).
- Limit a short set to two or three recurring voices; each new voice costs the audience attention.
- Base the voice on attitude and rhythm before accent. Accents add risk (offence, inconsistency) and are rarely the funny part.

## Making the switch readable
- A small physical marker per character: head angle, shoulder, eyeline, hand position. Hold it for that character only.
- Give each character a fixed position on stage (stage left parent, stage right you) so the audience tracks who is talking without attribution lines.
- Cut the "he said / she said" tags once the markers are established; see `the-mix-switching-narrator-and-character`.

## Consistency
- Record each voice's pitch/pace on tape and match it every time; drift between sets reads as sloppiness.
- Return to narrator voice for the punchline unless the character is the punchline.

## Gotchas
- A character who gets a bigger laugh than you can take over the persona; check it fits.
- Impersonating real people is a different skill; see `writing-and-performing-impressions-in-a-set`.

## Verify
- [ ] A listener with eyes closed can tell narrator from characters.
- [ ] A listener with sound off can tell from posture alone.
