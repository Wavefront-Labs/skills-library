# Writing segues between bits

**Goal:** transitions that keep momentum instead of "So... anyway... what else."

## Types
| Type | Example | Use when |
|---|---|---|
| Logical bridge | "Which is why I can't date." | bits share a theme |
| Joke segue | the last tag of bit A is also the setup of bit B | strongest option |
| Character link | a person from bit A appears in bit B | personal material |
| Hard cut | a confident pause, then the new premise | unrelated bits; one-liner acts |

## Writing them
1. Lay bits on index cards. Look for shared people, places, emotions or words.
2. Write a one-line bridge between each pair; try to make the bridge itself funny.
3. If none exists, reorder the cards until neighbours connect.
4. For hard cuts, rehearse a clear physical reset (step, sip of water, mic adjust) and
   start the new premise with energy.

## Gotchas
- Announcing transitions ("Moving on...", "Talking of...") drains energy.
- Segues that are long setups with no laugh make dead patches; keep under 10 seconds.

## Verify
- [ ] On tape, no transition gap longer than 10 seconds without a laugh.
