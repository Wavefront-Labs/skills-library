# Filing and versioning jokes

**Goal:** never lose a joke or the wording that worked.

## A workable system
- One entry per joke or bit, in a document, spreadsheet or notes app you already use. Choose one place.
- Fields: title, current text, premise, status (idea, draft, tested, retired), rooms tried, last performed, and notes on laughs.
- A tag for the topic and the attitude.

## Versioning
- When rewriting, keep the previous version below the new one with the date, instead of overwriting. If you use files, keep dated copies or use version control (a text file in a git repository works well).
- Note the version that was performed in each recorded set.

## Routine
1. After each gig, update statuses and add the new wording.
2. Weekly: move bits to the "set list" document if tested and retired items out.
3. Back up to a second location.

## Searching
Use consistent topic tags so you can find, for example, every joke about family when writing a new chunk.

## Gotchas
- Writing jokes only in the notes app of your phone with no backup.
- Not recording the exact wording that got the laugh.

## Verify
- [ ] You can locate any joke from a recording within a minute.
