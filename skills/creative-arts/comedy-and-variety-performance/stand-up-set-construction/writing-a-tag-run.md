# Writing a tag run

**Goal:** get three to six laughs from one setup instead of one.

## What a tag is
An additional punchline that relies on the setup already given. No new setup sentence;
at most a few words of bridge ("Which also means...").

## Procedure
1. Take a joke that already gets a laugh.
2. Brainstorm every other reinterpretation or consequence of the same setup (use the
   assumption list from joke prospecting). Write 10-15.
3. Cut to the strongest 3-5.
4. **Order to escalate:** smallest to biggest; the most absurd or most personal last.
   Each tag should be shorter than the one before — speed builds momentum.
5. Perform without pausing for applause between tags; let laughs overlap slightly.
6. End the run on the biggest; do not add a weaker "one more".

## Escalation rules
- Escalate in size, specificity or emotional honesty.
- A tag that repeats the same reinterpretation in other words is a weak duplicate — cut it.
- Callback tags (referencing earlier material) often top a run.

## Gotchas
- Too many tags on a joke that only got a small laugh: the room tires.
- A tag that needs explanation breaks the run's pace.

## Verify
- [ ] On tape, laughs grow or hold through the run; the last tag is the biggest laugh.
