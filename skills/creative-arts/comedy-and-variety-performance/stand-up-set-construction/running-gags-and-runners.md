# Running gags (runners)

**Goal:** a recurring element that ties the set together and gets bigger each time it appears.

## Runner vs callback
- **Callback:** one earlier line referenced once later.
- **Runner:** a motif that recurs three or more times, each time in a new context.

## Building one
1. Pick an element from an early bit that got a laugh and is short and distinctive
   (a phrase, a character's catchphrase, an object).
2. Plan at least three returns spaced through the set.
3. Each return must **change**: new context, escalation, or reversal. Pure repetition dies on the third go.
4. The final return should be the biggest, ideally in the closer.

## Pattern (rule of three and beyond)
- Return 1: plain reprise, small laugh of recognition.
- Return 2: in an unexpected bit, bigger laugh.
- Return 3: twist — the runner turns on you or resolves.

## Gotchas
- A runner that did not land the first time will not land later — test the original first.
- Late arrivals miss the origin; make the first appearance strong enough that most remember.
- Do not force a runner into a bit where it breaks logic.

## Verify
- [ ] On tape, laugh size increases on each return.
