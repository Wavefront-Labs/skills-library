# Analysing a joke: target assumption, connector, reinterpretation

**Goal:** take a joke that "sort of works" and know exactly which part is broken.

## The five parts (Dean)
| Part | What it is | Lives in |
|---|---|---|
| Setup | Words that lead the audience to imagine story 1 | setup |
| Target assumption | The specific thing the audience assumes without being told | the audience's head |
| Connector | The word/phrase/situation that can be read two ways | setup |
| Reinterpretation | The second, unexpected reading of the connector | punch |
| Punch | The words that reveal story 2 and shatter the assumption | punch |

Example: "I've been married 20 years. (setup) / to three different women. (punch)"
- Target assumption: one marriage lasting 20 years.
- Connector: "married 20 years" (total time vs one marriage).
- Reinterpretation: 20 years spread over three marriages.

## Procedure
1. Write the joke out in two lines: setup / punch.
2. Write in one sentence what the audience pictures after the setup (story 1).
3. Underline the connector: the item in the setup that the punch reinterprets. If you
   cannot find one, it is not a joke yet — it is a statement or an opinion.
4. Write story 2 in one sentence. Check it is (a) surprising, (b) plausible once heard,
   (c) revealing an attitude or truth.
5. Check the target assumption is *shared*: if half the room does not make it, the
   punch does not land for them. Fix by adding setup detail that forces the assumption.

## Diagnosis table
| Symptom | Likely broken part | Fix |
|---|---|---|
| Groan, no laugh | Reinterpretation too obvious / pun only | Make story 2 say something true about the speaker |
| Silence, confused faces | Target assumption not shared | Add detail to the setup that steers the picture |
| Laugh before the punch | Punch revealed early in the setup | Move the revealing word later |
| Polite smile | Story 2 low stakes | Raise the attitude, make it personal |

## Gotchas
- Too much setup detail kills surprise: give only what forces the assumption.
- A connector that is a homonym gives a pun; the laugh is bigger when the
  reinterpretation is about behaviour, not just word sense.
- Dean's model is analytic; do not write first drafts by filling the table — write freely, analyse afterwards.

## Verify
- [ ] For each joke in the set you can name its target assumption and connector in one line each.
- [ ] Rewritten jokes tested at an open mic get a laugh more often than the originals (log it).
