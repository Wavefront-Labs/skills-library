# Building a bit's arc

**Goal:** a 1-4 minute bit where laughs grow from start to finish.

## Shape
1. **Premise line:** state the attitude and topic in one sentence.
2. **First laugh fast:** within 10-15 seconds of the premise.
3. **Development:** 3-6 jokes, each a new angle on the premise.
4. **Peak:** the biggest joke — often an act-out or the most extreme escalation.
5. **Button:** a short final line (tag or callback) that ends the bit decisively.

## Ordering jokes inside the bit
- Order by **logic first** (the story or argument must make sense), then by size.
- Strongest-but-one early, strongest last.
- Put setup-heavy jokes early while attention is fresh; short tags late for momentum.
- Remove any joke that needs a setup another joke already used.

## Laugh rhythm
Aim for a laugh every 15-20 seconds in club sets (stories can stretch to 30-45s with smaller laughs).

## Gotchas
- A bit that peaks in the middle and trails off: move the peak to the end or cut what follows.
- Premise lines delivered as a question ("Anyone here...?") slow the start; state it.

- [ ] Laugh map shows rising laugh size and no gap over 30 seconds.
