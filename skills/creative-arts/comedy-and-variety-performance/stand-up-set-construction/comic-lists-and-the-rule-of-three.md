# Comic lists and the rule of three

**Goal:** a list whose last item is the laugh.

## The shape
- Items one and two set a pattern the audience can predict; item three breaks it (a different category, scale, tone or reveal).
- The break must still be true to the premise: it surprises, but it must be connected back to the list's frame.
- Put the funniest item last (see `punch-word-last`); never end on a "meh" connective.

## Procedure
1. State the frame in one line ("Things in my fridge: ...").
2. Write 8-10 candidate items without censoring; mark which are "ordinary" and which "wrong".
3. Choose two ordinary-but-specific items (specifics beat generics: "oat milk" beats "drinks").
4. Pick the wrongest item that is still believable as the third.
5. Match rhythm: items one and two similar length; item three often shorter or longer on purpose.

## Longer lists
Three is the default, not a law. Run four or five when each item escalates (a tag run in list form) and stop at the strongest. A list of unrelated one-liners is not a list; see `sequencing-one-liners-and-deadpan-delivery`.

## Gotchas
- Two items too weird: no pattern for item three to break.
- Third item the same kind of thing but "bigger": predictable, not surprising.
- Pausing too long after item two telegraphs the turn.

## Verify
- [ ] Recording shows the laugh lands on item three, not earlier.
- [ ] Swapping the order makes it weaker.
