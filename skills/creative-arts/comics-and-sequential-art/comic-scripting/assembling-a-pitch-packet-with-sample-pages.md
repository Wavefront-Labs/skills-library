# Assembling a pitch packet with sample pages

**Goal:** one professional PDF that proves the team can deliver the book.

## Contents, in order
1. Cover mock-up with logo and credits (shows the book on a shelf).
2. Pitch document (logline, comps, characters, synopsis).
3. Character designs: one page, front views at least, colour if the book is colour.
4. **Sample pages**: typically the first 5 pages of issue 1, fully finished (pencils,
   inks, colours, letters) or as finished as the team will deliver. Letters matter:
   unlettered pages hide whether dialogue fits.
5. Optional: full script for the samples, or the whole first issue script.
6. Team bios with links, contact email.

## Why the first five pages
They show the hook and the storytelling. Editors read them as a reader would. Skipping
to a "cool" middle sequence hides the opening problem.

## File preparation
- Single PDF, RGB, ~150 dpi for pages: aim for under ~10-20 MB so it can be emailed;
  host a high-res version on a link.
- File name: `TITLE_pitch_TEAMNAME.pdf`.
- Page numbers and the team's contact details on every page footer.
- Embed fonts; check the PDF on a phone.

## Etiquette
- Follow each publisher's submission instructions over this list.
- Watermark lightly if worried, but never so it obscures art.
- Don't send production files (PSD/CLIP) unless asked.

## Verify
- [ ] Packet opens fast and is under the size limit.
- [ ] Sample pages lettered and in reading order.
- [ ] Contact details present; links work.
