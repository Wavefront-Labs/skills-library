# Estimating script page count and length

**Goal:** the story fits the page count the publisher bought, decided at outline stage
rather than discovered on page 27 of a 22-page issue.

## Know the container
Common Western lengths (check the contract; formats vary by publisher):
- Monthly floppy: ~20-22 story pages (ads/backmatter excluded); an extra-sized issue
  ~30-40.
- Short story in an anthology: 4, 6, 8 or 10 pages; often an even number.
- Graphic novel: page count is usually a multiple of 8 or 16 for printing signatures
  (for example 96, 128, 144, 160, 176, 192), including front matter.
- Webcomic episode: no fixed page, measured in panels; see the webcomics product.

## The page breakdown (do this before the script)
1. List story beats (one line each).
2. Assign each beat a page count; write the page numbers beside it.
   ```
   1     Splash: harbour fire (reveal on p.1)
   2-4   Mara and Teo argue on the dock (talk scene)
   5-6   Flashback: the deal (2 pages)
   7     Page-turn reveal: Teo's badge
   ```
3. Total it. Over the count? Cut or merge beats now.
4. Mark odd/even so reveals land on page turns (odd-to-even turns, i.e. a reveal on an
   even page, seen after turning).

## Rules of thumb
- A full page of talk takes ~5-6 panels with 2-3 balloons each before it feels crowded.
- A big action beat or splash eats a full page; a fight typically wants 3-6 pages.
- Average panel load for a 22-page issue at about 5 panels per page is ~110 panels;
  more than ~140 starts reading dense.
- Script length is not a guide: some writers write 1 page of script per comic page,
  some 2-3. Count comic pages, not script pages.

## When it overruns
- Cut a scene that only repeats information, not a scene that turns the plot.
- Merge two talk scenes in one location.
- Compress travel and transitions to a caption or a single scene-to-scene cut.
- Move material to the next issue only if the arc structure allows it.

## Verify
- [ ] Breakdown totals exactly the commissioned page count.
- [ ] Key reveals sit on even pages (after a turn).
- [ ] No page averages more than ~7 panels without a reason.
