# Reference and character notes for artists

**Goal:** the artist draws the right people, places and things the first time, without
reading paragraphs of backstory inside every panel.

## In the script
- **First appearance**: a 1-3 line visual description in the panel where a character
  first appears: age, build, distinctive features, clothes, attitude.
  "MARA (34): wiry dockworker, cropped grey-streaked hair, oil-stained canvas jacket;
  moves like she's always late."
- **After that**: just the name.
- **Notes** in a separate style (italic, `NOTE:` prefix) so the letterer never letters
  them and the artist can skim.
- **Must-see props**: capitalise the first mention (`the LEDGER`) so they're easy to
  scan.

## Reference pack (send with the script)
- Folder per issue: `characters/`, `locations/`, `props/`, `previous_issue_pages/`.
- Photos or links with a one-line caption saying what matters ("this crane, the cab
  shape", not just a photo dump).
- Previously established designs (model sheets) beat new descriptions.
- Licensed reference for real places/brands; don't send copyrighted images expecting
  them to be traced.

## Avoid
- Backstory paragraphs in panel descriptions: it's not drawable.
- Casting real actors as descriptions without saying which features matter.
- Late reference: send it before thumbnails, not after pencils.

## Verify
- [ ] Every new character/location has a first-appearance description.
- [ ] Notes visually distinct from letterable text.
- [ ] Reference pack delivered with the script, labelled.
