# Revising scripts from editorial notes

**Goal:** turn notes into a better script quickly, without breaking pages already drawn.

## Triage
1. Read all notes once without reacting.
2. Sort into: **must** (continuity, legal, page count, content standards), **story**
   (clarity, motivation, pacing), **taste** (line-level preferences).
3. For each story note, find the **underlying problem**. "Add a scene where Teo explains"
   usually means "readers won't understand Teo's motive". You can fix the motive
   another way.
4. Ask the editor about any note you'd push back on, with a proposed alternative.

## Revise
- Work on a new version file; never overwrite the version the artist has.
- Keep a **change log** at the top:
  ```
  v3 -> v4 (2026-10-16)
  - p5 pnl 3: new dialogue (motive)
  - p9: cut pnl 4; pnl 5-6 renumbered to 4-5
  - p14-15: scene replaced (new location: warehouse)
  ```
- Highlight changed text (colour) for the artist and letterer.
- Re-check page count, page sides, balloon numbering after structural changes.

## Protect in-progress art
- Ask what pages are pencilled/inked before changing them.
- Prefer dialogue fixes on finished pages; structural changes only on undrawn pages
  unless the editor approves redraw costs.

## Gotchas
- Silent changes the artist doesn't see lead to drawing the old version.
- Over-correcting: one note about pace isn't a request to cut half the dialogue.

## Verify
- [ ] Every note answered: done, alternative proposed, or discussed.
- [ ] Change log and highlights delivered with the new version.
- [ ] Artist confirmed which pages changed.
