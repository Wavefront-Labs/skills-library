# Tone materials and patterns

## The library
- **Material** palette > **Monochromatic pattern**: basic dot tones by density and lpi, gradations,
  textures (sand, noise), backgrounds (flowers, sparkles, effects), patterns (fabric, check).
- Use search tags; favourites go into a custom folder.

## Applying
1. Select an area on the page.
2. Drag the material onto the selection or click **Paste selected material to canvas**; it creates an
   image material/tone layer clipped to the selection mask.
3. Object tool: scale, rotate and move the pattern; the Tool property has **tiling** options and scale
   ratio.
4. For fabric, use Edit > Transform > Mesh transformation on a rasterised copy so stripes follow folds.

## Downloading and saving
- Clip Studio Assets (assets.clip-studio.com): many free and paid tone packs; download, then find them in
  Material palette > Download. Check each material's usage terms for commercial work.
- Create your own: draw a tile on a monochrome layer, Edit > **Register material** > Image, set "Use for
  paper texture / Tiling" options and a save location.

## Rules
- Keep consistent lpi across tones on a page.
- Don't scale dot tones up or down a lot after placement; dots change frequency and moire with other tones.
  Pick the right preset frequency instead.

## Gotchas
- Image materials with grey pixels must have tone effect applied to print as dots.
- Asset licences may forbid redistribution of the material itself (e.g. in a template file you sell).

## Verify
- [ ] All placed tones export as clean bitmap dots in Monochrome 2-tone.
