# Special rulers for focus and speed lines

**Goal:** mechanical consistency for effect lines and shapes while keeping a hand-drawn
stroke.

## Special ruler types (Ruler tool > Special ruler; Tool property > Special ruler)
| Type | Use |
|---|---|
| Parallel line | speed lines in one direction, hatching |
| Parallel curve | curved speed lines, hair flow |
| Multiple curve | flowing parallel curves |
| Radial line | focus (concentration) lines toward a point |
| Radial curve | swirling radial effects |
| Concentric circle | ellipses/circles of matching proportion (wheels, cups) |
| Guide / Cross | straight guides |

## Drawing focus lines by hand with a ruler
1. Create a Radial line special ruler centred on the focal point.
2. Snap on (View > Snap to special ruler).
3. Draw tapered strokes with an inking pen from the outside inward, varying length;
   leave a clear zone around the subject.

## Figure tools (generated)
CSP also has saturated line (focus line) and speed line generators in the Figure tool
group, which create editable line layers: set line count, gap, thickness, length
variation and inside/outside bounds. Edit the reference position and area with the
Object tool. Good for many lines quickly; touch up by hand for a natural look.

## Tips
- Put effect lines on their own layer, above or below the figure as needed, so the
  subject stays clear (mask the centre).
- Tapered strokes: pressure-sensitive pen with a low minimum size.

## Verify
- [ ] Focus/speed lines converge or align correctly and don't cover the subject.
- [ ] Effect lines on separate layers for editing.
