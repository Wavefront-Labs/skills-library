# Balloon tool and balloon tails in CSP

**Goal:** lettering done inside CSP with editable text and balloons that follow
lettering conventions.

## Text
1. Text tool: click and type (or paste from the script). Set font, size, leading,
   alignment (centre) in Tool property. Save a sub tool preset for dialogue.
2. Shape the text block (manual line breaks) into a rounded diamond.

## Balloons
- Balloon tool sub tools: Elliptical balloon, Curve balloon, Polyline balloon, Balloon
  pen (freehand), and flash/burst types in materials.
- Drag a balloon around the text; text and balloon share a balloon layer, so moving
  one moves both.
- Tool property: line width, fill colour (white), stroke colour, margin.

## Tails
- Balloon tail tools: Straight balloon tail, Curved balloon tail, Balloon tail (spiky
  types in some versions). Drag from inside the balloon toward the speaker; adjust
  width and curve with the Object tool.
- Tails merge with the balloon outline automatically.

## Linking
Draw a second balloon overlapping the first on the same balloon layer to merge them
(butted); or draw a connector shape with a balloon tool.

## Editing
- Object tool selects text or balloon for adjustments.
- Text stays live (editable) until rasterised; keep it live for corrections and
  translation.

## Verify
- [ ] Balloons follow padding and tail conventions.
- [ ] Text live and consistent styles across pages.
