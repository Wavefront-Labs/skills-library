# Frame templates

## Apply a template
1. Open the **Material** palette > **Framing template** folder (or downloaded panel layouts from Clip
   Studio Assets).
2. Drag the template onto the page, or select it and click **Paste selected material to canvas**.
3. The template creates frame border folders fitted to the base frame (inner frame) of the canvas; the
   gutters and border width come from the template settings.
4. Adjust with the **Object** tool (move panel corners) or Divide frame border tool.

## Page templates (whole page setups)
- When creating a new comic (File > New > Comic), the **Template** option applies a page template that
  can include frames, layers and guides; set it per story for consistency.

## Create your own
- Build a layout with frame border folders on a blank page, then register it as material
  (**Edit > Register material**) choosing the framing template type, and save it to a folder in the
  Material palette. Name by panel count and rhythm ("6-panel grid", "tall left splash").
- Set tags so you can search it later.

## Gotchas
- A template made on a canvas with a different base frame size will rescale; gutters may stretch.
  Make templates per paper size.
- Templates bring border width; check it matches your style sheet (line width set in Tool property of
  the frame border).

## Verify
- [ ] Gutters even and borders inside the base frame on applied templates.
