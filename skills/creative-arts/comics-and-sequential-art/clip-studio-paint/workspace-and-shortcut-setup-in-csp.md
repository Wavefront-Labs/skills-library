# Workspace and shortcut setup

## Palette layout
- Dock the essentials for comics: Tool, Sub tool, Tool property, Layer, Layer property, Material, Page
  manager (EX), Navigator, Colour wheel/Colour set.
- Hide palettes you don't use (Window menu). Tab key toggles all palettes for full canvas view.

## Register a workspace
- **Window > Workspace > Register workspace** - save named layouts ("Inking", "Colour", "Lettering").
  Switch from the same menu. Export/import workspaces to move them between machines.

## Shortcuts
- **File > Shortcut settings** (Windows) or **CLIP STUDIO PAINT > Shortcut settings** (macOS): assign keys
  to menu commands, tools, sub tools and auto actions. Example extras: flip canvas horizontally
  (vital for checking drawing), new vector layer, frame border tool, export.
- **Modifier key settings**: what Shift/Ctrl/Alt/Space do with each tool (e.g. Alt = eyedropper).
- Tablet buttons and devices (TourBox, express keys) map to these shortcuts.

## Command bar
- File > Command bar settings: add one-click buttons (snap to ruler, flip, rotate reset, export).

## Backup
- Settings can be backed up via the CLIP STUDIO launcher cloud sync (account) or by exporting workspaces,
  shortcut sets and sub tools individually.

## Gotchas
- Tablet driver shortcuts overriding CSP shortcuts cause confusion; set them in one place.
- Resetting CSP (Initialize at startup) wipes custom setup unless backed up.

## Verify
- [ ] Saved workspaces load correctly; shortcut list exported as a backup.
