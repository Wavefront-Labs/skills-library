# Lettering file delivery and corrections

**Goal:** a clean handoff: approvals tracked, corrections quick, final files exactly
as the publisher needs.

## Proofs
- Export low-res PDFs (or JPEGs) of lettered pages, numbered, as one file per issue.
- Reviewers (writer, editor) mark corrections with page/panel/balloon references or
  PDF comments.

## Correction rounds
1. Collect all corrections into one list; ask about unclear notes before changing.
2. Make changes in the editable master.
3. Send a revised proof listing changed pages; optionally highlight changed balloons.
4. Version numbers in file names (`TITLE_03_letters_v2.pdf`).
5. Track rounds; contracts may cap free correction rounds.

## Final files (follow the spec)
- **Print**: often press-ready PDF (PDF/X) of art + letters, or letters-only files at
  page size with transparent background for the publisher to combine. Text 100K,
  overprinting.
- **Outline fonts** (Type > Create Outlines) on a copy if the recipient lacks font
  licences; keep a live-text master for future fixes and translation.
- **Digital**: RGB flattened pages at the platform's resolution.
- **Translation**: editable text layers or a text export so localisers can replace
  copy.

## Archive
Keep the live-text masters, fonts list, and final exports together; publishers ask for
fixes for reprints years later.

## Proofreading checklist
- Spelling against the final script; names consistent.
- Balloon order and tails.
- Crossbar I, emphasis, punctuation conventions.
- Nothing outside safe area; no text covering key art.

## Verify
- [ ] Every correction addressed and logged.
- [ ] Final files match the spec (format, colour, fonts outlined or licensed).
- [ ] Editable masters archived.
