# Balloon placement guides and script import

**Goal:** text moves from the script to the page without retyping, and balloons go
where the team expects.

## Placement guides
- Writer or artist marks a low-res copy of the page with numbered balloon positions
  (1, 2, 3 matching the script's balloon numbering). Letterer follows unless it
  creates a problem; then flags it.
- Without a guide: letterer drafts placement and sends a quick JPEG for approval on
  the first few pages of a new team.

## Script import
1. Clean the script: one balloon per paragraph, remove panel descriptions into a
   separate file, convert bold/italic markup consistently (e.g. *word* or
   asterisks to emphasis character style).
2. Illustrator: copy-paste per balloon is common; scripts and plugins (e.g. custom
   JavaScript) can import text files paragraph by paragraph into point text objects.
3. InDesign alternative: threaded frames or data merge for text-heavy books.
4. Paragraph and character styles: Dialogue, Caption, Bold emphasis, Whisper, SFX
   small; change globally later.

## Proofing
- Compare lettered text against the script after import; letters must not be
  retyped from memory.
- Writer reviews lettered PDFs; corrections in a list by page/panel/balloon.

## Verify
- [ ] Every scripted balloon present, in order.
- [ ] Styles applied, no local overrides.
