# Font licensing for comics

**Goal:** every font in a published comic is licensed for that use, avoiding takedowns
or retroactive fees.

## Licence questions to answer (read each foundry's EULA; terms differ)
1. **Who is the licensee?** Freelance letterer vs publisher. Some foundries price
   differently for individuals/indies and for larger publishers, and some require the
   publisher (not the letterer) to hold the licence.
2. **Print use**: usually covered by a desktop licence; check run or revenue caps on
   indie licences.
3. **Digital comics and ebooks**: embedding fonts in PDFs/EPUBs may need explicit
   permission or an ebook/app licence. Flattened raster pages often count as images,
   but check.
4. **Logos/trademarks**: some EULAs restrict using the font in a trademarked logo or
   require a separate licence.
5. **Seats**: number of users/computers; studio work may need multi-seat licences.
6. **Modification**: altering glyph outlines for a logo may be restricted.
7. **Free fonts**: "free for personal use" is not free for a commercial comic.

## Records
- Keep invoices/licence PDFs with the project files.
- List fonts used per book in a production note for the publisher.
- When sending editable files to a publisher, don't send font files unless the
  licence allows; tell them which licences they need.

## Gotchas
- An indie licence outgrown when a book is picked up by a big publisher.
- Using a font bundled with software (e.g. a design app) beyond its permitted scope.

## Verify
- [ ] Licence on file for every font, matching licensee and uses (print, digital, logo).
- [ ] Font list supplied with deliverables.
