# Translated speech and foreign-language markers

**Goal:** readers know which language is being spoken and whether they're meant to
understand it.

## Conventions
1. **Translated for the reader**: put the English text inside **angle brackets**
   `< >` (a common comic convention). First occurrence often gets an editorial caption:
   "*Translated from Spanish." Some books use italics or a coloured balloon instead.
2. **Untranslated** (the viewpoint character doesn't understand): letter the actual
   foreign text (accurately, checked by a speaker) or an invented script, no brackets,
   no translation. Ensure the font supports the needed characters/script.
3. **Invented/alien languages**: a custom symbol font or hand-drawn glyphs; keep a key
   so the same "word" looks the same each time if it matters.
4. **Mixed lines**: brackets around only the translated portion.

## Placement and style
- Brackets sit inside the balloon around the whole text block (each line or the block;
  pick one).
- If brackets are already used for something else in the book, choose another marker
  and state it.

## Accuracy
- Real languages: verify with a fluent speaker; machine translation errors are
  embarrassing and common in published comics.
- Right-to-left scripts (Arabic, Hebrew) need proper shaping support in the app;
  test before committing.

## Verify
- [ ] Translation convention stated once and used consistently.
- [ ] Foreign text checked by a speaker; fonts support the glyphs.
