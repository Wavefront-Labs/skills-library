# Lettering point size and text legibility

**Goal:** text comfortably readable at final print or screen size, consistent across
the book.

## Print
- Standard US comic (6.625 x 10.25 in trim): dialogue lettering about 7-8 pt at print
  size with leading close to the point size (e.g. 7.5/8). Many letterers letter at
  print size; others at 1.5x art board scale with a proportionally larger size.
- Smaller formats (manga digest, 5 x 7.5 in) need slightly bigger relative text or
  fewer words per balloon.
- Captions same size as dialogue; whispers same size, dashed balloon; small text
  only for intentional asides.

## Screen
- Vertical scroll: check at actual phone width (around 360-430 CSS px); text should
  be roughly equal to body text in a phone app. On an 800 px wide WEBTOON canvas,
  set a provisional size, export one slice and adjust after viewing on a phone.
- Page comics read on phones: guided view or zoom; increase size if you know the
  primary market is digital.

## Test
- Print one page at 100 percent on a laser printer; read at arm's length.
- Phone test: export a slice, view on a phone at mid brightness.

## Failure modes
- Text scaled down to fit too many words: cut words instead.
- Leading too loose: balloons balloon.

## Verify
- [ ] Size consistent book-wide (paragraph styles).
- [ ] Passes print and phone test.
