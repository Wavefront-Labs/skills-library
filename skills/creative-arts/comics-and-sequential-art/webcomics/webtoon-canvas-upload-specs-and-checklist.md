# WEBTOON CANVAS upload specs and checklist

**Goal:** an episode that uploads first time and looks right in the app.

## Specs seen in WEBTOON sources (re-check before each launch)
- **Episode images**: up to 800 px wide x 1280 px tall each (handbook); larger images are
  automatically reduced/sliced. Per-episode total size cap (commonly cited as 20 MB;
  confirm in the dashboard).
- **File types**: JPG/JPEG/PNG. File names in English letters and numbers.
- **Series thumbnails** (help centre): a square image (1080 x 1080, under 500 KB) and a
  vertical image (1080 x 1920, under 700 KB).
- **Episode thumbnail**: help centre currently recommends 202 x 142 px under 500 KB
  (older material says 160 x 151); go by the current help-centre article.

## Pre-publish checklist
- [ ] Images sliced cleanly (no cuts through balloons/faces), in order, named
  `ep##_###`.
- [ ] Total size under the cap; quality checked on a phone.
- [ ] sRGB colour (see colour export skill).
- [ ] Episode thumbnail crisp at small size; not a spoiler.
- [ ] Title and episode number correct; creator's note written.
- [ ] Content rating/genre tags accurate.
- [ ] Scheduled publish time set for the series' regular update slot.

## Gotchas
- Thumbnails with small text: unreadable at listing size.
- Uploading a wrongly ordered slice; preview the episode before publishing.

## Verify
- [ ] Preview mode shows the whole episode correctly before publishing.
