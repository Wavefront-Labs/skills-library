# Character model sheets and turnarounds

**Goal:** one sheet that lets the penciller, inker, colourist, cover artist and any
fill-in artist draw the character the same way.

## Turnaround
1. Draw horizontal guide lines first: top of head, eyes, chin, shoulders, chest,
   waist, crotch, knees, soles.
2. Front view, then project lines across for 3/4, profile and back. Every feature
   must land on the same guide line in all views.
3. Neutral standing pose, arms slightly away from the body so the silhouette shows.

## What else goes on the sheet
- Height comparison with one other lead (or a 6 ft scale figure).
- 6-8 expression heads (neutral, happy, angry, sad, scared, smug + their signature).
- Hands if distinctive (gloves, rings, claws).
- Costume callouts: emblem drawn flat, seam lines, which side the holster is on,
  what is fabric vs armour.
- Colour key or reference to the colour model sheet.
- Do/Don't notes ("hair parts on her left", "scar runs over right eye").

## Production tips
- Keep the sheet on a shared drive with version date; update when designs change.
- For digital, build it as a layered file; turnarounds double as 3D-model refs.
- Mirror-check: flip the front view; asymmetric details must stay on the correct side.

## Verify
- [ ] Features line up across all turnaround views.
- [ ] A fill-in artist can answer any costume question from the sheet alone.
