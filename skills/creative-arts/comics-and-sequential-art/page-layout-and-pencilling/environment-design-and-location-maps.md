# Environment design and location maps

**Goal:** recurring sets that stay consistent across issues and let staging obey
geography.

## Process
1. Floor plan (top-down) for every interior used more than twice: walls, doors,
   windows, furniture, light sources. Mark north or a compass for sun direction.
2. Exterior/town map for chase or travel stories; track routes on it.
3. Elevation or 3/4 view sketch establishing ceiling height and style.
4. Location sheet: plan + 3 key angles + props + colour/lighting note.
5. Mark camera positions for the scene on the plan before thumbnailing; this
   keeps the 180-degree line honest.

## Design for story
- What does the location say about its owner? Clutter, era, money, care.
- Give each set a memorable silhouette feature (arched window, staircase) so a
  single panel identifies it.
- Plan the light: a single strong source makes spotting blacks and colour easy.

## Tools
- SketchUp, Blender or CSP 3D for complex sets; paint over renders.
- Keep a location folder per series with plans and reference photos.

## Verify
- [ ] Doors, windows and furniture in the same place in every panel.
- [ ] Every scene opens with or near an establishing shot.
