# Breakdowns and layouts for another finisher

**Goal:** layouts that lock storytelling while leaving the finisher room to draw well.

## Terms
- **Breakdowns / layouts**: page and panel design with rough figures, staging and camera.
- **Finishes**: a second artist adds full drawing (tight pencils or pencil+ink).
Common in deadline-driven books and studio pipelines.

## Must define
1. Panel borders at final size and position.
2. Camera: distance, angle, horizon line and vanishing points marked.
3. Figure placement, poses (gesture level), facing direction.
4. Key acting: expression notes where the gesture can't show it ("smirk").
5. Balloon placement zones, numbered.
6. Light source if it drives blacks.
7. Required props and backgrounds labelled; reference file names noted in margins.

## Leave open
- Anatomy and costume details (the finisher draws from model sheets).
- Background detail beyond what staging needs.
- Rendering and spotting blacks, unless the style requires them fixed.

## Annotation
- Use a second colour (blue/red) for notes, separate from drawing.
- Margin notes reference page/panel ("p6.3: use ref harbour_crane_02.jpg").
- Deliver at full page size, 300 dpi greyscale scans or layered digital files with
  notes on their own layer.

## Gotchas
- Breakdowns too vague: finisher re-stages, storytelling drifts.
- Breakdowns too tight: you've done finishes for breakdown rates.
- Inconsistent perspective markers between panels of the same room.

## Verify
- [ ] Every panel has camera, figures, balloons and required elements defined.
- [ ] Notes legible and separated from art.
