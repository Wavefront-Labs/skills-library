# Panel size and shape as duration

**Goal:** make the reader feel time stretch or snap through layout, not captions.

## Principles (McCloud ch. 4 "Time Frames"; Eisner "Timing")
- In comics, **space = time**. A panel's width and the number of panels for a moment
  set how long it feels.
- **Wide panels** read as longer moments or pauses; a tier-wide silent panel is a held
  breath.
- **Several narrow panels** in a tier read as rapid beats (a clock ticking, quick
  exchanges).
- **More panels for the same action** = slower (moment-to-moment).
- **Borderless / bleed panels** feel timeless or lingering; the moment spills out of
  its frame.
- **Dialogue takes time**: a panel with three exchanges lasts several seconds, even if
  the image is a single instant.

## Applying it
| Desired feel | Layout move |
|---|---|
| Suspense, slow | repeat narrow panels, same framing, tiny changes |
| Pause after a shock | one wide silent panel, generous gutters |
| Rapid action | many small panels, angled borders, little text |
| Epic moment | splash or tier-wide panel, minimal text |
| Rhythm in a talk scene | alternate panel widths to avoid monotony |

## Gotchas
- A huge panel for a trivial beat makes it feel important; match size to weight.
- Dense dialogue in a "quick" small panel contradicts the timing.

## Verify
- [ ] The biggest panels on each page carry the most important or longest moments.
- [ ] Rapid sequences use smaller, lighter panels; pauses use width and silence.
