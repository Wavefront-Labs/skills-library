# Thumbnailing pages from a script

**Goal:** solve storytelling at the cheapest stage, before any finished drawing.

## 1. Mark up the script
- Read the whole issue first.
- On each page: circle the key beat (the panel that matters most), note balloon load
  per panel, mark page side (L/R) and any reveals.
- Note reference you'll need (locations, props).

## 2. Thumbnail at small size
- Draw page rectangles at correct proportion, about 5-8 cm tall, **in spread pairs**
  (even left, odd right).
- Panel borders first: give the key beat the most space.
- Shapes and stick figures: who, where, which way they face. Mark the light source if
  it matters.
- Sketch balloon ovals in rough positions with numbers.

## 3. Test
- Arrow test for reading order (panels and balloons).
- Check the spread as a whole: composition, black/white balance, no facing-page
  spoilers.
- Shrink to phone size: key beat still reads?

## 4. Iterate
- Do 2-3 versions of problem pages; pick the clearest.
- Variety check across the issue: not every page the same 5-panel layout unless
  that's the design.

## 5. Layouts for approval
- Enlarge thumbnails (scan/photo and scale, or digital canvas) to page size as rough
  layouts; send to writer/editor if that's the agreement.
- Lock layouts before tight pencils; changes now cost minutes, later hours.

## Verify
- [ ] Every page thumbnailed in spreads with balloon placeholders.
- [ ] Arrow test passes; key beats get the space.
- [ ] Approval received (if required) before pencils.
