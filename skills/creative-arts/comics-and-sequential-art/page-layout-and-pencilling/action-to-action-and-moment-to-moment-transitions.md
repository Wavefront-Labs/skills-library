# Action-to-action and moment-to-moment transitions

**Goal:** sequence one subject's action with the right number of steps: enough to be
clear, few enough to keep pace.

## Definitions (McCloud, Understanding Comics ch. 3)
- **Action-to-action**: one subject progressing through distinct actions (swings,
  connects, opponent falls). McCloud's counts show it is the most common transition in
  mainstream Western comics.
- **Moment-to-moment**: very small changes between panels (a blink, a drop forming).
  Little closure required; time slows.

## Breaking down an action
1. Write the action as a list of key poses: anticipation, action, impact, reaction,
   aftermath.
2. Drop poses the reader can infer. Usually keep anticipation or impact plus the
   result; the gutter supplies the rest.
3. Each panel must show a **clear change**; if two consecutive panels look nearly the
   same by accident, cut one.
4. Keep screen direction consistent (left-to-right movement continues left-to-right).

## When to use moment-to-moment
- Tension and suspense: a hand reaching for a trigger across 3 tight panels.
- Emotional beats: a face changing slowly from hope to grief.
- Technique: **same framing, tiny change**. Lock the camera so the change is the only
  thing the eye sees; draw the background once and copy it (traditional: lightbox;
  digital: duplicate layer).

## Gotchas
- Too many action-to-action steps make fights read like instruction manuals.
- Skipping the impact moment in a fight leaves readers unsure what happened.
- Moment-to-moment overused becomes decompressed and slow.

## Verify
- [ ] Each panel shows a visible change from the last.
- [ ] A reader can describe the action correctly from the art alone.
- [ ] Moment-to-moment used only where time should slow.
