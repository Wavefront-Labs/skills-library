# Panel grids and tier structures

**Goal:** a layout system that gives the book rhythm and makes deviations meaningful.

## Common systems
| Grid | Feel | Notes |
|---|---|---|
| Three tiers, variable panels | standard mainstream | most flexible; tiers keep reading order clear |
| Six-panel (2x3) | steady, cinematic-ish | common in European and indie work |
| Nine-panel (3x3) | controlled, dense, metronomic | associated with Watchmen; good for talk-heavy, ironic or tense work |
| Four-tier | dense, strip-like | humour, compressed storytelling |
| Widescreen (3-4 tier-wide panels) | cinematic | each panel full width; slower |

## Working with a grid
- **Merge cells for emphasis**: two cells = a wider panel; a full tier = a held beat;
  the whole grid = splash. Because the grid is regular, any merge reads as important.
- **Keep the cell size constant** across the book (set a template).
- **Tiers stay intact**: merging vertically across tiers is the strongest break; use
  rarely.
- **Rhythm**: a 9-panel page followed by a full splash is a powerful contrast.

## Building templates
- Traditional: rule a master page and lightbox it or print bluelines.
- Digital: CSP frame templates or Divide frame border with fixed gaps; save as a
  material for reuse.

## When to go free-form
Action climaxes, dream sequences, or a style built on page design. Keep tier logic
underneath unless the page has a strong alternative lead.

## Verify
- [ ] Grid choice suits the book's tone; template consistent.
- [ ] Merges correspond to story emphasis.
