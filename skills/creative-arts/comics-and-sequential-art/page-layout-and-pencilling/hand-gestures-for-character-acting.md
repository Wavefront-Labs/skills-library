# Hand gestures for character acting

**Goal:** hands that add meaning to a panel rather than dangling as afterthoughts.

## Gesture vocabulary (Western conventions)
| Gesture | Reads as |
|---|---|
| Palm up, open | explaining, pleading, honesty |
| Palm down, pressing | calming, control, authority |
| Pointing | accusation, direction, command |
| Fist | anger, resolve |
| Hand to mouth | shock, secrecy, regret |
| Hand on back of neck | embarrassment, uncertainty |
| Steepled fingers | calculation, superiority |
| Hands in pockets | casual, or hiding something |
| Rubbing hands | anticipation, greed, cold |
| Hand on chest | sincerity, hurt |

## Making hands read
- Silhouette: open the fingers enough to show the shape; avoid hands overlapping the
  face or body with no contrast.
- Simplify at small scale: a mitten shape with thumb separated reads better than five
  fussy fingers.
- Exaggerate size slightly in foreground for emphasis (foreshortened pointing hand).

## With dialogue
Match gesture to the line's intent, or contradict it deliberately (calm words, clenched
fist under the table) for subtext. Change gestures across panels in a speech so the
figure doesn't freeze.

## Cultural caution
Gestures differ between cultures (thumbs-up, OK sign, beckoning). Research for the
setting and audience, especially in international editions.

## Verify
- [ ] Each panel with a speaking character has a deliberate hand action.
- [ ] Hands read in silhouette at print size.
