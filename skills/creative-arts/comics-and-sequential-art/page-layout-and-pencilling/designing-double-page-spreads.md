# Designing double-page spreads

**Goal:** a spread that reads as one image (or one designed layout) in print and
digital, with nothing lost in the binding.

## Canvas
- Width = 2 x trim width + bleed on the outer edges (+ bleed between pages only if
  your printer requests individual pages with bleed on all sides).
  Example US comic: trim 6.625 x 10.25 in each; spread trim 13.25 x 10.25 in plus
  0.125 in bleed around the outside.
- Ask the printer whether spreads are delivered as one file or two pages. Many want
  single pages; you split after drawing.

## The centre (gutter) zone
- Saddle-stitched books lose little at the centre; **perfect-bound** books lose more
  (glue and curve). Keep faces, text and key details out of the centre ~0.5-0.75 in
  for perfect binding (confirm with printer).
- Don't put a character's face exactly on the fold.

## Panelled spreads
- Reading order must be obvious: tiers run across both pages. Mark the intended path
  clearly, or readers read the left page's tiers first, then the right.
- Use tier-wide panels crossing the fold, or a big background image with panels inset.

## Digital
- Single-page readers split spreads; make sure each half still reads. Some platforms
  accept spread images; check.

## Splitting files
Split precisely at the centre line; add bleed to each inner edge if printer requires
it (duplicate a strip of art or extend the art).

## Verify
- [ ] Spread starts on an even page.
- [ ] Nothing critical in the binding zone.
- [ ] Reading order across pages is unambiguous.
- [ ] Files delivered in the printer's required form.
