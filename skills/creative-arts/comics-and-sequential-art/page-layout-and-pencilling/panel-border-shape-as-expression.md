# Panel border shape as expression

**Goal:** borders that carry meaning (time, mood, reality) and are used as a
consistent code.

## Eisner's point
In Comics and Sequential Art, Eisner treats the frame itself as a narrative device:
its shape and treatment tell the reader about time and state, not just containment.

## Common codes (conventions, not rules)
| Border | Common meaning |
|---|---|
| Straight ruled line | present, reality, default |
| Wavy / scalloped / cloud | dream, flashback, memory, thought |
| Jagged / spiky | shock, explosion, sudden pain |
| Dashed or thin | faded memory, uncertainty |
| No border | timelessness, openness |
| Black-filled gutters | night, horror, past (if coded) |
| Rounded corners | soft/past, sometimes TV/screen |
| Broken border (figure breaks out) | breakout action, emphasis, energy |

## Breaking the border
- A figure or object crossing the border feels like it's bursting into the reader's
  space. Use at peaks only.
- The overlapped gutter should not hide part of an adjacent panel's key content.
- Digital (CSP): draw the figure on a layer outside the frame folder, or mask part of
  the border.

## Consistency
Write the codes in the book's style notes. If flashbacks use wavy borders on page 4,
they must on page 80. Mixing codes undermines them.

## Gotchas
- Wavy borders on every emotional moment cheapen the device.
- Angled/tilted borders everywhere in action sequences make pages hard to read.

## Verify
- [ ] Each non-default border style maps to one meaning, listed in style notes.
- [ ] Breakouts used for peak moments only.
