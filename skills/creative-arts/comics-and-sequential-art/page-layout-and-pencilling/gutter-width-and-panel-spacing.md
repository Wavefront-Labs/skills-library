# Gutter width and panel spacing

**Goal:** gutters that separate panels cleanly, guide reading order, and occasionally
carry meaning, measured consistently across the book.

## Typical measurements (house styles vary)
- At printed size, gutters of roughly 1/8 in to 1/4 in (about 3-6 mm) are common.
- If you draw at 10x15 in original-art size (about 150% of print), scale accordingly
  (roughly 3/16-3/8 in on the board).
- Many artists make **horizontal gutters (between tiers) slightly wider than vertical
  gutters (between panels in a tier)** so the eye reads across tiers first. This helps
  Western left-to-right, then down reading.

## Setting up
- Traditional: rule a template once, or use pre-printed boards with a live area.
- Clip Studio Paint: frame border tool / Divide frame border with set horizontal and
  vertical gaps (Tool property > Gap), so every page matches.
- Keep gutters at least as wide as needed for trimming tolerance near the trim.

## Gutters as storytelling (McCloud: closure happens in the gutter)
- **Wider gutter** = more implied time or a stronger break; use at scene changes.
- **No gutter** (panels touching or overlapping) = simultaneity or rush.
- **Borderless panels bleeding into gutters** = timelessness, openness.
- Coloured gutters (black for flashbacks/night) = mood code; use consistently.

## Gotchas
- Inconsistent gutters page to page look amateur.
- A vertical gutter that lines up across two tiers can make readers read down
  instead of across. Offset vertical gutters between tiers.

## Verify
- [ ] Gutter widths measured and consistent; horizontal >= vertical if using the rule.
- [ ] No aligned vertical gutters across tiers inviting wrong reading order.
- [ ] Any gutter variation is deliberate.
