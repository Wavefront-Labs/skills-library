# Flashback and dream colour coding

**Goal:** readers recognise a time or reality shift instantly from the colour,
with no extra captions.

## Treatments
- Sepia or warm monochrome: past, memory.
- Desaturated / greyscale with one colour accent: trauma, key memory object.
- Duotone (two inks) or limited 3-colour palette: alternate timeline.
- Saturated, unnatural hues, soft gradients: dream, hallucination.
- Halftone dot texture or flat colour without rendering: period pastiche (old comics).

## Applying
1. Colour flats normally (so later reuse is easy), then apply the treatment as an
   adjustment: gradient map, hue/saturation, or a colour layer set to Color mode.
2. Coordinate with the letterer: flashback captions may get a different colour
   box; borders may change (wavy or rounded) via the artist.
3. Use the same treatment every time the series visits that time or place; log it
   in the colour bible.

## Gotchas
- Too subtle: a slightly desaturated flashback reads as a printing error.
- Too similar to night scenes: avoid blue monochrome for memory if night is blue.
- Recurring characters' identifying colours should survive the treatment (keep
  hue relationships).
