# Limited-palette and flat-colour styles

**Goal:** a strong, cohesive look with few colours: faster to produce and often more
distinctive than full rendering.

## Approaches
| Style | Description |
|---|---|
| Flat colour | flats as final colour, maybe one shadow tone |
| Duotone | black + one colour, values via tints (percentages) |
| Limited palette | 3-5 hues plus black/white across the whole book or per scene |
| Spot colour | specific inks (Pantone) printed instead of CMYK |
| Risograph | each colour is a separate drum/ink; files are greyscale separations per ink |

## Choosing the palette
1. Pick a dominant hue, a secondary, and an accent for focal points.
2. Test a key page with only those colours; ensure enough value range (light, mid,
   dark) to separate figure from ground.
3. Use tints (percentages) for variety within the palette.
4. Reserve the accent colour for story-critical elements (McCloud notes colour can
   carry symbolic weight; a single red object in a muted book commands attention).

## Production
- Duotone/limited in CMYK: build colours from fixed CMYK recipes, store as swatches.
- Spot/Riso: separate each ink to its own greyscale layer/channel; export per ink;
  check overlaps (overprint makes new colours).
- Halftone patterns may be part of the look; use proper halftone screens at print
  scale, not tiny soft brushes.

## Gotchas
- Too few values: figures merge into backgrounds.
- Spot inks and CMYK mixed without printer agreement.

## Verify
- [ ] Palette swatches defined and used consistently.
- [ ] Greyscale check shows clear separation.
- [ ] Separations correct for the print method.
