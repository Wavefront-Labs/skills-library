# Character colour model sheets

**Goal:** every colourist, flatter and cover artist uses the same colours for each
character.

## Contents
- Turnaround line art from the model sheet, flatted.
- Swatch list per part: skin, hair, eyes, costume parts, emblem, props, with
  RGB hex and CMYK values (or the swatch file).
- Shadow and highlight versions for standard daylight; optional night variant.
- Notes: "boots match gloves", "emblem is metallic: gold render", "eye colour only
  visible in close-ups".

## Swatch files
- Export swatch libraries (Photoshop .aco/.ase, CSP colour set) per character.
- Keep a master colour bible PDF with every lead and recurring location.
- Version the bible; note changes with dates.

## Using it
- Flatters pick from the swatch set only; colourist adjusts with lighting layers
  over correct flats.
- Cover artists and variant artists get the same sheet.

## Verify
- [ ] Every recurring character has a swatch set with values.
- [ ] Flats across the book sample to the same base values.
