# Working with flatters and colour assistants

**Goal:** flats come back usable without rework, on time.

## Brief the flatter
- File spec: dimensions, resolution (often 600 ppi line art / flats at same size),
  colour mode (RGB for flats is common), file type (PSD/TIFF), layer names
  ("LINES" on top, "FLATS" beneath).
- Conventions: every distinct region a distinct flat colour; no anti-aliasing
  (pencil/aliased fill); flats extend under line art; no gaps at line edges.
- Colour legend: either use the character swatch sets, or arbitrary distinct colours
  for later selection only. Say which.
- Notes: which panels have colour holds, background drops, special effects.

## Handoff
- Send pages in batches as inks arrive; agree turnaround (often 1-2 days per batch).
- Shared folder with structure: /issue-03/inks, /flats, /colours.
- Rate per page agreed in writing.

## Quality check
- Magic wand (non-contiguous off, anti-alias off) test random regions.
- Zoom to 200 percent at line edges for gaps or halos.
- Overlay check: hide lines; every region filled.

## Verify
- [ ] Flats meet the spec on spot-check before rendering begins.
- [ ] Credits and payment logged per batch.
