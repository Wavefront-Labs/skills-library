# Running gags and continuity strips

**Goal:** jokes and stories that build across days without losing casual readers.

## Running gags
- A repeated situation or line that readers anticipate (a character's failed attempt,
  a catchphrase, a recurring object).
- **Evolve it**: each recurrence adds a twist; pure repetition wears out.
- **Space it**: weeks apart keeps it fresh.
- **Pay it off** occasionally: the long-awaited success (or a subverted payoff).

## Continuity (story) strips
- A storyline over several days or weeks.
- **Each daily needs its own laugh or hook**, because many readers see one strip, not
  the run.
- **Recap efficiently**: first panel restates the situation each day without
  repeating Monday's text.
- **Week-long arcs**: Monday set-up, mid-week escalation, Friday/Saturday payoff;
  Sundays often standalone because some papers run Sundays separately.
- Adventure/serial strips (non-humour) end each daily on a mini-cliffhanger.

## When to end
End a storyline when the jokes start relying on the plot rather than character. Long
runs risk losing readers who joined midway.

## Verify
- [ ] Each strip in a run works alone.
- [ ] Recap present but brief.
- [ ] Running gags evolve, spaced out.
