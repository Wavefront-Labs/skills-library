# Jordan and Hamman counts

**Goal:** have more than one false count, so a packet can be shown several times in a
routine without the same move repeating.

## The Jordan count
- Like the Elmsley, it displays four cards as four while concealing one.
- It conceals a **different position** in the packet and leaves the packet in a different
  order, which is why routines alternate the two.
- The cards are peeled one at a time into the other hand, with a block of cards taken at
  one point.
Learn the exact handling from Card College vol 3.

## The Hamman count
- Brother John Hamman's count lets you show the **same face** (or back) repeatedly while
  hiding others - e.g. show four cards as all the same.
- Typically used for "all the cards are the same" displays and transformations.

## Choosing between counts
- Which card must be hidden, and where must it end up? Map the packet before and after
  each count.
- Visual variety: if you have done an Elmsley, use a Jordan for the next display.
- Simplicity: if a genuine count can do the job, use it.

## Practice method
1. Write the packet order before and after each count on a card.
2. Do a genuine count, then the false count, ten times each, filming both.
3. Matching rhythm and hand motion is more important than speed.

## Gotchas
- Mixing up which count changes order which way: keep a written cheat-sheet until
  automatic.
- Counting too many times in one routine looks like "proving" something; three counts is
  plenty.

## Verify
- [ ] Packet order after each count predicted correctly 10/10.
- [ ] Video shows genuine and false counts look alike.
