# Si Stebbins and cyclic stacks

**Goal:** set the deck in a calculable order so any card's neighbour is known from a single
glimpse, without memorising 52 positions.

## Principle
In a **cyclic stack** each card follows the one before by a rule. In **Si Stebbins** each
card is three higher than the one before, with suits rotating in a fixed order (commonly
CHaSeD: clubs, hearts, spades, diamonds). The **Eight Kings** stack uses a mnemonic
sentence for values and a fixed suit rotation. Because the order is cyclic, complete cuts
never destroy it.

## Method (outline)
1. Set the deck by the rule (values add 3, ace=1, jack=11, queen=12, king=13, wrapping
   past 13; suits in rotation).
2. Have a card selected from a spread and cut the deck at that point.
3. Glimpse the bottom card; add 3 and move one suit along to name the selection.
4. Allow complete cuts freely; do not allow shuffles unless you use a false shuffle.

## Common faults
- A face-up spread reveals the pattern; it shows red and black alternating suits and a
  clear value sequence.
- Losing the suit rotation after a mistake: practise the rule both directions.
