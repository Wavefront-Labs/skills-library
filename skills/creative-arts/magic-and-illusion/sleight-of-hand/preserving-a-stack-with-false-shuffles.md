# Preserving the stack with false shuffles

**Goal:** make the deck appear thoroughly mixed while its stacked order survives, or
changes only in ways you can calculate.

## Principle
Three tools preserve order:
1. **Complete cuts** never change cyclic order.
2. **Full-deck false shuffles** (Zarrow, push-through) keep every card in place.
3. **Faro shuffles** mix the deck in a mathematically exact way: eight perfect out-faros
   restore a 52-card deck, and stacks can be designed to survive or be recalculated after
   a known number of faros.

Some stacks (Mnemonica) are designed so a few genuine actions produce new known orders.

## Method (outline)
- Open with a false shuffle and a false cut early, while attention is low.
- Use complete cuts by spectators; they feel fair and do nothing.
- Use a faro only when you can do it perfectly; a single miss breaks the arithmetic.
- Allow a spectator shuffle only at the end of the memorised-deck section.

## Common faults
- Overusing false shuffles: three in a row draws attention.
- An imperfect faro you pretend was perfect.

## Fine mechanics
Marlo's Faro Notes is the faro reference; Card College vol 3 gives full-deck false
shuffles; Mnemonica discusses stack-preserving actions.

## Verify
- [ ] Stack checked after each false shuffle in rehearsal.
- [ ] Eight perfect out-faros restore the deck.
- [ ] Routine order puts spectator shuffles last.
