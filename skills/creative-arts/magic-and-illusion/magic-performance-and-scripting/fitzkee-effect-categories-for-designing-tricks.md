# Fitzkee effect categories for designing tricks

**Goal:** a systematic way to think about what a trick *is* (the effect) separately from how
it works, and to generate new plots by combining categories with objects.

## The basic effects (Fitzkee's list, paraphrased)
Fitzkee identified around twenty basic effects, including:
- Production (appearance), Vanish (disappearance)
- Transposition (two things change places), Transformation (one thing changes)
- Penetration (solid through solid), Restoration (destroyed and made whole)
- Animation (object moves by itself), Anti-gravity / levitation
- Attraction (things cling together), Sympathetic reaction (one thing copies another)
- Invulnerability, Physical anomaly, Spectator's failure, Control (mind or physical),
- Identification / divination (mentalism), Prediction (and some others in the full list)
Check the book for his exact list and definitions.

## Using the categories
1. **Classify** existing tricks: what is the core effect? (Many "different" tricks are the
   same effect.)
2. **Combine** a category with an object or theme: "Restoration + a borrowed photo",
   "Transposition + two spectators' rings".
3. **Vary** within a routine: avoid three vanishes in a row; alternate categories.
4. **Invent**: the Trick Brain's method is to list objects, list effects, then cross them
   and evaluate each combination.

## Pitfalls
- A clever method with an unclear category confuses audiences (see clarity).
- Mixing several categories in one effect can muddle it.

## Verify
- [ ] Every piece in your set labelled with its Fitzkee category.
- [ ] No more than two adjacent pieces share a category.
