# Finding a presentational premise

**Goal:** give each effect a reason for being performed: a story, a question, a game or a
theme that makes it about something.

## Principle
An effect without a premise is a puzzle. A premise (Burger's "presentational hook")
gives the audience a reason to care and a frame for interpreting the magic. Nelms called
it the "theme" of the presentation. A good premise is simple, connects to the audience's
lives, and fits the performer's character.

## Sources of premises
- Personal stories (your grandfather's deck).
- Questions (can luck be learned?).
- Games and challenges.
- Demonstrations (how cheats work, how memory works).
- Myths and history.

## Testing
- State the premise in one sentence.
- Check that the effect illustrates it.
- Check that it fits your character.
- Try it on lay audiences; does the premise make the magic stronger?

## Common faults
- Premise that requires a long explanation.
- Premise that clashes with the method's needs.
- Using the same kind of premise for every effect.

## Verify
- [ ] Every effect has a one-sentence premise.
- [ ] Premise fits the character.
- [ ] Tested on lay audiences.
