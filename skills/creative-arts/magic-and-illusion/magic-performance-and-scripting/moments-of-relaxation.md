# Moments of relaxation

**Goal:** create moments where the audience's guard drops completely, and use them for the
secret work that the next effect needs.

## Principle
Tension builds through an effect and releases at the climax. Immediately after release
(applause, laughter, "that's it"), the audience relaxes and stops scrutinising. Tamariz
writes about this as the **on/off-beat** rhythm. A **false ending** is a deliberate
relaxation: the trick seems over, so the audience stops watching, and the real climax
follows.

## Designing relaxation
- After each reveal, script a beat of release: a joke, a thanks, putting a prop away.
- Do the setup for the next effect there.
- Use false endings: "And that's how it's done", then the kicker.
- Change the mode: sit down, switch spectator, move to a new table spot.

## Common faults
- Dead time instead of relaxation: an awkward pause is not a release.
- Using every relaxation moment for a move, so the audience learns to watch them.
- Releasing too long and losing the room.

## Verify
- [ ] Routine script marks each relaxation moment.
- [ ] Setup for the next effect falls inside one.
- [ ] At least one false ending tested on lay audiences.
