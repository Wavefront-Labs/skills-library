# Layering methods and cancelling solutions

**Goal:** make an effect resistant to analysis by using more than one method and by
killing off each possible explanation.

## Layering
- **Method switching**: phase 1 uses method A; when the audience starts suspecting A,
  phase 2 is done in conditions where A is impossible, using method B.
- **Redundancy**: two methods achieve the same moment; even if one is suspected, the
  other covers it.
- Teller has described this: the audience's theory from one phase is disproved by the next.

## Cancelling solutions
1. List all possible explanations (see Tamariz false solutions).
2. For each, design a condition that rules it out: shuffle by spectator (rules out stacks),
   signature (rules out duplicates), examination (rules out gimmicks).
3. Place cancellations before the climax.

## Design process (Ortiz's approach)
- Start from the effect you want, not the method you have.
- Choose methods that fit the conditions you want to show.
- Accept more work (more methods, more preparation) for a cleaner effect.

## Testing
- Perform for knowledgeable magicians: if they fix on one solution, add a layer that
  cancels it.
- Perform for lay audiences: check the effect is still clear (layering can add clutter).

## Verify
- [ ] Each routine phase lists its method and which theories it cancels.
- [ ] Magician test audience cannot settle on one method.
