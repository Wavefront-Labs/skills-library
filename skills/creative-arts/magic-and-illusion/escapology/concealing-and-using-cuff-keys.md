# Concealing and using keys

**Goal:** understand how escapologists have used hidden keys, so the act can survive
inspection while staying safe.

## Principle
For many cuffs, the most reliable method is the matching key, concealed so that a search
does not find it. Houdini's challenge escapes often involved keys obtained, concealed and
used under cover. The audience's belief that "he was searched" is the conviction the
performer must build.

## Principles of concealment (outline)
- Keys and picks hidden in places a polite search does not reach, or introduced after the
  search.
- Keys must be reachable with the hands restrained; plan the reach.
- A key that works on several common cuffs reduces what you need to carry.

## Safety rule
The **safety officer holds a separate set of keys** for every lock in the act. A hidden
key is a method, never the safety plan.

## Presentation
- Let the search be thorough-looking and visible.
- Use a screen or cabinet when the act needs cover (see the cabinet-versus-in-view skill).

## Common faults
- Dropping the key in view.
- Planning concealment without testing reach.

## Verify
- [ ] Reach tested with hands restrained in each cuff.
- [ ] Safety keys held by the officer for every lock.
- [ ] Search sequence scripted.
