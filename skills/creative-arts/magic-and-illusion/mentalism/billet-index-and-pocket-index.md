# Billet index and pocket index

**Goal:** have many possible predictions pre-written and stored so that, after a spectator's
choice, you can produce the right one from a pocket.

## What an index is
A holder (cards in a pocket wallet, a set of stepped pockets, a tabbed card case) with
each item in a known position. You reach in and take the one you need, apparently taking
"the prediction".

## Common uses
- **Card index**: all 52 cards (or a subset) to produce a named card.
- **Number index**: predictions for possible totals or choices.
- **Billet index**: written predictions for a limited set of choices (colours, ESP
  symbols, a few words).

## Layout and access
- Organise logically (by suit and value, by colour, by number).
- Position in a pocket you can reach naturally (jacket inner pocket, trouser pocket).
- Practise taking any item by touch alone in under two seconds.

## Pairing with forces and outs
An index reduces the need to force; combine with a partial force to keep the index small
(e.g. force a colour, index for a few objects). This is a multiple-out approach.

## Gotchas
- Too large an index is slow and bulky; limit choices with the presentation.
- Reaching too long into the pocket: practise until fast.
- Duplicate predictions must look identical (same pen, same handwriting, same fold).

## Verify
- [ ] Any index item retrieved in under two seconds blind.
- [ ] Items indistinguishable from each other in look and feel.
