# Verbal codes for two-person telepathy

**Goal:** a code in which ordinary-sounding questions from the person in the audience
transmit an object, number or name to the blindfolded partner on stage.

## Structure of a classic code
1. **Category first**: the first word of the question signals the category ("Tell me..."
   = jewellery, "What is..." = currency, "Can you..." = clothing...).
2. **Item within category**: the next cue word picks the item from a numbered list
   ("Now" = 1, "Please" = 2, "Quickly" = 3...).
3. **Details**: colour, number, letters via separate small tables.
Both partners memorise the same tables perfectly.

## Numbers and letters
- Digits coded by words (1-9, 0) in a fixed table; multi-digit numbers sent one digit per
  sentence or with pauses.
- Letters via a two-step code (group + position) or a phonetic table for names.

## Sounding natural
- Cue words must be words a person would say anyway.
- Vary the "filler" so the audience does not hear the same phrase twice.
- Mix in genuinely coded silence (see timing codes) to avoid repetition.

## Concealing the system
- The best acts (e.g. the Piddingtons) used multiple systems so no single theory fits.
- Occasional "misses" corrected by the partner make it look more like real telepathy.

## Gotchas
- Memorisation drift between partners: drill weekly.
- Noisy venues: microphones and monitors so the partner hears every word.

## Verify
- [ ] Both partners decode 50 random items with no errors.
- [ ] An observer told to listen for a code cannot spot it in a 5-minute demo.
