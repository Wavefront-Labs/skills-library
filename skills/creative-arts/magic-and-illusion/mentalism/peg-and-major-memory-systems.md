# Peg and major systems

**Goal:** a reliable mental filing system for numbers and lists, the basis of memory feats
and memorised decks.

## Principle
The **major system** converts digits to consonant sounds: 0 = s/z, 1 = t/d, 2 = n,
3 = m, 4 = r, 5 = l, 6 = j/sh/ch, 7 = k/hard g, 8 = f/v, 9 = p/b. Vowels are fillers. Any
number becomes words: 12 = "tin", 41 = "rat". **Peg words** for each number from 1 to 100
are learned once. To remember an item at position N, you create a vivid image linking the
peg for N to the item.

## Learning the system
1. Learn the ten digit-sound pairs.
2. Learn pegs 1 to 10, then 11 to 100, ten a day.
3. Practise random recall of pegs.
4. Apply: memorise a 20-item list called out by a friend, in and out of order.

## Image rules
Exaggerated, active, absurd images stick. Link peg and item in action.

## Uses
- Magazine memory, list memory, phone numbers.
- Memorised deck (each card's position linked by peg).

## Common faults
- Weak, static images.
- Learning too many pegs at once.

## Verify
- [ ] Pegs 1 to 100 recalled at random under two seconds.
- [ ] 20-item list recalled in and out of order.
- [ ] Digit-sound code applied to any four-digit number instantly.
