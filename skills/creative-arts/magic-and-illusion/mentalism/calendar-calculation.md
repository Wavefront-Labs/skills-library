# Calendar calculation

**Goal:** name the day of the week for any date a spectator calls, in a few seconds.

## Principle
Several methods reduce the calculation to small additions modulo 7. Conway's **doomsday
rule** uses the fact that certain easy dates (4/4, 6/6, 8/8, 10/10, 12/12, the last day of
February, and others) always fall on the same weekday in a given year (that year's
"doomsday"). Benjamin teaches a code method: a code for the year, the month and the date
are added and reduced modulo 7.

## Doomsday outline
1. Know the century anchor (for 1900s Wednesday, 2000s Tuesday).
2. Compute the year's doomsday from its last two digits.
3. Find the nearest doomsday date in the month.
4. Count forward or back to the target date.

## Practice
- Drill year doomsdays for the current century first.
- Time yourself on random dates; aim for under five seconds.

## Staging
- Ask for birthdays; the personal connection adds interest.
- Let a spectator verify with a phone.
- Combine with another feat for a memory and calculation act.

## Common faults
- Leap year errors (January and February).
- Century anchor mistakes for dates outside 1900 to 2099.

- [ ] Twenty random dates correct in a row.
- [ ] Average under five seconds.
- [ ] Leap-year cases handled.
