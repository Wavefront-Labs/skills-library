# Drilling a two-person code

**Goal:** both partners encode and decode instantly and identically, under stage pressure.

## Phase 1: learn the tables
- Turn each table into flashcards (cue word -> meaning and meaning -> cue word).
- Use a spaced-repetition app or Leitner boxes; daily short sessions.
- Learn in both directions; senders and receivers need different directions most.

## Phase 2: speed
- Partner A calls random items, partner B encodes aloud; time each.
- Target: under 2 seconds to form a natural sentence.
- Receiver decodes recordings of sender phrases.

## Phase 3: simulation
- Friends act as audience, hand objects to the sender, call out numbers and names.
- Add noise, interruptions and difficult items (foreign coins, unusual names).
- Record and review where you hesitated.

## Phase 4: maintenance on tour
- 15-minute warm-up drill before each show.
- Weekly full table review.
- Any table change is written, both partners initial it.

## Gotchas
- One partner updating the code alone.
- Over-reliance on the most common items; drill the rare ones.

## Verify
- [ ] 100 random items with zero errors in a single session.
- [ ] Pre-show drill done every show day.
