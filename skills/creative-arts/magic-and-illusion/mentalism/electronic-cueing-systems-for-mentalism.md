# Electronic cueing systems for mentalism

**Goal:** use a radio or app-based cueing system so an offstage partner can transmit
information (numbers, letters, categories) to the performer reliably.

## Types
- **Vibrating receivers** worn on the body: pulses encode digits or letters (e.g. a
  pulse count, long/short patterns).
- **Earpieces**: spoken information from the operator; very flexible, but visible and
  risky if feedback or interference occurs.
- **App/phone-based** systems over Wi-Fi or Bluetooth for short range.

## Operator workflow
1. Operator sees information (watching the audience, via a peek device, a camera, or a
   prepared list).
2. Transmits using the agreed code.
3. Performer acknowledges with a subtle cue if needed.
The code is still a code: pulses need the same tables as a two-person code.

## Reliability
- Test the full system in the venue at show time: radio noise changes with the crowd.
- Fresh batteries, charged phones, spare receivers.
- **Fallback**: every effect needs an out if the signal fails.

## Legal
Use only licence-exempt frequencies and power levels allowed in your country; venues
with radio mics may conflict - coordinate frequencies with the sound engineer.

## Ethics
Electronic cueing is a method for entertainment mentalism. Presenting it as genuine
psychic ability crosses into fraud; see mentalism disclaimers.

## Verify
- [ ] Full system tested in venue within an hour of the show.
- [ ] Out prepared for every effect that relies on cueing.
