# Rainbow ruse and cold reading elements

**Goal:** know the main statement types in cold reading and combine them into a flowing
reading for an entertainment character reading.

## Principle
Rowland names the elements of a reading. Key ones:
- **Rainbow ruse:** a statement giving a trait and its opposite ("you can be outgoing, yet
  at times you need to be alone").
- **Sugar lump:** a reward for cooperation ("you are open, which helps me read you").
- **Fine flattery:** a compliment framed as a judgement.
- **Jacques statement:** life-stage statements (from the "seven ages of man").
- **Forking:** following the subject's response in either direction.

## Sequencing a reading
1. Opening: sugar lump to build cooperation.
2. Personality: Barnum and rainbow statements.
3. Specific "hits": forking on reactions.
4. Close: a positive, forward-looking statement.

## Ethics
Present as entertainment; consider explaining that this is a known technique.

## Common faults
- Using every element in every reading; vary them.
- Losing the entertainment frame.

## Verify
- [ ] A reading script uses at least four distinct elements.
- [ ] Forking practised in both directions.
- [ ] Disclaimer or framing in the script.
