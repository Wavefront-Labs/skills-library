# Magic square

**Goal:** fill a 4x4 grid on a board so that every row, column and diagonal sums to a
number called by a spectator; or perform a knight's tour around a chessboard.

## Principle
A 4x4 magic square for a target total can be built from a memorised template whose cells
are offsets, adjusted by the spectator's number. Rouse Ball describes magic square
constructions; magicians and mental calculators (Benjamin among them) use a fixed
template so the performer only adjusts a few cells. Many more combinations than rows,
columns and diagonals sum to the total (corners, central squares), which strengthens the
finish. The **knight's tour** (a knight visiting every square once) is a memorised path
presented as calculation.

## Performance
1. Ask for a number in a suitable range (e.g. 22 to 99).
2. Fill the grid quickly but not instantly, in an order that hides the template.
3. Show rows, columns and diagonals sum, then the extra combinations.
4. Let a spectator check with a calculator.

## Practice
Drill the template until you can fill it for any total in under a minute.

## Common faults
- Filling in an obvious order.
- Arithmetic slip on the adjusted cells.

## Verify
- [ ] Ten random totals filled correctly.
- [ ] Extra combinations memorised and shown.
- [ ] Fill order disguises the template.
