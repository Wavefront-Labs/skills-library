# Magazine memory test

**Goal:** the audience calls any page number from a magazine and the performer describes
the page in detail.

## Principle
Lorayne's demonstrations popularised the feat. It can be done genuinely, using the **peg
system** (each page number has a peg image) linked to images of the page's main content,
or with mentalism methods. Genuine memorisation is entirely achievable with practice and
gives the performer a feat that withstands any test.

## Genuine method (outline)
1. Learn pegs for 1 to 100 (see the peg and major system skill).
2. For each page, link its peg to two or three vivid details: the main image, a headline,
   a colour.
3. Review in sequence, then randomly.
4. Refresh the day before and the hour before the show.

## Staging
- Hand out several copies; let spectators call pages.
- Describe the page vividly, then let the spectator confirm.
- Finish with a reverse test: they describe a detail, you name the page.

## Common faults
- Choosing a magazine with many similar pages.
- Over-describing; two or three details are enough.

## Verify
- [ ] Any page described within three seconds.
- [ ] Reverse test (detail to page) works.
- [ ] Magazine has visually distinct pages.
