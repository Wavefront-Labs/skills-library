# Nozzle checks, head cleaning and head strikes

## Nozzle check
1. Print a nozzle check pattern before every important print/session (plain paper or a strip of the paper).
2. Look for missing lines in any colour (use a loupe for light colours).
3. Missing segments = clogged nozzles -> clean.

## Head cleaning
- Run a normal cleaning, then re-check. Repeat up to 2-3 times.
- If still clogged: leave the printer for several hours (or overnight) and retry - ink softens.
- Power/heavy cleaning uses a lot of ink; last resort.
- Modern printers (Epson SC-P700/P900, Canon PRO) have auto nozzle checking/compensation - still verify.

## Preventing clogs
- Print something at least weekly (a small colour patch print); keep the printer powered (it runs maintenance).
- Room humidity 40-60%; avoid dust; keep cover closed.
- Shake ink cartridges per manufacturer for pigments that settle (some Epson models).

## Head strikes
Symptoms: ink scuffs, smears, or dark lines on thick or curled papers; the head touches the paper.
1. Set **Platen Gap** to Wide/Wider (Epson) or use "thick paper" settings; set the media thickness.
2. Flatten paper (store flat, decurl rolls); cut sheets have curled edges - reverse curl gently.
3. Use the correct paper path (front manual feed for thick fine-art, not the top feed).
4. Clean platen and head edges if ink built up (per manual).

## Verify
- [ ] Clean nozzle check before the edition; no scuffs on thick paper prints.
