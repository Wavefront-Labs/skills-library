# Shooting background plates and elements

## Plan
List every element (background, each figure, props, effects like rain/smoke) and which will be shot
separately. Sketch the final frame.

## Capture rules
1. **Lock the camera**: sturdy tripod, manual focus, manual exposure, manual WB; remote release.
   Do not touch zoom or focus between plates for the same composite.
2. Shoot a **clean plate** (empty set) for removing stands, crew and wires.
3. For elements shot elsewhere: record lens focal length, camera height, distance and tilt of the plate,
   and light direction/height (photo of the setup, compass bearing outdoors).
4. Shoot each element with **matching lens/height/angle and light direction** - perspective cannot be fixed later.
5. Overshoot: several takes of each element; for people, multiple frames of the same pose for best parts.
6. Shoot a grey/chrome ball or a reference figure in the plate for light matching.

## Gotchas
- Changing aperture changes depth of field and vignetting between plates.
- Auto ISO/auto WB creates mismatches; use manual.
- Moving sun changes shadows within an hour - shoot outdoor plates quickly.

## Verify
- [ ] Every element has a matching perspective record and a clean plate exists.
