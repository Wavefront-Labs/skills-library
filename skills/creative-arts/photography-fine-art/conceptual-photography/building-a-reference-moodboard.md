# Building a reference moodboard

## Procedure
1. Start from the concept sentence; list the elements the image needs: place, light, time of day,
   palette, figure(s), gesture, props, wardrobe.
2. Collect references per element - paintings, film stills, photographs, your own scouting
   shots. Use Milanote, Pinterest boards, PureRef (desktop) or printed wall.
3. Annotate each reference with what it is for ("this light direction", "this colour only").
4. Edit to 12-20 images; contradictory references confuse the crew.
5. Add a palette strip (sampled swatches) and a lighting note.
6. Share as PDF with crew (stylist, assistant, model) before the shoot; refer to it on set.

## Gotchas
- Copying a single reference too closely produces pastiche; mix sources per element.
- Credit references if the board is published.

## Verify
- [ ] Every element of the planned image has an annotated reference; crew has the board.
