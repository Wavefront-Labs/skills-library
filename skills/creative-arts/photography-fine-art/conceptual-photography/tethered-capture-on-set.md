# Tethered capture on set

## Hardware
- USB-C/USB-3 cable (Tether Tools TetherPro, high-visibility orange), 3-5 m; use an active extension
  beyond that; strain relief (JerkStopper) on camera and laptop.
- Laptop on a tether table; spare charger; second drive for backup.
- Wireless tether exists (Capture One Wi-Fi on some bodies, Camera Connect) - slower, less reliable.

## Capture One (industry standard)
1. File > New Session (Capture, Selects, Output, Trash folders).
2. Camera tool: confirm the camera is detected; set Next Capture Naming (Session name + counter) and Location.
3. **Next Capture Adjustments**: Copy from last / apply a style - so each frame arrives graded.
4. Overlay tool: load the layout/sketch PNG to check composition live.
5. Live View for focus and composition checks.

## Lightroom Classic
File > Tethered Capture > Start Tethered Capture; set session name, folder, metadata; Develop Settings
dropdown applies a preset to incoming frames.

## Backup
Capture One: dual card write in camera plus Session backup; copy sessions to a second drive at breaks.

## Gotchas
- Camera power saving/sleep disconnects tether - disable auto-off.
- Cable pulled out = lost frames if camera is set to save to computer only; set "save to card and computer".

## Verify
- [ ] Every frame lands named in the session with the grade applied; card also holds copies.
