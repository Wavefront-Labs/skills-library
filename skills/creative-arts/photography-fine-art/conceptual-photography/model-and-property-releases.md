# Model and property releases

## What a release does
Grants permission to use a recognisable person's likeness (model release) or private property/artwork
(property release) for defined uses. It protects you against privacy/right-of-publicity claims.

## When you need one
- **Commercial/advertising** use: always.
- **Fine-art sale and exhibition**: rules vary by jurisdiction; in New York, Nussenzweig v. diCorcia
  upheld art use without a release, but other places differ (privacy laws in France, Quebec, Germany).
  For staged work with cast sitters, **always get a release** - it is easy and avoids disputes.
- **Stock licensing**: agencies require releases.

## Contents
Names, date, description of shoot, scope of use (exhibition, print sale, book, online, advertising),
territory, duration (usually perpetual), compensation (even nominal), signatures; parent/guardian for minors.

## Procedure
1. Send the release before the shoot; explain uses in plain language.
2. Sign on the day (apps: Easy Release); photograph the sitter holding ID if required.
3. Store releases linked to image IDs; note release status in IPTC (Model Release Status).

## Gotchas
- Sensitive uses (implying illness, crime) need explicit consent beyond a standard release.
- Not legal advice: check local law for commercial projects.

## Verify
- [ ] Every identifiable sitter in published images has a signed release on file.
