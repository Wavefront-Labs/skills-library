# History, snapshots and virtual copies

## History panel
- Every Develop change is a step, stored in the catalog (not in XMP). Click a step to return; hovering previews it in Navigator.
- Making a change after clicking an earlier step discards later steps.
- Right-click a step > **Copy History Step Settings to Before** to compare against that point with `\` or `Y`.
- **Clear** (X) deletes history, keeping current settings; do it to shrink large catalogs, never on images in progress.

## Snapshots
- Snapshots panel `+` (Ctrl/Cmd+N): saves the current state with a name. Snapshots survive history clearing.
- Naming convention: `Printed 2026-03 Hahnemuhle PR 40x50`, `Exhibition v2`, `Before client changes`.
- Right-click > Update with Current Settings.

## Virtual copies
- Ctrl/Cmd+' : a second set of settings for the same file. Use for B&W vs colour, alternate crops, a soft-proofed print version.
- Rename: Metadata panel > Copy Name. Set as Master: Photo > Set Copy as Master.
- Virtual copies take negligible space and can be in different collections.

## Before/after
- `\` toggles Before; `Y` side-by-side; Alt/Option+Y top/bottom; Shift+Y split.

## Verify
- [ ] Every exhibited or sold print has a dated snapshot or virtual copy that reproduces it.
