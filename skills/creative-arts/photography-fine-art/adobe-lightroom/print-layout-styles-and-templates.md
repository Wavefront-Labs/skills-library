# Print layout styles and templates

## Layout styles (Layout Style panel, top right)
- **Single Image / Contact Sheet**: a grid of equal cells; 1x1 for a single fine-art print, 4x5 for contact sheets.
- **Picture Package**: one photo in several sizes on a page.
- **Custom Package**: free placement of cells of any size across pages; for multi-image pages, diptychs and test strips.

## Single fine-art print setup
1. **Page Setup** (bottom left): printer, paper size, orientation, borderless if wanted.
2. **Layout** panel: Ruler units; Margins (left/right/top/bottom) define the white border; Page Grid 1x1; **Cell Size** to the exact image size (e.g. 30 x 40 cm) and tick "Keep Square" off. Lightroom centres the cell between margins.
3. **Image Settings**: Zoom to Fill (crops to fill cell) off for exact framing; Rotate to Fit; Stroke Border for a keyline.
4. **Guides**: show rulers, bleed, margins, image cells, dimensions.

## Test strips
Custom Package: drag the same photo into several small cells, apply different virtual copies (brightness +/-) to compare on one sheet.

## Templates
- Template Browser (left) `+`: saves layout, overlays and Print Job settings together. Name with paper and size: `PR 40x50 - 30x40 image - Canson Baryta`.
- **Saved Print** (Create Saved Print button) stores layout plus the specific photos as a special collection: reprint the exact edition later.

## Gotchas
- Printer driver margins limit the printable area; borderless needs driver support and paper sizes marked "borderless".
- Page Setup must match the driver's paper size or the layout scales.

## Verify
- [ ] Dimensions overlay shows the intended image size and borders; a plain-paper draft measures correctly with a ruler.
