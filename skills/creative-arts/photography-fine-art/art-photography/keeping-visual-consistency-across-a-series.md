# Keeping visual consistency across a series

## Capture
- Fix camera, lens and aspect ratio for the series; note settings.
- Shoot under a consistent light class (overcast, dusk, flash) and a chosen palette.
- Set a fixed white balance rather than auto.

## Processing
1. Build a series base preset (profile, tone curve, colour grade, grain) on a representative image.
2. Apply to all; adjust only exposure/white balance per image to *match* - use Reference View
   (Lightroom) to compare side by side.
3. Use Survey/Grid views at small size: outliers in brightness, saturation or contrast stand out.
4. Match blacks and whites: identical black point and highlight treatment make prints sit together.
5. Print a set of small work prints together on the same paper; consistency on paper matters most.

## Gotchas
- Different cameras in one series need profile matching (ColorChecker).
- Strong grades hide inconsistencies on screen but they reappear in print.

## Verify
- [ ] Grid of thumbnails looks like one body; work prints side by side match in density and colour.
