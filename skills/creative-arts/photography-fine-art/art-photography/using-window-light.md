# Using window light

A window is a large directional source with **fast falloff** into the room.

## Positioning
- Subject close to the window (0.5-1.5 m): soft and bright with strong falloff across the face.
- Subject at 45 deg to the window = Rembrandt/loop style; 90 deg = split-like drama;
  facing it = flat and luminous.
- Camera with back to the window = flat; camera beside the window looking across = modelling.
- North-facing windows (northern hemisphere) give constant indirect light; sun-facing windows
  need sheer curtains or diffusion fabric.

## Controls
- **White reflector** on the shadow side to lift it; **silver** for more punch; **black** to deepen.
- Pull curtains partly to shrink the window = harder, more directional light.
- Turn off room lights to avoid mixed colour.

## Exposure
Meter on the highlight side of the face; the room will go dark - that falloff is the look.
Expose so the window itself clips if in frame, or use flash to balance if it must hold detail.

## Gotchas
- Direct sun patches move fast; diffuse them or wait.
- Coloured curtains/walls tint the light.
