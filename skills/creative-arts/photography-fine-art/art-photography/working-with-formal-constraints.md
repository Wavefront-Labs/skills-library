# Working with formal constraints

Constraints make viewers notice differences between images instead of differences in technique.

## Common constraints
- One focal length, one aperture, one camera height.
- Same distance or same framing of a subject class (portrait at chest height, frontal).
- Same light (overcast only, flash only, dusk only).
- Same format and aspect ratio, colour or B&W.
- Time rules (one frame per day, one exposure per site, same time each day).

## Procedure
1. Write 3-5 rules for a trial period (e.g. 4 weeks).
2. Shoot only within them. Keep a "rule break" folder for images that call for exceptions.
3. Review: which rule made pictures stronger, which only restricted?
4. Revise and commit; publish the rules (in the statement) only if they are part of the meaning.

## Gotchas
- Constraints without a subject produce formal exercises; tie them to the question.
- Changing rules mid-series breaks visual consistency; reshoot early work if you change.

## Verify
- [ ] Rules written; a grid of the series shows coherent form with meaningful variation.
