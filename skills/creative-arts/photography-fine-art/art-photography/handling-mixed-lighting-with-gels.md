# Handling mixed lighting with gels

## Typical correction gels (Lee/Rosco)
| Gel | Use |
|---|---|
| Full CTO (Lee 204) | daylight/flash -> tungsten (~3200 K) |
| 1/2 CTO, 1/4 CTO | partial warming |
| Full CTB (Lee 201) | tungsten -> daylight (costs ~1.7 stops) |
| Plus Green (Window Green, 1/4-full) | flash -> fluorescent/office LEDs |
| Minus Green (magenta) | remove green from fluorescents/cheap LED |

## Procedure
1. Identify each source: daylight window, room tungsten, fluorescents, your flash.
2. Choose which source wins (usually the one you cannot change: the room).
3. Gel your lights (and if possible the windows with CTO/ND sheets) to match it.
4. Set WB to that source (custom from a grey card).
5. Shoot a test; check skin and neutral surfaces in each zone.

## Creative mismatch
Leaving daylight windows blue against warm tungsten interiors is a classic cinematic look; do
it consciously, keeping skin in the correctly balanced light.

## Gotchas
- Low-CRI LEDs and fluorescents have spiky spectra: gels cannot fix all; RGB pixels may look
  fine but skin goes muddy. Test with a ColorChecker.
- Cycling (flicker) of mains-powered lights causes colour/exposure banding at fast shutter speeds;
  use anti-flicker mode or shutter <= 1/100 (50 Hz) / 1/120 (60 Hz).

## Verify
- [ ] Neutrals neutral in the main subject zone; any mismatch elsewhere deliberate.
