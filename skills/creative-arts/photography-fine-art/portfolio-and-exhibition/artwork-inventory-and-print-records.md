# Artwork inventory and print records

## One record per physical object
Every print (each edition number, each AP, each size) is its own record, linked to the image (file) record.

## Fields
- **Inventory ID**: e.g. `JD-2025-TL-012-3/7` (artist-year-series-image-edition). Pencil it on the print verso and label it on the frame back.
- Title, year made, year printed, medium/process, paper, printer/lab, image and sheet size, frame size and type.
- Edition: number, total, size, APs; status (available, sold, gift, damaged-destroyed).
- **Location**: studio rack/box number, gallery on consignment (receipt number), exhibition, loan.
- Price history and current retail price.
- Sales: buyer, date, price, invoice number, commission paid.
- Exhibition and publication history; condition notes and condition report links.
- Images: reference photo of the print (verso and recto) and the master file name and Lightroom snapshot/virtual copy that produced it.

## Tools
- Artwork Archive, Artlogic, Arternal (paid art-inventory systems), a FileMaker/Airtable base, or a spreadsheet with strict ID rules.
- Back up the database with the image archive (3-2-1).

## Practice
- Update at every movement (out to framer, gallery, fair) the same day.
- Annual stock check: physically match every unsold print to its record.
- Destroyed or damaged prints: record destruction (keeps edition counts honest).

## Verify
- [ ] Annual stock check finds every print where the inventory says it is, and sold + available + destroyed numbers equal each edition's size.
