# Competitive UX audit

**Goal:** know how comparable products serve users, so you can match necessary conventions and differentiate where it matters.

## Steps
1. **Questions first:** what decision will this inform (which features to prioritise, where to differentiate)?
2. **Choose 4-8 competitors** in three groups: **direct** (same users, same job), **indirect** (different solution, same job: spreadsheets for a budgeting app), **analogous** (a different field with the same interaction challenge: booking in a clinic vs a restaurant).
3. **Define criteria** from user tasks, not feature lists: top tasks (sign up, find an item, check out), plus heuristics, content, accessibility, performance, pricing and onboarding.
4. **Evaluate consistently:** same tasks, device, account state and date. Score each criterion (for example 0-3 with written anchors) and capture screenshots and notes. Two reviewers on the key criteria reduce bias.
5. **Compare:** matrix of competitors by criteria; heat-colour the scores; mark parity, advantage and gap. Add a feature-by-product table only after tasks.
6. **Synthesise:** table stakes (all do it), differentiators (few do it well), whitespace (none do it), and anti-patterns to avoid.
7. **Link to action:** opportunities feed the UX strategy and roadmap (`creative-arts.design-for-form-and-experience.ux-design.building-a-ux-roadmap-with-impact-effort-prioritisation`).

## Gotchas
- Copying competitors copies their mistakes; validate with your users.
- Competitors change; date every capture.
- Features that exist are not features that work; test the tasks.

## Verify
- [ ] Competitors cover direct, indirect and analogous sets.
- [ ] Criteria and scoring anchors defined before evaluation.
- [ ] Output names table stakes, differentiators and gaps.
