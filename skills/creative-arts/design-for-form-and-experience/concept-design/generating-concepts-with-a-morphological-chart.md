# Morphological chart

**Goal:** move from a handful of obvious ideas to a structured space of concepts, then pick
a few combinations worth sketching.

## Steps
1. **List functions or features** the product must have, as verbs or sub-problems, not
   solutions: "hold the phone", "adjust angle", "store cable", "attach to desk". Keep 4-8 rows;
   more and the space explodes.
2. **For each row list means** (solutions): 3-6 options each. For "adjust angle": friction
   hinge, ratchet, ball joint, magnetic detent, fold-out leg. Sketch each as a small thumbnail
   in the cell, not just words; forms differ more than words suggest.
3. **Combine:** pick one cell per row to form a concept. Draw a coloured path through the chart
   per concept. Aim for 3 deliberately different paths: safe, balanced, wild.
4. **Prune** incompatible pairs early (a ball joint plus a slim fold-flat brief). Mark them
   with an X between rows.
5. **Sketch** each chosen path as a full concept thumbnail and name it.

## Size control
5 rows x 4 means = 1024 combinations. You never evaluate all; the chart's value is making you
see options per function. Use constraint rows first (the ones most bound by the brief).

## Gotchas
- Rows must be independent; if "material" changes every other row, make it a separate pass.
- Means must solve the same function; "make it pretty" is not a function.
- A combination of locally best cells is often not the best whole; evaluate whole concepts
  (see the Pugh matrix skill `creative-arts.design-for-form-and-experience.concept-design.selecting-concepts-with-a-pugh-matrix`).

## Verify
Each chosen concept can be traced as one path; each row has at least one cell you had not
thought of before starting.
