# Interior finish fire performance

Check the adopted code edition and the AHJ; this is a specification workflow.

## Classes (ASTM E84 / UL 723 tunnel test)
- **Class A (I):** flame spread index 0-25, smoke-developed index 450 or less.
- **Class B (II):** 26-75, smoke 450 or less.
- **Class C (III):** 76-200, smoke 450 or less.
Smoke-developed index over 450 fails any class. Materials are tested in their end-use mounting (adhered, mechanically fastened).

## IBC limits (Table 803.13 summary)
By occupancy group, location (**exit enclosures and exit passageways**, **corridors**, **rooms and enclosed spaces**) and sprinkler status. Typical: assembly (A) exit enclosures **Class A** (sprinklered: Class B), corridors Class A or B, rooms Class B or C; education (E) similar; business (B) and mercantile (M) exit enclosures Class A/B, corridors B/C, rooms C; institutional (I-2) strict. Sprinklers relax by one class in many cases (Table notes). Confirm in the current code.

## Other tests and materials
- **Floor coverings:** critical radiant flux (ASTM E648 / NFPA 253): **Class I at least 0.45 W/cm2**, Class II 0.22-0.44 W/cm2; required in corridors and exits of many occupancies.
- **Textiles and drapery:** NFPA 701 (Test 1 or 2) for curtains, hangings, and wallcoverings; California Technical Bulletin 117-2013 for upholstered furniture smoulder resistance; TB 133 for seating in public occupancies; wall coverings tested as Class A/B/C (and room corner test NFPA 286 allowed for installation like textile wallcoverings).
- **Foam plastics and trim:** limits on combustible trim (10 percent of wall area for Class C) and decorative materials (**decorative materials and trim must be flame-resistant**, trees and foliage non-combustible in some occupancies).
- **Fire-retardant treated wood** for millwork where required.
- **Exhibit and event materials:** temporary structures and booths are subject to fire marshal rules (flame retardant fabrics with certificates, no open flames, minimum aisle widths).

## Process
1. Establish occupancy and sprinkler status in the code analysis (`creative-arts.design-for-form-and-experience.experiential-design.doing-a-code-analysis`).
2. Map required class per room type on the finish plan.
3. Require **test reports or product data** in submittals; spec the standard and class explicitly (`creative-arts.design-for-form-and-experience.experiential-design.writing-specifications-with-csi-masterformat` Part 2).
4. Keep flame-retardant treatment certificates and have the fire marshal review as needed.

## Verify
- [ ] Required class per space matches occupancy, location and sprinkler status.
- [ ] Specs name the test standards and classes; submittals require reports.
- [ ] Textiles, flooring and furniture meet their specific tests.
