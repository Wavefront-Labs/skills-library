# Memorising repertoire

**Goal:** a memorised performance that survives nerves and slips.

## 1. Four kinds of memory (use all)
| Type | How to build it |
|---|---|
| **Motor (kinesthetic)** | comes from repetition; fast but fragile under stress |
| **Aural** | sing the melody and bass; hear what comes next |
| **Visual** | picture the page and the keyboard shapes |
| **Analytical** | know the form, keys, harmonic progression, sequences, where sections differ |
- Motor memory alone is the main cause of slips; analytical memory is the safety net.

## 2. Method
1. **Analyse** the score: sections, phrases, harmony (write Roman numerals or chord names), repeats and their differences (e.g. exposition vs recapitulation endings).
2. Memorise in small sections (phrase by phrase), hands separately then together.
3. **Starting points** (performance cues): mark every 4-8 bars; practise starting from any of them, in random order.
4. Test away from the instrument: write out a passage, or play it in your head with the score closed; play on a tabletop.
5. Play slowly from memory (slow playing exposes motor-only knowledge).

## 3. Before performance
- Perform for others repeatedly; record runs; play when cold (first thing in a day).
- Practise recovering: deliberately stop and jump to the next starting point.

## 4. When a slip happens
- Keep the pulse; jump to the next starting point you know; improvise a cadence in the key if needed. Audiences rarely notice a quick recovery.

## Gotchas
- Memorising only by playing through from the start: you can't restart mid-piece.
- Similar passages confused (recapitulation changes): label and practise the differences explicitly.

## Verify
- Start from any marked point on request without hesitation.
- Write out the harmonic outline of each section from memory.
