# Leitmotif and thematic scoring

**Goal:** a small set of themes that the audience learns, so changes to them tell the
story without dialogue.

## 1. Decide what gets a theme
- One theme per main character, relationship, place or idea - usually 2 to 5 in total.
  More than that and the audience cannot track them.
- Each theme needs one **identifying cell** (2-5 notes, a distinctive interval or
  rhythm) that survives fragmentation. Think of the two-note shark motif or a rising
  fifth for heroism.

## 2. Write themes that can transform
- Keep the core cell harmonically flexible: it should work over major, minor and
  modal harmonies.
- Test each theme in at least four guises before committing: heroic (brass, major,
  slow), tender (solo woodwind, thin texture), threatened (minor, low, fragmented),
  triumphant (full orchestra, augmented).

## 3. Transformation toolkit
- **Mode change** (major to minor or Dorian), **reharmonisation** under the same melody.
- **Augmentation / diminution** - slower for grandeur, faster for urgency.
- **Fragmentation** - only the head cell, as a hint that a character is near.
- **Orchestration change** - same notes, new colour.
- **Combination** - two themes in counterpoint when their characters meet.

## 4. Plan the arc
Map each theme across the cue list: where it is introduced, where it is withheld, and
where it lands in full. The full statement is usually saved for the climax or the end
credits.

## Gotchas
- Introducing a theme before the audience knows what it represents wastes it; pair the
  first statement with a clear on-screen reference.
- Over-quoting: full statements every scene flatten the payoff.
- Themes too similar in contour get confused; contrast interval and rhythm.

## Verify
- [ ] Each theme has a distinct head cell and is tied to one clear referent.
- [ ] The cue list shows where each theme appears and in what guise.
- [ ] The climactic full statement is not used earlier in the same form.
