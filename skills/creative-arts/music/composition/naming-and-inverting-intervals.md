# Naming and inverting intervals

**Goal:** name intervals correctly (number + quality) from notation, including the awkward ones.

## 1. Number first (letter names only)
Count letter names inclusive from bottom to top: C up to G = C D E F G = **5th**, whatever
the accidentals. C# to Gb is still a 5th.

## 2. Quality using the major scale of the bottom note
- Imagine the major scale on the **lower note**. If the top note is in it: 2, 3, 6, 7 are **major**; 1, 4, 5, 8 are **perfect**.
- One semitone smaller than major = minor; smaller than minor = diminished. One semitone larger than major or perfect = augmented. Perfect minus a semitone = diminished.
- If the bottom note has an awkward scale (e.g. D-sharp), remove the accidental from both notes, name the interval, then add the accidentals back and adjust.

Semitone counts: m2 1, M2 2, m3 3, M3 4, P4 5, A4/d5 6, P5 7, m6 8, M6 9, m7 10, M7 11, P8 12.

## 3. Compound intervals
Larger than an octave: subtract 7 to get the simple interval (a 10th = octave + 3rd). Name as
"major 10th" or "compound major 3rd". Jazz uses 9, 11, 13 as tensions.

## 4. Inversion
- Numbers add to **9**: a 3rd inverts to a 6th, a 2nd to a 7th, a 4th to a 5th.
- Quality flips: major <-> minor, augmented <-> diminished, perfect stays perfect.
- Example: M3 C-E inverts to m6 E-C.

## Gotchas
- Enharmonic intervals sound the same but are spelled differently: C-F# is an augmented 4th, C-Gb a diminished 5th. Spelling depends on letter count, never on sound.
- Unisons: C to C# is an augmented unison, not a minor 2nd.
- Intervals are measured from the lower note even if it is written second.

## Verify
- Count semitones as a check against your quality label.
- Inversion check: semitones of an interval and its inversion add to 12.
