# Theme and variations

**Goal:** build a satisfying set of variations from one theme.

## 1. Pick a theme
- Short (8-32 bars), clear phrase structure (often rounded binary), simple harmony, a memorable melody **or** bass line.
- Write down what stays constant: usually the **phrase structure and harmonic skeleton**; sometimes only the bass (ground) or only the melody.

## 2. Variation types
| Type | Method |
|---|---|
| Ornamental / melodic | decorate the melody with passing notes, turns, runs |
| **Figural** | constant new figuration (triplets, semiquaver arpeggios, Alberti) across the whole variation |
| Rhythmic | change metre or rhythm (duple to compound, dotted rhythms) |
| Harmonic | reharmonise the melody (secondary dominants, chromatic bass) |
| **Minore / maggiore** | switch mode (the standard mid-set contrast) |
| Contrapuntal | canon or fugato on the theme |
| **Character** | new genre/style (march, waltz, chorale, siciliano) - Romantic sets (Brahms, Rachmaninoff) |
| Textural / orchestral | same notes, new instrument or register |

## 3. Ground bass, chaconne, passacaglia
- A repeating bass line (ostinato) of 4-8 bars with continuous upper-part variation (Purcell "Dido's Lament", Pachelbel). Chaconne/passacaglia: slow triple metre, often a descending tetrachord.
- Keep the bass audible; vary the upper texture progressively in density.

## 4. Pacing the set
1. Theme.
2. Increase rhythmic activity across the first few variations (quavers -> triplets -> semiquavers).
3. A slow and/or minore variation near the 2/3 point for contrast.
4. A brilliant or contrapuntal climax, then a final variation or coda that recalls the theme.

## Gotchas
- Too many variations with the same density in a row lose momentum; alternate.
- Changing both harmony and melody at once loses the thread (unless it's a Romantic character variation with the theme's rhythm kept).

## Verify
- For every variation, state in one line what's kept and what's changed.
- Play the theme's bass line under each variation: the harmonic skeleton should fit (unless deliberately reharmonised).
