# Italian terms, dynamics and articulation signs

**Goal:** write directions that every player reads the same way, and interpret printed
directions accurately.

## 1. Tempo terms (slow to fast, approximate bpm)
Grave (~40), Largo (~45-50), Lento (~50-55), Adagio (~55-70), Andante (~75-100, "walking"),
Moderato (~95-110), Allegretto (~100-120), Allegro (~120-155), Vivace (~155-175), Presto
(~170-200), Prestissimo (200+). Always add a metronome mark; terms are moods as well as speeds.
- Modifiers: molto (very), poco (a little), poco a poco (little by little), meno (less), piu (more), assai (very), ma non troppo (but not too much).
- Changes: rit./rall. (slow down), accel. (speed up), a tempo, tempo primo, rubato, allargando (broaden, often louder), stringendo, meno mosso, piu mosso, l'istesso tempo.

## 2. Dynamics
- ppp pp p mp mf f ff fff; sfz/sf (sudden accent), fp (loud then immediately soft), subito p.
- Hairpins and cresc./dim. **end on a target dynamic**; a hairpin with no target is ambiguous.
- Write dynamics below the staff for instruments, above for voices (so they don't clash with lyrics).

## 3. Articulation signs
| Sign | Meaning | Note |
|---|---|---|
| Dot | Staccato: shortened, detached | Roughly half value; context-dependent |
| Wedge/teardrop | Staccatissimo / very short (Classical: often just accented staccato) | |
| Line | Tenuto: full value, slight weight | |
| Line + dot | Mezzo-staccato / portato | Strings: on one bow, separated |
| > | Accent | |
| ^ | Marcato: strong, often short (jazz: "hat", short and hard) | |
| Slur | Legato; for strings = one bow, winds = tongued once | Phrase marks are longer slurs |

## 4. Instrument-specific readings
- Strings: a slur is a **bowing**; separate musical phrasing from bowing with a dashed slur or text.
- Winds/brass: slur = no tongue; long phrases need breath marks (comma).
- Jazz horn articulations: "doit", "fall", "shake", ghosted notes in parentheses.
- Piano: pedal marks override short articulation in practice; mark "senza ped." if needed.

## Gotchas
- "sfz" is relative to the current dynamic; in p it is a strong accent, not fortissimo.
- Mixing English and Italian in one score looks amateur; pick one (film session parts commonly use English).

## Verify
- Every hairpin has a destination; every tempo change has a return or a new mark.
- Play through with a player or notation playback: articulations audible as intended.
