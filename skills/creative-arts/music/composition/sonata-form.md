# Sonata form

**Goal:** find the landmarks in a sonata movement and write one with a working key plan.

## 1. The plan (major key; minor key in brackets)
| Section | Content | Key |
|---|---|---|
| (Slow introduction) | optional | tonic or ambiguous |
| **Exposition** | First subject (P) | tonic |
| | Transition (TR): modulates, gains energy, ends on V of new key with a **medial caesura** (break) | moving |
| | Second subject group (S) | **dominant** (minor: **relative major**) |
| | Closing section (C), codettas; **essential expositional closure** = first PAC in new key | new key |
| (Repeat) | | |
| **Development** | fragments of P/S/TR sequenced through keys, often minor/flat side; ends on **dominant pedal** (retransition) | unstable |
| **Recapitulation** | P in tonic; TR **rewritten** so it doesn't modulate; S and C transposed to **tonic** | tonic |
| Coda | confirms tonic; may revisit development material | tonic |

## 2. Composing steps
1. Write P as a sentence or period (see phrases skill); write S with a contrasting character (lyrical vs energetic is a convention, not a rule).
2. Write TR from P material: sequence, then a half cadence in the new key (V of V) and a rest - the medial caesura.
3. Development: pick 1-2 motifs, sequence by 2nds or 5ths through 3-4 keys, end on V pedal, build expectation.
4. Recap: adjust TR (often by moving the modulation pivot or shortening) so S arrives in tonic. Check S's range after transposition.

## 3. Variants
- Monothematic exposition (Haydn): S begins with P material in the new key.
- Three-key exposition (Schubert); minor-key sonata with recap of S in the tonic minor.
- Sonatina: no development (or a few bars).

## Gotchas
- Labelling the first new theme as S before the medial caesura: it may be part of TR.
- Forgetting to recompose TR: the recap then ends in the dominant.

## Verify
- Form chart with bar numbers, keys and cadences (half cadence before S, PAC at the end of S and at the end of the recap).
- Recap: every S-group bar is in the tonic.
