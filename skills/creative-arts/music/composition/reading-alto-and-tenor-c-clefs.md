# Reading alto and tenor C clefs

**Goal:** read and write C-clef parts fluently and choose clefs that minimise ledger lines.

## 1. Where middle C is
- The C clef's centre points to **middle C (C4)**.
- **Alto clef**: C4 on the **middle (3rd) line**. Lines bottom to top: F3 A3 C4 E4 G4.
- **Tenor clef**: C4 on the **4th line** (second from top). Lines: D3 F3 A3 C4 E4.

## 2. Fast reading by landmarks
- Don't translate via treble or bass ("up one, down two"): it is slow and error-prone.
- Learn 3 landmarks per clef and read intervals from them:
  - Alto: C4 middle line, G4 top line, F3 bottom line.
  - Tenor: C4 4th line, A3 middle line, D3 bottom line.
- Read by interval and contour from the landmark (step/skip/leap), the same way sight-readers read treble.
- Drill: read a viola part (alto) and a cello/bassoon tenor passage daily for two weeks.

## 3. Who uses which clef
| Clef | Instruments |
|---|---|
| Alto | Viola (primary), alto trombone, some old vocal parts |
| Tenor | Cello, bassoon, tenor trombone, double bass (upper register), euphonium in some editions |
| Treble | Viola and cello very high passages (cello treble is at sounding pitch in modern editions) |

## 4. Writing parts
- Change clef when a passage would need more than **2-3 ledger lines** for more than a few notes; don't change for a single note.
- Put the clef change **before the barline** if it applies from the next bar, or immediately before the note mid-bar (small clef).
- Cello: bass clef, then tenor for the upper middle register, then treble; avoid going bass to treble directly unless the jump is large.
- Old editions sometimes write cello treble clef an octave higher than sounding; modern practice is at pitch. Check the edition before transcribing.

## Gotchas
- Confusing alto and tenor: tenor's C is one line higher, so everything reads a 3rd lower (alto line = C, same line in tenor = A).
- Notation software: set the clef on the instrument, not by transposing the staff, or playback and part extraction break.

## Verify
- Transcribe 8 bars from tenor to bass clef and check by playback.
- Time yourself naming 20 random C-clef notes; aim for under 1 second each.
