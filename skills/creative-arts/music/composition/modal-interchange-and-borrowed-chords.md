# Modal interchange and borrowed chords

**Goal:** colour a major-key progression with chords from the parallel minor (and other
parallel modes) without changing key.

## 1. The most-used borrowed chords in C major
| Chord | From | Notes | Effect / use |
|---|---|---|---|
| iv (Fm) | Aeolian | F-Ab-C | Wistful; IV-iv-I ("Creep", Beatles) |
| bVI (Ab) | Aeolian | Ab-C-Eb | Epic, cinematic; bVI-bVII-I |
| bVII (Bb) | Mixolydian/Aeolian | Bb-D-F | Rock cadence bVII-I |
| bIII (Eb) | Aeolian | Eb-G-Bb | Bold, rock |
| ii half-dim (Dm7b5) | Aeolian | D-F-Ab-C | Darker pre-dominant |
| bVII7 (Bb7) | | | **Backdoor** dominant: bVII7-I instead of V7-I |
| bII (Db) | Phrygian | | Neapolitan-like colour |
| I (in minor) | Ionian | | **Picardy third**: ending a minor piece on a major tonic |

## 2. Voice leading
- The borrowed note usually moves by **semitone**: in IV-iv-I the A goes to Ab then G. Keep that line in one voice; it is the sound of the device.
- Borrowed chords typically precede the tonic or dominant (pre-dominant role).

## 3. Labelling
Roman numeral with accidental relative to the major key (bVI, bVII, iv); jazz/Berklee calls
them "subV"-style or "modal interchange chords" (MI) and assigns a chord scale from the
source mode (Ab maj7 = Lydian; Bb7 = Mixolydian).

## 4. Using it well
- One borrowed chord per phrase is usually enough; whole progressions of borrowed chords become a modulation to the parallel minor.
- In melody, the borrowed note (Ab, Eb, Bb) must agree with the chord: don't sing A natural over Fm.
- In pop, bVI-bVII-I is a stock climax; use the iv in a pre-chorus for emotional lift into a major chorus.

## Gotchas
- Mislabelling bVII as V/bIII; it functions as a borrowed dominant substitute, not a secondary dominant.
- Clashing melody notes on reused toplines: re-check the melody when you swap IV for iv.

## Verify
- Every borrowed chord's source mode is identifiable; the key centre stays the original tonic.
- A/B listen: diatonic version vs borrowed version; the borrowed chord should change colour, not the key.
