# Realising figured bass

**Goal:** turn a bass line with figures into correct harmony, on paper or at the keyboard.

## 1. Reading the figures (intervals above the bass, in the key)
| Figure | Chord | Full figuring |
|---|---|---|
| none | root-position triad | 5/3 |
| 6 | first inversion triad | 6/3 |
| 6/4 | second inversion triad | 6/4 |
| 7 | root-position 7th chord | 7/5/3 |
| 6/5 | first inversion 7th | 6/5/3 |
| 4/3 | second inversion 7th | 6/4/3 |
| 4/2 or 2 | third inversion 7th | 6/4/2 |
| 4-3 | suspension: 4th above resolving to 3rd | |
| 9-8, 7-6 | suspensions resolving | |
- **Accidentals**: a sharp/flat/natural alone means the **3rd** above the bass is altered; next to a number it alters that interval; a slash through a number (6 with a stroke) means raised.

## 2. Written realisation (exam style)
1. Identify each chord from bass + figures; write chord symbols/Roman numerals above.
2. Add soprano line first for a good melody (stepwise, with a clear high point), then alto and tenor.
3. Apply SATB rules: no parallel 5ths/8ves, resolve leading notes and 7ths, prepare and resolve suspensions (prepared in the previous chord, held, resolved down by step).

## 3. Keyboard realisation (continuo)
- Left hand plays the bass; right hand plays 3-voice chords in close position, mid-register, moving smoothly (common tones held, nearest chord tones).
- Simple and supportive: don't double the soloist's melody high above; thicken at cadences; lighter textures for soft passages.
- Ornament at cadences (cadential trill in the right hand when the soloist isn't trilling).

## Gotchas
- Forgetting that unfigured bass notes are root position (5/3) - except passing notes, which take no new chord.
- Applying a "#" to the bass note itself instead of to the 3rd above.
- Suspensions not prepared (the suspended note must appear in the previous chord in the same voice).

## Verify
- Chord check: every chord contains exactly the intervals indicated above the bass.
- Play it with the bass: smooth upper voices, correct resolutions.
