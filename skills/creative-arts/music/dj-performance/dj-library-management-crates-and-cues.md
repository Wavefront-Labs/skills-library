# DJ library management: crates, tags and cues

**Goal:** find the right track in seconds, with every track already prepared to mix.

## 1. Import and tag
- Buy/download high-quality files (WAV/AIFF or 320 kbps MP3); avoid low-bitrate rips.
- Fix metadata (artist, title, mix name, label, year) before importing; consistent naming survives across software.
- Analyse BPM and key; set key notation to Camelot or musical key consistently.
- Tag by **role and energy**: rekordbox **My Tag** / Serato comments/colours / Traktor tags (e.g. Energy 1-5, Warm-up/Peak/After-hours, Vocal/Instrumental, Intro length).

## 2. Beat grids
- Check every new track: first downbeat on beat 1, grid aligned throughout (adjust BPM/grid shift; for live-drummed tracks use dynamic analysis or manual grid markers).
- Bad grids break sync, quantised loops and hot cues.

## 3. Cue conventions (same on every track)
| Cue | Position |
|---|---|
| Memory cue / hot cue A | first downbeat (mix-in point) |
| B | first breakdown or vocal entry |
| C | drop / chorus |
| D | mix-out point / outro start |
- Colour-code by type (e.g. green = mix-in, red = drop). Loops saved for intros/outros.

## 4. Crates and playlists
- Crates by **genre/sub-genre**, plus **set-role crates** (openers, peak, closers, tools, acapellas).
- **Smart crates/intelligent playlists** by BPM range, key, rating, date added (e.g. "new this month, 122-126 bpm").
- Pre-gig playlist: 2-3x more tracks than you'll play, in rough energy order.

## 5. Backups and sync
- Back up the library folder and the database (rekordbox: File > Library > Backup Library; Serato: _Serato_ folder) regularly; keep music on a drive with a consistent path.

## Gotchas
- Moving files outside the software breaks track paths (missing files).
- Duplicates with different cues; use duplicate-finder tools.

## Verify
- Any track in the gig playlist has a correct grid, standard cues and role tags.
- Restore the backup on another computer: library and cues intact.
