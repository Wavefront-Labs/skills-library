# Stems and performance FX in DJ software

**Goal:** remix live with stems and effects, without making a mess.

## 1. Stems
- **Serato Stems**, **rekordbox Track Separation**, Traktor Stems / Engine DJ stems, VirtualDJ stems: real-time separation into vocals, melody/instrumental, bass, drums.
- Pre-analyse stems where possible (better quality and lower CPU than on-the-fly separation).
- Uses:
  - **Acapella over instrumental**: vocals of track A over track B (key-compatible).
  - **Drum swap**: keep A's melody, B's drums.
  - Clean transitions: drop the outgoing vocal before the incoming vocal starts.
- Mixer/pad controls: stem mute buttons, stem FX (Serato Stem FX like echo on vocals only).

## 2. Beat FX (tempo-synced)
| FX | Use |
|---|---|
| Echo/Delay | echo outs, vocal throws |
| Reverb | wash out on breakdowns |
| Roll / loop roll | builds |
| Flanger/Phaser | transitions, ear candy (sparingly) |
| Trans/Gate | rhythmic chops |
- Set beat length (1/4 to 4 beats) and wet level; apply to a channel or master.

## 3. Colour FX (one-knob)
- Filter (most used), Space (reverb), Dub Echo, Noise, Crush, Pitch. Turn left/right for different flavours.

## 4. Restraint
- Effects should support the music; the dance floor reacts to tracks, not to effects.
- Use stems/FX at phrase boundaries; return everything to neutral after use.

## Gotchas
- Separation artefacts (watery vocals, smeared hats) on dense tracks; use pre-analysed stems and check before playing.
- CPU load from real-time separation on older laptops; drops and glitches.
- Forgetting an effect on (filter left half-on) leaves the mix thin.

## Verify
- Rehearse each mashup: key and phrasing match, no artefacts at club volume.
- After every FX use, all knobs back at neutral.
