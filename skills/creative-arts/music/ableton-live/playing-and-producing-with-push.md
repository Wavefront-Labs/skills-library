# Playing and producing with Push

**Goal:** write and perform in Live from the Push hardware without looking at the screen.

## 1. Modes
- **Note mode**: play instruments on the pad grid. **Scale** button: choose root and scale; **In Key** (only scale notes) or **Chromatic** (scale notes highlighted); layout 4ths (default) or 3rds/sequential. Octave up/down buttons.
- **Session mode**: the pads become clip slots; launch clips and scenes; hold Session for the overview.
- **Drum Rack** tracks show the 16-pad drum layout + step sequencer (pads at the top), or 64-pad mode for finger drumming.
- **Device mode**: the 8 encoders control the selected device's parameters (rack macros first); Mix mode for volume/pan/sends.

## 2. Sequencing
- **Drums**: select a pad, then tap steps in the upper pads; hold a step and turn encoders for velocity, nudge, length. Set the step grid with the Note Repeat/scene buttons (1/4 to 1/32 including triplets).
- **Melodic step sequencer**: Layout button cycles to the 32-note / melodic sequencer view (steps and pitches on the grid).
- **Note Repeat** for rolls; velocity via pad pressure; fixed velocity option.
- Record with the Record button; **Capture** for what you just played; Duplicate, Double Loop, Quantize buttons.

## 3. Push 3 specifics
- **MPE** pads (per-pad pitch, slide and pressure) - set MPE on in Push settings and use MPE-capable instruments.
- **Standalone** Push 3 runs Live sets on the device (limited CPU, no third-party plugins except supported ones); transfer sets between Push and computer.
- Built-in audio interface (inputs, outputs, phones) for standalone use.

## Gotchas
- Scale set on Push vs clip scale in Live 12: keep them linked so playback and pads agree.
- Push controls the selected track; ensure the right track is selected before recording.
- Standalone: CPU-heavy devices or plugins won't run.

## Verify
- Record an 8-bar loop entirely from Push: drums via step sequencer, bass in Note mode in key, launch as a scene.
