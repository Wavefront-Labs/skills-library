# Restringing and string gauges

**Goal:** fresh strings that stay in tune within minutes, in a gauge that suits the player.

## 1. General method (steel-string)
1. Remove strings one at a time (keeps neck tension on trem guitars and bridges in place) or all at once if cleaning the fretboard (oil rosewood/ebony with a little lemon or fretboard oil; never oil maple-gloss).
2. Thread through the bridge (or put the ball end on the acoustic bridge pin, pushing the pin in while pulling the string up so the ball seats against the bridge plate).
3. **Measure slack**: pull the string taut past the tuner by about 2 posts' distance (~5 cm), bend, cut. Aim for **2-3 wraps** on plain strings and 1.5-2 on wound strings.
4. Wind so the string goes **down** the post (wraps below the hole) for a good break angle; wind treble strings clockwise on 3-a-side headstocks, standard direction so strings go to the inside of the post.
5. Tune to pitch, then **stretch**: pull each string gently up from the fretboard along its length, retune; repeat 3 times.

## 2. Specific types
- **Locking tuners**: pull taut, lock, minimal wraps (half to one).
- **Floyd Rose**: cut ball ends, clamp at the saddle, back off fine tuners to mid-position first, tune in passes (tuning one string changes the others), then lock the nut and use fine tuners.
- **Classical (nylon)**: tie at the bridge (loop and 2-3 tucks), several wraps at the roller; nylon stretches for days - retune often.
- **Bass**: cut long enough that the tapered part (not the full-diameter winding) wraps the post; don't cut inside the winding or it unravels.

## 3. Gauge and material
| Instrument | Common gauges | Notes |
|---|---|---|
| Electric | 9-42 (light), **10-46** (standard), 11-49+ (heavier/drop tunings) | heavier = more tone and stability, harder bends |
| Acoustic | 12-53 (light), 13-56 (medium) | phosphor bronze warm, 80/20 bronze bright |
| Bass | 45-105 standard | roundwound bright, flatwound thumpy |
| Classical | normal or hard tension | carbon trebles brighter |
- Changing gauge changes neck relief and intonation; check setup afterwards.

## Gotchas
- Too many wraps cause slipping and tuning drift.
- Not seating acoustic ball ends: string rides up the pin and won't hold pitch.
- Cutting bass strings too short: unravelled winding, dead string.

## Verify
- After stretching, play hard for a minute; strings should stay within a few cents.
- Check intonation at the 12th fret if gauge changed.
