# Writing for orchestral percussion and harp

**Goal:** percussion and harp parts the players can actually execute in the time given.

## 1. Timpani
- Usually 4 drums (roughly 32", 29", 26", 23"); each covers about a 5th. Combined range
  about D2-A3 (practical).
- Pedal tuning changes need time; mark new tunings ("Change E to F") and leave a few
  bars of rest for retuning.
- Write rolls with tremolo slashes; mark sticks (soft, hard, wooden) when it matters.

## 2. Mallet percussion (sounding ranges vary by instrument model)
- **Glockenspiel:** sounds two octaves above written; bright, short.
- **Xylophone:** sounds an octave above written; dry and short.
- **Marimba:** written at pitch (often 4.3 or 5 octaves); warm; rolls sustain.
- **Vibraphone:** at pitch, F3-F6; motor and pedal - mark pedalling.
- **Tubular bells:** about C4-F5.

## 3. Percussion section layout
- Count players: list which instruments each player covers and leave time to move
  between them. Supply a **percussion assignment chart**.
- Use a consistent notation key for unpitched instruments.

## 4. Harp
- Seven pedals, one per note name, each flat/natural/sharp. Every note of that name in
  every octave changes together.
- Write the **pedal diagram** at the start (D C B | E F G A) and pedal changes in the
  part with time to change (one pedal per foot at a time).
- Chords up to four notes per hand (no little finger), span about a 10th.
- Glissandi are written by giving the pedal setting; enharmonic tricks allow
  chords like a diminished 7th glissando.
- Harmonics sound an octave above written.

## Gotchas
- Chromatic passages are very hard on harp; give them to a keyboard or celesta.
- Timpani tuning changes without rest time are unplayable.
- Too many percussion instruments for the number of players.

## Verify
- [ ] Harp part has a starting pedal setting and playable pedal changes.
- [ ] Timpani retunings have enough rest time.
- [ ] Percussion assignment chart matches the number of players.
