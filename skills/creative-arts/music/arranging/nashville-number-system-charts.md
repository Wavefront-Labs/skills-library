# Nashville number system charts

**Goal:** a one-page chart any session player can read and that works in any key.

## 1. Numbers instead of letters
- Chords are scale degrees of the key: in G, G = 1, C = 4, D = 5, Em = 6- (or 6m).
- Minor: "-" or "m" (6-). Seventh: 57. Major 7: 1maj7 or 1Δ7. Sus: 5sus. Diminished: 7° .
- **Inversions/slash bass**: 1/3 (G/B in G). Non-diatonic: b7 (F in G), b3, #4°.
- Key written at the top ("Key: G"); the band can play it in A by changing one word.

## 2. Rhythm and bars
- Each number = **one bar** in the song's metre unless shown otherwise.
- **Split bar**: numbers underlined or boxed together share a bar equally (e.g. "1 4" underlined = 2 beats each in 4/4).
- Uneven splits: add dots or slashes over numbers to show beats.
- **Diamond** around a number: hit and let ring (whole note). **Push** (^ or < before a number): chord anticipates the beat (usually an eighth early). **Stop/choke**: a staccato mark or "stop".
- Time-signature changes noted inline (2/4 bar).

## 3. Layout
- Sections labelled (Intro, V1, Ch, Br, Solo) with bar counts in rows of 4 bars per line.
- Repeat signs and "x2"; road map at the top for complex forms; dynamics and feel notes ("half-time", "build", "drums out").
- Hits written above or beneath the numbers.

## 4. Working in the room
- Chart the demo with the band in a few minutes; correct on the fly; producers call changes by number ("go to the 4 on the turnaround").
- Modulations: write the new key ("Key: A") at the change and restart numbering, or use degrees relative to the original with accidentals for brief tonicisation.

## Gotchas
- Minor-key songs: most Nashville players still number from the relative major (6- as home); state the convention if you number from the minor tonic.
- Ambiguous splits: always underline or box shared bars.

## Verify
- A player reads the chart in a different key with no errors on first pass.
- Bar count on the chart matches the demo.
