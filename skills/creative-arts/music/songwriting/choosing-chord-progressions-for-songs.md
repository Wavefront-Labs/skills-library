# Choosing chord progressions for songs

**Goal:** a progression that supports the melody and the mood of each section, and
changes enough between sections to create lift.

## 1. Work in Roman numerals
Write progressions as numerals so you can move them to the singer's key.

## 2. The four-chord loop and rotations (major key)
- `I-V-vi-IV` - bright, anthemic.
- `vi-IV-I-V` - same chords starting on vi, more wistful.
- `I-vi-IV-V` - 50s/doo-wop.
- `IV-I-V-vi` - starts off-tonic, feels unresolved; good for pre-choruses.
The starting chord changes the feel more than the chord set does.

## 3. Substitutions
- Swap chords that share two notes: `I` and `vi` or `iii`; `IV` and `ii`; `V` and `vii°`.
- Borrowed from parallel minor: `iv`, `bVI`, `bVII` (for example `I-bVII-IV-I`, rock).
- Secondary dominant (`V/vi` = III major) before vi adds pull.

## 4. Section planning
- Verse and chorus should differ: start the chorus on a different chord, change
  harmonic rhythm (one chord per bar in the verse, two per bar in the pre), or move
  the chorus to IV.
- **Harmonic rhythm** speeding up builds tension; a long held chord releases it.
- A pedal bass under changing chords is a strong pre-chorus device.

## 5. Melody first or chords first
If melody is written first, pick chords that contain the melody's long notes. If chords
first, avoid writing the melody only on chord roots.

## Gotchas
- Same loop in every section flattens the song; change the start chord or rhythm.
- Ending the chorus on I closes it completely; ending on V or IV pulls back to the verse.
- Check the melody against borrowed chords for clashes (major 3rd vs minor iv).

## Verify
- [ ] Progressions are written in numerals and work in the singer's key.
- [ ] Chorus harmony differs from verse in start chord or harmonic rhythm.
- [ ] Long melody notes are chord tones or deliberate tensions.
