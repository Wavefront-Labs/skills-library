# Mix revisions, recall and client notes

**Goal:** get from first mix to approved mix efficiently, with every version recallable.

## 1. Recall-proof sessions
- Save a new session version per mix print (Song_Mix_v03). Commit/print outboard and hardware inserts to audio or note settings with photos.
- Freeze or print virtual instruments if plugin versions might change.
- Keep a mix log: date, version, changes made, who requested them.

## 2. Getting good notes
- Ask for **timestamped** notes ("1:32 vocal too quiet on 'tonight'") via a review tool (Filepass, Samply, Frame.io, Dropbox comments).
- Ask the client to listen on a system they know and to compare against your agreed reference.
- Translate vague notes:
  | Client says | Usually means |
  |---|---|
  | "Needs more energy" | louder drums/upper mids, more compression, brighter, or bigger chorus contrast |
  | "Muddy" | 200-500 Hz build-up, too much reverb |
  | "Vocal doesn't sit" | level, de-essing or reverb balance |
  | "Make it pop" | presence, transient punch, louder overall |
- Make the change you think is right and also offer an alternative if unsure.

## 3. Revision policy
- Agree up front: number of included revision rounds (e.g. 2-3), what counts as a new mix vs a revision, fee for extra rounds.
- Batch notes: one consolidated list per round from one decision maker.

## 4. Deliverables (typical)
- Main mix (24-bit WAV, project sample rate), **instrumental**, **a cappella**, **TV mix** (no lead vocal, BVs kept), clean/radio edit if needed, **stems** (drums, bass, music, vocals, FX - each printed with master-bus processing bypassed or as agreed, all starting at bar 1/zero).
- Leave mix-bus limiting off the file sent to mastering (or send both), peaks around -3 to -6 dBFS.

## Gotchas
- Overwriting old versions: clients often come back to v2.
- Acting on notes from multiple band members separately: conflicting changes.

## Verify
- Any past version can be reopened and printed identically.
- Delivered files named consistently: Artist_Song_Mix_v05_Instrumental_48k24b.wav, all same length.
