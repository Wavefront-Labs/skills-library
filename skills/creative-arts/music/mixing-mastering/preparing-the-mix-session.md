# Preparing the mix session

**Goal:** a clean, organised session where you can mix fast without technical distractions.

## 1. Import and check
- Request consolidated files from bar 1 (all the same start point), 24-bit, the project sample rate, plus the rough mix and tempo/key info.
- Import at zero; set the session tempo (or import the tempo map) so the grid matches.
- Listen to the **rough mix** first and keep it on a muted track as a reference: the artist is used to it.

## 2. Organise
- Order tracks by family: drums, bass, guitars, keys, synths, vocals (lead, doubles, BVs), FX.
- Short consistent names ("Kick In", "Kick Out", "Sn Top", "LdVox").
- **Colour-code** by family; set up **folder/track stacks** or groups.
- Delete or hide empty, duplicate and unused takes (keep a backup of the original session).

## 3. Template routing
- Buses per family (Drums, Bass, Music, Vocals) feeding the mix bus.
- Common send FX: short room, plate, long hall, quarter/eighth delay, slapback, parallel drum compression.
- Mix-bus chain placeholder (bus compressor, metering), reference-track channel routed outside the mix bus.

## 4. Clean-up
- Remove noise, clicks and count-ins; strip silence on toms and vocals (with fades).
- Fix obvious timing/pitch issues or flag them for the producer.
- Clip-gain level wildly varying sections (see vocal-riding skill).
- Check polarity/phase between multi-miked sources.

## 5. Levels
- Pull all faders down; build the balance from the most important element (see balance-order skill). Gain-stage so tracks peak around -18 to -10 dBFS.

## Gotchas
- Mixing over a producer's buried plugins: decide whether to keep them (print them if they're part of the sound).
- Files at the wrong sample rate imported without conversion.

## Verify
- Every track named, coloured and routed; the session plays without clicks; rough mix loaded for comparison.
