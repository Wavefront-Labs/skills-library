# String quartet rehearsal and communication

**Goal:** productive rehearsals in a group without a conductor.

## 1. Rehearsal structure
- Agree the plan and pieces in advance.
- Tune with the cello's C/G and the viola.
- Alternate playing through and detailed work.

## 2. Leading
- Whoever has the main line leads: breath and bow gestures.
- Practise leading entries with all four players.

## 3. Tuning and balance
- Tune chords from the bass up (cello first).
- Listen for the melody and lighten accompaniment.

## 4. Communication
- Suggest by playing ("let's try it this way").
- Take turns proposing ideas; record and listen.
- Decide quickly; if disagreeing, try both.

## Gotchas
- One player always deciding.
- Endless talk without playing.
- Ignoring the viola's and cello's lines.

## Verify
- [ ] Each player leads at some point.
- [ ] Recordings show balance improvements.
- [ ] Decisions made and noted.
