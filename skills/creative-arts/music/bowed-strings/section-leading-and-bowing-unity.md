# Section leading and bowing unity

**Goal:** a section that plays as one: same bowing, same part of the bow, same sound.

## 1. Bowings
- Principal sets the bowings (agreed with the concertmaster).
- Mark them in pencil in all parts before the first rehearsal.
- Change bowings only in rehearsal breaks and pass them back.

## 2. Leading
- Lead entries with a visible breath and bow movement.
- Show style: bow length, placement (upper/lower half), articulation.
- Sit where the section can see you.

## 3. Bowing unity
- Same bow direction, same part of the bow, same speed.
- Agree the bow distribution for long phrases.

## 4. Working with the conductor
- Translate the conductor's request into bowing ("more bow", "off the string").
- Ask questions on behalf of the section.

## Gotchas
- Changing bowings without telling the section.
- Unclear leading gestures.
- Section split into different bowings.

## Verify
- [ ] Parts marked with identical bowings.
- [ ] Entries led clearly.
- [ ] Section bows together in a video.
