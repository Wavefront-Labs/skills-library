# Monadic concept test with action standards

**Goal:** decide go/no-go (or which of several options) for a product concept or
ad *before* spending on launch, with a rule agreed before the data arrives so the
result can't be argued away.

## 1. Set the action standard first
Write it down and get sign-off before fieldwork:
- Metric: usually **top-2-box purchase intent** ("definitely" + "probably would buy").
- Benchmark: your norm database, a current product tested the same way, or the
  best previous concept. Example: "Proceed if T2B ≥ category norm AND
  significantly ≥ current product at 90% confidence; otherwise optimise or kill."
- Secondary: uniqueness, believability, relevance, value for money.
Without this, every result gets reinterpreted.

## 2. Write fair stimulus
- Same format for every concept: headline, consumer insight (the need), benefit,
  reason to believe, pack shot or image, price if price is part of the proposition.
- Same length, same production quality — a nicer picture beats a better idea in tests.
- Plain language; no ad-agency superlatives unless the ad itself is what you're testing.
- For ad copy: animatics, storyboards or finished film — compare within one stage only.

## 3. Choose the design
- **Monadic** (each respondent sees one concept): the cleanest read, closest to real
  life, no order effects. Needs n ≈ 150–200 per cell.
- **Sequential monadic** (each sees 2–4, rotated, rated one at a time): cheaper,
  good for screening; analyse the *first-shown* position too to check order bias.
- **Paired comparison / ranking**: forces choice, good for close options, no absolute read.
- **Screening** many early ideas: short sequential monadic or a MaxDiff of ideas,
  then monadic tests for the finalists.
Matched cells: identical quotas (category users, demographics) so differences come
from the concepts.

## 4. Questionnaire core
1. Expose concept (minimum view time).
2. Purchase intent (5-point).
3. Likes/dislikes open-ends (immediately after intent — richest diagnostics).
4. Uniqueness, believability, relevance, value, frequency/substitution
   ("instead of what?").
5. Attribute agreement grid; for ads: branding recall, message take-out, emotion.
6. Re-expose for detailed feedback if needed.

## 5. Read the results
- Test vs action standard first — the decision.
- Significance at the agreed confidence; cells of 150 detect ~10–12 point T2B
  differences reliably, not 3-point ones.
- Diagnostics explain *why*: low believability → strengthen reason to believe;
  low uniqueness → weak differentiation; strong intent but "instead of my current
  brand from you" → cannibalisation.
- Stated intent overstates real trial; volume forecasting models apply
  calibrations (e.g. weighting "definitely" far above "probably") plus awareness and
  distribution — treat any forecast as a range. **Uncertain:** calibration weights
  are proprietary/vary by category.

## 6. Report
Page 1: decision vs action standard, in one line. Then the scorecard (metrics vs
benchmark with significance), top diagnostics, and specific optimisation fixes.

## Gotchas
- Moving the goalposts after results — the action standard prevents it.
- Testing concepts at different prices without saying so.
- Category non-users in sample deflate scores; screen properly.
- Ad tests on finished film vs animatics aren't comparable; norms must match stage.

## Verify
- [ ] Action standard written and signed off before fieldwork.
- [ ] Stimulus matched in format, length and finish.
- [ ] Design and cell sizes chosen for the difference you need to detect.
- [ ] Open-ends asked right after intent; diagnostics read for "why".
- [ ] Report leads with the go/no-go against the standard.
