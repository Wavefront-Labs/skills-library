# Reconstructing and critiquing an argument

**Goal:** take an argument from a text or conversation, state it precisely in
standard form, evaluate it fairly, and write up a critique a philosopher would accept
— the core working skill behind every other philosophy skill in this library.

## 1. Reconstruct in standard form
1. **Find the conclusion** first: what is the author trying to get you to accept?
   Indicators: *therefore, so, hence, it follows that*.
2. **Find the stated reasons**: *because, since, given that, for*.
3. **Write numbered premises and a conclusion:**
   ```
   P1. If an action maximises happiness, it is right.
   P2. Lying to the murderer maximises happiness.
   C.  Lying to the murderer is right.   (P1, P2, modus ponens)
   ```
4. **Add hidden premises** needed for validity (enthymemes) — and mark them
   `[implicit]`. Choose the **most plausible** premise that makes it valid
   (**principle of charity**), not the weakest one you can knock down.
5. **Fix terms:** use each key word in one sense throughout. If the author slides
   between senses, note it — that's an equivocation.
6. For longer arguments, draw a **map**: sub-conclusions feeding the main one.
   Tools: paper boxes-and-arrows, Rationale, Argdown (text syntax), or MindMup's
   argument mode.

## 2. Evaluate: validity first, then truth
- **Valid**: the conclusion must be true if the premises are. **Sound**: valid + all
  premises true.
- **Test validity by counterexample:** imagine a case where every premise is true and
  the conclusion false. If you can, it's invalid. Check form: *If A then B; B; so A*
  (affirming the consequent) is invalid; *If A then B; not B; so not A* (modus
  tollens) is valid.
- **Then attack premises:** for each, ask whether it is true, what supports it, and
  find a counterexample to universal claims ("all", "only", "never").
- **Reductio:** show a premise or the argument's form implies something absurd.
- **Parity (parallel argument):** same form, obviously false conclusion — shows the
  form is bad.

## 3. Fallacies — use the name only when it fits
| Fallacy | Shape | Check |
|---|---|---|
| Begging the question | conclusion assumed in a premise | would a doubter of C accept the premise? |
| Equivocation | key term shifts meaning | substitute a precise phrase each time |
| Straw man | attacking a weaker version | compare with the author's own words |
| False dilemma | only two options offered | list a third |
| Ad hominem | attacking the person | is the person's trait relevant to the claim's truth? |
| Appeal to authority | authority outside expertise | is the authority expert *on this*? |
| Composition/division | whole ↔ parts | does the property transfer? |
Many "fallacies" are fine in context (testimony from real experts is evidence).
Saying "slippery slope!" is not a refutation — show the slope's steps are unlikely.

## 4. Write the critique (philosophy essay)
1. **Thesis** in the first paragraph: what you will argue, specifically.
2. **Exposition**: the reconstruction, fairly — the author should recognise it.
3. **Objection**: target one premise or the inference; give the counterexample.
4. **Reply on the author's behalf**: the strongest response.
5. **Counter-reply**: why your objection survives (or how far it does).
6. **Conclusion**: what has and hasn't been shown.
Plain prose, signposting ("I will argue…", "The second premise fails because…"),
one idea per paragraph, examples over adjectives.

## Gotchas
- Critiquing premises before checking validity wastes effort if the argument fails
  anyway, and vice versa — do both.
- Charity is not agreement; it's making sure you beat the best version.
- Don't count objections; one decisive objection beats five shallow ones.
- Formal logic as a calculus (proofs, semantics) is mathematics; this is informal method.

## Verify
- [ ] Argument in numbered standard form with implicit premises marked.
- [ ] Validity checked with a counterexample attempt.
- [ ] Each premise evaluated; weakest identified.
- [ ] Any fallacy named only with the check passed.
- [ ] Essay contains objection, reply and counter-reply.
