# Working through a metaphysical puzzle

**Goal:** handle any classic metaphysical problem — identity over time, material
constitution, causation, free will, the nature of time — with a repeatable method
that makes the options and their costs explicit, instead of trading intuitions.

## 1. State the puzzle as an inconsistent set
Write 3–5 individually plausible claims that cannot all be true. Example — the
**statue and the clay**:
1. The statue and the lump of clay occupy exactly the same place and are made of
   the same matter.
2. The lump would survive being squashed; the statue would not.
3. If x and y differ in a property, x ≠ y (Leibniz's law).
4. Two material objects cannot occupy the same place at the same time.
Every answer to the puzzle is a choice of which claim to deny. Test: can you derive
a contradiction from your list? If not, the puzzle isn't stated tightly yet.

## 2. Map the positions
| Deny | Position | Example proponent |
|---|---|---|
| 4 | coincident objects (constitution is not identity) | Lynne Rudder Baker |
| 2 (as stated) | modal properties are relative to how we describe the object | David Lewis (counterpart theory) |
| 1 | there is no statue (or no lump) — eliminativism | Peter van Inwagen |
| (reframe) | statue and lump are temporal parts of overlapping four-dimensional worms | Theodore Sider |
Build the same table for your puzzle; a missing row is often an overlooked position.

## 3. Cost each option
For each position, list:
- **Which intuitions it gives up** and how bad that is.
- **Ontological commitments** (Quine: what must exist if the theory is true —
  temporal parts, possible worlds, universals?).
- **Theoretical virtues:** simplicity/parsimony, explanatory power, consistency
  with physics, generality (does it handle neighbouring puzzles too?).
- **Spread:** does denying the claim here force denying it elsewhere?

## 4. Test against neighbouring cases
A good answer handles the family:
- **Ship of Theseus:** planks replaced one by one; the old planks reassembled. Which
  is the ship?
- **Fission:** a person splits into two qualitatively identical successors (Parfit).
- **Sorites/vagueness:** removing one grain at a time from a heap.
- **Free will:** (1) we sometimes act freely; (2) every event is determined by prior
  events and laws; (3) free action is incompatible with determinism. Compatibilists
  deny (3); libertarians deny (2); hard determinists deny (1).
- **Time:** A-theory (tense is real; often presentism) vs B-theory (earlier/later
  relations only; eternalism).

## 5. Distinguish types of question
- **Conceptual** (what do we mean by "same ship"?) vs **metaphysical** (what is there,
  whatever we mean?). Say which you are answering.
- **Modal** claims: necessary vs possible vs actual; use possible-worlds talk as a
  tool (*necessarily p* = p in all possible worlds) without committing in advance to
  their reality.
- **Merely verbal disputes:** if both sides agree on all the facts and differ only in
  words, say so (Hirsch's deflationism) — but argue for it.

## 6. Write it up
Inconsistent set → positions table → your choice with costs → reply to the best
objection → a neighbouring case your view handles.

## Gotchas
- "Common sense" is not a premise on its own; say which claim it supports.
- Don't let physics settle it by fiat — show how physics bears on which premise.
- Parsimony counts entities of kinds, not individual objects — clarify which.
- Uncertain: attributions in the table are simplified; check each author's text.

## Verify
- [ ] Puzzle stated as an explicitly inconsistent set of numbered claims.
- [ ] Positions table built, each row denying an identified claim.
- [ ] Each option costed (intuitions, ontology, virtues).
- [ ] Your view tested on at least two neighbouring puzzles.
