# Plan review, staged inspections and occupancy sign-off

**Goal:** make sure what is built matches approved drawings that themselves comply with
the adopted code, and only sign off occupancy when life-safety systems are proven. Models:
US jurisdictions adopting ICC codes (IBC/IFC/IRC) with local amendments, and England's
building control regime (Building Regulations 2010, Approved Documents, and the Building
Safety Act 2022 gateway system for higher-risk buildings). Which code **edition** and
amendments apply is set by the jurisdiction and the permit application date — confirm it
first, every time.

## 1. Plan review (plan check)
Work through the drawings in this order — later checks depend on earlier ones:
1. **Use/occupancy classification** (IBC Group A, B, E, I, M, R, S...; England purpose groups) and any mixed-use separation.
2. **Construction type and allowable height/area** — with sprinkler and frontage increases where permitted.
3. **Fire resistance:** rated walls, floors, shafts, compartment/fire-area limits, protected openings.
4. **Means of egress:** occupant load, number of exits, travel distance, exit width, dead-ends, stair design, exit signage and emergency lighting.
5. **Fire protection systems:** sprinklers, alarm/detection, standpipes, smoke control triggers.
6. **Accessibility** (ADA/ICC A117.1 or Approved Document M), structural, energy, plumbing/mechanical as your remit covers.
Issue a **plan review comment letter**: numbered comments, each citing the code section and what must change. Track resubmittals until each comment is closed. Never approve "subject to" a vague condition.

## 2. Staged construction inspections (typical US sequence)
| Stage | What you check |
|---|---|
| Footing/foundation | Excavation, bearing soil, rebar, forms before pour |
| Under-slab / underground | Plumbing, electrical, vapour barrier |
| Framing / structural | Members, connections, shear walls, hold-downs vs approved drawings |
| Rough MEP | Before cover: wiring, ducts, pipes, penetrations |
| Fire-stopping / fire-resistance | Listed systems at penetrations and joints, rated assemblies |
| Insulation / energy | R-values, air barrier |
| Final (building + fire) | Everything complete and tested |
Rule: **nothing gets covered before it is inspected.** In England, notification stages are set by regulation and the higher-risk building regime adds gateway approvals before work and before occupation.

## 3. Correction notices and enforcement
- Write corrections against a code section and a location; photograph.
- Re-inspection only when the contractor calls it ready; fees may apply.
- Serious or continuing breach: stop-work order (US) or enforcement/contravention notices (England; time limits for formal action apply — check).
- Unsafe structure provisions allow emergency action; use them rarely and document fully.

## 4. Fire-safety inspection of existing buildings
Fire-code inspectors (US fire marshal; England fire and rescue authority under the Fire Safety Order 2005, which relies on the responsible person's fire risk assessment) check: exits unobstructed and unlocked in the direction of travel, fire doors self-closing and latching, alarm and sprinkler maintenance records (e.g. NFPA 25/72 inspection-test-maintenance), extinguishers serviced, storage and housekeeping, occupancy limits posted.

## 5. Occupancy sign-off
Before issuing a **certificate of occupancy** (US) or **completion certificate** (England):
- All inspections passed, corrections closed.
- Acceptance tests witnessed for fire alarm, sprinklers, smoke control, emergency lighting, lifts as applicable.
- Special inspections/structural observation reports received.
- As-built fire-safety information handed over (England Regulation 38 information; golden thread for higher-risk buildings).
A **temporary CO** can be issued for partial occupancy only when life-safety systems serving the occupied area are complete — list exclusions explicitly.

## Gotchas
- Reviewing against the wrong code edition.
- Accepting fire-stopping without the listed system's details.
- Signing off a final with a "we'll fix it later" life-safety item.
- Mixing up the designer's responsibility with the inspector's — approval does not certify design.

## Verify
- [ ] Applicable code edition and local amendments recorded on the file.
- [ ] Every plan comment closed with a reference.
- [ ] Every concealment stage inspected before cover.
- [ ] Life-safety acceptance tests witnessed and records filed.
- [ ] Occupancy document lists any conditions or excluded areas.
