# Verifying carbon and sustainability claims

**Goal:** give an independent, evidence-based opinion on whether a sustainability claim
(an emissions inventory, a batch of carbon credits, a green-building rating, a "sustainably
sourced" label) meets the scheme it claims. Model: the ISO 14064-3 / ISO 14065 /
ISO/IEC 17029 validation-verification framework, used by carbon programmes (e.g. Verra VCS,
Gold Standard) and corporate GHG assurance. Each programme publishes its own methodology,
materiality threshold and report template — the programme rules override generic practice.
Rules on green claims in advertising vary by country and are tightening (e.g. EU and UK
consumer-protection guidance) — check current law.

## 1. Agree the engagement
- **Validation** (forward-looking: is the project design/baseline sound?) vs **verification** (backward-looking: did the claimed reductions/emissions occur?).
- **Level of assurance:** reasonable (positive opinion, more evidence) or limited (negative-form conclusion).
- **Materiality:** often 5% of the total claim for many carbon programmes/corporate inventories; smaller projects may use a different level — check the programme. Set qualitative materiality too (misstatements that would mislead a user regardless of size).
- Independence: no prior consultancy on the same claim; rotation limits on lead verifiers per programme rules.

## 2. Verification plan and risk assessment
1. Understand the boundary (organisational/operational, project area, crediting period).
2. Identify where misstatement is most likely: large sources, manual data, estimates, emission factors, model parameters, changes since last period.
3. Write a **sampling plan** weighted to those risks; plan site visits (usually required for first verification and high-risk projects).

## 3. Evidence work
| Area | Tests |
|---|---|
| Activity data | Trace a sample from source (meter readings, fuel invoices, harvest records) to the reported totals; recalculate |
| Emission factors | Correct source, version and units; GWP values from the required IPCC report |
| Baseline & additionality (offsets) | Baseline scenario credible; additionality test per methodology (investment, barrier, common practice); not required by law already |
| Permanence & leakage (nature-based) | Buffer pool contribution, risk rating, leakage deductions applied |
| Double counting | Credits not also claimed by another entity/registry; corresponding adjustments where relevant |
| Monitoring | Equipment calibration, monitoring plan followed, data gaps handled conservatively |
Raise **findings** as clarification requests, corrective action requests (CARs) and forward action requests per programme terminology; all CARs closed before a positive opinion.

## 4. Green-building and sourcing audits (same logic, different evidence)
- **Green building (LEED, BREEAM and similar):** check each credit claimed against its submittal requirements — commissioning reports, energy model, product declarations, site photos — and confirm the assessor's evidence trail.
- **Sourcing/chain of custody (FSC, PEFC, RSPO, Fairtrade-type schemes):** volume reconciliation — certified input ≥ certified output claimed, with conversion factors; supplier certificate validity on the transaction date; segregation or mass-balance rules applied as declared.

## 5. Opinion and report
- Aggregate uncorrected misstatements; compare against materiality.
- Opinion: unqualified, qualified, adverse, or no opinion (scope limitation).
- Report states standard, scope, assurance level, materiality, criteria, findings and the verified quantity.
- For public claims: check the wording matches what was verified ("carbon neutral" vs "offset 80% of scope 1-2") — overreach is the classic greenwashing failure.

## Gotchas
- Using the wrong GWP set or an outdated emission factor.
- Rolling over last year's baseline without retesting it.
- Verifying the number but not the claim made from it.
- Mass-balance claims written as if physically segregated.

## Verify
- [ ] Engagement letter states criteria, assurance level and materiality.
- [ ] Risk-based sample traced to source data and recalculated.
- [ ] Additionality, permanence, leakage and double counting addressed (offsets).
- [ ] All corrective action requests closed or reflected in the opinion.
- [ ] Public claim wording consistent with verified scope.
