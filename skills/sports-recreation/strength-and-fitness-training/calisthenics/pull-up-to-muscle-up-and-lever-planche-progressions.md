# Calisthenics — pull-up to muscle-up and lever/planche progressions

**Goal:** get strong with your bodyweight by making exercises harder through
**leverage**, not added plates — and progress the static skills (levers,
planche) without wrecking elbows and wrists. Equipment: a bar, parallel bars/
parallettes, rings optional.

## 1. Foundations (strength base)
| Pattern | Easier → harder |
|---|---|
| Push | incline push-up → push-up → diamond/archer → pseudo-planche push-up → one-arm |
| Dip | bench dip → support hold → negative dips → parallel-bar dips → ring dips |
| Row | high-incline Australian row → horizontal row → archer row |
| Pull | dead hang → scapular pull-up → negatives (5 s down) → band-assisted → pull-up → chest-to-bar → weighted/archer |
| Legs | squat → split squat → Bulgarian split squat → shrimp/pistol; Nordic curls for hamstrings |
| Core | hollow body hold → hanging knee raises → hanging leg raises → L-sit |
Train the base 3×/week in a **5–8 rep, 3–4 set** range near failure; move to the
next progression when you can do the top of the range for all sets.

## 2. The muscle-up path (bar)
Prerequisites: around **8–10 strict pull-ups** and **10+ dips** (common
guideline), explosive chest-to-bar pull-ups.
1. **High pull-ups** — pull to the lower chest/belly, explosively.
2. **Negative muscle-ups** — start on top, lower slowly through the transition.
3. **Transition drills** — jumping muscle-ups or low bar, lean over the bar.
4. **Kipping muscle-up** → strict. Pull *toward the hips*, not straight up;
   lean the chest over the bar at the top of the pull.
Rings: learn the **false grip** (wrist over the ring) for strict ring muscle-ups.

## 3. L-sit and handstand
- **L-sit:** support on parallettes, shoulders depressed, legs straight and
  horizontal. Progression: tuck sit → one leg extended → full.
- **Handstand:** wall handstand (chest to wall) → kick-ups → freestanding holds;
  balance with the fingers; daily short practice beats long weekly sessions.

## 4. Static levers and planche
Use the same progression ladder for each: **tuck → advanced tuck → one leg
(or half lay) → straddle → full.**
- **Front lever** (body horizontal, face up, hanging below the bar): straight
  arms, scapulae depressed, posterior pelvic tilt. Accessories: front-lever raises,
  ice-cream makers, weighted pull-ups.
- **Back lever** (face down, below the bar/rings): reached via **skin the cat**;
  hard on the biceps tendon and shoulders — progress slowly.
- **Planche** (body horizontal above the hands, arms straight): lean (planche
  lean) → tuck → advanced tuck → straddle → full. Usually takes **years**.
- Hold-based training: e.g. 5–8 sets of 5–10 s at the hardest progression you
  can hold with good form; finish with negatives or partial reps.

## 5. Tendons and joints
- **Straight-arm** work (planche, levers, back lever) loads elbows and
  biceps tendons heavily; tendons adapt slower than muscles. Add volume slowly
  and stop at elbow pain.
- **Wrists:** warm up and condition (wrist circles, palm lifts) for planche and handstand.

## 6. Structuring the week
- 3–4 sessions: skill work first (fresh), strength next, accessories last.
- **Grease the groove** (many submaximal sets through the day) works for pull-ups
  and push-ups.
- Example: Mon/Thu pull + core + front lever; Tue/Fri push + legs + planche;
  handstand practice 10 min daily.

## Verify
- [ ] Each base pattern has a current progression and a next step.
- [ ] 8–10 strict pull-ups and 10 dips before muscle-up attempts.
- [ ] Static holds are tracked by progression and seconds.
- [ ] Straight-arm volume increased gradually; no elbow pain.
- [ ] Skill work placed at the start of sessions.
