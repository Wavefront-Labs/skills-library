# Memory sports — memory palaces, PAO and competition disciplines

**Goal:** memorise long sequences of numbers, cards, names and words fast
and accurately using the systems competitive memory athletes use. The
methods are learnable — top competitors describe ordinary natural memory.

## 1. The memory palace (method of loci)
- Pick a familiar place (home, route to work). Choose a fixed **journey**
  of distinct **loci** (stations): front door, coat hook, mirror, sofa…
- Always walk it in the **same order**; number the loci in your head.
- Place one vivid **image** per locus (or one per pair/triplet of items
  with advanced systems). Make images exaggerated, moving, funny or gross,
  interacting with the location.
- Build many palaces (competitors use dozens) so you can rest palaces
  between uses — recently used palaces cause "ghost" images.
- Practise with a 20-item shopping list before moving on.

## 2. Turning numbers into images
- **Major system:** digits → consonant sounds (0 s/z, 1 t/d, 2 n, 3 m,
  4 r, 5 l, 6 j/sh/ch, 7 k/g, 8 f/v, 9 p/b); fill with vowels to make
  words (e.g. 14 = T-R → "tyre"). Make a fixed image list for 00-99.
- **PAO (person-action-object):** each 2-digit number has a person, an
  action and an object. A 6-digit chunk becomes one image: person of the
  first pair, doing the action of the second, to the object of the third.
- **Dominic system:** digits → letters → initials of a person (variants).
- Many competitors move to 3-digit systems (1000 images) later — big up-
  front investment.

## 3. Cards
- Assign each of the 52 cards an image (or a PAO set); a common start is
  card → number (e.g. hearts 10-19 style) → your number image.
- **Speed cards:** memorise a shuffled deck, then reconstruct it with a
  second deck. Train: learn images to instant recall first (flash-card
  each card under ~1 second), then journeys of 2-3 cards per locus.

## 4. Training structure
1. Build and **drill the image system** until each conversion is
   automatic — slow conversion is the main bottleneck.
2. Timed practice with immediate scoring; log time and errors.
3. **Accuracy before speed:** in many disciplines an error costs heavily
   (rows/units scored zero).
4. Review: for long-term retention (non-competition use) revisit after
   1 day, 1 week, 1 month.
Free training software (e.g. memory-sport training websites and the
Memory League platform) provides timed disciplines.

## 5. Competition disciplines (typical)
Classic championship formats include: **speed numbers** (5 min), **hour
or 30-min numbers**, **binary digits**, **speed cards**, **hour cards**,
**names and faces**, **random words**, **historic/future dates**,
**abstract images**, and spoken numbers (one digit per second, recall
until first error). Scoring and timings vary by organisation and have
changed over the years — read the current rulebook of the event (I have
not verified the latest IAM/WMSC rule versions).
Memory League runs short head-to-head formats (e.g. one-minute
memorisation) online.

## 6. Everyday use
Shopping lists, speeches (one locus per point), names (link the name to a
feature of the face), PINs and phone numbers via the major system.

## Gotchas
- Images that are too similar (two "ball" images) → confusion; make each
  unique.
- Reusing a palace too soon → ghost images.
- Rushing before the system is automatic.

## Verify
- [ ] You have a 00-99 image list and can convert any pair in under a second.
- [ ] You can recall a 20-item list from a palace forwards and backwards.
- [ ] You have a card image system and a timed deck baseline.
- [ ] You know the rules and scoring of your target discipline.
