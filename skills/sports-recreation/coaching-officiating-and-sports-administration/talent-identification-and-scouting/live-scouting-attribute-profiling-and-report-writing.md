# Live scouting, attribute profiling and report writing

**Goal:** judge a player against what your club actually needs in that position, using
consistent grades and evidence, and write a report a decision-maker can act on.

> Draft: general recruitment practice in team sports (football/soccer-centred
> examples). Each club has its own grading scale and report template; follow it.
> Safeguarding and approach rules for young players (contacting players, parents,
> clubs) are set by governing bodies — know them before speaking to anyone.

## Before the game
- **Profile**: get the club's **position profile** — the 6–10 attributes that matter
  for that role in your game model (e.g. a full-back: recovery speed, 1v1 defending,
  crossing, overlapping timing, decision-making in build-up).
- **Context**: league level, opposition strength, player's age (and month of birth),
  minutes played, injuries, previous reports.
- Pre-watch video if available, so the live viewing targets what video can't show.

## Watching live
- **Arrive for warm-up**: body language, coachability, interaction with teammates.
- **Position**: high and central if possible, so you see shape and off-ball movement.
- **Watch the player, not the ball** for long stretches: scanning, positioning, effort
  in transition, communication, reactions to mistakes.
- Note **specific moments with times** ("23' — lost duel, recovered in 3 s and won the
  ball back") — evidence over adjectives.
- Watch **multiple games** (different opponents, home/away, a bad day) before a firm
  recommendation.

## Grading
- Use the club's scale consistently (e.g. 1–5 or A–D) **per attribute**, against the
  level you're recruiting for — not against this game's opposition.
- Separate **current ability** from **projected potential**; state the timeframe.
- **Calibrate** with colleagues: watch the same player and compare grades; discuss
  differences to align the scale.

## Bias checks (especially youth)
- **Relative age effect**: players born early in the selection year are often more
  physically mature — over-represented in squads. Adjust for it.
- **Maturation**: early maturers dominate physically now; late maturers may have
  higher technical ceilings. Some clubs use **bio-banding** or maturity estimates.
- **Halo effect**: one great moment colouring every grade.
- **Similarity bias**: preferring players like you/past signings.

## The report
1. Header: player, DOB, club, position(s), match details, minutes, conditions.
2. **Summary line**: recommendation (sign / monitor / trial / no) in one sentence.
3. Attribute grades with evidence notes.
4. Strengths, development areas, character notes.
5. Fit with the game model and squad needs.
6. Next step: more viewings, data check, trial, or close.

## Gotchas
- Writing the report days later — memory rewrites; write the same evening.
- Judging a player out of position or in a dysfunctional team without context.
- Over-relying on data (or ignoring it) — combine data screening with live viewing.

## Verify
- [ ] Position profile and context gathered before viewing.
- [ ] Notes include timed, specific moments for each key attribute.
- [ ] Grades on the club scale, current vs potential separated.
- [ ] Bias checks (age, maturation) noted for youth players.
- [ ] Report submitted within 24 h with a clear recommendation and next step.
