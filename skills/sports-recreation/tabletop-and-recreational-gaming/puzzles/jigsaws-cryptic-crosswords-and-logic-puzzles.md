# Puzzles — jigsaws, cryptic crosswords and logic puzzles

**Goal:** solve more, faster, with less frustration, by using the methods
experienced puzzlers use instead of brute force. For speed-solving twisty
puzzles see `sports-recreation.mind-sports-and-games.speedcubing`.

## 1. Jigsaws
1. **Flip all pieces face up** and pull out edge pieces.
2. **Build the border** — it fixes size and gives anchors. Count edge
   pieces against the expected number if it won't close (a piece can hide
   under the box lid or the table edge).
3. **Sort by colour/texture** into trays: sky, text, distinct objects.
4. Build **distinct areas** first (text, faces, strong lines), then
   connect them to the border.
5. **For uniform areas** (sky, sea): sort by **piece shape** — count the
   knobs ("tabs") and holes ("blanks"); arrange in rows by shape, then try
   a few candidates per gap.
6. Work under good, even light; glare hides subtle colour shifts.
A felt roll-up mat lets you pause big puzzles.

## 2. Cryptic crosswords (British-style)
Every clue = **definition** (at the start or end) + **wordplay** that
also leads to the answer. Typical wordplay types:
- **Anagram** — signalled by words like "broken", "mad", "novel".
  (Toy example: "Dirty room rearranged for sleepers (9)" — "rearranged"
  is the indicator, DIRTY ROOM the fodder, "for sleepers" points to the
  definition: DORMITORY.)
- **Hidden word** — "in", "some", "part of": the answer is spelt inside
  consecutive words.
- **Container/insertion** — "around", "holding", "inside".
- **Charade** — answer built from parts in sequence.
- **Double definition** — two meanings, no wordplay.
- **Reversal** — "back", "returned", "up" (in down clues).
- **Homophone** — "we hear", "reportedly".
- **Deletion** — "headless", "endlessly", "heartless".
- **Abbreviations:** common substitutions (e.g. "about" = C or CA or RE,
  "sailor" = AB or TAR, "learner" = L). Keep a list.
Method: find the definition first (try the first and last word or
two), count letters, look for an indicator, check crossing letters.
Start with short clues and anagrams. Read the setter's blog/solution
explanations next day — the fastest way to learn their tricks.

## 3. Logic puzzles (sudoku, nonograms, kakuro)
- **Sudoku:** scan for "only place" first (hidden singles), then
  pencil-mark **candidates** in every cell. Advance through standard
  techniques: naked/hidden pairs and triples, pointing pairs, box-line
  reduction, X-wing. **Never guess** in a well-formed sudoku — there is a
  logical path, and one guess wastes the grid when wrong.
- **Nonograms (picross):** start with rows/columns whose clue numbers +
  required gaps nearly fill the line ("overlap" method); mark known empty
  cells with X.
- **Kakuro/killer sudoku:** learn the unique sums (e.g. 3 in two cells is
  only 1+2; 45 is a full 1-9 row).
- Use a pencil/erasable marks; verify each deduction before inking.

## 4. Mechanical puzzles
- **Disentanglement:** follow the string/loop path; the solution usually
  reverses the assembly; many involve passing a loop through a hole and
  around an end.
- **Burr/interlocking:** look for the key piece that moves first.
- Never force; mechanical puzzles are designed not to need it.
- Photograph the start so you can reset.

## Gotchas
- Missing jigsaw piece? Check the floor, the box and under the mat
  before blaming the manufacturer.
- In cryptics, the surface meaning is designed to mislead; ignore it.
- Guessing in sudoku creates contradictions far from the guess.

## Verify
- [ ] Jigsaw border complete before interior filled.
- [ ] For each cryptic answer you can identify the definition and wordplay.
- [ ] Your sudoku solutions came from deductions with no guessing.
