# Speedrunning — routes, splits, practice and verified runs

**Goal:** get a personal best (PB) that appears on the leaderboard, by
learning a known route efficiently and recording runs that the moderators
can verify.

## 1. Pick a game and category
- Look up the game on **speedrun.com** (the main leaderboard host). Read
  the **game rules** page fully: categories (Any%, 100%, Glitchless, etc.),
  allowed versions/platforms, emulator policy, timing method and video
  requirements.
- **Timing methods:** RTA (real-time), IGT (in-game time), or
  load-removed time. The rules page says which one counts.
- For a first run, pick a popular, well-documented category with guides
  and active community (Discord linked from the leaderboard).

## 2. Learn the route
- Watch the **world record and 2–3 runs near your level**, plus the
  community route doc/guide.
- Write the route as segments (level, boss, area) with the key tricks
  in each.
- Start with the **easier "backup" versions** of hard tricks; add the risky
  strats once runs are consistent.
- Ask in the game's Discord — runners are usually happy to explain.

## 3. Set up timing: LiveSplit
- **LiveSplit** (free, Windows; LiveSplit One runs in a browser/other OS)
  is the standard timer.
- Edit splits: one split per route segment. Download a community splits
  file if one exists.
- **Autosplitter:** many games have one (Edit Splits › Activate); it starts,
  splits and removes loads automatically. Check whether the leaderboard
  accepts autosplitter timing.
- Compare against **Personal Best** and watch **Sum of Best** (your best
  segment times added up) — the gap between PB and SoB shows how much time
  consistency would save.
- Gold splits (best-ever segment) tell you where you're improving.

## 4. Practise segments, not only full runs
- Use **practice saves** or, where the platform allows, savestates/practice
  ROM hacks to repeat hard segments 10–20 times.
- Track success rate per trick; a trick you land 50% of the time in
  practice is a run-killer early in the route. Use the safe strat until
  it's 80%+ (adjust to taste).
- Do full runs regularly too — nerves and fatigue only show up there.
- **Reset culture:** early resets after a lost trick are normal, but
  finishing runs builds late-game experience. Finish at least some runs.

## 5. Record a verifiable run
- Record the **full run with the timer visible**, from the start condition
  to the end condition as defined in the rules.
- Many games require **game audio**, uncut video, and sometimes a
  view of the console start-up or hands-cam for top runs. Read the rules
  for your game.
- OBS: record locally at decent quality even if you also stream; Twitch
  past broadcasts expire, so upload the run to YouTube or a permanent host
  before submitting.
- Submit on speedrun.com with video link, time and platform. Moderators
  verify manually; wait times vary.

## 6. Routing and discovery (advanced)
- Time savings come from finding skips/glitches and testing alternatives.
  Document the new strat with video and share with the community before
  using it on the board, as rules may need a ruling.

## Gotchas
- Using a disallowed version, emulator or setting and having the run rejected.
- Starting/ending the timer at the wrong moment.
- Losing the video because only the stream VOD existed.
- Category rules change after discoveries; reread before submitting.
- **Specific LiveSplit menu names may vary by version.**

## Verify
- [ ] Rules page read; category, version and timing method confirmed.
- [ ] Splits set up with a PB and SoB comparison.
- [ ] Per-trick success rates tracked in practice.
- [ ] Run video is permanent, uncut and shows the timer.
