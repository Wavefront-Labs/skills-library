# Reading and hoisting International Code of Signals flags

**Goal:** recognise the flag signals that matter for safety on sight, decode longer
hoists with the code book, and hoist your own signals so they can't be misread.

## 1. The set
- **26 letter flags** (named by the phonetic alphabet: Alfa, Bravo…), **10 numeral pennants**,
  **3 substitutes** (repeaters) and the **code/answering pennant**.
- The **International Code of Signals (ICS)** gives meanings in many languages; keep a
  current copy aboard. Meanings below are paraphrased — the book is authoritative.

## 2. Single-letter signals to know cold
Single flags carry urgent or common messages:
| Flag | Meaning (paraphrase) |
|---|---|
| A | Diver down — keep well clear at slow speed |
| B | Carrying/handling dangerous goods |
| C / N | Yes (affirmative) / No (negative) |
| D | Keep clear, I'm manoeuvring with difficulty |
| E / I | Altering course to starboard / to port |
| F | I'm disabled; communicate with me |
| G / H | I need a pilot / I have a pilot aboard |
| J | On fire with dangerous cargo — keep well clear |
| K | I wish to communicate with you |
| L | Stop your vessel instantly |
| M | My vessel is stopped, making no way |
| O | Man overboard |
| P | (In harbour) all aboard, vessel about to sail |
| Q | My vessel is healthy; I request free pratique |
| U | You are running into danger |
| V / W | I need assistance / I need medical assistance |
| Y / Z | I'm dragging anchor / I need a tug |
Also memorise **NC** (in distress, need immediate assistance).

## 3. Hoists and code groups
- A hoist reads **top to bottom**. Two-letter groups are general signals, three-letter groups
  beginning with **M** are the medical section; numbers via numeral pennants.
- Several hoists flown at once are read in a fixed order (masthead first, then the yardarms —
  check the ICS for the exact sequence your vessel's rig implies).
- **Substitutes** repeat a flag already in the same hoist, because you carry only one of each:
  first substitute repeats the topmost flag of that class, second the second, third the
  third. So `AAA` needs A, 1st sub, 2nd sub.
- Look up every multi-flag hoist in the book — guessing from letters is how ships misunderstand each other.

## 4. Answering procedure
- Receiving vessel hoists the **answering pennant at the dip** (half-way) when it sees a signal,
  and **close up** (fully hoisted) when it has understood. The sender lowers the hoist; the
  receiver returns the pennant to the dip for the next one.
- The code pennant hoisted by itself or over a group indicates the ICS is being used
  (rather than a local code).

## 5. Dressing ship
Flags strung bow to stern over the mastheads for celebrations. Use a **mixed sequence that
spells nothing** — avoid accidentally flying `O`, `V` or a meaningful group in a prominent
spot. Don't dress ship while under way in many navies'/clubs' customs (check yours).

## Gotchas
- **Racing flags differ:** under yacht-racing rules, flags such as P, AP, X and the
  numerals have race-committee meanings unrelated to the ICS. Context decides.
- Fading and limp flags in light air are hard to read — use binoculars and wait for them to stream.
- A "diver down" can also be shown by the red-and-white sport diver flag in some countries;
  treat either as keep clear.
- Old charts or reference cards may use pre-1969 meanings.

## Verify
- [ ] Shown any single letter flag, you give its ICS meaning in under 3 s.
- [ ] You can build a hoist needing a substitute and explain which flag it repeats.
- [ ] You can demonstrate dip vs close-up with the answering pennant.
- [ ] A dressing-ship sequence you made contains no meaningful single flags at prominent points.
