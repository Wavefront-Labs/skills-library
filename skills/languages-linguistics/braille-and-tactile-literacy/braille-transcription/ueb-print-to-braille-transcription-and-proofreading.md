# UEB print-to-braille transcription and proofreading

**Goal:** turn a print document into braille a reader can trust — correct code, correct
format, no silent omissions — and catch your own errors before it is embossed.

## 1. Before you start
- **Confirm the code and format authority** for the reader: UEB is the literary code in
  most English-speaking countries; formatting rules differ (BANA *Braille Formats* in the
  US/Canada, national guidance elsewhere). Ask whether the reader wants contracted or
  uncontracted braille — early learners and some adults want grade 1.
- **Survey the print:** headings levels, lists, tables, images, footnotes, emphasis, foreign
  words, maths. Decide each treatment once and write it on a **transcriber's note sheet**
  so the whole document is consistent.
- Standard page: commonly **40 cells × 25 lines** on 11 × 11.5 in paper; check the reader's
  embosser or display.

## 2. Indicators that cause most errors
- **Capitals:** dot 6 before a letter; dots 6,6 for a whole word; three dot-6 cells for a
  passage of three or more words, closed by the capitals terminator (6, 3).
- **Numbers:** numeric indicator (3-4-5-6) before digits; letters a–j directly after digits
  need a **grade 1 indicator** (5-6) or they read as digits (`3d` vs `34`).
- **Grade 1 indicator:** needed when a letter or letter group could be misread as a
  contraction — a single letter `b` standing alone reads as *but*, so it takes 5-6 first.
- **Typeforms:** italic, bold, underline each have symbol, word and passage indicators.
  Only reproduce emphasis that carries meaning; decorative print styling is usually dropped
  (note the decision on your sheet).

## 3. Contraction rules transcribers trip on
- **Standing-alone rule:** whole-word contractions (`b` = *but*, `c` = *can*) apply only when
  the word stands alone, with only certain punctuation touching it.
- **Don't bridge a word-part boundary** with a groupsign when it would distort
  pronunciation: classic examples are *mis-hap* (no `sh`) and *pot-hole* (no `th`).
- **Lower-sign sequences:** runs of lower-cell signs without an upper-cell sign can be
  ambiguous; follow the UEB lower-sign rule rather than trusting software output.
- **Proper names, URLs, email addresses** are often best uncontracted or in grade 1 passage
  mode — check current authority guidance; practice varies (uncertain across regions).
- **Hyphenated line breaks:** don't carry print hyphenation; re-divide only at syllable
  boundaries and never split a contraction.

## 4. Format essentials
- Print page numbers are shown (print page indicator) so a braille reader can follow a
  class or a citation; braille page numbers sit separately (usually upper/lower right).
- Headings use centred and cell-5/cell-7 conventions by level; blank lines are expensive in
  braille, so follow the authority's rules rather than mimicking print spacing.
- **Images:** describe them in a transcriber's note or refer to a tactile graphic
  (see the tactile-graphics skill); never silently drop them.
- **Tables:** linearise or use a stairstep/listed format if columns won't fit 40 cells.

## 5. Proofreading in two passes
1. **Comparison pass:** braille against print, line by line, ticking off every print
   element — catches omissions, number errors and missing indicators.
2. **Cold-read pass:** read the braille *without* the print, as the reader will. Catches
   wrong contractions, ambiguous sequences and format that doesn't make sense by touch.
Have a second qualified person proof anything high stakes (exams, legal, medical). If you
used translation software, still do both passes: it errs on proper names, foreign words,
emphasis and mixed maths.

## Verify
- [ ] Code (UEB, grade 1/2) and format authority confirmed with the reader or agency.
- [ ] Transcriber's note sheet records every treatment decision.
- [ ] Every number, capital, and single standing letter checked for indicators.
- [ ] No images, footnotes or table cells omitted silently.
- [ ] Both proofreading passes completed; errors logged and fixed before embossing.
