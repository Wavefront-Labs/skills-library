# Designing and producing tactile diagrams and maps

**Goal:** turn a print image into a raised graphic that conveys the *same information* by
touch — not a copy of the picture, which almost never works.

## 1. First decide: graphic, description, or object?
Ask what the reader must **do** with the image.
- Decorative or illustrative only → a short text description is enough.
- Information is a list or sequence (a flow chart, a timeline) → a list or table in braille
  may beat a graphic.
- Spatial relationships matter (a map, a circuit, a cell diagram, a graph's shape) → make a
  tactile graphic.
- 3D shape matters (a molecule, an organ) → a physical model may teach better than any drawing.

## 2. Simplify ruthlessly
Touch resolves far less detail than sight and reads serially (fingertip by fingertip).
- **Remove** everything not needed for the task: shadows, perspective, decorative borders,
  repeated items (show one, note "repeated 6 times").
- **Flatten 3D to 2D:** use plan or elevation views, never perspective drawings.
- **Enlarge** so elements are separable; split a complex image into several graphics
  (an overview plus detail sheets).
- **Distort deliberately if needed:** exaggerate a narrow river or tiny organ so it can be
  felt, and say so in a note.

## 3. Lines, areas, symbols, labels
- Use a **small set of distinguishable line types** (solid, dashed, dotted, thick) — about
  four is a practical ceiling — and a similarly small set of **area textures**.
- Keep **clear space** between features (roughly 3 mm / 1/8 in or more) so lines don't merge.
- Put **braille labels** horizontally, not on curves or angles; where there's no room use a
  short abbreviation and a **key** on the same or facing page.
- Include a **title** and orient consistently (north at top for maps). Add a tactile start
  point or legend location that the reader can always find.
- Texture contrast is relative: test that two textures are distinguishable *next to each other*.

## 4. Production methods
- **Swell (microcapsule) paper:** print or draw in black carbon-based ink (laser print or
  photocopy works; most inkjet ink does not swell well), then pass through a heat fuser.
  Fast, cheap, good lines; textures limited and paper costly per sheet.
- **Graphics embossers:** print from drawing software at multiple dot heights; repeatable,
  integrates braille labels; needs digital files built for touch.
- **Collage:** layered card, fabric, string and sandpaper glued on board — rich textures,
  good for young learners; fragile and hard to copy.
- **Thermoform:** vacuum-forms plastic over a master for many copies; strong 3D relief.
Hand-made masters and collage are often best for teaching; embossed/swell for volume.

## 5. Teaching the reader to read it
Tactile reading is a skill: explore with both hands flat for an overview, find title and
key, then trace systematically. A first-time reader needs a guided walkthrough, not just
the sheet.

## Gotchas
- Braille labels on swell paper can lose crispness — check they read well after fusing.
- Over-heated swell paper puffs background areas; test fuser settings on a scrap sheet.
- A graphic that looks clear to a sighted designer often fails by touch — always test.
- Don't rely on colour or line weight that only differs visually.

## Verify
- [ ] You can state the task the graphic supports and nothing extra is drawn.
- [ ] Line types and textures are few and distinguishable side by side.
- [ ] Labels are horizontal braille or keyed abbreviations; a key and title are present.
- [ ] A braille reader (ideally the intended one) answered the task question from the graphic alone.
