# Learning a new script in four weeks

**Goal:** read a new script slowly but accurately within a week or two, write it legibly,
and reach comfortable reading speed in about a month — without leaning on romanisation.
For logographic systems (hanzi, kanji) see logographic-literacy instead; that's a
different, much longer craft.

> Draft. Timelines assume ~20–30 minutes daily and a phonetic script of roughly 25–50
> base symbols; complex abugidas (Devanagari conjuncts, Thai tones/classes) take longer.

## Step 0: classify the script (it tells you what to learn)
- **Alphabet** (Cyrillic, Greek, Georgian, Armenian): letters for consonants and vowels.
  Learn ~30 letters; done.
- **Abjad** (Arabic, Hebrew): consonants written; short vowels mostly omitted (optional
  diacritics). You'll need vocabulary to read unvowelled text — expect slower reading.
- **Abugida** (Devanagari, Bengali, Thai, Ethiopic, Tamil): consonant + inherent vowel,
  vowel signs modify it, and consonant clusters form **conjuncts**. Learn consonants, then
  vowel signs, then the common conjuncts.
- **Syllabary** (Japanese kana, Cherokee): one symbol per syllable; more symbols, simple
  rules.
- **Featural** (Hangul): letter shapes encode articulation; letters stack into syllable
  blocks. Typically one of the fastest to learn — often a few days.
Also check: **direction** (RTL for Arabic/Hebrew), **case** (Cyrillic/Greek have it;
Arabic doesn't), **contextual forms** (Arabic letters change shape by position; Hebrew has
five final forms).

## Week 1: letters in batches
1. Split the inventory into batches of 5–8, starting with the **most frequent** letters
   so you can read real words immediately (frequency lists exist for most languages).
2. For each letter: sound, printed form, handwritten form, and (for Arabic) the four
   positional forms.
3. **False friends first-class:** list letters that look like Latin letters but sound
   different — Cyrillic Р = r, Н = n, В = v, С = s, У = u; Greek ρ = r, η = ē/i, ν = n. Drill
   them deliberately; they cause most early errors.
4. Spaced repetition (e.g. Anki) with cards **script → sound** and **sound → write it**.

## Week 2: read words, not letters
- Read real high-frequency words, signs, menus, place names you already know
  (Москва, Αθήνα, 서울). Known words give instant feedback.
- **Remove romanisation now.** Transliteration aids slow you down long-term.
- Write each new word by hand, saying it aloud.

## Week 3: rules and edge cases
- Abjads: learn the vowel diacritics, but practise unvowelled text too.
- Abugidas: vowel-sign placement (some vowel signs are written **before** the consonant
  they follow in speech, e.g. Devanagari ि), inherent-vowel deletion, the 20–30 most
  common conjuncts.
- Language-specific spelling rules (e.g. Russian unstressed vowel reduction — spelling
  ≠ pronunciation).
- Cursive/handwritten forms where they differ markedly (Russian cursive т, д, и; Hebrew
  script cursive).

## Week 4: speed
- Timed reading: the same short passage daily; record seconds; aim to halve your time.
- Graded readers or children's texts in the target language.
- Type in the script: install the keyboard layout (OS settings → keyboards); typing
  reinforces letter recognition.

## Gotchas
- Learning with a font that differs from real-world signage/handwriting — look at both.
- Ignoring stroke direction in handwriting (Arabic/Hebrew written right to left; letters
  join in specific ways).
- Reading aloud letter-by-letter forever: push to chunk syllables early.
- Confusing **script** with **language**: Cyrillic serves Russian, Ukrainian, Serbian,
  Kazakh… with letter differences (Ukrainian і, ї, є; Serbian ј, љ, њ).

## Verify
- [ ] You can write every letter from its sound, unprompted.
- [ ] You read 20 unfamiliar words aloud with ≤2 errors, no romanisation.
- [ ] False-friend letters no longer cause errors in a timed test.
- [ ] Your timed passage reading time has at least halved since week 2.
- [ ] You can type a short sentence on the native keyboard layout.
