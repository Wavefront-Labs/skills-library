# Factoring primes in number fields

**Goal:** given K = ℚ(α) of degree n and a prime p, compute the factorisation
pO_K = 𝔭₁^{e₁}⋯𝔭_g^{e_g} — the basic calculation behind class groups, Diophantine
applications and reciprocity laws.

## 1. Get the ring of integers right first
O_K is often larger than ℤ[α]:
- ℚ(√d), d squarefree: O_K = ℤ[√d] if d ≡ 2, 3 (mod 4); ℤ[(1+√d)/2] if d ≡ 1 (mod 4).
  Discriminant d_K = 4d or d respectively.
- Cyclotomic ℚ(ζ_m): O_K = ℤ[ζ_m].
- In general disc(f) = [O_K : ℤ[α]]² · d_K for the minimal polynomial f of α. Primes p
  with p² ∤ disc(f) cannot divide the index — ℤ[α] is p-maximal there.
In practice let software do this: PARI/GP `nf = nfinit(f); nf.zk; nf.disc`, SageMath
`K.<a> = NumberField(f); K.maximal_order(); K.discriminant()`, Magma `MaximalOrder`.

## 2. Dedekind–Kummer (when p ∤ [O_K : ℤ[α]])
Factor f mod p: f ≡ Π ḡ_i^{e_i} (mod p), with ḡ_i distinct irreducible. Then
pO_K = Π 𝔭_i^{e_i}, 𝔭_i = (p, g_i(α)), residue degree f_i = deg ḡ_i.
Example K = ℚ(√−5), f = x² + 5, ℤ[√−5] = O_K:
- p = 2: x² + 5 ≡ (x + 1)² → 2 = 𝔭², 𝔭 = (2, 1 + √−5); ramified.
- p = 3: x² + 5 ≡ x² − 1 = (x − 1)(x + 1) → 3 = (3, 1 + √−5)(3, 1 − √−5); split.
- p = 7: x² + 5 ≡ x² − 2 ≡ (x − 3)(x + 3) (since 3² = 9 ≡ 2) → split.
- p = 11: −5 ≡ 6 is not a square mod 11 → x² + 5 irreducible → 11 inert.
If p divides the index, Dedekind–Kummer can give wrong answers; use a different
generator α, or the general algorithms (Buchmann–Lenstra) via software.

## 3. Read the invariants
- **Σ e_i f_i = n** (always check this).
- p **ramifies** (some e_i > 1) ⇔ p | d_K. So only finitely many primes ramify — the
  discriminant tells you which to watch.
- Galois case: all e_i equal, all f_i equal, efg = n.
- Quadratic fields: p odd, p ∤ d: split iff (d_K/p) = 1, inert iff −1 (Legendre symbol).
- Cyclotomic ℚ(ζ_m), p ∤ m: f = order of p mod m, g = φ(m)/f.

## 4. Using factorisations: class groups
Minkowski bound M_K = (n!/nⁿ)(4/π)^{r₂}√|d_K|: every ideal class contains an integral
ideal of norm ≤ M_K. So the class group is generated by primes 𝔭 with N𝔭 ≤ M_K.
For ℚ(√−5): M_K = (2/4)(4/π)√20 ≈ 2.85, so only 𝔭 above 2 matters. 𝔭² = (2) is
principal; 𝔭 is not (no element of norm a² + 5b² = 2), so h_K = 2 and the class group
is ℤ/2. Relations between generators come from factoring principal ideals (α) with small
norm. Software: PARI `bnfinit(f).cyc`; note that by default PARI's class group
computations assume GRH (`bnfcertify` removes the assumption).

## 5. Software cross-checks
PARI/GP:
```
nf = nfinit(x^2 + 5);
idealprimedec(nf, 3)     \\ list of primes above 3 with e and f
idealfactor(nf, 6)
bnfinit(x^2 + 5).cyc     \\ class group structure, e.g. [2]
```
SageMath: `K.factor(3)`, `K.class_group()`, `K.ideal(2, 1 + a).is_principal()` (gated: unconfirmed, source is paywalled or blocked: Sage not installed).
Run here with PARI 2.15.4 (cypari): `nfinit(x^2+5)` gives zk [1, x] and disc -20; `idealprimedec` gives one ramified prime above 2 (e=2), two primes above 3 and above 7, one inert prime above 11 (f=2); `bnfinit(x^2+5).cyc` is [2] and `bnfcertify` returns 1; `factormod` of x^2+5 mod 11 is irreducible. `polgalois(x^8-2)` fails without the galdata files, as the PARI manual says for degree 8 and above.

## Gotchas
- Using ℤ[√d] when d ≡ 1 (mod 4) gives the wrong ring and wrong factorisations at 2.
- Factoring f mod p over 𝔽_p is about the polynomial, not about p in ℤ: compute it
  carefully (or with `factormod`/`factor(f*Mod(1,p))` in PARI).
- Element factorisation can fail to be unique (6 = 2·3 = (1+√−5)(1−√−5)); ideal
  factorisation is always unique in O_K — that is the point.
- Uncertain: PARI function names/flags occasionally change between versions; check `?`
  help in your installation.

- [ ] O_K identified (or p shown not to divide the index).
