# Spirometry quality and PFT interpretation

> General clinical/professional reference, not a substitute for independent clinical judgement, current guidelines, or verified dosing references.

**Goal:** produce spirometry that meets the standard, then read the full PFT set with
reference equations and z-scores rather than fixed percentages.

## 1. Before the test
- **Calibration:** 3-L syringe check daily (within ±2.5%, i.e. ±3% including syringe
  error per 2019 standard); log ambient temperature/pressure if the system needs it.
- Record **height measured (not stated), age, sex at birth and the reference set**
  (GLI 2012 or race-neutral GLI Global 2022 — know which your system uses; switching
  changes predicted values).
- Withhold bronchodilators if testing reversibility (SABA 4–6 h, LABA 24 h, LAMA 36–48 h
  — check lab protocol). Avoid testing within weeks of eye/chest/abdominal surgery,
  recent MI, untreated pneumothorax.

## 2. Doing the manoeuvre
- Seated, nose clip, tight lip seal. Maximal inspiration → **blast out** without
  hesitation → keep blowing to plateau.
- **Acceptability** (each blow): back-extrapolated volume < 5% FVC or 0.100 L; no cough
  in first second; no glottic closure/leak; end-of-forced-expiration = plateau
  (< 0.025 L in last 1 s) or ≥ 15 s exhalation, or the patient cannot continue.
- **Repeatability:** best two FEV1 and FVC within **0.150 L** (0.100 L if FVC ≤ 1 L).
- Up to 8 attempts usually; stop earlier if fatigue or symptomatic.
- **Grade** A–F (2019): A = ≥ 3 acceptable, within 0.150 L; lower grades still
  reportable with caveats — report the grade.

## 3. Interpretation (2022 ERS/ATS approach)
- Use the **lower limit of normal (LLN, z-score −1.645)**, not a fixed FEV1/FVC 0.70.
  The fixed ratio over-diagnoses obstruction in elderly and under-diagnoses in young.
  (GOLD still uses 0.70 for COPD — note both if your service requires.)
- **Obstruction:** FEV1/FVC < LLN. Severity by FEV1 z-score: > −2.5 mild, −2.5 to −4
  moderate, < −4 severe.
- **Low FVC with normal ratio** → possible restriction **or** PRISm (preserved ratio
  impaired spirometry) → need lung volumes; spirometry alone cannot diagnose
  restriction.
- **Bronchodilator response (2022):** change > **10% of the predicted value** in FEV1 or
  FVC (replaces the old 12% and 200 mL rule).

## 4. Lung volumes and gas transfer
- **Restriction:** TLC < LLN (plethysmography preferred; helium dilution underestimates
  with air trapping).
- Air trapping: RV/TLC > ULN. Hyperinflation: TLC > ULN.
- **DLCO/TLCO:** correct for haemoglobin. Pattern guide:
  - Low DLCO + low volumes → ILD (KCO may be normal or high in extraparenchymal).
  - Low DLCO + obstruction → emphysema.
  - **Isolated low DLCO** with normal spirometry/volumes → pulmonary vascular disease,
    anaemia, early ILD — think PH.
  - High DLCO → polycythaemia, alveolar haemorrhage, asthma, obesity.

## Gotchas
- Wrong height or sex entry → wrong predicteds; check before interpreting.
- Submaximal effort mimicking restriction (low FVC, slow rise) — look at the curve
  shape, not just numbers.
- Comparing serial tests run against different reference equations.
- Upper airway obstruction: flattened inspiratory and/or expiratory loop — inspect the
  flow-volume loop every time.

## Verify
- [ ] Calibration logged; reference equation stated on report.
- [ ] Acceptability and repeatability met; grade reported.
- [ ] Interpretation uses LLN/z-scores; flow-volume loop inspected.
- [ ] Restriction only called with TLC.
- [ ] DLCO Hb-corrected; pattern linked to clinical question.
