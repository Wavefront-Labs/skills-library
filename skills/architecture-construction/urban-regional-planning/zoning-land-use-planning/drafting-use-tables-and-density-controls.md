# Zoning — use tables, density controls and rezoning tests

**Goal:** controls that say clearly what may be built where, produce the built form the
plan intends, and can be applied consistently by an assessor who wasn't in the room.

Terminology differs: US "zoning ordinance/code", UK "local plan policies" (UK planning
is discretionary, not zoning-by-right), Australian "planning scheme", etc. The drafting
logic below transfers; legal form and process are set by your jurisdiction's statute.

## 1. The use table
- Rows = **defined uses**, columns = zones; cells = Permitted (by right), Conditional/
  Special (needs approval against criteria), or Prohibited. Add a column for the
  specific use standards section.
- **Definitions matter more than the table.** Every use in the table needs a definition;
  undefined uses become disputes. Use nested/grouped definitions (e.g. "retail" includes
  "shop" and "kiosk") so new business types fall somewhere.
- Include an **"unlisted uses"** rule: either prohibited unless listed, or the
  administrator determines the most similar listed use.
- Avoid controlling *who* uses a building (ownership, tenure) unless your law allows it;
  control the activity and its impacts.
- Ancillary/accessory uses (home office, small residential units) need clear limits
  (floor area, employees, parking).

## 2. Density and form controls
- **FAR (floor-area ratio)** = gross floor area ÷ site area. Controls bulk, not shape.
- **Dwellings per hectare/acre** controls unit count, not size — on its own it pushes
  developers towards larger units.
- **Height** in metres *and/or* storeys (storeys alone invite tall floor-to-floor
  heights); define the measuring point (natural ground vs finished, to parapet or ridge).
- **Setbacks, lot coverage, landscaped area, minimum lot size/frontage.**
- Controls interact: test them together. A FAR of 2.0 is unachievable if height and
  setbacks only allow an envelope of 1.4 — and then FAR is not the binding control.

## 3. Test on real lots
Before adoption, model 3–5 typical lots (small/narrow, corner, large/deep, sloping).
For each: draw the building envelope from height, setbacks and coverage; calculate the
achievable floor area and units; check parking and open-space requirements fit.
Typical findings: minimum lot widths that block infill, parking rules that make small
sites infeasible, setbacks that leave unusable side strips.

## 4. Overlays
Overlays (heritage, flood, airport, transit) add or vary controls on top of base zones.
State precedence rules explicitly: which prevails when overlay and base conflict.

## 5. Assessing a rezoning (map amendment)
Consider and document:
- Consistency with the adopted comprehensive/strategic plan.
- Compatibility with surrounding uses and the transition between zones.
- Infrastructure capacity (water, sewer, roads, schools).
- Whether it benefits one owner at odds with the plan (a "spot zoning" risk in US law).
- The full range of uses the new zone allows by right — not just the applicant's proposal.

## 6. Non-conforming uses
Existing lawful uses that the new code prohibits usually continue; draft rules for
expansion, discontinuance (e.g. lapse after a period) and rebuilding after damage, per your law.

## Gotchas
- Silent conflicts: two sections controlling the same thing differently. Search the code
  for every reference to a term before changing it.
- Measurement rules (height datum, what counts as floor area) decide outcomes; define them once.
- Copying another city's code imports its definitions and assumptions.

## Verify
- [ ] Every use in the table is defined; unlisted-use rule present.
- [ ] Density, height and setback controls tested together on real lot types.
- [ ] Overlay precedence stated.
- [ ] Rezoning reports address plan consistency, compatibility, infrastructure and full use range.
- [ ] Legal review against enabling legislation before adoption.

*Uncertainty:* written as general practice; statutory process and legal limits (e.g.
on regulating tenure) vary by jurisdiction.
