# Running cornices in situ and fixing fibrous mouldings

**Goal:** a continuous moulding whose profile matches the drawing (or the surviving
original) with crisp members, true lines and invisible joints.

## 1. Capture the profile
- **New work:** draw the section full size from the detail drawing.
- **Repair:** take a profile from a surviving length — cut a thin slot and insert a
  card/zinc template, use a profile gauge, or take a "squeeze" (press clay or plasticine
  into a cleaned section, or cut out a small piece if consent allows). Photograph with a
  scale. For listed/heritage buildings, get consent before cutting anything.
- Transfer to sheet zinc (or aluminium), cut close with snips, file to the line, and
  **bevel the back** of the edge so only a sharp arris scrapes. This is the **profile**.

## 2. Build the running mould ("horse")
- Mount the profile on a timber stock, braced square, with a slipper (runner) that rides a
  **running rule** fixed to the wall and a nib/second slipper on the ceiling rule.
- Wax or seal timber parts so plaster doesn't stick.
- Run the empty mould along the rules first to check it clears everywhere and the
  profile sits where the line marks say.

## 3. Running in situ
1. Key and dampen the background; fix a core (lath, wire or a rough-plaster bulk "muffle")
   so the final coat is thin — a full-thickness pour of plaster cracks.
2. Lay on casting plaster (often gauged with a little lime putty to slow it) and pass the
   horse along, repeatedly, adding plaster to hollows. Work fast; gypsum gives a short
   window.
3. Final passes with a soupier mix to close the surface. Clean the profile between passes.
4. **Mitres and returns** can't be run — they're formed by hand after: cut back, then build
   up and work with joint rules and small tools to meet the run members exactly.

## 4. Fibrous plaster (cast lengths)
1. Run a reverse (or use a rubber/silicone mould from a master).
2. Cast: thin gauge coat of casting plaster, then **hessian scrim** dipped in plaster laid in,
   with timber laths embedded along the back for stiffness and fixing.
3. Demould when set, let dry before fixing.
4. Fix with screws through laths into framing/noggins (and plaster wads/adhesive per
   system). Large elements need mechanical fixing — never adhesive alone overhead.
5. **Joints:** cut square or mitred, butt, scrim across the back where reachable, fill the
   face with plaster and run a joint rule along the profile to carry members through.

## Gotchas
- Profile not back-bevelled → it drags and tears the surface.
- Running rule not straight/fixed → wavy cornice the eye picks up instantly.
- Too thick a single pour → cracks and heavy sag risk.
- Hardware in contact with wet plaster rusts and stains — use galvanised/stainless.
- Gypsum near damp walls (failed gutter) fails quickly; fix the water first.

## Verify
- [ ] Hold the original template against the finished run: no gaps at any member.
- [ ] String line or long straightedge along the run: no waves.
- [ ] Mitres meet with every member continuous.
- [ ] Fibrous elements mechanically fixed; no movement when pushed.
- [ ] Heritage consent/records completed (photos before/after, profile kept).
