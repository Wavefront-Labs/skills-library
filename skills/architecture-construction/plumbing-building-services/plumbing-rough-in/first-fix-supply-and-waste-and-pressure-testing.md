# First-fix supply and waste, and the pressure test

**Goal:** every pipe arrives exactly where the fixture needs it, is protected from fixings
and frost, and is proven leak-free before anyone hides it behind board or in concrete.

## 1. Setout from the fixture, not the frame
- Get the **fixture schedule** (make/model) before first fix — tap centres, waste
  height and outlet position differ between products. A wall-hung basin, a vanity and a
  pedestal all want different stubs.
- Mark on the floor/frame: fixture centrelines, finished floor level (FFL), finished wall
  line (board + tile thickness).
- Typical heights (check fixture sheets): basin waste ~450–550 mm above FFL, basin
  supplies ~500–550 mm; shower mixer ~1,000–1,100 mm; kitchen sink waste ~400–500 mm.

## 2. Supply pipework
- Size from the run and flow needed (local code tables, or the engineer's design).
  Residential branches are typically DN15/½ in, mains DN20/¾ in — **verify locally.**
- Route the shortest sensible way; avoid running through exterior walls in cold climates
  (frost) and hot-water runs alongside cold.
- Hot pipes insulated (energy codes often require it), cold pipes lagged where
  condensation or frost is a risk.
- Clip at the manufacturer's spacing (PEX more often than copper); allow for thermal
  expansion on long PEX runs — don't clip it rigidly tight.
- **Nail plates** wherever a pipe is within ~30–40 mm of a stud face. Fasteners through
  pipes are the classic first-fix failure.
- Through slabs: sleeve the pipe so it can move and isn't in contact with concrete.
- Fit hammer arrestors if quick-closing valves (washing machine, solenoids) are planned.

## 3. Waste pipework (drain rough-in)
- Grade, vent and trap sizes per drainage-waste-vent rules (see that skill). Typical
  minimum fall ~1:40 to 1:60 for small branches — local code governs.
- Stub-outs plumbed to the finished wall line, capped/taped against debris.
- Under slabs: set to level/grade, fully bedded, and inspected before the pour.

## 4. Capping off
- Every supply end capped (soldered/press cap, or test plugs). Every waste end capped.
- Label hot/cold. Photograph every wall with a tape measure in shot before lining —
  priceless later when someone wants to hang a cabinet.

## 5. Pressure testing
- **Supply:** fill, bleed air at the highest points, pressurise to the code test pressure
  (commonly ~1.5× working pressure or a fixed value such as 1,500 kPa / ~200 psi for a
  set period — **your jurisdiction specifies exact numbers and duration**).
  Isolate and watch a gauge for the hold time; a drop means a leak.
  Air testing of plastic pipe is restricted by many manufacturers — check before using air.
- **Drainage:** water test (fill to a head, typically to the top of the highest fixture
  or a set height, and hold) or air/smoke test, per code.
- Walk every joint during the test with the gauge holding. Booked inspections usually
  need the test live when the inspector arrives.

## Gotchas
- Roughing to the wrong fixture → cut-outs and re-plumbing after tiling.
- Forgetting tile thickness → stubs too short for escutcheons.
- Testing with air at high pressure on plastic → explosive failure risk.
- Leaving a test plug in a waste → flood at second fix.

## Verify
- [ ] Stub positions match the actual fixture data sheets.
- [ ] Nail plates over every pipe near a stud face.
- [ ] Supply held test pressure for the full time; drainage passed its water/air test.
- [ ] Photos taken of each wall before lining; inspection signed off.
