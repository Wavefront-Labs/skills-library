# Running live quizzes and reading the response data

**Goal:** use a live-response platform to find out what the class understands — and act
on it — rather than just running a fun game where the fastest students win.

## 1. Pick the tool for the job
| Need | Typical fit |
|---|---|
| High-energy retrieval game, whole class | Kahoot, Blooket, Gimkit |
| Self-paced practice with per-student reports | Quizizz (rebranded **Wayground** in 2025 — *verify current name*), Kahoot student-paced mode |
| Interactive slides with questions embedded in teaching | Nearpod, Pear Deck |
| Opinion polls, word clouds, open text, anonymous questions | Mentimeter, Slido |
| No student devices | Plickers (printed cards scanned by your phone) |
Free tiers change often and commonly cap participants, question types or report access;
check before planning a lesson that depends on a feature.

## 2. Design the questions for diagnosis
- Write the question **first**, then put it in the tool — the tool's templates nudge you to trivia.
- Use **misconception-based distractors** (each wrong answer reveals a specific error; see
  education-training.pedagogy-and-teaching-method.formative-assessment.hinge-questions-exit-tickets-and-responsive-reteaching).
- 6–12 questions is enough for a check; 30-question games test stamina.
- **Timer:** speed-scored games (Kahoot's points reward speed) penalise careful thinkers and
  reward guessing. For diagnostic questions, lengthen the timer (60–120 s), switch off or
  ignore speed points, or use a student-paced mode.
- Use images and the platform's math/equation support where available; check rendering on a
  phone screen before class.
- Name questions sensibly — the report lists them by text, so "Q7" is useless later.

## 3. Run it
1. **Nicknames:** require real first names or set the tool to use roster/login so reports are
   usable; turn on the nickname filter or name generator to prevent offensive names.
2. **Pause after each question** in teacher-paced mode to show the answer distribution. Ask
   "Why might someone pick C?" before revealing the correct answer.
3. **Re-ask** a question students split on after a short discussion and compare distributions.
4. For anonymous polls (Mentimeter), moderate open-text responses if the tool supports it before
   showing them to the class.

## 4. Read the report afterwards
Most platforms export per-question and per-student results (often to a spreadsheet).
- **Per question:** sort by % correct. Anything under roughly 60% is a re-teach candidate;
  look at which wrong option dominated.
- **Per student:** list who scored low on the questions tied to today's objective (not overall
  score — that includes warm-up trivia).
- **Distractor pattern:** one dominant wrong answer = shared misconception → whole-class
  re-teach. Scattered wrong answers = guessing/weak knowledge → more practice.
- Save the report alongside the lesson; reuse the same questions later as retrieval and compare.

## Gotchas
- **Engagement isn't learning.** Leaderboards motivate the top quarter and can demoralise the
  rest; consider hiding the podium or using team mode.
- **Accounts and privacy:** student logins, data retention and age limits (e.g. COPPA in the US,
  GDPR/UK GDPR) — use only tools approved by your school, and avoid collecting more personal
  data than needed.
- **Device and Wi-Fi failure** — always have a paper fallback (mini-whiteboards or printed ABCD
  cards).
- **Copied public quizzes** contain errors; check every answer key before using one.
- *Unconfirmed:* specific feature names, plan limits and the Quizizz/Wayground naming change
  should be checked against current vendor documentation.

## Verify
- [ ] Every question tests the lesson objective and has diagnostic distractors.
- [ ] Timer and scoring settings don't reward speed on thinking questions.
- [ ] Students were identifiable in the report (roster or real names).
- [ ] You paused on split questions and discussed the wrong answers before revealing.
- [ ] After class you listed the re-teach questions and students from the report.
