# Running assignment workflow in Google Classroom

**Goal:** a class where students always know where work is, every submission is
accounted for, and grading and returning work doesn't eat your evening.

*Menu names below are from the web version of Classroom and change periodically; feature
availability also depends on your school's Google Workspace for Education edition
(Education Fundamentals vs Plus). Check against the current Help Center.*

## 1. Set up the class once
- **Create class** › name it consistently (e.g. "Y9 Science 9B 2026–27"); add **co-teachers**
  via People so cover staff can access it.
- **Settings:** decide whether students can post/comment on the Stream; set the **class code**
  or use your admin's roster sync instead of codes if available.
- **Grading** settings: choose *Total points* or *Weighted by category*, create **grade
  categories** (e.g. Homework 20%, Tests 50%), and decide whether students see the overall grade.
- **Classwork › Create › Topic** for each unit or week. Put a "Start here" topic at the top with
  the course outline and expectations. Topics are the main navigation students use.

## 2. Post an assignment properly
**Classwork › Create › Assignment**:
1. Clear title with a date or lesson number; instructions that stand alone (absent students read
   them without you).
2. **Attach a Google Doc/Slides/Sheet and choose "Make a copy for each student"** — the
   default "Students can view file" means nobody can edit it. This is the most common mistake.
3. Set **points**, **grade category**, **due date and time**, and **topic**.
4. Add a **rubric** (Create rubric or reuse one) if the work is criterion-graded.
5. Use **Schedule** to post in advance, and post to **multiple classes** at once if you teach
   parallel groups.
6. For quizzes, **Quiz assignment** creates a linked Google Form; turn on *Grade importing* so
   scores flow into the gradebook. Locked mode is available only on managed Chromebooks.

## 3. Collect, grade and return
- Open the assignment › **Student work** to see *Turned in / Assigned / Missing*.
- Grade in the **grading tool** (opens each student's file with rubric and comment bank
  alongside). Add **private comments** for individual feedback; use the comment bank for
  recurring notes.
- **Return** — work isn't visible to students as graded until you return it. Grades saved as
  "draft" stay invisible. You can select several students and return together.
- Returned work becomes editable again by the student, so they can act on feedback and resubmit.

## 4. Chase missing work
- Classroom flags work as **Missing** after the due date if not turned in; students who
  "unsubmit" also fall back to not-turned-in, which surprises people.
- Use the **Grades** tab to scan the whole class; sort to find students with several missing items.
- Email or private-comment the missing list directly from Student work.

## 5. Guardian summaries
If your admin has enabled it, invite guardians from **People › Invite guardians**. They get an
email summary (daily or weekly) of upcoming and missing work — they do **not** get access to the
class itself.

## Gotchas
- **"View" vs "Make a copy"** — check every attachment before posting; changing it after posting
  isn't possible for that assignment in many cases, so you may have to repost.
- **Due-date time zone** — "due at 11:59 pm" is in the student's local time zone settings; agree a
  time and say it explicitly.
- **Material vs Assignment** — Material posts aren't graded or tracked; use Assignment for anything
  you need submitted.
- **Archive** old classes at year end rather than deleting them; you can still reuse posts.
- **Student data:** follow your school's policy on what you put in comments and who you invite.

## Verify
- [ ] Classwork is organised by topic and a student can find this week's work in one click.
- [ ] Every editable attachment uses "Make a copy for each student".
- [ ] Assignments have points, category, due date and (where needed) a rubric.
- [ ] Graded work has been *returned*, not left as draft.
- [ ] The Grades tab shows no unexplained Missing items older than a week.
