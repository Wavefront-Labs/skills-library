# Choosing accommodations vs modifications for inclusion

**Goal:** a student with a disability learns the same curriculum alongside peers, with the
smallest set of supports that removes their specific barriers — and you can tell whether
each support is changing *how* they learn or *what* they're expected to learn.

## 1. The core distinction
| | Accommodation | Modification |
|---|---|---|
| Changes | **how** the student accesses or shows learning | **what** is learned or the standard of mastery |
| Example | read math test aloud; extended time; type instead of write | fewer/simpler items; alternate grade-level text; different rubric |
| Consequence | grade/credential means the same thing | may affect grading, credits, diploma eligibility — *check state rules* |

Rule of thumb: **accommodate first; modify only when accommodation can't give access**
and the IEP team agrees. Note: reading a *reading-comprehension* test aloud changes the
construct being measured — whether something is an accommodation depends on what's being
assessed.

## 2. Pick by barrier, using four categories
For each class, name the task demand and the barrier, then choose from:
- **Presentation:** large print, audio/text-to-speech, read-aloud, fewer items per page,
  visual supports, pre-taught vocabulary, guided notes.
- **Response:** speech-to-text, scribe, oral answers, calculator, graphic organiser,
  word bank, typed responses.
- **Setting:** reduced-distraction space, preferential seating, noise-cancelling headphones,
  small-group testing.
- **Timing/scheduling:** extended time, breaks, chunked tasks, tests split across days.
Choose those the student **already uses in instruction**; testing-day-only supports
rarely help and may not be allowed on state tests unless used routinely.

## 3. Build access into the lesson (UDL)
Design the lesson so many supports are available to everyone: multiple means of
**engagement** (choice, relevance), **representation** (text + audio + visual), and
**action/expression** (write, record, build). Fewer individual accommodations then need
to be bolted on, and students aren't singled out. *UDL guidelines were revised to v3.0 in
2024; use the current version.*

## 4. Low-tech supports that pay off
Visual schedule, first–then board, checklists for multi-step tasks, colour-coded
folders, timers, highlighted texts, sentence starters, fidget/seating options, a
"break card". Try these before high-tech assistive technology, then escalate via an AT
assessment if needed.

## 5. Co-teaching models (gen-ed + special-ed teacher)
| Model | When it fits |
|---|---|
| One teach, one observe | collecting data on target students |
| One teach, one assist | brief; overused — the specialist becomes a classroom aide |
| Station teaching | content in chunks; small groups rotate |
| Parallel teaching | halve group size for discussion/practice |
| Alternative teaching | pre-teach/reteach a small group (rotate who's in it) |
| Team teaching | both deliver together; needs trust and planning time |
Plan weekly together: which model, who leads, which students need which supports in
each activity.

## 6. Make it happen and check it works
- One-page **support summary** per student for every teacher, substitute and aide.
- Monitor: is the support **used**, and does performance change? Drop supports that
  don't help (they can increase dependence) and fade where possible.
- Ask the student — older students often know which supports help and which embarrass.

## Gotchas
- **Modifying by default** (lower expectations) because accommodations take more effort.
- **Too many accommodations** listed "just in case" — teachers can't track 20 items.
- **Paraprofessional as the only support** — can isolate the student and stand between
  them and the teacher.
- **Testing accommodations not allowed** on the state test or exam board; check the
  current accommodations manual each year.
- Terminology varies: UK "reasonable adjustments", "access arrangements" for exams.

## Verify
- [ ] Each support is labelled accommodation or modification, and modifications are
      team-approved with consequences understood.
- [ ] Each support links to a named barrier in a named task.
- [ ] Testing accommodations are also used in daily instruction and permitted on tests.
- [ ] Co-teaching model is planned per lesson, not defaulted to one-teach-one-assist.
- [ ] There's evidence (data or student report) each support is used and helping.
