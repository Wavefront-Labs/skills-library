# Writing a BIP from an FBA and monitoring fidelity

**Goal:** a behaviour intervention plan (BIP) where every strategy follows from the
*function* the FBA identified, the student gets a better way to meet that need, and staff
actually run it the same way every day.

*Assumes an FBA has been completed by qualified staff (school psychologist, BCBA, behaviour
specialist). Under US IDEA, behaviour that impedes learning must be considered in the
IEP, and an FBA/BIP is required in certain disciplinary situations (§300.530). Check
state rules on who may conduct an FBA and on restraint/seclusion.*

## 1. Start from the summary statement
The FBA should give a testable hypothesis:
> **When** [antecedent/setting event] **, [student] does** [defined behaviour] **to**
> [function: get attention / escape-avoid / get item or activity / sensory] **, and this is
> maintained by** [consequence].

Example: *During independent writing (antecedent), after little sleep (setting event),
Jo tears up the worksheet and leaves the room (behaviour) to escape writing (function),
maintained by being sent to the office.* No clear hypothesis → go back; don't write the BIP.

## 2. Competing behaviour pathway
Draw three paths from the same antecedent:
- **Problem behaviour** → current payoff.
- **Replacement behaviour** — gets the *same* payoff in an acceptable way (Jo asks for a
  break using a card).
- **Desired behaviour** — the long-term goal (Jo completes the writing task).
The replacement must be **easier and faster** for the student than the problem behaviour,
or it won't compete.

## 3. The four parts of the plan
1. **Setting-event and antecedent strategies** — make the behaviour unnecessary: shorter
   writing chunks, speech-to-text option, choice of topic, check-in when the student
   arrives tired, a visual timer.
2. **Teaching strategies** — explicitly teach the replacement (model, role-play, practise
   when calm), plus skills behind the desired behaviour (e.g. writing instruction).
3. **Consequence strategies** —
   - Reinforce the replacement **immediately and every time** at first (break granted
     when the card is used), then thin the schedule ("write 2 lines, then break").
   - Reinforce desired behaviour richly.
   - Respond to the problem behaviour so it **no longer pays off** (here: escape doesn't
     happen; the task is reduced but resumes). Plan for an **extinction burst** — it
     often gets worse before better.
   - Avoid consequences that deliver the function (sending an escape-motivated student
     out of class *rewards* it).
4. **Crisis/safety plan** — only for dangerous behaviour: early warning signs, de-escalation
   steps, who responds, when to call for help, and restraint/seclusion only as allowed by
   law and policy, with documentation and parent notification.

## 4. Define success and data
- Operational definitions for the problem and replacement behaviours (observable,
  countable: "paper torn or student leaves room without permission").
- Measure: frequency, duration or interval recording; set a baseline and goal.
- Review at a set date (e.g. 4–6 weeks) with graphed data.

## 5. Fidelity monitoring
- Create a **one-page checklist** of plan steps; staff self-rate daily and a
  supervisor observes weekly at first.
- Train every adult who works with the student, including lunch and bus staff.
- If behaviour doesn't improve, **check fidelity before changing the plan** — a plan run
  40% of the time hasn't been tested.

## Gotchas
- **Function-blind plans**: generic sticker charts and loss-of-recess for every student.
- Punishment-only plans with no replacement behaviour — behaviour returns or a worse
  one replaces it.
- Replacement taught only *during* crises; teach it when calm.
- Forgetting **setting events** (sleep, medication, home changes).
- Escape-maintained behaviour + time-out = reinforcement.

  district's procedures.)*

## Verify
- [ ] A summary statement names antecedent, behaviour, function and maintaining consequence.
- [ ] The replacement behaviour serves the same function and is easier than the problem.
- [ ] Plan has antecedent, teaching, consequence and (if needed) crisis sections.
- [ ] Behaviours are operationally defined with baseline and graphed data.
- [ ] Fidelity is measured and checked before any plan change.
