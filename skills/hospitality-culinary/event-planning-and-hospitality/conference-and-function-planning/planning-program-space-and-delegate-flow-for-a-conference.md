# Planning program, space and delegate flow for a conference

**Goal:** a conference where delegates get to every session on time, are fed and
caffeinated without queuing through the next talk, and every speaker's slides and
mic work first time.

## 1. Program shape
- Start with objectives and audience size. Build a grid: days × time slots × rooms.
- Plenary sessions at the start and end of each day; breakouts in between.
- Session length 45–60 min is common; **15 minutes minimum transition** between
  sessions in different rooms (longer for large venues or floors apart).
- Breaks: mid-morning and mid-afternoon 20–30 min; lunch 45–60 min (longer if
  networking is a goal).
- Don't schedule the most popular topic in the smallest breakout — ask
  registration for session preferences early.

## 2. Space allocation
- **Plenary room** set theatre or cabaret for the full delegate count plus a margin.
- **Breakouts** sized for expected attendance per session, not delegates ÷ number of
  rooms — popular sessions overflow.
- Separate **catering/exhibition space** so breaks don't happen in session rooms
  (rooms then need resetting).
- Registration area near the main entrance with queue space, power, and Wi-Fi.
- Speaker ready room (quiet, with screen) for slide checks.
- Contract terms to watch: **room block attrition** (penalty if delegates don't book
  bedrooms), **F&B minimum spend**, cancellation scale, AV exclusivity.

## 3. AV coordination
- Specification per room: projector/LED, screen size relative to depth, lectern
  mic, lapels/handhelds (count simultaneous speakers on panels), confidence monitor,
  laptop or a central playback machine, clicker, recording/streaming.
- Collect slides by a deadline in an agreed format and aspect ratio (16:9 typical);
  load centrally.
- **Technical rehearsal** for plenary sessions; mic checks for every speaker before
  their session.
- One AV technician per busy room or a roaming tech for simple breakouts.

## 4. Catering timing
- Coffee break throughput: one service point per ~100 delegates (double-sided
  stations help); pre-pour or self-serve to speed it.
- Lunch: buffet stations or grab-and-go for short lunches; plated only if the
  program allows 60+ minutes.
- Dietary needs collected at registration; labelled food; separate dietary station.
- Water in every room. Food out **before** the session ends, not when people arrive.

## 5. Registration and delegate flow
- Online registration with session choices, dietary needs, accessibility needs.
- On-site: pre-printed badges sorted alphabetically or self-print kiosks. Staff for
  peak arrival — roughly one desk per 100–150 delegates arriving in the first hour,
  plus a problems desk.
- Signage at every decision point; room names matching the app/program.
- Ushers/room monitors close doors at start time, count attendance, manage overflow.
- Watch pinch points (lifts, stairs, cloakroom) and stagger session ends if necessary.

## 6. Production schedule
A minute-by-minute document for the event team covering bump-in, rehearsals,
session cues, break turn-overs, room resets and bump-out. Daily morning briefing
with venue, AV and catering leads.

## Gotchas
- 5-minute transitions between floors — sessions start late all day.
- Breakout rooms sized evenly; the popular one overflows into the corridor.
- Slides collected on the morning, in random formats.
- Coffee lines at one station for 400 people.
- Attrition clause triggered because the room block was over-estimated.

## Verify
- [ ] Grid built with realistic transitions and breaks.
- [ ] Breakouts sized by expected attendance; overflow plan exists.
- [ ] Contract clauses (attrition, F&B minimum, cancellation) understood.
- [ ] AV spec per room confirmed; slides collected centrally; rehearsals scheduled.
- [ ] Catering stations sized for throughput; dietary needs labelled.
- [ ] Registration staffed for peak; signage at every junction.

*Uncertain:* throughput ratios are planning estimates; validate against venue
experience and past event data.
