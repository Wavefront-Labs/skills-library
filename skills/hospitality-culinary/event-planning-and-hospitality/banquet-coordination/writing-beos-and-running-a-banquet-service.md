# Writing BEOs and running a banquet service

**Goal:** a function where the room, food, timing and bill all match what the
client signed — because everything was written on one document that every
department worked from.

## 1. The BEO (banquet event order)
One BEO per function (per room per time slot). Everything not on it doesn't exist.
Sections:
- **Header:** event name, client contact (on-site name + mobile), date, room, times
  (access, start, meal, end, out), BEO number and revision.
- **Numbers:** expected, **guarantee** (final number billed — usually due a set
  number of working days before; 72 hours is common), and **set** number.
- **Room set:** style + diagram reference, head table, stage, dance floor, registration,
  cake/gift tables.
- **Menu:** each course with portion and service style; dietary counts by type with
  names/seat or table numbers where possible.
- **Beverage:** package or consumption, bar times, brands, wine with which course.
- **AV & other:** lectern, mics, projector, power, lighting.
- **Timeline (run sheet):** speeches, courses, toasts, entertainment.
- **Billing:** prices, service charge, deposit, payment method.
- Client signature; **revisions numbered and redistributed** to kitchen, banquets,
  AV, engineering, front office.

## 2. Room sets (approximate capacities — check fire limits)
| Style | Use | Space rule of thumb |
|---|---|---|
| Rounds of 8–10 (1.5–1.8 m tables) | Dinners, galas | ~1.1–1.4 m² per person |
| Cabaret (rounds, one side open) | Dinner + presentation | slightly more |
| Theatre | Talks | ~0.6–0.9 m² |
| Classroom | Training | ~1.2–1.5 m² |
| U-shape / boardroom | Meetings, small groups | most space per head |
Leave service aisles (≥ ~1.5 m between table edges for trays), clear fire exits,
and **never exceed the room's legal capacity** (often posted). Figures vary by
source and code.
**Over-set** a few percent above guarantee (e.g. 3–5%) for no-notice extras; agree
billing for extras in the contract.

## 3. Service timing
- **Plated:** staffing commonly one server per 1–2 tables of 10 for dinner (more for
  fine service). Clear course before the next goes; captain cues each course.
  Typical: entrée 15–20 min after seating, main 25–35 min later, dessert after
  speeches — but **the run sheet rules**.
- **Buffet:** one buffet line per ~75–100 guests (double-sided lines halve the queue);
  release tables in order; keep it replenished and wiped; time limits for
  hot/cold holding per food-safety rules.
- **Family style:** platters per table, needs more table space.
- Dietary meals: printed list to the captain and kitchen; serve them first, same time.

## 4. On the day
1. Room check against the BEO and diagram 2 hours out (or more).
2. **Pre-function briefing** with staff: timeline, sections, dietary seats, VIPs,
   speeches (silence during them — no clearing).
3. Meet the client at agreed time; confirm last changes and the client's decision
   maker on site.
4. Captain runs the floor; banquet manager handles client and kitchen calls.
5. Track actual numbers served (for billing above guarantee).
6. Client signs off actual numbers and extras at the end.

## Gotchas
- Verbal changes not written into a revised BEO.
- Dietary meals listed by count only, so servers can't find the guest.
- Clearing during a speech.
- Guarantee date passing without chasing the client.
- Under-sized buffet for numbers → 40-minute queues.

## Verify
- [ ] BEO complete (all sections), signed, latest revision with every department.
- [ ] Room set matches diagram, aisles and exits clear, within legal capacity.
- [ ] Guarantee received on time; over-set agreed.
- [ ] Dietary meals mapped to tables/seats.
- [ ] Briefing done; course cues follow the run sheet.
- [ ] Actual numbers and extras signed off by the client.

*Uncertain:* space and staffing ratios are common industry estimates; local fire
code and venue standards override them.
