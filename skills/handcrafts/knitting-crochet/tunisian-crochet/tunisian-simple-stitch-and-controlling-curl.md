# Tunisian simple stitch and controlling curl

**Goal:** firm, even Tunisian fabric with straight edges that lies flat — the curl
being the thing that puts most people off.

## 1. How it works
Each row has two passes, both worked with the **right side facing** (no turning):
- **Forward pass:** pick up a loop in each stitch, keeping all loops on the hook.
- **Return pass:** yarn over, pull through 1 loop; then *yarn over, pull through 2*
  repeatedly until one loop remains (which is the first stitch of the next row).
Hooks: a long **Tunisian/afghan hook** with a stopper, or a **cabled** hook for wide
pieces. Use **1–2 sizes larger** than you'd use for regular crochet with the same yarn
(often more for the knit stitch).

## 2. Core stitches
- **Tunisian simple stitch (Tss):** insert hook front-to-back under the front vertical
  bar, yarn over, pull up a loop. Dense, woven look.
- **Tunisian knit stitch (Tks):** insert hook between the front and back vertical bars,
  under the horizontal strands, pull up a loop. Looks like knit stockinette — curls most.
- **Tunisian purl stitch (Tps):** yarn to the front, insert under front bar, yarn
  over from the back, pull up a loop.
- **Last stitch:** work it under **both** strands of the edge stitch (both loops of the
  last vertical bar) for a firm edge. Skipping this is why edges go wavy and the piece
  narrows.

## 3. Foundation row
Chain the number of stitches; on the forward pass pick up loops in the **back bumps**
of the chain for a neat bottom edge that matches the bind-off. Count loops on the hook
at the end of every forward pass.

## 4. Controlling curl
The fabric curls toward the front because all loops are pulled forward. Reduce it:
- **Bigger hook** — the largest single factor. Go up until the fabric drapes.
- **Loose foundation chain** (use a hook a size bigger for the chain).
- **Start with a few rows of Tps or a garter-like combination** (alternating Tks/Tps
  rows) and border with regular crochet sc/slip stitch.
- Choose **stitch patterns** with purl components or Tunisian full stitch; pure Tks is
  the worst offender.
- **Blocking:** wet or steam blocking flattens wool and cotton substantially; acrylic
  steam-block lightly. It reduces but rarely eliminates curl in Tks.
- A crochet border all round anchors edges.

## 5. Bind off
Slip stitch across in pattern: insert as for the stitch, pull loop through the stitch
**and** the loop on the hook. Keep it loose — a tight bind-off pulls the top in.

## 6. Colourwork and wide pieces
- Simplest stripe: finish a forward pass, then work the **whole return pass in the new
  colour** (yarn over with it, pull through 1, continue). For blocks of colour within a
  row, change yarn on the return pass at the colour boundary; carry the unused colour
  loosely behind.
- Tunisian **entrelac** builds diagonal blocks; good use of variegated yarn.
- **Double-ended hooks** let you work in the round or reversible two-colour fabric.

## Gotchas
- **Slanting fabric:** usually from inconsistent return-pass tension or always
  starting the return pass with "through 2" instead of "through 1".
- **Hook too long and heavy:** rest the hook in your lap; use a cabled hook for blankets.
- Gauge must include several rows; it compresses vertically more than regular crochet.

## Verify
- [ ] Loop count correct after each forward pass.
- [ ] Last stitch worked under both edge strands; edges straight.
- [ ] Return pass starts with "through 1".
- [ ] Fabric lies flat (or curl reduced to what blocking/border fixes).
- [ ] Bind-off same width as the body.
