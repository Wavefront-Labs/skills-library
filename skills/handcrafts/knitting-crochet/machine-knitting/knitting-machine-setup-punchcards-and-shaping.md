# Knitting machine setup, punchcards and shaping

**Goal:** clean machine-knit fabric at a known gauge, patterned and shaped, without
dropped stitches or jammed carriages. Brand details vary (Brother/KnitKing,
Silver Reed/Studio, Passap); check your manual for exact lever names.

## 1. Match machine to yarn
| Machine gauge (needle pitch) | Yarn |
|---|---|
| **Standard** (~4.5 mm) | fine: 2-ply–4-ply / fingering, coned yarn |
| **Mid-gauge** (~6.5–7 mm) | sport–DK |
| **Bulky/chunky** (~9 mm) | worsted–aran |
Too thick a yarn jams and breaks hooks. Coned yarns are often **oiled or waxed** for
machine knitting; they bloom after washing — swatch washed.

## 2. Setup
1. Clamp the bed level and solid; wobble = dropped stitches.
2. **Yarn mast:** yarn goes from the cone (on the floor, behind) up through the mast
   tension disc and spring, then to the carriage feeder. Set the take-up spring so it
   lifts the yarn smoothly at the end of each row.
3. Clean the bed: lint in the needle channels and sponge bar causes misbehaviour. Old
   machines often need a **new sponge bar** — the single most common fix for
   dropped stitches on a vintage Brother.
4. Oil per the manual (sparingly, wipe excess).

## 3. Cast on
- **E-wrap** cast-on: wrap each needle by hand; good for a finished edge.
- **Waste-yarn start:** knit several rows in waste yarn, a row of ravel cord, then the
  main yarn; remove waste later to pick up live stitches or hem.
- Hang a **cast-on comb** and claw weights to give downward tension; move weights up
  every 20–30 rows.

## 4. Tension and gauge
- Tension dial (stitch size) numbers: higher = looser.
- Knit a swatch at a middle setting, marking needles with contrast yarn at, e.g.,
  needle 20 left and right, and contrast rows every 20 rows. Wash, dry, measure the
  marked distance → stitches and rows per 10 cm. This tension swatch is your
  calculation basis; machine knitting gauge must be measured washed and relaxed.

## 5. Patterning
- **Punchcard** (most 24-stitch-repeat machines): insert the card, lock it on the first
  row, select needles on a preparatory row, then release.
  - **Fair Isle:** second yarn in the B feeder; floats behind.
  - **Tuck:** selected needles hold loops — textured, wider fabric.
  - **Slip/skip:** unselected needles don't knit — narrower, tighter fabric.
- **Electronic** machines read patterns from built-in memory, a pattern panel, or a
  computer connection (third-party interfaces exist; verify compatibility).

## 6. Shaping
- **Decrease/increase** with a **transfer tool**: move the edge stitch(es) inward
  (fully-fashioned decreases show as a neat line).
- **Short-rowing** with **holding position** (needles pushed fully forward, carriage set
  to hold): shoulders, darts, sock heels.
- **Ribber** for true rib; without one, hand-latch up ribs with a latch tool.

## Gotchas
- **Dropped stitches / carriage jam:** stop immediately; never force the carriage.
  Push needles back, rehang with a latch tool.
- **Bent needle hooks** cause a line of faults — replace (they pull out from the bed).
- **Weights too low** = loops pile up on needles and the carriage jams.
- Very hairy yarns (mohair) need a looser tension and sometimes waxing.

## Verify
- [ ] Machine gauge suits the yarn; mast and spring threaded correctly.
- [ ] Washed tension swatch measured from marked needles and rows.
- [ ] Weights moved up regularly; no loops riding high.
- [ ] Pattern card locked/released at the correct row; first pattern row correct.
- [ ] Shaping edges neat; no missed transfers.
