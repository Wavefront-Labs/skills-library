# Stitch heights, amigurumi and reading crochet patterns

**Goal:** follow any crochet pattern correctly — the first time — and make firm,
neat 3D toys and motifs.

## 1. US vs UK terms (the classic trap)
The same name means a **different stitch** in each convention:
| US | UK | Height (approx.) |
|---|---|---|
| slip stitch (sl st) | slip stitch | ~0 |
| single crochet (sc) | double crochet (dc) | 1 chain |
| half double (hdc) | half treble (htr) | 2 chains |
| double crochet (dc) | treble (tr) | 3 chains |
| treble (tr) | double treble (dtr) | 4 chains |
Check the pattern's abbreviation key: if it contains "sc", it's US. UK patterns never
use "sc". Australian patterns usually follow UK terms.

## 2. Turning chains and edges
- Turning chain height = stitch height (ch 1 for sc, ch 2 for hdc, ch 3 for dc).
- Whether the turning chain **counts as a stitch** varies by pattern — it changes stitch
  counts and edge straightness. Check the note. Wobbly or shrinking edges usually mean
  the first or last stitch is being missed or doubled.
- Count stitches at the end of every row for the first few rows.

## 3. Reading patterns
- `*sc in next 3 sts, 2 sc in next st; rep from * around (20)` — the number in brackets is
  the stitch count at the end of the round.
- `( )` or `[ ]` group stitches worked into the same place or repeated.
- **Charts:** symbols per stitch (an "x" or "+" for sc, a "T" with a slash for dc etc.);
  read rounds counter-clockwise from the centre (for right-handers), rows alternate
  direction. Charts are language-neutral — useful with patterns in other languages.

## 4. Amigurumi
1. **Hook** 1–2 sizes **smaller** than the yarn label suggests for tight fabric where
   stuffing won't show.
2. **Magic ring:** wrap yarn around fingers, work the first round of sc into the
   loop, pull the tail to close the centre completely.
3. **Spiral rounds:** don't join; mark the first stitch of each round with a
   stitch marker and move it up each round.
4. **Increase rounds** for a flat circle of sc: R1 6, R2 12, R3 18… (+6 per round);
   stop increasing to make the sides go straight up into a sphere/tube.
5. **Invisible decrease:** insert hook into the **front loops only** of the next two
   stitches, yarn over, pull through both, finish as sc. Neater than sc2tog.
6. **Stuff firmly** as you go, before the opening gets small; poly-fibre in small
   tufts. Lumps = big wads.
7. **Safety eyes** go in **before** closing; for children under 3, embroider eyes
   instead (choking hazard).
8. Close with a tapestry needle through the front loops of the last round; pull
   tight.

## 5. Motifs and granny squares
- Work the first round into a ring; corners are clusters with chain spaces between.
- Join-as-you-go (slip stitch into the neighbouring motif's chain space on the last
  round) saves seaming.
- Block motifs to the same size before joining.

## Gotchas
- **Yarn under vs yarn over** (yu vs yo) changes how sc looks; consistency matters more.
- Pattern size depends on **gauge** in crochet too — swatch for garments.
- Pulling too tight in the first loop of each stitch makes the next row hard to enter.

## Verify
- [ ] Pattern convention (US/UK) identified before starting.
- [ ] Stitch counts match the bracketed numbers each round.
- [ ] Edges straight; turning-chain rule followed.
- [ ] Amigurumi: no gaps showing stuffing; magic ring closed; eyes secure (or embroidered).
