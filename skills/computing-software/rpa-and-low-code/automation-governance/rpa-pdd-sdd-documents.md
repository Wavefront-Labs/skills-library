# Write the PDD and SDD
**Goal:** Document the as-is process and solution design.

- The Process Definition Document captures steps, systems, rules, exceptions and volumes; the Solution Design Document captures architecture, credentials, error handling and run schedule.
- Review with the business and IT security.
- Keep versioned.

## Gotchas
- Missing exception rules cause failures in production.

## Self-check
PDD walkthrough matches observed work.
