# Assess process suitability
**Goal:** Pick processes that RPA will run reliably.

- Prefer rule-based, high-volume, stable, digital-input processes with clear exceptions and low change rate.
- Score volume, rule clarity, system stability, data quality and risk; prefer an API or integration when one exists.
- Estimate effort and benefit.

## Gotchas
- Automating a broken process fixes nothing; simplify first.

## Self-check
A scored shortlist is signed off by process owners.
