# Set guardrails with environments and DLP
**Goal:** Allow makers to build safely.

- Provide personal-productivity space with limits, shared team environments and managed production environments; apply DLP policies by environment.
- Define who can create environments.
- Provide templates and training.

## Gotchas
- Unrestricted default environment sprawl is the common failure mode.
