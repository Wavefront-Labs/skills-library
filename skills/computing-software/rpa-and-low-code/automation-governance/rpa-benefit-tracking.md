# Track benefits and ROI
**Goal:** Measure the value delivered.

- Baseline manual handling time and error rates before; measure hours saved, errors avoided and licence/run costs after.
- Report per automation and review the portfolio.
- Retire low-value automations.

## Gotchas
- Unverified savings erode trust; measure from logs.

## Self-check
Benefits report reconciles with job logs.
