# Choose approval types
**Goal:** Use Start and wait for an approval correctly.

- Types: Approve/Reject first to respond, Approve/Reject everyone must approve, custom responses.
- Assign to users or groups; include details and item links.
- Approvals are stored in Dataverse.

## Gotchas
- Approver must have licensing access to the approvals centre.

## Self-check
Approver receives and responds to the request.
