# Transform arrays with Select, Filter array and Parse JSON
**Goal:** Process collections without loops.

- Select maps arrays; Filter array filters; Parse JSON with a schema gives typed dynamic content.
- Prefer these over Apply to each for speed.
- Join and Create HTML table for output.

## Gotchas
- Wrong schema makes later actions silently null.

## Self-check
Output array is the expected shape.
