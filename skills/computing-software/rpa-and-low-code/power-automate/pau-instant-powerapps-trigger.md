# Call flows from Power Apps
**Goal:** Run flows from app buttons with parameters.

- Instant flow with the Power Apps (V2) trigger defines inputs; call `FlowName.Run(args)` from the app.
- Return values with Respond to a Power App or flow.
- Keep flows in the same solution.

## Gotchas
- Run-only users and connections must be set at share time.

## Self-check
App button triggers and returns output.
