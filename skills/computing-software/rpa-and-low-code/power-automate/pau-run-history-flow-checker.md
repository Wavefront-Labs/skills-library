# Monitor runs and use the flow checker
**Goal:** Diagnose flow runs.

- Run history shows inputs and outputs for each action; Flow checker flags errors and warnings in the designer.
- Set failure notifications and owner co-owners.
- Analytics dashboard in the details page.

## Gotchas
- Run history retention is limited (confirm days in docs).

## Self-check
Failed run diagnosed from action outputs.
