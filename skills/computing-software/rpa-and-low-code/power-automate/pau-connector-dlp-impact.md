# Consider DLP for custom connectors
**Goal:** Classify custom connectors.

- DLP policies can classify custom connectors by URL pattern as business, non-business or blocked.
- Review before publishing connectors.
- Document owners.

## Gotchas
- Unclassified connectors default to non-business.

## Self-check
Connector appears in the right group.
