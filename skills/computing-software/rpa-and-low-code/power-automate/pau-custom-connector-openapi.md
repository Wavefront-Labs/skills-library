# Build a custom connector from OpenAPI
**Goal:** Wrap a REST API as a connector.

- Import an OpenAPI definition or build in the wizard; define security (API key, OAuth 2.0), actions and triggers, and test.
- Share within the environment or certify via the connector programme for wider use.
- Use policy templates to modify behaviour.

## Gotchas
- API key stored in the connection is shared by those using it.

## Self-check
Test operation returns data.
