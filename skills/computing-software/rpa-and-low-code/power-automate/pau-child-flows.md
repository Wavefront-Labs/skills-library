# Reuse logic with child flows
**Goal:** Split large flows into callable children.

- Child flows are in solutions and use the Manually trigger a flow trigger and Respond to a Power App or flow.
- Call with Run a Child Flow; pass inputs and read outputs.
- Share connections via connection references.

## Gotchas
- Child flows must be in the same solution or accessible.

## Self-check
Parent flow receives child outputs.
