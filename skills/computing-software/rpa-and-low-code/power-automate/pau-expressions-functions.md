# Write expressions
**Goal:** Use the workflow expression language.

- Functions such as `concat`, `formatDateTime`, `utcNow()`, `coalesce`, `if`, `equals`, `items('Apply_to_each')` and `triggerOutputs()`.
- Use `?` for null-safe property access.
- Test in Compose.

## Gotchas
- Single quotes inside strings must be doubled.

## Self-check
Compose output matches expected value.
