# Automate UI with Power Automate for desktop
**Goal:** Record and build desktop flows.

- Desktop flow designer: actions, variables, UI elements captured with selectors; subflows and error handling blocks.
- Use image-based fallback sparingly.
- Test on the target screen resolution.

## Gotchas
- UI element selectors break when apps update.

## Self-check
Flow runs reliably three times in a row.
