# Run desktop flows attended and unattended
**Goal:** Register machines and trigger runs from cloud flows.

- Register machines in Power Automate; use the on-premises data gateway or direct connectivity per documentation; unattended runs need a licence and an active session settings.
- Cloud flow action Run a flow built with Power Automate for desktop; choose attended or unattended.
- Use machine groups for scaling.

## Gotchas
- Unattended runs need an unlocked session; configure credentials.

## Self-check
Cloud flow triggers the desktop flow and returns outputs.
