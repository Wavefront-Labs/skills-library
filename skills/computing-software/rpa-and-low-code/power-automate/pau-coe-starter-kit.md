# Use the CoE Starter Kit
**Goal:** Inventory flows and apps tenant-wide.

- The Centre of Excellence Starter Kit inventories apps, flows and makers and provides compliance, nurture and governance flows.
- Install in a dedicated environment.
- Use to find orphaned or unused assets.

## Gotchas
- The kit needs admin permissions and updates regularly.

## Self-check
Inventory lists makers and resources.
