# Build sequential and parallel approvals
**Goal:** Chain or fan out approval steps.

- Sequential: one approval after another with conditions; parallel: multiple approval actions in a parallel branch.
- Set timeouts and reminders.
- Use escalation paths.

## Gotchas
- Long-running approvals hit the flow's 30-day run duration limit (confirm).

## Self-check
Flow completes with all outcomes recorded.
