# Choose project type and compatibility
**Goal:** Pick Process, Library or Test Automation and the right compatibility.

- Studio creates Process, Library and Test Automation projects; compatibility (Windows, Cross-platform, Legacy) decides which activities are available.
- Libraries publish reusable workflows as packages; test projects hold test cases.
- Use the Modern design experience for new projects where supported.

## Gotchas
- Legacy projects use different activities; migrate deliberately.

## Self-check
Project analyzer shows no compatibility errors.
