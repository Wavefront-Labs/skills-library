# Choose sequence, flowchart or state machine
**Goal:** Use the right container for the process shape.

- Sequences for linear logic, flowcharts for branching, state machines for long-running multi-state processes such as the REFramework.
- Keep each workflow small and single-purpose.
- Document with annotations.

## Gotchas
- Flowcharts with many crossing links are hard to maintain.

## Self-check
A new developer can follow the flow in a minute.
