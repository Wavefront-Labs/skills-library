# Run data-driven tests
**Goal:** Feed a test with multiple data sets.

- Test Data Queues or data variations from Excel run one test per row.
- Keep expected outputs alongside inputs.
- Track coverage per requirement.

## Gotchas
- Data sets with hidden dependencies cause order-dependent failures.

## Self-check
Each row reports its own result.
