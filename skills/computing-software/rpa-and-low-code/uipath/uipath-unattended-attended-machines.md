# Compare attended and unattended robots and machine templates
**Goal:** Choose the right execution model.

- Attended robots run on user desktops; unattended robots run on a dedicated or templated machine with a robot account.
- Machine templates and folder assignments control scaling and licensing.
- Keep a robot machine locked-screen policy (e.g. console session) per your runtime requirements.

## Gotchas
- Unattended UI automation needs an active interactive session.

## Self-check
Job runs on the target machine under the right account.
