# Use anchors and modern targets
**Goal:** Disambiguate elements with anchors and fuzzy matching.

- Anchors use a nearby stable label to identify an element; the modern experience combines selector, fuzzy selector and image or computer vision targeting (confirm names in your Studio version).
- Use as fallback, not the first choice.
- Keep screen resolution and scaling consistent on robot machines.

## Gotchas
- Image-based targeting depends on resolution and theme.

## Self-check
Automation runs on a robot machine with different resolution.
