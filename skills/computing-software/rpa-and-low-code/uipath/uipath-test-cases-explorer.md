# Write test cases in Test Explorer
**Goal:** Create automated tests for workflows.

- Test Cases are workflows marked as tests with verify activities (Verify Expression, Verify Expression With Operator); run them in Test Explorer.
- Set up and tear-down workflows prepare data.
- Publish tests and run from Test Manager or Orchestrator.

## Gotchas
- Tests that depend on production data are flaky; use fixtures.

## Self-check
Test explorer shows pass/fail with evidence.
