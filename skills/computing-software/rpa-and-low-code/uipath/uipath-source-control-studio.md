# Use source control with Studio
**Goal:** Manage projects in Git.

- Studio's Team panel supports Git; commit workflow files and project.json, ignore .local and .objects folders.
- Branch per feature and review XAML diffs carefully.
- Merge conflicts in XAML are hard; keep workflows small.

## Gotchas
- Do not commit credentials or Config files with secrets.

## Self-check
Clone to a new machine opens and builds.
