# Set confidence thresholds and validation
**Goal:** Route low-confidence data to humans.

- Compare field confidence to thresholds; send below-threshold documents to Action Center validation.
- Use validation feedback to retrain.
- Track straight-through-processing rate.

## Gotchas
- Thresholds too low let errors through; too high overload reviewers.

## Self-check
Straight-through rate and error rate are measured.
