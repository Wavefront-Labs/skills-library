# Understand premium connectors and licence types
**Goal:** Predict licence needs.

- Use of premium connectors or Dataverse requires per-user or per-app Power Apps licences; standard Microsoft 365 connectors are included in many plans (confirm current terms with Microsoft licensing guide).
- Check each app's licence requirement in the admin view.
- Plan costs before launch.

## Gotchas
- Premium use found late forces rework or purchases.

## Self-check
Licence requirement documented for each app.
