# Share components via a library
**Goal:** Reuse controls across apps.

- Component libraries publish components; apps import and receive update prompts.
- Use custom properties and events for communication.
- Version carefully since updates propagate.

## Gotchas
- Breaking a component's properties breaks dependent apps.

## Self-check
Update appears in a consuming app.
