# Build a model-driven app
**Goal:** Compose apps from Dataverse tables.

- App designer: add tables, forms, views, dashboards; site map for navigation.
- Forms use main, quick view and quick create; views filter and sort.
- Security roles determine visibility.

## Gotchas
- Model-driven apps require Dataverse tables with privileges.

## Self-check
User with role sees the app and table data.
