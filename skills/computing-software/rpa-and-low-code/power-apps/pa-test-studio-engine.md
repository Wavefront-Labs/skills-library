# Test with Test Studio or Test Engine
**Goal:** Automate UI tests.

- Test Studio records test cases for canvas apps with assertions; Test Engine runs YAML-based tests from a pipeline.
- Use fixed test data.
- Run before deploying.

## Gotchas
- Test Studio tests depend on screen layout.

## Self-check
Test run results in pass/fail.
