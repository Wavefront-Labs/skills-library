# Use SharePoint lists as data
**Goal:** Build apps over lists safely.

- Use the SharePoint connector; watch column types (choice, lookup, person) and delegation limits.
- Index columns used in filters; list view threshold of 5,000 items applies.
- Consider Dataverse for relational data.

## Gotchas
- Lookups and person fields have limited delegation.

## Self-check
Filtered gallery responds quickly on a large list.
