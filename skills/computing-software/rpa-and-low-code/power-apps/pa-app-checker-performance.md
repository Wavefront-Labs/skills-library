# Use App Checker and performance tips
**Goal:** Find formula and performance issues.

- App Checker lists errors, warnings and performance advice; Monitor traces network calls and formula timing.
- Reduce controls per screen, use Concurrent, cache with collections only where needed.
- Test on a low-end device.

## Gotchas
- Many controls in galleries slow rendering.

## Self-check
Screen load time is measured before and after.
