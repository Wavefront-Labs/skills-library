# Debug with Monitor
**Goal:** Trace network and formula events.

- Monitor (Advanced tools > Open monitor) streams events including network calls with timings; join sessions to watch published apps.
- Look at slow calls and errors.
- Filter by category.

## Gotchas
- Do not share monitor sessions with sensitive data to untrusted users.
