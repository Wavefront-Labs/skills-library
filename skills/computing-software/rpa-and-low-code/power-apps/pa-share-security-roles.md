# Share an app securely
**Goal:** Share the app and the data access it needs.

- Share canvas apps with users or groups; sharing the app does not grant data access; grant data source permissions separately and Dataverse security roles for tables.
- Use Entra security groups.
- Review sharing regularly.

## Gotchas
- Sharing with Everyone widens exposure.

## Self-check
A new group member gets app and data access.
