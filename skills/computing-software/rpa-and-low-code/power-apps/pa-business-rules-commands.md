# Add business rules and commands
**Goal:** Apply logic without code.

- Business rules show/hide, set required, set defaults; scope Entity, All forms or specific form.
- Command bar buttons use Power Fx (modern commanding).
- JavaScript web resources are the alternative.

## Gotchas
- Business rules run client-side on forms; server-side needs plugins/flows.

## Self-check
Field required/visible toggles as expected.
