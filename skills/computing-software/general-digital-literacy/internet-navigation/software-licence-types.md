# Software licence types

**Goal:** know what the licence lets you do: how many devices, home vs business use, sharing, modifying.

## You never "buy" software; you get a licence
| Type | What it usually allows | Examples |
|---|---|---|
| **Proprietary, perpetual** | use one version forever on N devices; upgrades cost extra | Office 2024, older Adobe versions |
| **Subscription** | use while you pay; stops or goes read-only when you cancel | Microsoft 365, Adobe Creative Cloud |
| **Freeware** | free to use; source closed; often personal use only | some utilities, free editions |
| **Freemium / free tier** | basic features free; paid upgrades | Zoom, Canva |
| **Shareware / trial** | try for N days, then pay | WinRAR, many apps |
| **Open source, permissive** (MIT, BSD, Apache 2.0) | use, modify, redistribute, incl. commercially; keep the licence notice | VLC (parts), Python |
| **Open source, copyleft** (GPL, AGPL) | use freely; if you distribute modified versions you must share source under the same licence | Linux, GIMP, LibreOffice (MPL) |
| **Public domain / CC0** | no restrictions | SQLite |

## Common terms in an EULA
- **Number of installs/devices** and whether a home licence covers one person or a household.
- **Non-commercial / home and student** editions: not for business use (e.g. Office Home, some free antivirus, free tiers of many apps).
- **Transfer:** OEM licences (pre-installed Windows) are tied to the device; retail licences can usually move to a new PC.
- **Education** licences require being a current student or staff member.

## Practical rules
- Use the free tier for work only if the licence allows commercial use; check before using "personal" software at work.
- Cracked or "keygen" software breaks the licence and is a top malware source.
- Keep licence keys and purchase emails in your password manager.
