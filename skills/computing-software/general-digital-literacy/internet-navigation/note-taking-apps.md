# Note-taking apps

**Goal:** one trusted place for notes, findable later on any device.

## Pick one
| App | Strengths | Sync |
|---|---|---|
| **Apple Notes** | Fast, free, scan documents, tags, locked notes | iCloud (Apple devices; web at icloud.com) |
| **Google Keep** | Quick checklists, reminders, labels, colours | Google account, all platforms |
| **Microsoft OneNote** | Notebooks › sections › pages, free-form ink, audio | OneDrive |
| **Notion** | Pages + databases, templates, team wikis | Cloud (account) |
| **Obsidian** | Plain Markdown files you own, links between notes | Local; optional paid or own sync |

## Organise lightly
- Few top-level containers (Notebooks/folders: Home, Work, Projects); rely on **search** and tags.
- Start notes with a clear title and date (`2026-10-16 Call with plumber`).
- Use checklists for actions; move finished projects to an Archive.
- Capture quickly: phone widget, share sheet "Add to Notes/Keep/OneNote", voice notes.

## Clipping and scanning
Share › to your note app from the browser to save a link with summary; OneNote Web Clipper and Notion
Web Clipper save full pages; Apple Notes and Keep can scan or OCR images (search finds text in them).

## Gotchas
- Don't store passwords in notes; use a password manager (Apple Notes can lock notes, still not ideal).
- Export options matter if you might switch apps (Obsidian/Markdown is most portable).
- Shared notes are editable by others; check sharing settings.
