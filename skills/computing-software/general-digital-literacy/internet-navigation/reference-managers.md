# Reference managers

## Why
- Save each source once with full metadata; insert in-text citations and bibliographies that update dynamically.

## Zotero setup
1. Install the Zotero desktop app and the Zotero Connector for Chrome, Firefox, Edge or Safari.
2. Create a Zotero account to sync. Data syncing is free and unlimited and can be used without file syncing.
3. Word processor plugins exist for Microsoft Word, LibreOffice and Google Docs; see Zotero's documentation for each.

## Collect
- The Connector's save button finds bibliographic information on pages you visit and adds it to Zotero with one click.
- **Add Item by Identifier:** type or paste an ISBN, DOI, PubMed ID, arXiv ID or ADS Bibcode.
- For a PDF without metadata, right-click it, choose **Create Parent Item**, enter an identifier such as a DOI or ISBN, or use **Manual Entry**.
- Check every entry: imported metadata can be incomplete, and a bibliography is only as good as its data.

## Cite
- Use the word processor plugin to insert citations and bibliographies; do not edit generated citations by hand, since they are managed by the plugin.

## Backup and storage
- File syncing uses Zotero Storage (the recommended option) or WebDAV. Each user gets 300 MB of free Zotero Storage for attached files; larger plans are paid.
