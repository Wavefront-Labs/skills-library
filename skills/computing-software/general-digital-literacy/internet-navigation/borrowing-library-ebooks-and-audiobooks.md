# Borrow library e-books and audiobooks

## Get set up
- Join your public library (often online with proof of address) to get a card number and PIN.
- Install the library's app: **Libby** (OverDrive; most of the US, Canada, many UK and Australian libraries), **BorrowBox** (many UK/Australian libraries), **Hoopla**, **cloudLibrary**, or **PressReader** for newspapers/magazines.
- In Libby: *Find my library*, then *Enter card number*. You can add several libraries.

## Borrow
- Search, **Borrow** if available, or **Place hold** if not (you're notified when it's ready; Libby can auto-borrow or let you delay).
- Loans last 7, 14 or 21 days; books return automatically, so no fines.
- Read in the app, on a computer browser, or in the US send to **Kindle** (*Read with Kindle*). Kindle sending isn't available outside the US; Kobo e-readers have Libby built in.
- Audiobooks: download over Wi-Fi for offline listening; set sleep timer and speed.

## Tips
- Use **tags** in Libby to keep a wishlist; filter search by *Available now*.
- Library limits: number of loans and holds per card; popular titles may have long waits.
- Libraries also offer free learning platforms (LinkedIn Learning, language courses) with the same card.

## Verify
- [ ] A borrowed book downloads and opens offline, and holds show estimated wait times.
