# Visual search with Lens (Chrome)

## Requirement
Chrome's help: set Google as your default search engine.

## Search a page
- More > **Search this tab with Google Lens**, or right-click the page and choose the same item.
- Ask a question about the page in the search box or side panel, or select anything: click, highlight text, or drag over an area. Follow-up questions go to AI Mode.
- Results appear in the side panel; select a result to open it in a new tab. Close the panel with Esc, Close, or by selecting the page. The Lens side panel can be pinned to the toolbar.

## Search an image
Right-click the image > **Search with Google Lens**; or right-click outside an image and choose it from the menu. You can also use the address bar's "Ask Google about this page".

## Privacy
When you use Lens on a page, a screenshot of the page and page data are sent to Google. Google says it keeps nothing beyond temporary storage to process the query and does not use the page or image for training. A selected part of the page is sent to Google Search, so it can appear in your Search activity (My Google Activity manages or deletes it). Avoid searching pages that show personal documents.
