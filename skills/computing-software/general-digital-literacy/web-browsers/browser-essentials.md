# Browser essentials — fast, tidy and safe in any browser

**Goal:** move around the web with the keyboard, keep bookmarks and downloads under
control, and keep the browser itself safe. Shortcuts are Windows/Linux for Chrome,
Edge and Firefox; on macOS (including Safari) use **Cmd** instead of Ctrl unless noted.

## 1. Tabs and the address bar
| Action | Shortcut |
|---|---|
| New tab / close tab | `Ctrl+T` / `Ctrl+W` |
| **Reopen the tab you just closed** (repeatable) | `Ctrl+Shift+T` (Safari: `Cmd+Z` or `Cmd+Shift+T`) |
| Next / previous tab | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Jump to tab 1–8 / last tab | `Ctrl+1`…`Ctrl+8` / `Ctrl+9` |
| Focus address bar | `Ctrl+L` (or `Alt+D`, `F6`) |
| Open link in background tab | `Ctrl+click` or middle-click |
| Find on page | `Ctrl+F` |
| Zoom in / out / reset | `Ctrl++` / `Ctrl+-` / `Ctrl+0` |
| Back / forward | `Alt+Left` / `Alt+Right` (Mac: `Cmd+[` / `Cmd+]`) |

- The address bar is also the search box: type words to search, or a full address to go
  there directly. Typing the real address of a bank or government service is safer than
  clicking an ad in search results.
- Too many tabs? Bookmark the set ("Bookmark all tabs", `Ctrl+Shift+D` in Chrome/Edge/
  Firefox) or use tab groups (Chrome/Edge: right-click a tab › Add to new group) and close
  the rest. Dozens of open tabs cost memory and battery.

## 2. Bookmarks and history
- `Ctrl+D` bookmarks the current page. Show the bookmarks bar with `Ctrl+Shift+B` in
  Chrome/Edge (in Firefox that shortcut opens the Library instead; toggle the toolbar
  via right-click on the tab strip).
- Keep a few folders on the bar (Work, Admin, Reference); put the rest in "Other bookmarks".
- History is `Ctrl+H`; it is searchable, which is often faster than bookmarking everything.
- Sign in to the browser's sync (Google account, Microsoft account, Firefox account,
  iCloud) to carry bookmarks and passwords to a new device — but only on devices you own.

## 3. Downloads
- Open the downloads list: `Ctrl+J` (Chrome/Edge), `Ctrl+Shift+Y` (Firefox on Windows),
  `Cmd+Option+L` (Safari).
- Turn on **"Ask where to save each file"** (Settings › Downloads) if you lose files in
  the default Downloads folder; otherwise clean that folder monthly.
- Check the **file extension** before opening: an "invoice" ending `.exe`, `.scr`, `.js`,
  `.bat` or `.msi` is a program, not a document. Heed browser download warnings; don't
  click "keep anyway" for something you didn't expect.

## 4. Profiles, private windows and passwords
- Use separate **profiles** for work and personal (Chrome/Edge: profile icon › Add;
  Firefox: Containers or `about:profiles`). Each keeps its own logins, history and extensions.
- Private/Incognito windows (`Ctrl+Shift+N` Chrome/Edge, `Ctrl+Shift+P` Firefox,
  `Cmd+Shift+N` Safari) don't keep local history or cookies after closing. They do **not**
  hide you from your employer's network, your internet provider or the sites you log into.
  They are handy for testing a site "logged out" or with no extensions.
- Use the built-in password manager (or a dedicated one) with unique passwords, and accept
  passkeys where sites offer them.

## 5. Extensions and site permissions
- Install extensions only from the official store, check the publisher, review count and
  the permissions requested. "Read and change all your data on all websites" is a lot of
  trust. Remove what you don't use (Chrome `chrome://extensions`, Edge
  `edge://extensions`, Firefox `about:addons`).
- Click the icon left of the address (padlock / tune icon) to see and change a site's
  camera, microphone, location and **notification** permissions. Block notification
  prompts by default if sites keep nagging. The padlock only means the connection is
  encrypted — not that the site is trustworthy.

## 6. When a page misbehaves
1. Hard refresh: `Ctrl+F5` or `Ctrl+Shift+R` (Mac `Cmd+Shift+R`).
2. Try a private window — if it works there, an extension or stale cookie is the cause.
3. Clear that site's data (padlock icon › Site settings / Clear cookies), or all browsing
   data with `Ctrl+Shift+Delete` (choose cookies + cached files; leave passwords).
4. Update the browser: Chrome `chrome://settings/help`, Edge `edge://settings/help`,
   Firefox Menu › Help › About Firefox; Safari updates with macOS. Restart to apply.

## Verify
- [ ] You can reopen a closed tab and jump to the address bar without the mouse.
- [ ] Bookmarks bar shows a handful of folders; history search finds a page from last week.
- [ ] Downloads go where you expect, and you check extensions before opening files.
- [ ] Only extensions you use and trust are installed; notification spam is blocked.
- [ ] The browser reports it is up to date.
