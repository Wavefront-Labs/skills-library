# Annotate PDFs in the browser

## Edge
- Open the PDF (drag into Edge or right-click > *Open with > Microsoft Edge*).
- Toolbar: **Highlight** (choose colour), **Draw** (pen colour, thickness), **Erase**, **Add text**, right-click selected text > *Add comment*.
- **Fill & Sign / Add signature**: draw or type a signature and place it.
- **Save** (Ctrl+S) overwrites; **Save as** (Ctrl+Shift+S) keeps the original.

## Firefox
- PDF toolbar: **Text** (add text, set size/colour), **Draw**, **Highlight** (also select text then highlight), **Add image** (with alt text), **Signature** (Firefox 2025+).
- **Save** (download icon) gives you an annotated copy.

## Chrome
- Built-in viewer (2024+): the **Annotate** pen icon in the toolbar for drawing and highlighting; fills form fields; *Save* or *Save as* to keep changes. Older versions only fill forms.

## Safari
- No annotation in the browser; open in **Preview** (Markup toolbar) instead.

## Gotchas
- Annotations are added as PDF annotations; they show in other readers, but some viewers hide comments.
- Scanned PDFs are images: text highlight won't work; use the draw highlighter or run OCR first.
- Signing in a browser is a picture of a signature, not a certified digital signature; use the service the sender requests for legal e-signing.
- Annotations on a PDF opened from email or cloud preview may not save back; download first.

## Verify
- [ ] Reopen the saved copy in another app and annotations are present.
