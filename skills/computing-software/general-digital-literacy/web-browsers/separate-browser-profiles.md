# Separate work and personal profiles

**Goal:** work logins, bookmarks and history never mix with personal ones.

## Chrome
Chrome's help: profiles keep bookmarks, history, passwords and other settings separate, and suit sharing a computer or keeping work and personal accounts apart.
- **Add:** profile icon (top right) > Add Chrome profile; choose a name, photo and colour. Signing in to the new profile with a Google Account saves its bookmarks and passwords to that account.
- **Switch:** profile icon > choose the profile.
- **Show profiles at startup:** profile icon > under "Other Chrome profiles" Manage Chrome profile > check Show on startup.
- **Rename or recolour:** profile icon > Customize profile, or Manage Chrome profiles > More > Edit.
- **Remove (warning):** removing a profile erases its bookmarks, history, passwords and other settings from the computer. Profile icon > Manage Chrome profiles > select the profile > More > Delete > Delete.

## Cautions
- Only share a device with people you trust: anyone with the device can switch to another profile and see sites visited.
- Guest mode is separate from profiles; use it for someone borrowing your computer (Chrome: "Browse Chrome as a guest").
- Different colours and avatars help you tell which profile is active.
