# Tab groups

**Goal:** dozens of tabs organised by task instead of a wall of tiny icons.

## Chrome
- Right-click a tab > **Add tab to group** > **New group** (or an existing group). Right-click the coloured circle or name to name the group, choose its colour, add tabs or remove the group. Drag a tab into a group to add it; right-click a tab > **Remove from group** to take it out.
- Select the group's name or circle to **collapse or expand** it.
- **Close group** (right-click the group) closes the tabs but does not delete the group: it is saved in the bookmarks bar or under More > **Tab groups**, and you can reopen it there. Turn on Settings > Appearance > **Show tab groups in bookmarks bar** to see them on the bar.
- **Delete group** and **Ungroup** both remove the group on all devices using the same Google Account (Ungroup keeps the tabs open).
- With history and tabs synced, changes to tab groups sync across your devices.
- **Tab search:** the Tab Search button in the tab strip, or Ctrl+Shift+A (Mac Cmd+Shift+A); or type `@tabs` then Tab or Space in the address bar.

## Safari (Mac)
- In the toolbar, click the arrow next to the sidebar button (or the sidebar button if the sidebar is open) > **New Empty Tab Group**, or **New Tab Group with [n] Tabs**, then name it and press Return.
- Control-click a tab > **Move to Tab Group**, or drag tabs into a group. Control-click a group in the sidebar > **Show Tab Overview** to preview it.
- On supported Macs, Apple Intelligence can also suggest topic groups for tabs; this is not available in all languages or regions.

## Edge and Firefox
Not covered here; use each browser's own tab-group or collection help.

## Habits
- One group per task (for example "Trip", "Tax return"); close the group when done.
- To keep a set as a plain bookmark folder instead: Ctrl+Shift+D in Chrome or Edge saves all open tabs in a new folder (Cmd+Shift+D on Mac).

## Verify
- [ ] Collapsing a group hides its tabs; Close group then reopening it from the bookmarks bar or Tab groups menu restores them.
