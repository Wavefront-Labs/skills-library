# Split view in Chrome

**Goal:** read one page while working in another (a form and its instructions).

## How split view works
Two websites show in one window. One view is **active** (thicker border); toolbar items such as back, forward, home and the address bar apply to the active view only. Tab features such as Translate, Print and Reading mode work on the active view, not both. Clicking the inactive view makes it active; you can scroll it without activating it. Side panels such as Bookmarks or History stay open when you switch views; tab-specific panels such as Reading mode collapse.

## Open split view
- Inactive tab: right-click it > **New split view with current tab**.
- Active tab: right-click it > **Add tab to new split view**.
- Drag a tab to the left, right or bottom edge of the target window until the "Create split view" plus icon appears, then release.
- Link: right-click > **Open link in split view**.
- Shortcut for the active tab: Windows and Linux `Shift+Alt+N`; Mac `Cmd+Option+N`; Chromebook `Ctrl+Alt+N`.
- Also, when Chrome is in full screen, a new window starts in split screen by default (Chrome's Manage tabs page).

## Manage
- The split view icon sits left of the address bar; right-click it > Pin to keep it in the toolbar.
- Right-click a tab in split view to: Separate split view, close a view, change between stacked and side-by-side, or reverse position.
- Turn off drag-and-drop: More > Settings > Appearance > "Allow split view drag-and-drop on left, right, or bottom edge of window".

## Verify
- [ ] Both pages are visible, and the active-view border moves when you click the other one.
