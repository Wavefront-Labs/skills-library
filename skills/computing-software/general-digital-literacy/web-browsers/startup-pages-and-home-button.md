# Startup pages and home button

**Goal:** the browser opens to what you expect every time.

## Chrome
Your startup page (what shows when Chrome launches) and your homepage (what Home opens) are different unless you set them the same.
- More > Settings > **On startup**: *Open the New Tab page*, *Continue where you left off* (sites you were signed in to open signed in), or *Open a specific page or set of pages* (**Add a new page**, enter the address, Add; or **Use current pages**; edit or delete from More).
- Home button: Settings > **Appearance** > turn on **Show Home button**, then choose the New Tab page or a custom page.
- To show all Chrome profiles at launch: Profile > Manage Chrome profile > tick **Show on startup**.
- On a work or school Chromebook the administrator controls these pages.

## Safari (Mac)
Safari > Settings > **General**:
- **Safari opens with:** a new window, a new private window, all windows from your last session, or all non-private windows from your last session. Some options appear only if "Close windows when quitting an app" is selected in Desktop & Dock settings.
- **New windows open with** and **New tabs open with:** Start Page, Homepage, Empty Page, Same Page (windows also offer Tabs for Favourites and a chosen tabs folder).
- **Homepage:** type an address, or click **Set to Current Page**.

## Hijacked start page
A start page, homepage or search engine you did not set can mean unwanted software (Chrome's help); see the Chrome page on removing unwanted ads, pop-ups and malware, and reset settings if needed. Apple says Safari that keeps reopening unwanted windows or changing the search engine may mean a phishing site tricked you into installing unwanted software: update macOS, restart, and remove unknown apps and Safari extensions.
