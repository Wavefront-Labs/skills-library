# Full-page screenshots

**Goal:** one image of an entire long page (evidence of a listing, a receipt, a design to share).

## Edge: Web Capture
`Ctrl+Shift+S` or ⋯ › **Screenshot** (Web capture) › *Capture area* or **Capture full page** › edit with pen › Copy or Save (PNG/JPEG).

## Firefox: Screenshots
Right-click the page › **Take Screenshot** (`Ctrl+Shift+S`) › **Save full page** or *Save visible*, or drag to select › Download/Copy.

## Chrome
No menu item; use DevTools: `F12` › `Ctrl+Shift+P` (`Cmd+Shift+P` on Mac) › type **screenshot** › *Capture full size screenshot* (PNG saved to Downloads). *Capture node screenshot* grabs a selected element.

## Safari (Mac)
File › **Export as PDF** captures the whole page as one long PDF page. Or Develop menu › *Show Web Inspector*, right-click the `<html>` node › *Capture Screenshot*.

## Phones
- **iPhone:** take a screenshot (side + volume up) › tap the thumbnail › **Full Page** tab › Done › Save PDF to Files.
- **Android:** screenshot › **Capture more / Scroll capture** button (Samsung, Pixel) keeps scrolling to extend the image.

## Gotchas
- Pages with sticky headers or lazy-loaded images may show repeats or blanks; scroll to the bottom first so everything loads, then capture.
- Very long pages produce huge images; save as PDF or JPEG instead of PNG.
- For legal evidence, also save the URL and date (print to PDF with headers on) or use an archiving service.

## Verify
- [ ] Image covers the page top to bottom with no missing sections.
