# Change the download location

**Goal:** downloads land where you want them (a project folder, an external drive, a synced folder) instead of piling up in Downloads.

## Chrome
More > **Settings** > **Downloads**. To change the default, click **Change** and choose a folder. To choose each time, turn on **Ask where to save each file before downloading**. If you never change it, Chrome saves to the Downloads folder in your user folder (Windows, Mac and Linux).

## Edge
Settings and more > **Settings** > **Downloads**; in the *Location* area select **Change** and pick a folder. The same dialog has an option to have Edge ask where to save each file before downloading.

## Safari (Mac)
Safari > **Settings** > **General** > **File download location**: choose a location, or choose to be asked each time. Related: the "Remove download list items" menu in the same pane sets when entries leave the downloads list.

## Gotchas
- If you move a downloaded file, or change the download location after downloading, Safari cannot find the file from its downloads list.
- Company-managed browsers may lock settings; ask your administrator.
- Firefox and phone-browser menus are not covered here (see Checked).
