# Saving a web page as PDF or for offline reading

**Goal:** keep a copy of a page (a receipt, a policy, an article) that won't change or disappear.

## PDF
- **Chrome/Edge:** `Ctrl+P` › Destination: **Save as PDF** (Edge: Microsoft Print to PDF also
  works) › More settings: tick *Background graphics* for colours, untick *Headers and footers* for
  clean output (leave on to record URL and date as evidence).
- **Firefox:** `Ctrl+P` › Destination: Save to PDF; or use Reader View first for a clean layout.
- **Safari:** File › **Export as PDF** (single continuous page) or Print › PDF.
- Phones: Share › Print › pinch out on the preview (iPhone) / Chrome three dots › Share › Print.

## Other formats
- `Ctrl+S` › *Webpage, Complete* saves HTML plus a folder of images; *Single file* (`.mhtml`) in
  Chrome/Edge. Safari: Web Archive (`.webarchive`).
- Reading later: Chrome Reading list, Safari Reading List (can save for offline), Edge Collections,
  Firefox bookmarks.

## Evidence and citations
Save a public page at **web.archive.org** › *Save Page Now*: a timestamped public copy you can cite.
Keep your own PDF of receipts and confirmation pages too.

## Gotchas
- Pages behind logins (banking statements) often have a proper "Download PDF" option; use it rather
  than printing the page.
- Long pages may split adverts and menus across the PDF; Reader View or the site's print view first.

## Verify
- [ ] Open the PDF: text is selectable and the important part is complete.
