# Extensions on mobile browsers

## iPhone and iPad (Safari)
- Install from the **App Store** (search "Safari extensions"); each is an app.
- Enable: **Settings > Apps > Safari > Extensions** (older iOS: Settings > Safari > Extensions), turn it on, set *Allow* for websites or *Ask*.
- In Safari, tap the **page menu** (the icon left of the address bar) > *Manage Extensions* to toggle and grant per-site access.
- Content blockers (ad blockers) are a separate type; enable them in the same Extensions list.
- Third-party browsers on iOS (Chrome, Firefox, Edge) can't run extensions; outside the EU they use Safari's engine.

## Android
- **Firefox for Android**: menu > **Add-ons** > browse the full addons.mozilla.org catalogue (uBlock Origin, password managers, Dark Reader).
- **Edge for Android**: Settings > *Extensions* offers a small curated set.
- **Chrome for Android**: no extensions. Samsung Internet has its own *Add-ons* menu; Kiwi-style forks are unmaintained and risky.

## Caution
- Same rules as desktop: few extensions, known developers, minimal permissions. An extension with access to all websites sees banking pages too.
- Password manager autofill on phones works better through the OS (iOS *AutoFill Passwords*, Android *Autofill service*) than via a browser extension.

## Verify
- [ ] The extension appears in the browser's extension menu and works on a test site.
