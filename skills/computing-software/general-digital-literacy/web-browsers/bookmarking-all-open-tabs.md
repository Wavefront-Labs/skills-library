# Bookmark all open tabs

## Save them
- **Chrome:** **Ctrl+Shift+D** (Mac Cmd+Shift+D) saves all open tabs as bookmarks in a new folder.
- **Edge:** **Ctrl+Shift+D** (Mac Command+Shift+D) saves all open tabs as favorites in a new folder.
- Name the folder when prompted; the other browsers are not covered here (see Checked).

## Reopen
- **Safari:** Command-click a bookmarks folder on the Favourites bar to open all its bookmarks.
- **Chrome and Edge:** open the folder from the bookmark manager or bar and use the folder's right-click menu to open its links; check the menu in your version for the exact wording.

## Alternatives
- **Chrome saved tab groups:** closing a tab group keeps it, and it can be reopened from the bookmarks bar or More > Tab groups; groups sync when history and tabs are synced.
- **Safari Tab Groups:** New Tab Group with [n] Tabs from the sidebar menu in the toolbar.
- **Continue where you left off** (Chrome Settings > On startup) reopens the last session. It is a convenience, so keep a bookmark folder for any set you cannot lose.

## Gotchas
- Pages that need sign-in open signed out if cookies have been cleared.
- Date the folder name ("Research 2026-10-27") so old sets are easy to prune.

- [ ] Close the window, then open the saved folder's links and every tab returns.
