# Keyboard shortcuts for tabs

Chrome and Edge on Windows/Linux shown first; Mac uses **Cmd** for Ctrl. Firefox shortcuts are not covered here (see Checked).

| Action | Chrome / Edge (Windows) |
|---|---|
| New tab | Ctrl+T |
| Close tab | Ctrl+W (or Ctrl+F4) |
| **Reopen last closed tab** (repeat for more) | Ctrl+Shift+T |
| Next / previous tab | Ctrl+Tab / Ctrl+Shift+Tab (also Ctrl+PgDn / Ctrl+PgUp) |
| Jump to tab 1-8 / last tab | Ctrl+1 to Ctrl+8 / Ctrl+9 |
| New window | Ctrl+N |
| New private window | Chrome Incognito: Ctrl+Shift+N; Edge InPrivate: Ctrl+Shift+N |
| Close window | Ctrl+Shift+W (or Alt+F4) |
| Address bar | Ctrl+L, Alt+D or F6 |
| Reload / reload ignoring cache | F5 or Ctrl+R / Shift+F5 or Ctrl+Shift+R |
| Search open tabs | Chrome: Ctrl+Shift+A (Mac Cmd+Shift+A) |
| Duplicate tab / mute tab | Edge only: Ctrl+Shift+K / Ctrl+M |
| Open link in new background tab | Ctrl+click |
| Open link in a new tab and switch to it | Ctrl+Shift+click (Edge page; Cmd+Shift+click on Mac Chrome) |

Move a tab to a new window by dragging it out of the tab strip (Chrome).

## Mac
- **Chrome:** Cmd+T new tab, Cmd+Shift+T reopen closed tab, Cmd+Option+Right / Left next / previous tab, Cmd+1 to Cmd+8 and Cmd+9, Cmd+W close tab, Cmd+Shift+W close window, Cmd+Shift+N Incognito.
- **Edge:** Cmd+Shift+N opens an InPrivate window; Ctrl+M toggles tab mute.
- **Safari:** Shift-Cmd-T reopens the last closed tab (and the last closed window); Ctrl-Tab or Shift-Cmd-] next tab; Ctrl-Shift-Tab or Shift-Cmd-[ previous tab; Cmd-1 to Cmd-8 and Cmd-9 last tab; Cmd-W close tab; Shift-Cmd-\ shows tab overview; Option-click a tab's close button to close all other tabs; Cmd-click a link opens it in a new tab, Shift-Cmd-click opens it and switches to it.
- Apple notes shortcuts can vary with keyboard layout; check the app menus if one does not work.

## Gotchas
- Edge's shortcut page lists Ctrl+Shift+K for duplicate; Chrome's shortcut page has no duplicate-tab shortcut, so use the tab's right-click menu there.
- If a shortcut does nothing, click the page or address bar first so the browser, not a web app, has keyboard focus.

## Verify
- [ ] You can close a tab by accident and get it back in one keystroke.
