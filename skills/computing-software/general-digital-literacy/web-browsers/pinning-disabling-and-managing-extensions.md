# Pin, disable and manage extensions

## Chrome
- Open the manager: More > Extensions > **Manage extensions**.
- **Turn off or on:** the toggle on the extension. **Remove:** Remove, then confirm (or right-click its toolbar icon > Remove from Chrome).
- **Allow in Incognito:** Details > Allow in incognito.
- **Repair a corrupted extension:** Repair > Repair extension. If it stays corrupted, a suspicious program may be altering its files: run antivirus or anti-malware.
- **Site access:** Details > "Allow this extension to read and change all your data on websites you visit" > only when you select the extension, On specific sites, or On all sites. Under Permissions use Add or More > Remove to manage allowed sites.
- **Toolbar:** drag an icon to reorder; right-click > Unpin to hide; hidden ones are under the Extensions button, where Pin brings them back (some extensions lack this option).
- Sign in to Chrome to use your extensions on any computer.

## Edge
- Select **Extensions** next to the address bar > **Manage extensions**; toggle to turn off.
- Remove: right-click the icon > Remove from Microsoft Edge > Remove, or Extensions > More actions > Remove from Microsoft Edge > Remove.

## Work-managed browsers
A school or work organisation may install or block extensions; contact the administrator.

## Verify
- [ ] Only extensions you use remain, and broad site access is limited where the extension allows it.
