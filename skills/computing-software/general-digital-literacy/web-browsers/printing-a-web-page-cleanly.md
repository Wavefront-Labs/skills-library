# Print a web page cleanly

**Goal:** a readable printout of the article or receipt only, on as few pages as possible.

## Open the print dialog
- Chrome: File > Print, or `Ctrl+P` (Windows and Linux) / `Cmd+P` (Mac). Choose the destination, adjust settings, select Print.
- Edge: `Ctrl+P` (Windows) / `Cmd+P` (Mac). To open the system print dialog directly, `Ctrl+Shift+P` (Windows) or `Option+Command+P` (Mac).

## Strip the clutter (Edge)
Microsoft says a clutter-free print option is not yet in the print dialog (it removes ads and site navigation) and suggests **Immersive Reader** as the workaround: select the Immersive Reader icon in the address bar or press `F9` on Windows, then print from there. Immersive Reader may not be available on every site.

## Print only part of a page (Edge)
Select the text, right-click, choose Print (the selection is printed).

## Print dialog options in Edge (More settings)
- **Layout:** Portrait or Landscape.
- **Scale:** adjust the size to fit the paper; preview or test print first.
- **Pages per sheet, Paper size, Quality, Margins.**
- **Headers and footers:** adds the current date in the header and the page number in the footer.
- **Background graphics:** include the page background; Microsoft suggests turning it on if the preview looks different from the page.

## Save instead of printing
Chrome's print dialog lists Save as PDF as a destination (see saving-web-pages-as-pdf).
