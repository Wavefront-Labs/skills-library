# Downloads page and clearing the list

## Open it
- **Chrome:** More > **Downloads**, or `Ctrl+J` (Mac `Cmd+Shift+J`). The download tray beside the address bar shows recent downloads.
- **Edge:** `Ctrl+J` on Windows (Mac `Command+Option+L`).
- **Safari:** the downloads button near the top-right of the window (it is hidden when the list is empty).

## What you can do
- Chrome: click a file to open it; point to the name for extra actions such as **Show in Folder**; use **Pause**, **Resume** or **Cancel**; drag a downloaded file to another folder or program.
- Safari: pause or resume a download, and use the button next to a filename to find the item on your Mac. If you move a file or change the download location afterwards, Safari cannot find it.
- Blocked downloads: Chrome blocks dangerous, suspicious, unverified and insecure downloads. You can choose to download anyway after a warning, but treat warnings seriously; if you do nothing, Chrome removes the warning from your history after one hour, and **Delete from history** removes it sooner.

## Clearing
- Chrome: **Remove** next to a file removes it from the Downloads page only, not from your computer.
- Safari: **Clear** removes all list entries; Control-click an item > **Remove From List** removes one. Entries leave automatically after one day by default; change this in Safari > Settings > General > **Remove download list items**.
- Edge: clearing download history removes the list only, not the downloaded files.

## Can't find a file?
- Check the download location setting (Chrome Settings > Downloads; Edge Settings > Downloads; Safari Settings > General). Chrome's default is the Downloads folder in your user folder.

## Verify
- [ ] You can locate any recent download from the list, and the list contains nothing you need to find later.
