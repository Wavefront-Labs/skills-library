# Install an extension safely

**Goal:** add a useful tool (password manager, ad blocker) without inviting adware or data theft.

## Chrome
- Open the Chrome Web Store, choose the extension, select **Add to Chrome**. Some extensions ask for permissions or data: only select **Add extension** for extensions you trust. You cannot add extensions in Incognito mode or as a guest.
- On a work or school computer your organisation may block some extensions.
- **Enhanced protection** (Safe Browsing): if on, Chrome warns "This extension is not trusted by Enhanced Safe Browsing" when the developer is not trusted (trusted means the developer follows Chrome Web Store Developer Program Policies; new developers generally take a few months to become trusted). Choose Close to abort, or Continue to install anyway.
- Installing a Windows or Mac application can also add a Chrome extension; the next time Chrome opens it asks you to Enable or Remove it. Only enable what you expect.
- To use the extension, select its icon to the right of the address bar.

## Edge
- Select **Extensions** next to the address bar (or Settings and more > Extensions) > Get Extensions for Microsoft Edge > Get. At the prompt "carefully review the permissions" and select Add extension only if you want to proceed.
- Extensions from the Chrome Web Store work in Edge: on the store page select Get extension; if asked, select Allow extensions from other stores.
- Report a harmful extension on the Edge Add-ons site: select it > Report abuse.

## Warning signs to act on
Chrome's list for unwanted software includes extensions or toolbars that keep coming back, a homepage or search engine that keeps changing, and redirects or pop-ups. See removing-browser-hijackers.

## Verify
- [ ] The extension is listed in the extensions page and the browser homepage and search engine are unchanged.
