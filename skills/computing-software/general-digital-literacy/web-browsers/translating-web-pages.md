# Translating web pages

**Goal:** read a page in another language.

## Chrome (computer)
- **Whole page:** open the page, select **Translate** at the right of the address bar, or right-click the page and select Translate to [Language]; pick the language. If it does not work, refresh the page.
- **Selected text:** highlight, right-click, Translate selection to [Language]. More > Choose another language changes the target.
- **Settings:** More > Settings > Languages. Under "Google Translate": turn Use Google Translate on or off, choose "Translate into this language", and manage "Automatically translate these languages" and "Never offer to translate these languages". Under "Preferred languages": Add languages, and use More to move down or remove.
- **Display language (Windows only):** Preferred languages > More > Display Google Chrome in this language, then restart Chrome. On Mac and Linux Chrome follows the system language.
- Other route: translate.google.com > Websites.

## Edge
- Edge offers to translate pages in a language not in your Preferred languages list (Settings and more > Settings > Languages). The Translate icon appears in the address bar.
- In the prompt choose the "Translate to" language and select **Translate**; tick "Always translate from [Language]" for automatic translation; "Not now" or "Never translate [Language]" to skip.
- Translate manually: select the translate icon in the address bar > Translate to > Translate.
- Back to the original: translate icon > **Show original**.
- Turn offers on or off: Settings > Languages > "Offer to translate pages that aren't in a language I read".
