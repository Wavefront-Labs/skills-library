# Setting the default browser

**Goal:** links from email, documents and apps open in the browser you choose. Install the browser first.

## Windows 11
Start > **Settings** > **Apps** > **Default apps**. Search for the browser (Chrome's help uses "Chrome"), select it, and next to "Make [browser] your default browser" select **Set default**. Then review the list under "Set default file types or link types" so the right file and link types point to it.

## Chrome on Mac or Linux
Open Chrome > More > **Settings** > in the "Default browser" section select **Make default**. If you do not see the button, Chrome is already the default.

## macOS
Apple menu > **System Settings** > **Desktop & Dock**, scroll down, and choose a web browser from the **Default web browser** menu (macOS Ventura 13 or later). Earlier macOS: System Preferences > General > Default web browser.

## iPhone and iPad
Settings > **Apps** > **Default Apps** (top of the list) > **Browser App**, then choose the browser. Update to the latest iOS or iPadOS to see Default Apps. In the European Union and Japan you may be offered a browser choice screen instead. If the option is missing for an app, contact the app's developer.

## Android
Settings > **Apps** > under "General" tap **Default apps** (or Choose default apps) > **Browser app** > choose the browser. Menu names can vary by phone maker.

## Gotchas
- If a browser asks to become the default, read the prompt before accepting so you do not switch by accident.

## Verify
- [ ] Click a link in an email: it opens in your chosen browser.
