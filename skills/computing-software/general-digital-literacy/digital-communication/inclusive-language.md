# Inclusive language

## Core principles
- Refer to people as they refer to themselves: correct **names** (spelling, accents), **pronouns** (shown in profiles; ask or use their name if unsure).
- Mention a characteristic (age, disability, ethnicity) only when relevant.

## Common swaps
- Gender-neutral: *everyone/folks/team* instead of "guys"; *chair*, *staffing*, *police officer*, *spokesperson*; singular *they*.
- Disability: follow the person's preference; UK guidance often uses *disabled people*, many US styles prefer person-first (*person with a disability*). Avoid "suffers from", "wheelchair-bound" (use *wheelchair user*).
- Age: *older people*, not "the elderly".
- Avoid terms with exclusionary history in tech: *allowlist/blocklist*, *primary/replica*.

## Global readers
- Plain words, short sentences; avoid idioms ("hit it out of the park"), sports metaphors, sarcasm, and region-specific slang. Write dates unambiguously (3 Oct 2026).
- Explain acronyms on first use.

## Tools
- Microsoft Editor *Inclusiveness* refinements (gender bias, ethnic slurs, age bias, etc.); Google Docs suggestions; style guides like APA bias-free language and the Microsoft Style Guide.

## When you get it wrong
- Thank the person for correcting you, fix it, move on; long apologies make it about you.

## Verify
- [ ] Reread the message as someone of a different background would read it, and run the inclusiveness checker.
