# Online learning platforms

**Goal:** never miss a deadline, find every resource, and submit work in the right format.

## Common platforms
| Platform | Used by |
|---|---|
| **Google Classroom** | schools; Google accounts |
| **Microsoft Teams for Education** | schools and colleges with Microsoft 365 |
| **Moodle, Canvas, Blackboard, Brightspace (D2L)** | universities, colleges, training providers |
| **MOOCs**: Coursera, edX, FutureLearn, Khan Academy, OpenLearn | anyone; free audit or paid certificates |

## Getting set up
- Sign in with the account the school gave you (not a personal one); install the mobile app and turn on notifications for assignments and announcements.
- Join classes with a class code or invite link.
- Check notification settings so you get due-date reminders by email or app.

## Finding things
- **Course page / Classwork tab / Modules:** materials organised by week or topic.
- **Calendar / To-do / Upcoming:** every assignment with due dates; sync to your own calendar (Google Classroom calendar, Canvas calendar feed `.ics`).
- **Announcements / Stream:** changes and messages from teachers.

## Submitting work
1. Open the assignment, read instructions and rubric.
2. *Add or create* › upload a file (check required format: PDF, DOCX) or create a Doc from the template.
3. Press **Turn in / Submit** (an uploaded but unsubmitted file isn't handed in). Look for "Turned in" status or a confirmation email.
4. Late submissions are often marked late automatically; message the teacher if you have an extension.
5. Plagiarism checkers (Turnitin, originality reports) scan submissions; cite sources and follow AI-use rules.

## Live classes
Linked Meet/Teams/Zoom sessions appear in the course; recordings often appear afterwards in the same place.

## Verify
- [ ] All deadlines in your calendar; a test submission shows "Turned in/Submitted".
