# Block-based coding basics

## Tools by age
- **ScratchJr** (5-7, tablet app): picture blocks, no reading needed.
- **Scratch** (8+, scratch.mit.edu, free, browser or desktop app): sprites, stages, sound; huge community of shared projects to *remix*.
- **Code.org** (Hour of Code, courses for all ages), **Blockly Games**, **Tynker**.
- **MakeCode** for BBC micro:bit, Minecraft Education and LEGO: blocks that also show the JavaScript/Python equivalent.

## Core concepts with Scratch examples
- **Sequence**: blocks run top to bottom (`move 10 steps`, `say Hello`).
- **Events**: `when green flag clicked`, `when space key pressed`, `when this sprite clicked`.
- **Loops**: `repeat 10`, `forever`.
- **Conditionals**: `if touching edge then`, `if ... else`.
- **Variables**: `make a variable` *score*, `change score by 1`.
- **Broadcasts**: messages between sprites to coordinate.
- **Debugging**: run small pieces, click a block to test it alone, add `say` blocks to show values.

## First projects
- Animate your name; a maze game with arrow keys; a quiz with score; a story with backdrops.

## Moving on
- MakeCode's Python/JavaScript view; **Python** with Turtle graphics; Scratch extensions for micro:bit and LEGO.
- Code.org's App Lab shows blocks and JavaScript side by side.

## Safety
- Scratch accounts for under-13s should use a parent's email for confirmation; teachers can make class accounts. Community comments are moderated, but remind children not to share personal details.

## Verify
- [ ] A project uses an event, a loop, a condition and a variable, and runs as intended.
