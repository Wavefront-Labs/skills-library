# Views, sort and group files

**Goal:** spot the newest, biggest or wrong-type file in a busy folder.

## Windows File Explorer
- **View** on the ribbon switches between icons, lists, details and more; **View > Compact view** reduces the space between files.
- `Ctrl+Shift+` a number from 1 to 9 changes the view style; for example `Ctrl+Shift+2` is Large icons and `Ctrl+Shift+6` is Details. `Ctrl` plus the mouse wheel changes icon size.
- `Ctrl+Plus` (numeric keypad) resizes all columns to fit text.

## Mac Finder
- `Command+1` Icons, `Command+2` List, `Command+3` Columns, `Command+4` Gallery.
- Group items: click the group button in the toolbar and choose an option such as Date Last Opened. When sorting by name you can keep folders at the top.
- `Command+J` (View > Show View Options) changes sort and display options; "Show item info" works in Icon view only.

## Verify
- [ ] The newest file in Downloads appears first after sorting by date.
