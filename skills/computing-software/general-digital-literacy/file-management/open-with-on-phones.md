# Open with on phones

## iPhone and iPad
- iOS opens a file in the app that registered its type, or in a Quick Look preview.
- To use another app: preview > **Share** button > pick the app (e.g. *Word*, *Acrobat*) or *More* to see all. In Files, long-press > **Share** or *Open in...*.
- Default **browser, mail, messaging, calling, navigation, passwords and keyboard** apps: Settings > Apps > Default Apps. Other file types can't be set by default.

## Android
- Tapping a file shows **Open with** and app choices with **Just once / Always**.
- Chose *Always* by mistake: Settings > Apps > [the app] > **Open by default** (or *Set as default*) > **Clear defaults**. Next tap asks again.
- Default apps for browser, phone, SMS, home: Settings > Apps > **Default apps**.
- Links: Settings > Apps > [app] > *Open by default > Open supported links* controls whether links open in the app or browser.

## When nothing can open it
- Install a viewer for the type (Microsoft 365, Adobe Acrobat, VLC for video, RAR/7z opener). Get apps from the official store only.
- Unknown extension on a phone (.eml, .msg, .heic on Android): open on a computer or convert.
- Zip files: iOS Files and Files by Google extract zips natively.

## Verify
- [ ] Tapping the file type opens your chosen app, and Android asks again after clearing defaults.
