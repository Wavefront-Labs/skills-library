# Choose which folders sync

**Goal:** large cloud libraries don't fill a small laptop drive, yet the files you need are available offline.

## OneDrive (Windows and Mac)
- **Files On-Demand** (default): files show with a cloud icon (online-only) until opened. Right-click › **Always keep on this device** (green solid tick) or **Free up space** (back to cloud).
- Choose folders entirely: OneDrive icon › Settings › Account › **Choose folders**; unticked folders don't appear at all.

## Google Drive for desktop
Settings (gear › Preferences › Google Drive): **Stream files** (online-only by default, right-click › *Offline access › Available offline*) or **Mirror files** (full copy on disk). Choose computer folders to back up under *My Computer*.

## iCloud Drive
- Mac: System Settings › Apple Account › iCloud › iCloud Drive › **Optimise Mac Storage** removes local copies when space is low. Right-click a file › *Download Now* / *Remove Download*. Keep folders local with right-click › *Keep Downloaded* (recent macOS).
- Windows iCloud app: right-click › Always keep on this device.

## Dropbox
Preferences › Sync › **Selective Sync** (choose folders) or right-click › *Make online-only / available offline*.

## Status icons
Cloud = online only; green outline tick = downloaded, can be freed; solid green tick = always kept; blue arrows = syncing; red X = error.

## Gotchas
- Online-only files can't open without internet; mark travel files offline before leaving.
- Unticking a folder in "Choose folders" deletes the local copy, not the cloud copy; deleting a synced file deletes it everywhere.
- Backup tools may trigger downloads of every online-only file.

## Verify
- [ ] Turn off Wi-Fi: files marked offline open; disk usage fell after freeing space.
