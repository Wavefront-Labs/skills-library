# Recent files and lost downloads

**Goal:** recover "where did that file go?" in under a minute.

## Start in the app
- Office apps: **File › Open › Recent** (right-click › *Open file location* or *Copy path*). Most apps have File › Open Recent.
- Windows: right-click the app's taskbar icon for its **jump list** of recent files.

## Operating system recents
- **Windows:** File Explorer **Home › Recent**; or press `Win+R` › `shell:recent`.
- **Mac:** Finder sidebar **Recents** (`Shift+Cmd+F`); Apple menu › Recent Items.
- iPhone Files › **Recents**; Android Files by Google › Recent.

## Downloads
- Browser list: `Ctrl+J` (Chrome/Edge), `Ctrl+Shift+Y` (Firefox), `Option+Cmd+L` (Safari) › **Show in folder**.
- Default folders: Windows `Downloads`, Mac `~/Downloads`, iPhone *Files › Downloads* (iCloud Drive or On My iPhone), Android *Download*.
- Mail attachments opened directly live in a temporary cache; reopen from the email and save.

## Search by date
- Windows: in File Explorer search box type `datemodified:today` or `datemodified:this week`, starting from **This PC**.
- Mac: Finder `Cmd+F` › *Last opened date / Last modified date* is *within last 1 days*.
- Sort any folder by Date modified, newest first.

## Gotchas
- Saved to a cloud folder (OneDrive/iCloud) by default? Check there and in the web version.
- Files saved from a private browser window still save to Downloads.
- If Recent is empty, privacy settings may hide it (File Explorer Options › Privacy).

## Verify
- [ ] File found and moved to a sensible named folder; consider changing the app's default save location.
