# Saved searches and smart folders (Mac)

**Goal:** a live view such as "documents opened this year" without moving files.

## Mac Smart Folders
1. In the Finder choose File > **New Smart Folder** (`Option+Command+N`).
2. In the search field enter a topic, phrase, date or other characteristic and choose a suggestion; refine with the Action pop-up in the search field.
3. Add a rule: click the add button below the search field, then use the Action pop-up to choose attributes (click **Other** in the first pop-up for the complete list).
4. Click **Save**, enter a name and location. Unselect **Add To Sidebar** if you do not want it in the sidebar. Names cannot use certain characters such as a colon.
5. To change criteria later open the Smart Folder, click the Action button and choose **Show Search Criteria**.
- The list updates automatically as files that match are added, changed or deleted.
