# Select multiple files

**Goal:** pick exactly the files to copy, move, zip or delete in one go.

## Mouse and keyboard (Windows and most web apps)
| Action | How |
|---|---|
| A range | click first, **Shift**+click last |
| Scattered files | **Ctrl**+click each (Ctrl+click again to deselect one) |
| Everything | `Ctrl+A` |
| Add a range to a scattered selection | Ctrl+Shift+click |
| Box select | drag a rectangle from empty space |
| Invert | File Explorer ⋯ › **Invert selection** |

Touch screens: View › Show › **Item check boxes** in File Explorer.

## Mac Finder
- Range: click first, **Shift**+click last (in List view).
- Scattered: **Cmd**+click.
- All: `Cmd+A`; deselect all: `Option+Cmd+A`.

## Cloud and phones
- Google Drive/OneDrive web: hover for the tick circle, or Shift/Ctrl(Cmd)+click; Gmail-style checkboxes.
- iPhone Files/Photos: **Select** › tap, or drag a finger across thumbnails to sweep-select.
- Android Files/Photos: long-press one item, then tap others or drag.

## Narrow down first
Sort or group by type or date, or search (`*.pdf`, `kind:pdf`), then Select all in the results.

## Gotchas
- A plain click without Ctrl/Cmd throws away the selection you built.
- Selection in icon view follows grid order, not visual columns; use Details/List for ranges.
- Before deleting a big selection, glance at the count in the status bar ("23 items selected").

## Verify
- [ ] Status bar count matches the number of files you meant to select.
