# Resize and compress images for sharing

**Goal:** a 6 MB phone photo becomes a 300 KB image that uploads to the form and still looks fine.

## Pixels vs file size
- Phone photos are about 4000 × 3000 px; screens and email need 1600-2000 px on the long side; ID photo forms often ask for exact pixels and under 1-2 MB.
- File size also drops with **JPEG quality** around 70-85%.

## Windows
- **Photos app:** open › ⋯ › **Resize image** › pick preset or custom pixels and quality › Save as a copy.
- **Paint:** Home › *Resize* (percentage or pixels, keep aspect ratio) › File › Save as JPEG.
- **PowerToys Image Resizer:** select many files › right-click › *Resize with Image Resizer*.
- Email from File Explorer: right-click › Send to › Mail recipient offers sizes in some setups.

## Mac
- **Preview:** Tools › **Adjust Size** (pixels, keep proportional, shows resulting size) › File › Export › JPEG quality slider.
- Many files: select in Finder › right-click › **Quick Actions › Convert Image** › image size Small/Medium/Large.
- Mail: the *Image Size* menu in the compose window.

## Phones
- iPhone: Mail offers Small/Medium/Large when sending; Shortcuts app *Resize Image*. Set Camera › Formats › *Most Compatible* for JPEG.
- Android: Google Photos › Edit › Crop/Export; many gallery apps offer *Resize*.

## Gotchas
- Resize a **copy**; keep originals for printing.
- PNG screenshots compress better with PNG optimisers than converting to JPEG (text gets blurry).
- Online "compress image" sites upload your photos; avoid for ID documents.
- Strip location data before posting publicly (Photos info › remove location; iPhone share › Options › Location off).

## Verify
- [ ] New file meets the size/pixel limit and is still sharp at 100% zoom.
