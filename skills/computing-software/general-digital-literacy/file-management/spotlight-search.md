# Spotlight search on the Mac

**Goal:** find any file or app on a Mac quickly.

## Spotlight
- `Command+Space` opens Spotlight; start typing. `Return` opens the selected result, holding `Command` on a selected file shows its location in the Finder, `Space` gives a Quick Look preview, `Tab` reveals Quick Actions, and the Up Arrow recalls a previous search.
- It also calculates (for example `15% of 85`), converts units and currency (`5 km in miles`), shows dictionary definitions and searches clipboard history.

## Finder search for more control
- In a Finder window `Command+F` starts a Spotlight search in that window.
- To build precise rules, use File > **New Smart Folder** (`Option+Command+N`): type a topic, phrase or date in the search field, pick a suggestion, then click the add button below the field and choose attributes (click **Other** in the first pop-up menu for the full list). Save it to keep a live list.
