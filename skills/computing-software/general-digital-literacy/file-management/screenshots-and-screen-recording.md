# Screenshots and screen recordings (Windows and Mac)

## Windows 11
| Shortcut | Result |
|---|---|
| `Win+Shift+S` | Snipping Tool overlay to capture a snip |
| `Win+Shift+R` | Snipping Tool overlay to record a video clip |
| `PrtScn` | Depending on settings, copies the whole screen to the clipboard or opens screen snipping (a Print screen shortcut toggle in Settings controls this) |
| `Alt+PrtScn` | Active window to the clipboard |
| `Win+PrtScn` | Full screen saved to the Screenshots folder inside Pictures |
- Snips taken with Snipping Tool are saved automatically to the Screenshots folder; the save behaviour and folder can be changed in its settings.

## Mac
- `Shift+Command+3` full screen; `Shift+Command+4` for an area (then press `Space` to pick a window); `Shift+Command+5` opens the Screenshot app with recording and an **Options** menu (save location, timer).
- Screenshots save to the desktop by default. Add `Control` to any shortcut (for example `Control+Shift+Command+3`) to copy to the clipboard instead.

## Good practice
Crop to what matters and hide personal data before sharing.

- [ ] You can find the last screenshot in the Screenshots folder or on the desktop.
