# Comments in Word: insert, reply, resolve

## Word (modern comments)
- Select text › **Review › New Comment** (Ctrl+Alt+M) › type › **Post comment** (Ctrl+Enter).
- **@mention** someone (type `@` and the name) when signed in with a work or school account and the
  file is in OneDrive for work or school or SharePoint; tick *Assign to* to make it a task, and the
  assignee gets an email.
- Reply in the thread. **Resolve** (More thread actions **…**) hides the thread in Contextual view but
  keeps it; List view shows active and resolved comments, and you can reopen from there.
- Delete: **…** › delete the thread, or **Review › Delete › Delete All Comments in Document**.
- Navigate: Review › Previous / Next. Switch views: Review › Show Comments › *Contextual* or *List*.

## Google Docs
Select › **Ctrl+Alt+M** (or Add comment). Click **Resolve** on a comment to close it; open **Show all
comments** and filter resolved comments to find it, then **Re-open**. In a comment, `@` or `+` plus an
email address mentions someone; with a work or school account tick *Assign to* to make it an action item.
Suggesting mode is separate from comments.

## Before sharing externally
- Resolved comments are still in the file. Delete them (Delete All Comments in Document) before the file
  leaves the team.

## Gotchas
- Pressing Enter no longer posts a Word comment; use Post or Ctrl+Enter.
- @mentions and task assignment need a cloud-saved work or school file and recipients with access.

## Verify
- [ ] Review › Next finds no unresolved comments, and Delete All has been run if the file leaves the team.
