# Translate a document

## Word (Microsoft 365, Office 2021)
- **Review > Translate > Translate Document**: choose the language and select Translate; the translation opens in a separate window and your original stays open.
- **Review > Translate > Translate Selection**: choose a language and select **Insert** to replace the highlighted text.
- Needs an internet connection with Office connected experiences turned on; not available in Microsoft 365 operated by 21Vianet.

## Google Docs
**Tools > Translate document**: name the copy, choose the language, click Translate; the copy opens in a new window and is saved in Drive. If the command is missing you are probably editing an Office file in Office editing mode; convert it to a Google Doc first.

## LibreOffice Writer
Translate (selection or whole document) uses DeepL and is enabled only after you set a server URL and API key under Tools > Options > Languages and Locales > DeepL Server (Preferences on Mac).

## Other route
Google Translate's Documents feature accepts .docx, .pdf, .pptx and .xlsx up to 10 MB and is not available on mobile; text inside images and scanned PDF pages is not translated.

## Quality checks
- Machine translation is fine for the gist or low-stakes notes. For contracts, medical, legal, safety or published text use a qualified translator or a fluent reviewer.
- Back-translate a key paragraph to spot meaning drift.
- Watch numbers, dates (day/month order), units, names and product terms.
- Set the proofing language of the translated copy so spell-check works.

## Privacy
- Cloud translators send your text to a service. Do not upload confidential documents unless your organisation approves the service.

## Verify
- [ ] The original document is unchanged and the translated copy was reviewed for numbers, names and meaning.
