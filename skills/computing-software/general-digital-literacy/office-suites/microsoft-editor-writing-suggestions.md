# Microsoft Editor writing suggestions

## Where it runs
- **Word for Microsoft 365 (Windows):** **Home > Editor**. Word for the web also has Editor.
- **Outlook:** Editor is available in Outlook on the web and Outlook.com with a Microsoft 365 account and in new Outlook for Windows; older classic Outlook versions use the Spelling & Grammar tool instead.
- **Browser:** the Microsoft Editor extension for Edge and Chrome checks text in web forms, Gmail and social posts.

## Free vs subscription
- Free: basic spelling and grammar. A Microsoft 365 subscription adds refinements such as clarity, conciseness, formality and vocabulary suggestions.
- Editor checks grammar and refinements in more than 20 languages and spelling in 89; Microsoft states the Editor panel in Word is available only in English, French, German and Spanish.
- **Home > Editor > Document stats** opens readability statistics (Microsoft 365, Current Channel).

## Judge the suggestions
- Grammar checkers misread technical terms, quotations, deliberate fragments and names. Accept only what improves meaning.
- Do not chase a perfect score; clarity matters more than the number.
- For confidential text, follow your organisation's policy on cloud services.
