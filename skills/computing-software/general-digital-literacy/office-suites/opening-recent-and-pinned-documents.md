# Open recent and pinned documents

## Microsoft 365 desktop apps
- **File > Open** lists recently used files. Hover a file and select the **pin** icon to keep it at the top of the list.
- Microsoft says pinning is being de-emphasised in recent Microsoft 365 versions in favour of **Favorites**, a list you curate yourself; the file also stays in Recent.
- **Word (Windows):** **File > Options > Advanced > Display > Show this number of Recent Documents**; setting 0 hides the list.

## Gotchas
- Recent can show files that have moved or been deleted; search for the file instead.
- On a shared or public PC, set the recent count to 0 so the next user cannot see your file names.

## Verify
- [ ] The documents you use daily appear under Pinned or Favorites and open in one click.
