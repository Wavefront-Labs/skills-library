# Word for the web vs the desktop app

Microsoft's comparison page (older, check it for your build) lists what Word for the web cannot do.

## Needs the desktop app
- **Compare** versions is not available in the web app.
- **Macros** can be viewed and edited but do not run in the browser.
- **Page layout and columns** are preserved but cannot be edited; you cannot create or modify styles or adjust line spacing.
- **Password-protected or IRM-protected** documents cannot be opened in the browser.
- **Tracked changes** are shown in Reading view; tracking or editing a document that has them needs the desktop app.
- Documents in other formats such as RTF, HTML and PDF cannot be opened in Word for the web.
- No custom dictionary, grammar checking, translation or thesaurus in the web app.

## Switch
Use **Open in Desktop** (also worded Open in Word) in the web app. Co-authoring works in both for files stored in OneDrive or SharePoint, and the web app saves automatically with version history kept on the server.

## Gotchas
- A feature missing in the web app does not delete it from the file; it just cannot be edited there.
- Browser extensions and pop-up blockers can break web apps; try a private window.

## Verify
- [ ] The file opens in both web and desktop and the feature you need is editable in the one you chose.
