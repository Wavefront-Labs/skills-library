# Set up a new computer

**Goal:** a secure, updated, backed-up computer with your files and apps in the first hour or two.

## During first start
- Connect to your home Wi-Fi (not public Wi-Fi).
- **Windows:** sign in with a Microsoft account (enables BitLocker device encryption key backup, OneDrive and Find my device); decline optional data sharing screens you don't want. Windows 11 Home requires a Microsoft account during setup.
- **Mac:** sign in with your Apple Account; turn on **FileVault** and Find My; Migration Assistant offers to copy from an old Mac now or later.
- Set a strong password/PIN and Windows Hello or Touch ID.

## First hour checklist
1. **Updates:** Windows Update (repeat until nothing is left, including *Optional updates* for drivers); Mac System Settings › General › Software Update.
2. **Remove bloatware:** Settings › Apps › Installed apps; uninstall trial antivirus and games you don't want (Microsoft Defender is built in and enough for most people).
3. **Browser:** install/sign in to your preferred browser and password manager; set defaults.
4. **Encryption:** Windows Settings › Privacy & security › **Device encryption** on (or BitLocker on Pro); check the recovery key is saved in your Microsoft account.
5. **Backup:** File History/Windows Backup or OneDrive folder backup; Time Machine with an external drive or cloud.
6. **Files and apps:** restore from backup or cloud (see moving to a new computer); install apps from the Store or the maker's site, never from search ads.
7. **Standard account** for daily use if you're comfortable managing a separate admin.

## Gotchas
- Keep the old computer untouched until everything is confirmed on the new one.
- Register the device for warranty and note the serial number.

## Verify
- [ ] Updates done, encryption on, backup ran once, a restored file opens, password manager works.
