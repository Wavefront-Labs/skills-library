# Accessibility features in Windows and macOS

**Goal:** make the computer easier to see, hear and control, with no extra software.

| Need | Windows 11 (Settings › Accessibility) | macOS (System Settings › Accessibility) |
|---|---|---|
| Enlarge part of the screen | **Magnifier**: `Win` + `+` / `Win` + `Esc` to quit | **Zoom**: enable, then `Option+Cmd+8`, or Ctrl + scroll |
| Bigger text/pointer | Text size; Mouse pointer and touch | Display › pointer size; Larger Text |
| Screen reader | **Narrator**: `Win+Ctrl+Enter` | **VoiceOver**: `Cmd+F5` |
| Captions for any audio | **Live captions**: `Win+Ctrl+L` | Live Captions (Apple silicon) |
| Talk instead of type | **Voice typing**: `Win+H` | Dictation: press `Fn`/mic key twice |
| Colour blindness, contrast | Colour filters, Contrast themes (`Left Alt+Left Shift+PrtScn`) | Display › Colour Filters, Increase contrast |
| Hard to press two keys | **Sticky keys** (press `Shift` 5 times) | Keyboard › Sticky Keys |
| Reduce motion/flicker | Visual effects › Animation effects off | Display › Reduce motion |

## Tips
- Phones have the same features: iPhone Settings › Accessibility; Android Settings › Accessibility
  (Magnification, TalkBack, Live Caption).
- Browsers and Office apps add page zoom (`Ctrl` + `+`) and Read Aloud on top.

## Gotchas
- Sticky Keys prompt appearing by accident (pressing Shift repeatedly in games): turn off the
  keyboard shortcut in the Sticky keys settings.
- Narrator/VoiceOver started by accident: same shortcut turns it off.

## Verify
- [ ] You can start and stop Magnifier/Zoom and live captions with their shortcuts.
