# Move files and apps to a new computer

**Goal:** everything you need is on the new computer, and you can prove it before wiping the old one.

## Inventory first (on the old computer)
- Where are files? Documents, Desktop, Pictures, Downloads, plus app data (Outlook PST files, accounting databases, game saves, browser bookmarks if not synced).
- List installed apps and their licence keys/accounts (Office, Adobe, antivirus, printer software).
- Note Wi-Fi passwords and email server settings if you use IMAP/POP.

## Windows to Windows
- **Windows Backup** (old PC, Windows 10/11): back up folders, settings, app list and credentials to your Microsoft account/OneDrive; sign in on the new PC with the same account and choose *Restore from this PC*.
- Or copy user folders to an external drive / move them via OneDrive.

## Mac to Mac
**Migration Assistant** (Applications › Utilities) on both Macs: transfer directly over Wi-Fi/cable, or from a Time Machine backup; moves apps, accounts, files and settings.

## Windows to Mac (or Mac to Windows)
Migration Assistant on Mac includes *From a Windows PC* (install Windows Migration Assistant on the PC). Otherwise use cloud storage or an external drive; reinstall apps natively.

## Apps and licences
- Reinstall from the Store or vendor; sign in to unlock subscriptions. Deactivate old-computer licences where seats are limited (Adobe, some tax software).
- Browsers: sign in to sync; export bookmarks and passwords from browsers you don't sync.

## Check nothing was left behind
- Compare folder sizes and file counts (right-click › Properties / Get Info) between old and new.
- Open a sample of documents, photos and emails on the new computer.
- Keep the old computer (or a full backup of it) for a few weeks before wiping and recycling.

## Verify
- [ ] Sample files open; email, browser, password manager and key apps work on the new computer.
