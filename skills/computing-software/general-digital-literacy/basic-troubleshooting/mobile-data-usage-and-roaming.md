# Mobile data usage and roaming

## See where data goes
- **iPhone**: Settings > Mobile Data (Cellular): usage per app for the *current period* (reset manually at your billing date with *Reset Statistics*). Turn off mobile data for heavy apps you only need on Wi-Fi.
- **Android**: Settings > Network & internet > SIMs > [SIM] > **App data usage**; set the billing cycle start date, a **data warning** and **data limit**.

## Use less
- iPhone **Low Data Mode** (Mobile Data Options) and Android **Data Saver**: pause background updates and lower streaming quality.
- Streaming apps: set mobile quality to Low/Data saver; download playlists, maps (Google Maps *Offline maps*) and videos on Wi-Fi.
- Turn off *Wi-Fi Assist* (iPhone) / *Switch to mobile data* (Android) if Wi-Fi is weak but you're on a small plan.
- iCloud/Google Photos backup over Wi-Fi only.

## Roaming abroad
- Check your plan's roaming terms before leaving (many UK/EU plans charge daily fees; US plans vary).
- Turn **Data Roaming off** (iPhone Mobile Data Options; Android SIM settings) until you decide to use it.
- **Travel eSIM** (Airalo, Holafly, carrier day passes): install before leaving, set it for data, keep your home SIM for calls/SMS (2FA codes). Settings > Mobile Data > *Mobile Data* line selection.
- Calls over Wi-Fi (Wi-Fi Calling) may still be billed as roaming by some carriers; check.
- Cruise ships and planes use satellite roaming at very high prices; airplane mode plus onboard Wi-Fi.

## Verify
- [ ] Data warning set at your plan size and roaming off unless deliberately switched on.
