# Archive vs delete and inbox zero

## What archive does
- **Gmail**: removes the *Inbox* label; the message stays in **All Mail** and in search. Shortcut `e`.
- **Outlook**: moves it to the **Archive** folder (Backspace / *Archive* button). Classic Outlook can
  set archive folder in File › Options.
- **Apple Mail**: moves to the account's Archive mailbox (Ctrl+Cmd+A).
- **Delete** sends to Trash/Deleted Items, which empty automatically (Gmail after 30 days).
Archive anything you might need again; delete newsletters, notifications and junk.

## Daily triage (the 4 Ds)
For each message, once: **Delete/archive** it, **Do** it now (< 2 minutes), **Delegate** (forward),
or **Defer** (snooze, flag, or turn into a task). Inbox = only what still needs a decision.

## Set up
- Phone swipe actions: Gmail Settings › Swipe actions (archive left/right); Outlook Settings › Swipe
  options; iPhone Mail Settings › Swipe Options.
- Gmail: Settings › *Send and Archive* button in replies.
- Search instead of folders: `from:alex invoice` finds archived mail faster than a folder tree.

## Gotchas
- Archived Gmail messages come back to Inbox when someone replies (conversation).
- Outlook's *Archive* button is different from AutoArchive (classic Outlook moving old mail to a
  local PST file, not backed up to the server). Avoid PST archives for new setups.

## Verify
- [ ] Inbox holds only messages awaiting action; an archived message is found by search in seconds.
