# Contact groups and distribution lists

## Personal lists (only you can use)
- **Outlook (classic)**: People › New Contact Group › add members › Save. **New Outlook / web**:
  People › **New contact list**. Type the list name in To/Bcc.
- **Gmail**: contacts.google.com › select contacts › **Manage labels** › create a label (e.g. "Book
  club"). In Gmail type the label name in To/Bcc to add everyone.
- **Apple**: Contacts › File › New List; type the list name in Mail.
- Expand a list in Outlook (+) to remove one person for this message only.

## Shared lists (organisation)
- Microsoft 365: an **Outlook group / Microsoft 365 group** or a **distribution list** (created by you
  or IT) gives one address like team@company.com; membership updates for everyone.
- Google Workspace: **Google Groups** address.

## Etiquette and privacy
- External people who don't know each other: put the list in **Bcc** and yourself in To.
- More than ~50 recipients or anything marketing-like: use a mailing service with unsubscribe links
  (consent and anti-spam laws apply).

## Gotchas
- Contact groups in classic Outlook don't sync to the phone in all apps; Gmail labels do.
- Replies to a group address go to the whole group; say so in the message if replies should come only
  to you.

## Verify
- [ ] Send a test to the list including yourself; check recipients aren't visible if you used Bcc.
