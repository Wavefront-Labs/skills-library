# Data story
1. Answer first: finding, size, confidence, recommended action.
2. Evidence: one chart per point, title states the takeaway.
3. Uncertainty: intervals, assumptions, what would change the conclusion.
4. Next steps and decision owners; method in an appendix.
## Gotchas
- Reporting p-values to non-statisticians; translate to effect size and risk.
- Every chart should earn its place; remove decoration.
## Verify
- [ ] A colleague can state the recommendation after 60 seconds.
