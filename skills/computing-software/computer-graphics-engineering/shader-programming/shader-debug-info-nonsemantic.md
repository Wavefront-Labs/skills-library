# Shader debug info

Without debug info a GPU debugger can only show disassembly. With it you get source lines,
variable names and step debugging.

## 1. SPIR-V: NonSemantic.Shader.DebugInfo.100
The extended instruction set `NonSemantic.Shader.DebugInfo.100` carries full source, line tables,
scopes, local variables and types. Being "non-semantic", drivers may ignore it, so it is safe to
leave in debug builds.
```bash
glslangValidator -V -gVS shader.frag -o shader.spv     # -gVS = nonsemantic shader debug info with source (-gV: without source)
glslangValidator -V -g shader.frag -o shader.spv       # -g = generate debug information (OpLine/OpSource style)
dxc -spirv -fspv-debug=vulkan-with-source -Zi -T ps_6_0 -E main shader.hlsl -Fo shader.spv
slangc shader.slang -target spirv -g2 -o shader.spv
```
Requires `VK_KHR_shader_non_semantic_info` (core in 1.3) at runtime, otherwise strip it with
`spirv-opt --strip-nonsemantic`.

RenderDoc supports source-level debugging on Vulkan through `NonSemantic.Shader.DebugInfo.100`, generated by
glslang with `-gVS` and by dxc with `-fspv-debug=vulkan-with-source`. DXC's `-fspv-debug=` also accepts `file`,
`source`, `line` and `tool`; `vulkan-with-source` overrules the others and `-Zi`.

## 2. DXIL: PDBs
```bash
dxc -T ps_6_6 -E main -Zi -Qembed_debug shader.hlsl -Fo shader.cso     # debug info embedded
dxc -T ps_6_6 -E main -Zi -Fd pdbs/ -Qstrip_debug shader.hlsl -Fo shader.cso   # separate PDB
```
- `-Fd` writes debug information to the given file, or to an automatically named file in the directory when the path
  ends in a path separator (per the dxc help text, which shows a backslash).
- `-Qembed_debug` embeds the PDB in the container and must be used with `-Zi`; `-Qstrip_debug` strips debug info.
- `-Zss` computes the shader hash from source information too; `-Zsb` from the output binary only.
- `-Od` disables optimisation.
- RenderDoc supports split PDBs written with `/Fd`, and advises against `/Qstrip_debug` and `/Qstrip_reflection`
  because they remove useful reflection names.

## Gotchas
- Never ship debug info; archive it keyed by binary hash.
- Shader caches keyed only by bytecode will mix debug and release variants; include the flags.
- Debug the original SPIR-V or DXIL where possible, not the output of a translator.
