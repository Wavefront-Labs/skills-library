# ORDER BY, SKIP and LIMIT

Goal: page results predictably.
- `ORDER BY p.created DESC SKIP $o LIMIT $n`; `OFFSET` is a synonym for `SKIP`.
- Neo4j does not guarantee the results generated by `SKIP`/`OFFSET`; the only clause that guarantees a row order is `ORDER BY`, so always page with it.
- `SKIP` takes any expression that evaluates to a non-negative integer and refers to no variables, so a parameter works.
Verify: pages contain no duplicates when the sort key is unique.
