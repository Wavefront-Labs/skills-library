# FIPS 186-5 RSA key generation

## Requirements
- Modulus bit length `nlen` is even and at least 2048; p and q are the same length, half of `nlen`.
- Public exponent `e` odd with `2^16 < e < 2^256`; 65537 is the usual choice.
- (p-1) and (q-1) are relatively prime to e; each prime lies between `sqrt(2) * 2^(nlen/2 - 1)` and `2^(nlen/2) - 1`;
  `|p - q| > 2^(nlen/2 - 100)`.
- d satisfies `2^(nlen/2) < d < lcm(p-1, q-1)` and `d = e^-1 mod lcm(p-1, q-1)`; if d is too small, generate new values.
- Methods in Appendix A.1: A.1.2 provable primes, A.1.3 probable primes, A.1.4 provable primes with auxiliary
  provable primes, A.1.5 probable primes with auxiliary provable primes, A.1.6 probable primes with auxiliary probable
  primes. All need an approved DRBG whose security strength is at least that of the key being generated.

## Primality testing
Appendix B, Table B.1 gives minimum Miller-Rabin rounds by prime size and error probability (for example, for
p and q of 1024 bits at error probability 2^-100: 4 rounds, with 32 for the auxiliary primes). The Lucas test may follow the
Miller-Rabin rounds for extra assurance. Use the table for the size and error target you need.

## Using libraries
- Never implement prime generation yourself; use a validated module.
- Check your library's documentation for which FIPS 186 method it implements and whether its FIPS mode differs from
  the default path.

## Verify
- [ ] Key generated by a validated module, CMVP certificate lists RSA KeyGen (FIPS 186-5).
- [ ] Modulus size and e are as expected.
