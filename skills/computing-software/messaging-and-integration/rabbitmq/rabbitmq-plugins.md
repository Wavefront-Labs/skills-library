# rabbitmq-plugins

**Goal:** Manage plugins reproducibly.

## Steps
1. `rabbitmq-plugins list`, `enable <name>`, `disable <name>`. Use `--offline` to edit the enabled plugin file directly without contacting the node, for example during provisioning; it takes effect at next node start.
2. The `enabled_plugins` file can be generated by deployment tools; edits to it require a node restart.
3. Against a running node, enable and disable take effect without restart.

## Failure modes
- Without `--offline`, the command fails if it cannot connect to and authenticate with the node (`--online` makes that failure fatal).

## Verify
- `rabbitmq-plugins list -e` (enabled plugins only).
