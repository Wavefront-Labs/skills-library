# Auto attendants and call queues
**Goal:** Build call flows with resource accounts.

- Voice > Auto attendants / Call queues; each needs a resource account with a phone number.
- Set business hours, holiday sets and menu options.
- Call queue routing: attendant, serial, round robin, longest idle; agent opt-out.
- Test with time-of-day changes.

## Gotchas
- Resource accounts without a licence can't get a number.
- Nested attendants/queues need their own accounts.

## Self-check
Call the number during and outside hours and confirm both flows.
