# App permission and setup policies
**Goal:** Allow or block apps and pin them for users.

- Teams apps > Permission policies: allow/block Microsoft, third-party and custom apps.
- Setup policies pin apps in the app bar for assigned users.
- Manage apps: Teams apps > Manage apps; block or approve per app.
- App submission and approval workflows pass through Manage apps.

## Gotchas
- Blocking an app in Manage apps blocks it org-wide regardless of policy.
- Pinned apps need the user to restart Teams.

## Self-check
A test user sees only permitted apps.
