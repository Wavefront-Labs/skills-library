# Site lifecycle and inactive sites
**Goal:** Find and retire stale sites.

- Inactive sites policy (SharePoint Advanced Management or Syntex, licence-dependent, confirm).
- Site attestation / ownership policies request owner review.
- Report: SharePoint admin center > Reports or Graph usage reports.
- Archive via Microsoft 365 Archive when available (confirm).

## Gotchas
- Don't delete sites tied to teams; handle at the group.
- Hold policies still apply to deleted sites.

## Self-check
Stale sites list is reduced after an owner review cycle.
