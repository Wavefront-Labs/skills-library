# Emergency calling
**Goal:** Configure emergency addresses and policies.

- Voice > Emergency addresses, network topology (subnets, trusted IPs) for dynamic location.
- Emergency calling policy defines notifications to security desk.
- Routing policy for Direct Routing uses SBC-configured emergency routes.
- Regional rules differ (for example Ray Baum's Act in the US); confirm local law.

## Gotchas
- Remote workers need dynamic emergency addressing per local regulation.
- Test only in coordination with the carrier.

## Self-check
A test user's location shows in the E911 or equivalent record.
