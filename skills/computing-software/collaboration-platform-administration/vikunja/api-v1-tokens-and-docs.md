Docs are served by your own instance at `/api/v1/docs`, with the spec at `/api/v1/docs.json` for embedding in other OpenAPI-compatible applications. A public instance is at try.vikunja.io. They are autogenerated from swagger annotations in the code.

Authentication, recommended: create an API token in the web UI under Settings, API Tokens, and send:

```
Authorization: Bearer <token>
```

On self-hosted instances you can also authenticate with username and password via the `/api/v1/login` endpoint to obtain a JWT. Vikunja Cloud does not support username/password authentication; use API tokens.

Versions: from 2.4.0 there is also API v2 with standard REST verbs and an OpenAPI 3.1 spec. v1 stays supported but new endpoints land only on v2; per the docs 3.0 deprecates v1 and 4.0 removes it. Prefer v2 for new integrations when it covers your need.
