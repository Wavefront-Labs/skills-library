# Search results export and review
**Goal:** Export or review results with audit.

- Export report and results; PST or individual messages via the Export tool.
- Premium: Add search results to review set, tag, and export.
- Use the unified audit log to review who exported.
- Release the hold when the case closes.

## Gotchas
- Export keys expire; download promptly.
- Partially indexed items must be included.

## Self-check
Export report totals equal the item count in the search.
