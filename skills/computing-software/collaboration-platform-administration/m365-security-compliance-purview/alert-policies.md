# Alert policies and attack simulation
**Goal:** Tune alert policies and run phishing simulations.

- Defender > Email & collaboration > Policies > Alert policies; add recipients.
- Attack simulation training (Plan 2) sends simulated phishing and assigns training.
- Use pilot groups and get HR approval before simulations.
- Report click rates over time.

## Gotchas
- Notify the helpdesk before simulations.
- Do not use simulations to punish users.

## Self-check
Simulation completes and results report appears.
