# Records management
**Goal:** Declare records with file plans and disposition review.

- Records management > File plan: create labels marked as record or regulatory record.
- Enable disposition review and assign reviewers.
- Event-based retention starts retention from an event.
- Use the file plan import for bulk.

## Gotchas
- Regulatory record labels cannot be removed or edited.
- Plan retention periods with Legal first.

## Self-check
Dispositions queue shows a test item at expiry.
