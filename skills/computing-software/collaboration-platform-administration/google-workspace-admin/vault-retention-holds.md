# Vault retention rules and holds
**Goal:** Set retention and legal holds in Vault.

- Vault licence needed (Business Plus, Enterprise or Vault add-on).
- Retention rules per service (Gmail, Drive, Chat, Meet) with a period and action.
- Matters group search and holds; holds override retention deletion.
- Assign Vault privileges to a limited role.

## Gotchas
- Retention shortens as well as lengthens data lifespan; test scope.
- Holds apply only to included accounts or OUs.

## Self-check
A held user's deleted item still appears in Vault search.
