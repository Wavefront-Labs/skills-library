# Alert center and custom alerts
**Goal:** Triage alerts and create reporting rules.

- Security > Alert center lists suspicious logins, leaked passwords and phishing.
- Rules: Rules > Create rule for reporting (activity or data protection) with email notification.
- Delegate alert notifications to the security team.
- Close alerts with notes.

## Gotchas
- Default alerts notify super admins only; set recipients.
- Test rules produce an alert in a pilot OU.

## Self-check
Triggering a test event creates an alert and an email.
