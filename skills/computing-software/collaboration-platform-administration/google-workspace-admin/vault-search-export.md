# Vault search and export
**Goal:** Search a matter and export results.

- Create a matter, add collaborators, search by account, OU, date, terms.
- Export to MBOX or PST for Gmail; Drive exports include metadata.
- Download uses a secure link; audit the exports in the Vault audit log.
- Preview before exporting.

## Gotchas
- Limited privileges: only designated reviewers.
- Searches that include Drive may need shared drive scope.

## Self-check
The export file count matches the result count.
