# Groups for Business and access groups
**Goal:** Create groups for email lists and access control with sensible settings.

- Directory > Groups > Create group; set access: who can join, post, view members, and external posting.
- Group types: email list, collaborative inbox, Q&A, and security groups (label for access control, confirm current wording).
- Use groups to share Drive, Calendar, Sites and licences-by-group where supported.
- Dynamic groups (rule-based membership) exist in some editions (confirm).

## Gotchas
- Allow external members only where required.
- Nested group depth is limited; keep it simple.

## Self-check
Add a test member and verify a message to the group address reaches them.
