# Drive sharing and trust rules
**Goal:** Set external sharing and trust rules per OU.

- Apps > Google Workspace > Drive and Docs > Sharing settings: sharing outside the organisation, warn on external, link sharing default.
- Trust rules allow sharing with allowlisted domains (Allowed list) per OU.
- Distributing content outside: warn only vs block.
- Access checker restricts when sharing to a non-Google account.

## Gotchas
- Link sharing default 'Off' prevents accidental public links.
- Shared drives follow their own settings.

## Self-check
Test external share is blocked or warned per the policy.
