# Shared drives management
**Goal:** Create and manage shared drives with roles.

- Apps > Drive and Docs > Manage shared drives: create/delete, change membership.
- Roles: Manager, Content manager, Contributor, Commenter, Viewer.
- Restrict shared drive creation to selected OUs.
- Orphaned drive recovery by admin; trash retention 30 days for items.

## Gotchas
- Shared drive ownership is organisational; deleting the drive removes content after the retention period.
- Limit membership by role, not by user-by-user sprawl.

## Self-check
Admin console shows a manager for every shared drive.
