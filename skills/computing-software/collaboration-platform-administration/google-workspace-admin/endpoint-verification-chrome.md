# Endpoint Verification and Chrome management
**Goal:** Inventory computers and manage Chrome browser policy.

- Endpoint Verification extension reports OS, encryption and screen lock status for context-aware access.
- Chrome browser cloud management: Devices > Chrome > Settings.
- Force-install extensions, block sites, set update policies.
- Use enrolment tokens to manage Chrome on unmanaged machines.

## Gotchas
- Needs consent on personal devices; check privacy rules.
- Policy applies per signed-in profile vs per browser.

## Self-check
chrome://policy on a test machine shows the applied policies.
