# 2-Step Verification and security keys
**Goal:** Enforce 2SV and phishing-resistant methods.

- Security > Authentication > 2-step verification: allow, enforce with a start date and new-user grace period.
- Enforce security keys only for admins/high-risk groups.
- Backup codes and recovery methods per user; admin can issue codes.
- Advanced Protection Program for high-risk accounts.

## Gotchas
- Enforcing without enrolment time locks users out.
- Keep at least one super admin with a security key.

## Self-check
Security > Reporting > 2SV enrollment shows near-full coverage.
