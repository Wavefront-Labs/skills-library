# Message center and change management
**Goal:** Process Message center posts to prepare users for changes.

- Admin center > Health > Message center; filter by Major update, Retirement, Prevent or fix issue.
- Tag messages and mark as read; archive done ones.
- Subscribe to weekly digest or Planner sync for tracking.
- Use targeted release (Org settings > Release preferences) for pilot groups.

## Gotchas
- Dates are targets; Microsoft can move them, so recheck before communicating to users.
- Retirement posts often require admin action before a hard date.

## Self-check
Each Major update post has an owner and a pilot decision recorded.
