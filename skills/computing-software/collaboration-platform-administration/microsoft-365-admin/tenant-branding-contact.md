# Tenant branding and organization profile
**Goal:** Set organisation information, technical contact and sign-in branding.

- Settings > Org settings > Organization profile: name, address, technical contact, release preferences.
- Sign-in page branding is set in the Entra admin center under Company branding (reference, not duplicated here).
- Set a monitored technical contact mailbox; Microsoft sends notices there.
- Theme the Microsoft 365 apps via Organization profile > Custom themes.

## Gotchas
- Tenant name (onmicrosoft.com) cannot be changed after creation; plan the initial name.
- Branding images have size and format limits; check the upload hint.

## Self-check
Sign in as a test user and confirm the branding and theme.
