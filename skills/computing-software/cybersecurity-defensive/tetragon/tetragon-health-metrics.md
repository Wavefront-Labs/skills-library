# Tetragon health metrics

Goal: find the metric that shows whether the agent is dropping or failing to process events. The list is autogenerated from the metrics registry.

## Loss and errors

- `tetragon_bpf_missed_events_total`: perf events that failed to be sent from the kernel (labels `error`, `opcode`, `opstr`).
- `tetragon_observer_ringbuf_events_lost_total` / `_received_total` / `_errors_total`: ring buffer lost, received and read errors. `tetragon_observer_ringbuf_queue_events_lost_total` / `_received_total` cover its event queue.
- `tetragon_notify_overflowed_events_total`: events dropped because a listener buffer was full.
- `tetragon_events_export_failed_total`, `tetragon_export_ratelimit_events_dropped_total` (dropped by export rate limiting), `tetragon_field_filter_failed_total`.
- `tetragon_missed_link_probes_total`, `tetragon_missed_prog_probes_total`, `tetragon_enforcer_missed_notifications_total`.
- `tetragon_events_missing_process_info_total`; `tetragon_handler_errors_total` and `tetragon_errors_total` are for internal use.

## Export

`tetragon_events_exported_total`, `tetragon_events_exported_bytes_total`, `tetragon_events_last_exported_timestamp`.

## Caches and maps

- Process cache: `tetragon_process_cache_capacity`, `_size`, `_evictions_total`, `_misses_total`, and `_early_deletions_total` (GC may be deleting processes too early).
- Event cache: `tetragon_event_cache_entries`, `_inserts_total`, `_errors_total`, `_fetch_retries_total`, `_fetch_failures_total`.
- Data cache: `tetragon_data_cache_capacity`, `_size`, `_evictions_total`, `_misses_total`.
- BPF maps: `tetragon_map_capacity`, `tetragon_map_entries`, `tetragon_map_errors_update_total`, `tetragon_map_errors_delete_total` (label `map`: `execve_map`, `tg_execve_joined_info_map`).

## Policies and overhead

- `tetragon_tracingpolicy_loaded` by `state` (`disabled, enabled, error, load_error, partially_enabled, skipped`).
- `tetragon_tracingpolicy_kernel_memory_bytes`: memlock bytes used by a policy's non-shared BPF maps.
- `tetragon_tracingpolicy_selector_actions_total`: actions per selector.
- `tetragon_overhead_program_runs_total` and `tetragon_overhead_program_seconds_total`: BPF program executions and run time.
- `tetragon_policyfilter_operations_total`, `tetragon_cgroup_rate_total`, `tetragon_build_info`, `tetragon_handling_latency` (microseconds).

## Kubernetes watcher

`tetragon_watcher_events_total`, `tetragon_watcher_errors_total`, `tetragon_watcher_delete_pod_cache_hits`, `tetragon_watcher_delete_pod_cache_evictions`.
