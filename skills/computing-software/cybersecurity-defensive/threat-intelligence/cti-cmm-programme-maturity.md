# CTI programme maturity with CTI-CMM

The Cyber Threat Intelligence Capability Maturity Model (CTI-CMM) is a community-driven framework giving CTI
programmes a roadmap to improve stakeholder support. The site's premise: a programme's value depends on
understanding and serving internal customers, and it shows value by reducing risk exposure through cyber
defence actions.

## Structure (per cti-cmm.org)
- Domains define CTI support practices for stakeholder types found in most organisations (version 1.0 had
  10 domains; version 1.1 added Fraud).
- Each domain offers prescriptive practices and measures from common stakeholder use cases, mapping CTI
  practices to the maturity expectations of the stakeholder being supported.
- Assessment tool: an Excel spreadsheet (beta in 1.1, first production version in 1.2) to benchmark current
  support per stakeholder function.
- Version 1.2 added appendices: "CTI Metrics and Measurements", "CTI Data Source Library", "CTI Data Source
  Matrix". Version 1.3 fine-tuned use cases and practices; use the most recent version (free PDF download).

## Running an assessment
1. Choose the domains (stakeholder functions) relevant to your organisation.
2. Rate current practices with the stakeholders concerned, with evidence (products produced, actions taken).
3. Set target levels per domain from business priorities, then derive a roadmap with owners and measurable
   outcomes. Reassess periodically.
For domain names, level definitions and exact practices read the current CTI-CMM PDF; they are not
reproduced here.

## Gotchas
- Self-assessed maturity inflates: require examples of products and actions.
- Do not target the top level everywhere; pick the domains that matter.
