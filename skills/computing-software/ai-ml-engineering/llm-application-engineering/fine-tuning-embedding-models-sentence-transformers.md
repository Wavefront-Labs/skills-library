# Fine-tuning embedding models with sentence-transformers

**Goal:** retrieval recall on your domain (internal jargon, product codes, legal text) improves measurably over the off-the-shelf model.

## When it pays
Off-the-shelf models plus hybrid search and a reranker are the baseline. Fine-tune when evals show the retriever misses relevant chunks because of domain vocabulary, and you can get thousands of query-passage pairs.

## Data
`(anchor, positive)` pairs: real user queries with clicked/cited passages, or synthetic queries generated by an LLM for each chunk ("Write 3 questions this passage answers"). Filter synthetic pairs with a cross-encoder or LLM check. Hold out a test split by document, not by pair, to avoid leakage.

## Train
```python
from datasets import load_dataset
from sentence_transformers import SentenceTransformer, SentenceTransformerTrainer, SentenceTransformerTrainingArguments
from sentence_transformers.losses import MultipleNegativesRankingLoss, MatryoshkaLoss
from sentence_transformers.training_args import BatchSamplers
from sentence_transformers.util import mine_hard_negatives
from sentence_transformers.evaluation import InformationRetrievalEvaluator

model = SentenceTransformer("BAAI/bge-base-en-v1.5")
train = load_dataset("json", data_files="pairs_train.jsonl")["train"]           # columns: anchor, positive
train = mine_hard_negatives(train, model, num_negatives=1, range_min=10, range_max=50, sampling_strategy="random")
loss = MatryoshkaLoss(model, MultipleNegativesRankingLoss(model), matryoshka_dims=[768, 256, 128])
args = SentenceTransformerTrainingArguments(output_dir="out", num_train_epochs=1, per_device_train_batch_size=128,
    learning_rate=2e-5, warmup_ratio=0.1, bf16=True, batch_sampler=BatchSamplers.NO_DUPLICATES,
    eval_strategy="steps", eval_steps=200, save_steps=200, load_best_model_at_end=True)
ir_eval = InformationRetrievalEvaluator(queries=test_queries, corpus=test_corpus, relevant_docs=test_qrels, name="dev")
SentenceTransformerTrainer(model=model, args=args, train_dataset=train, loss=loss, evaluator=ir_eval).train()
```
- MultipleNegativesRankingLoss uses other batch items as negatives: larger batches help (use `CachedMultipleNegativesRankingLoss` for big effective batches on small GPUs).
- `NO_DUPLICATES` avoids false negatives from duplicate texts in a batch.
- Hard negatives mined from ranks 10-50 avoid picking unlabeled true positives at the very top.

## Evaluate
Report NDCG@10, recall@k, MRR on the held-out set against the base model, then re-run end-to-end RAG evals. Also check a general benchmark subset for catastrophic forgetting if the model serves other tasks.

## Deploy
A new model means re-embedding the entire corpus and a new index (never mix versions). Keep the base model's required query/passage prefixes consistent between training and inference.

## Verify
- [ ] Held-out NDCG@10 and recall improved over base.
- [ ] Corpus fully re-embedded with the new model before switching traffic.
