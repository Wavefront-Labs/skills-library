# NGO RPCs with the Rpc attribute

**Goal:** client requests and server broadcasts that are targeted, validated and cheap.

## Universal RPC (NGO 1.8+)
```csharp
public class Weapon : NetworkBehaviour {
    [Rpc(SendTo.Server)]
    void FireRpc(Vector3 aimDir, RpcParams p = default) {
        ulong sender = p.Receive.SenderClientId;
        if (sender != OwnerClientId || !CanFire()) return;                  // validate everything from clients
        var hit = ServerRaycast(aimDir);
        FireFxRpc(hit.point);                                               // tell everyone to show effects
    }

    [Rpc(SendTo.ClientsAndHost)]
    void FireFxRpc(Vector3 impact) => fx.Play(impact);

    [Rpc(SendTo.SpecifiedInParams)]
    void PrivateMessageRpc(FixedString128Bytes msg, RpcParams p) => chat.Show(msg.ToString());
    // call: PrivateMessageRpc("hi", RpcTarget.Single(clientId, RpcTargetUse.Temp));

    void Update() { if (IsOwner && Input.GetMouseButtonDown(0)) FireRpc(cam.forward); }
}
```
- Method names **must end in `Rpc`**. Code is generated by ILPP; compile errors appear if not.
- `SendTo` targets: `Server`, `Owner`, `NotOwner`, `Me`, `NotMe`, `Everyone`, `ClientsAndHost`,
  `NotServer`, `SpecifiedInParams`, `Authority`/`NotAuthority` (distributed authority).
- `RequireOwnership = false` in the attribute lets non-owners invoke a server RPC (interacting with doors).
- Delivery: `[Rpc(SendTo.Everyone, Delivery = RpcDelivery.Unreliable)]` for cosmetic, frequent messages.
- Legacy `[ServerRpc]` / `[ClientRpc]` still work; don't mix styles in new code.

## Parameters
Primitives, structs, `FixedString`, `NetworkObjectReference` / `NetworkBehaviourReference` (to reference
spawned objects), arrays of those, `INetworkSerializable`, and `string` (allocates; prefer FixedString). Class references cannot be sent.
```csharp
[Rpc(SendTo.Server)] void PickUpRpc(NetworkObjectReference itemRef) {
    if (itemRef.TryGet(out NetworkObject item) && InRange(item)) Give(item);
}
```

## Rules
- RPCs are events: missed by late joiners. Persisting state goes in NetworkVariables.
- RPCs only work on **spawned** NetworkObjects; calling before OnNetworkSpawn throws.
- Ordering: reliable RPCs on the same object arrive in order; no ordering guarantee versus NetworkVariable updates.
- Never trust client-supplied positions, damage or ids; recompute on the server.

## Verify
- [ ] A modified client calling FireRpc on another player's weapon is rejected.
- [ ] Late joiner state is correct without replaying RPCs.
