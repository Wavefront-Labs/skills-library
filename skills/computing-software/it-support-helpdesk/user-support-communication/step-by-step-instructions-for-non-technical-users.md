# step-by-step-instructions-for-non-technical-users

Goal: the user completes the task on the first attempt without calling.

## Rules for each step
- **One action per step**, numbered. Start with the verb: "Select",
  "Type", "Open".
- Use the **exact UI label** in bold, matching capitalisation: Select
  **Settings** > **Accounts** > **Sign-in options**. (Microsoft style: "select"
  for clicks/taps.)
- Say **where** on screen if it's not obvious ("at the bottom left").
- Show the **expected result** after important steps: "A window titled
  *Add a device* opens."
- Put conditions before actions: "If you see a yellow warning, select
  **Fix**." not after.
- Explain how to know it's finished.

## Format
1. Title as the user's goal: "Connect to the office printer from your
   laptop".
2. "Before you start" (what they need: laptop on office Wi-Fi, 5 minutes).
3. Numbered steps (7 ± 2; split longer procedures into parts).
4. "If it didn't work" — 2–3 most common issues, then how to contact
   support with the ticket reference.

## Screenshots
- Crop to the relevant area, annotate with one highlight box/arrow per
  image, hide personal data. Alt text describing the action for screen
  reader users.
- Update when the UI changes — outdated screenshots cause more calls than
  no screenshots.

## Language
- Avoid jargon ("authenticate" → "sign in", "cache" → explain or avoid).
- Second person, present tense, short sentences.
- Platform-specific variants (Windows / Mac / phone) as separate sections
  or tabs, not mixed in one list.

## Test it
Hand it to someone outside IT; watch silently; every hesitation is a step to
rewrite. Re-test after Windows/app updates.

## Verify
Novice test completed without help; KB article/ticket replies show fewer
follow-up questions; article feedback ratings improve.
