# TSIG keys over the API

Available since 4.2.0. Send `X-API-Key` on every request.

- `POST /api/v1/servers/localhost/tsigkeys` generates a new key and returns 201.
- `PUT /api/v1/servers/localhost/tsigkeys/mytsigkey.` updates the key and returns 200. The path uses the object's `id`, which is the name with a trailing dot.
- The full method list is in the OpenAPI definition served at `/api/docs`.

TSIGKey object:
- `name`: for example `mytsigkey`
- `algorithm`: for example `hmac-sha256`
- `id`: name with trailing dot, for example `mytsigkey.`
- `key`: base64 secret; generated by the server on POST, supplied by you on PUT
- `type`: `TSIGKey`

The PUT example sends `name` and `key`; the page does not say whether `algorithm` may change.
