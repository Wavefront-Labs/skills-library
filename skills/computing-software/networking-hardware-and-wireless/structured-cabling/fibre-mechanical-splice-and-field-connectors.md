# Mechanical splices and field connectors

- Mechanical splices align fibres in a V-groove with index-matching gel; quick and cheap in tooling but loss is higher and less stable than fusion (commonly 0.2-0.5 dB).
- Field-installable connectors (pre-polished stub with mechanical splice inside) suit small jobs, repairs and restoration; factory pigtails with fusion splicing are preferred for backbones.
- Pre-terminated assemblies with factory polish and tested loss save install time; measure length and routing carefully.
- Record method per link so loss budgets use realistic figures.

## Verify
- [ ] Loss measured on each link is within the budget that assumed the used termination method.
