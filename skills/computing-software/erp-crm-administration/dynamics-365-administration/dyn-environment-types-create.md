# Create and manage environments
**Goal:** Choose the right environment type and lifecycle.

- Environment types include production, sandbox, trial, developer and the default environment; manage them in the Power Platform admin center.
- Use separate environments for dev, test and production; assign security groups to restrict access.
- Back up, copy and reset sandboxes as needed.

## Gotchas
- The default environment is shared by all users; keep production workloads out of it.

## Self-check
Environment lists in the admin center show the correct types and security groups.
