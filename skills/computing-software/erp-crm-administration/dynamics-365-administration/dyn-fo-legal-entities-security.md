# Configure legal entities and security roles
**Goal:** Set up organisational structure and role-based security.

- Legal entities are the main company structure; security is role, duty, privilege.
- Assign users to roles and restrict by legal entity or organisation; use Segregation of Duties rules.
- Test with the Security diagnostics.

## Gotchas
- Over-privileged custom roles are common; start from standard roles.

## Self-check
User can access only the intended forms.
