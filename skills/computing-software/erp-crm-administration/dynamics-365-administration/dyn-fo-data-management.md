# Move data with data entities
**Goal:** Import/export with the Data management workspace.

- Import and export projects use data entities; staging tables allow validation before target.
- Recurring integration or the data management package REST API for automation.
- Batch jobs process in the background.

## Gotchas
- Entity sequences and dependencies matter for loads.

## Self-check
Import project completes with no staging errors.
