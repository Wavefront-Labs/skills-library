# Manage companies and permission sets
**Goal:** Set up users and permissions.

- Companies hold data; users get permission sets (SUPER is superuser; use specific sets) and user groups.
- Manage via the Business Central admin center for environments and via Users page.
- Use licences per user and entitlement.

## Gotchas
- SUPER permission should be limited to few accounts.

## Self-check
User with limited permission sets cannot open restricted pages.
