# Manage environments and extensions
**Goal:** Control updates and extensions.

- Production and sandbox environments are managed in the Business Central admin center; schedule updates and manage extensions (AL).
- Install apps from AppSource or custom extensions; use per-tenant extensions.
- Check update windows.

## Gotchas
- Extensions can block updates if incompatible.

## Self-check
Environment updates succeed with extensions installed.
