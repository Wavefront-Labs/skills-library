# Run periodic access reviews
**Goal:** Recertify who has what.

- Export users and roles per system, send to role owners, record keep/remove decisions and apply removals.
- Include privileged and service accounts.
- Keep evidence for audits.

## Gotchas
- Reviews without follow-through fail audits.

## Self-check
Removals executed and verified.
