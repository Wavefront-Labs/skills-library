# Define master data ownership and standards
**Goal:** Assign owners and rules to customer, vendor, material and account data.

- Name a data owner and steward per domain; define mandatory fields, formats and naming standards.
- Create request, approval and change workflows.
- Measure quality: completeness, uniqueness, validity.

## Gotchas
- Without ownership duplicates return after migration.

## Self-check
Quality dashboard shows trends and owners.
