# Use Setup Audit Trail
**Goal:** See configuration changes.

- Setup > View Setup Audit Trail shows the last 20 changes online and can download up to 180 days of changes as CSV.
- Export regularly if you need longer retention.
- Pair with field history tracking for data changes.

## Gotchas
- Setup Audit Trail retention is 180 days; archive it.

## Self-check
Recent change appears with user and time.
