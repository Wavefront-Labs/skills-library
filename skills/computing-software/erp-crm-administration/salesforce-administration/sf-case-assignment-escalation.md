# Configure case assignment and escalation
**Goal:** Route and escalate cases.

- Case assignment rules by criteria to queues or users; escalation rules based on business hours and age.
- Use queues, case teams and Omni-Channel for routing.
- Set up case record types and support processes.

## Gotchas
- Assignment rules apply only when checked on web-to-case or via API option.

## Self-check
A new case lands in the expected queue and escalates at the set time.
