# Build record pages with component visibility
**Goal:** Use Lightning App Builder with visibility filters and dynamic forms.

- Setup > Lightning App Builder: choose a template, add components, and set component visibility filters on record fields, user permissions or device.
- Dynamic Forms (on supported objects) split fields into sections with visibility rules.
- Activate the page as org default, app default or by app/record type/profile.

## Gotchas
- An unactivated page is not shown; check the activation assignment.

## Self-check
The tab shows the intended components for each role.
