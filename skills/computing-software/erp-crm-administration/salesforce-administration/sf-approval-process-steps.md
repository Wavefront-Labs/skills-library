# Design approval processes
**Goal:** Build multi-step approvals with entry criteria and actions.

- Setup > Approval Processes: set entry criteria, approver selection (users, queues, managers), record lock and initial/final actions.
- Add steps with criteria for amounts or regions and configure rejection behaviour.
- Recall action lets submitters withdraw.

## Gotchas
- Locked records block edits unless admins unlock them.

## Self-check
Submitted record locks, approver gets notification.
