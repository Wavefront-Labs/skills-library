# Create Lightning apps and navigation
**Goal:** Package tabs and utilities into an app per team.

- App Manager > New Lightning App: standard or console navigation, utility items, assign to profiles.
- Add personalisation rules, items in the nav bar, and set app-specific logo and colours.
- Keep nav lean per role.

## Gotchas
- Users need object and tab permissions or items won't appear.

## Self-check
Nav items show only for assigned users.
