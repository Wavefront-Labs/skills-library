# Configure page layouts and compact layouts
**Goal:** Arrange fields, related lists and actions for each audience.

- Page layout editor: sections, fields (read-only/required), related lists, buttons and quick actions; assign layouts per profile and record type.
- Compact layouts define highlight panel fields and mobile cards.
- Prefer permission-set-based FLS for security rather than layout.

## Gotchas
- Required on layout versus required on field differ: the layout requirement is UI-only.

## Self-check
A user sees the assigned layout on a record.
