# Build screen flows
**Goal:** Guide users through a process with input screens.

- Flow Builder Screen Flow: screens, inputs, decisions, record lookups and a Create/Update elements; launch from quick actions, Lightning pages or buttons.
- Use input validation on screen components.
- Test with the target profile's permissions (run in user context versus system context).

## Gotchas
- Flows run in user context by default for screen flows; FLS applies.

## Self-check
Launch from a record page and complete the process.
