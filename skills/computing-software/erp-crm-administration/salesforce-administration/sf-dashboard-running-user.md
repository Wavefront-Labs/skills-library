# Configure dashboards and running user
**Goal:** Choose between a fixed running user and viewer's own data.

- Dashboards show data as the running user; "Let dashboard viewers choose whom to view the dashboard as" or dynamic dashboards (edition-limited) show each viewer's data.
- Add filters and components, schedule refresh and subscriptions.
- Sharing for folders governs access.

## Gotchas
- A fixed running user with wide access can expose data to wider audiences.

## Self-check
A viewer sees only the intended scope.
