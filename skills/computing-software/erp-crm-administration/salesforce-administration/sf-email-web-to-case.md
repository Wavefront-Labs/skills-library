# Capture cases by email and web
**Goal:** Create cases from email and web forms.

- Email-to-Case (On-Demand): create routing addresses, verify them, and forward from support mailbox.
- Web-to-Case generates an HTML form; a daily limit applies (confirm current limit in docs).
- Set auto-response rules and templates.

## Gotchas
- Unverified routing addresses silently stay inactive.

## Self-check
Emailing the address creates a case.
