# Create custom report types
**Goal:** Control which objects and relationships a report can use.

- Setup > Report Types: choose a primary object, add child objects with With or With/Without relationships, and set Deployed.
- Structure joins: A with B, A with or without B.
- Folder access and sharing control who can run reports.

## Gotchas
- Fields added later must be placed on the layout of the report type.

## Self-check
New report type visible when creating a report.
