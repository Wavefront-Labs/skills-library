# Understand licence types and permission set licences
**Goal:** Match licence types to the features users need.

- Setup > Company Information shows user licences, permission set licences and feature licences with used and remaining counts.
- A permission set licence must be assigned before a permission set that needs it can be assigned.
- User licence (Salesforce, Platform, Identity and others) caps which standard objects are available.

## Gotchas
- A permission set that requires a licence fails assignment with a licence error.

## Self-check
Assigned counts in Company Information match the user list.
