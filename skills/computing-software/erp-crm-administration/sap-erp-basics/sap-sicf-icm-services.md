# Activate ICF services
**Goal:** Expose only the web services you need.

- SICF shows the ICF tree; activate services for Fiori, OData and others only when needed.
- SMICM shows ICM status, ports and threads.
- Restrict by authentication and SSL.

## Gotchas
- Leaving default services active expands attack surface.

## Self-check
Only intended services are active.
