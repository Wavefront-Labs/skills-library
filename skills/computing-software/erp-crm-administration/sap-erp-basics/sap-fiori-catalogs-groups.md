# Set up catalogs, groups and spaces
**Goal:** Assign apps to users through roles.

- Launchpad content comes from catalogs (technical) and groups/spaces and pages (layout); roles reference them.
- Use the launchpad designer or the content manager; add the roles to users.
- Test with the end-user role.

## Gotchas
- Missing OData service activation shows apps but they fail to load.

## Self-check
A user sees the new app tile and it opens.
