# Run the order-to-cash flow
**Goal:** Follow sales order to billing.

- VA01 sales order; VL01N delivery with picking and goods issue; VF01 billing document creating FI postings.
- Pricing via condition technique.
- Document flow shows the chain.

## Gotchas
- Delivery blocks and credit blocks halt the flow.

## Self-check
Billing document posts to accounting.
