# Post journal entries
**Goal:** Make basic FI postings.

- FB50 (G/L account posting) and F-02 or FB01 for general postings; document types and posting keys decide debit/credit.
- Park and post, reverse with FB08.
- Check balances in FAGLB03.

## Gotchas
- A document must balance to zero before posting.

## Self-check
Document shows debit equals credit.
