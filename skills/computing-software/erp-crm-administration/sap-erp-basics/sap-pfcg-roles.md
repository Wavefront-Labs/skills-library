# Build roles in PFCG
**Goal:** Create role-based authorisations.

- PFCG: create single or composite roles, add menu/transactions, maintain authorization data (from SU24 defaults), generate profile, then assign users.
- Check authorization objects and fill organisational levels.
- User comparison updates user buffer after changes.

## Gotchas
- Generating a profile is required; unsaved authorization data is not active.

## Self-check
User can run the transaction in the role.
