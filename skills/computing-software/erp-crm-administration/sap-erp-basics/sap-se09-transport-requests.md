# Create and release transport requests
**Goal:** Collect changes into transports.

- SE09/SE10 manage workbench and customizing requests; tasks hold changes; release tasks then the request.
- Customizing requests collect SPRO changes; workbench requests collect repository objects.
- Check objects in the request before release.

## Gotchas
- Releasing exports to the transport directory; the request cannot be modified after release.

## Self-check
Request shows released and has an export log.
