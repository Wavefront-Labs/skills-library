# Electron update hosting and rollout

**Goal:** controlled releases.

```yaml
# latest.yml, generated by electron-builder and published beside the installers
version: 1.1.0
files:
  - url: TestApp Setup 1.1.0.exe
    sha512: <hash>
    size: <bytes>
stagingPercentage: 10      # added by you; electron-builder does not write it
```

**Gotcha:** electron-builder signs update manifests by default (v27), and `stagingPercentage` is covered by the signature. Editing it by hand in a signed `latest.yml` makes every install that embeds the public key reject the manifest with `ERR_UPDATER_MANIFEST_SIGNATURE_INVALID`, so the release reaches no users. Re-sign `latest.yml` with the same key(s) before uploading, for every change including raising the percentage or setting `0` to pause. Only an unsigned manifest (`updateManifest: false`) can be edited by hand.

## Verify
- A sample of clients on the previous version updates in proportion to the percentage, and a client that is not selected does not offer the update.
- `electron-builder verify` on the build output checks the manifest against the key embedded in the packaged app.
