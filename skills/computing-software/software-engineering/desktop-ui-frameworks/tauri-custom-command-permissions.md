# Tauri permissions for custom commands

**Goal:** restrict your own commands to the windows that need them.

```rust
// src-tauri/build.rs
fn main() {
    tauri_build::try_build(
        tauri_build::Attributes::new()
            .app_manifest(tauri_build::AppManifest::new().commands(&["your_command"])),
    )
    .unwrap();
}
```

Then reference the generated permission for the command in a capability. App permissions can also be written by hand as TOML files in `src-tauri/permissions` (capabilities may be JSON or TOML, permissions TOML only):

```toml
[[permission]]
identifier = "my-identifier"
description = "This describes the impact and more."
commands.allow = ["read_file"]
```

**Gotcha:** by default every command registered with `invoke_handler` is usable by all windows and webviews. Listing commands in `AppManifest::commands` is what brings them under capability checks. Look in `src-tauri/gen/schemas` for the exact generated identifier of each command (autogenerated plugin permissions look like `allow-mkdir`).

## Verify
- Removing the permission from a capability makes the call fail from that window.
