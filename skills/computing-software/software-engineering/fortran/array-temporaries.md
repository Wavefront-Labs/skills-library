# Array temporaries and copy-in/copy-out
**Goal:** avoid unneeded copies.
- `-Warray-temporaries` warns about array temporaries generated by the compiler; the manual says the information is sometimes useful to avoid them.
- `-fcheck=array-temps` warns at run time when a temporary array had to be generated to pass an actual argument (printed once per location). `-fcheck-array-temporaries` is a deprecated alias.
- `-fstack-arrays` puts all arrays of unknown size and array temporaries on the stack; it is enabled at `-Ofast` unless `-fmax-stack-var-size` is given, and very large local arrays may need a larger stack limit.
- `-frealloc-lhs` (on by default except with `-std=f95`) reallocates an allocatable left-hand side of an intrinsic assignment when it is unallocated or has a different shape. `-Wrealloc-lhs` warns where this code is inserted; a whole-array spec such as `a(:,:,:) = ...` on the left prevents the reallocation check.
## Gotchas
- With `-fstack-arrays`, large temporaries on the stack can overflow it.
## Self-check
Compile with `-Warray-temporaries`, then rerun after a change and confirm the warning is gone.
