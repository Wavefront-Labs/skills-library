# Flags, conditionals and CI matrix

**Goal:** make one package build on several OSes and GHC versions.

```cabal
flag fast
  description: build with extra optimisation
  default: False
  manual: True

library
  if flag(fast)
    ghc-options: -O2
  if os(windows)
    build-depends: Win32 >=2.5
    cpp-options:   -DWINDOWS
  else
    build-depends: unix >=2.7
  if impl(ghc >= 9.6)
    build-depends: base >=4.18
  if arch(x86_64)
    cc-options: -msse4.2
tested-with: GHC == 9.4.8, GHC == 9.6.6, GHC == 9.8.2
```
Enable at build: `cabal build -f fast` or `-f -fast`; in cabal.project: `package myapp flags: +fast`.

## CPP in source
```haskell
{-# LANGUAGE CPP #-}
#if MIN_VERSION_base(4,18,0)
import Data.Foldable1 (foldl1')
#endif
#ifdef WINDOWS
...
#endif
```
`MIN_VERSION_<pkg>(a,b,c)` macros are generated by cabal for dependencies.

## Matrix testing
```bash
ghcup install ghc 9.6.6            # then
cabal build -w ghc-9.6.6 --builddir=dist-ghc96   # separate build dir per GHC
```
GitHub Actions: `haskell-actions/setup` installs GHC and cabal; cache `~/.cabal/store` and `dist-newstyle`.

## Gotchas
- A solver choosing flag values can silently change dependencies; make flags `manual: True` unless dependency-driven.
- CPP and `MIN_VERSION_*` clutter; prefer thin compat modules (`Compat.hs`) isolating CPP.
- The `tested-with` field is informational; it is not enforced.
- `impl(ghc ...)` uses the compiler version, not base; check base bounds too.
