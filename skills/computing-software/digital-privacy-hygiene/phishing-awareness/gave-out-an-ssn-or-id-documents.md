# Gave out an SSN or ID documents

**Goal:** make the stolen identity data hard to use, fast.

## By what you gave
| Data | Actions |
|---|---|
| SSN | Freeze credit at Equifax, Experian, TransUnion (and ChexSystems, NCTUE, Innovis); IRS IP PIN; create/secure my Social Security account |
| Driver's licence photo | Report to the DMV; ask about replacement with a new number (varies by state); freeze helps |
| Passport photo/scan | Report lost/stolen passport if the physical passport was taken (Form DS-64); a scan alone can't be cancelled, but monitor |
| Bank account and routing | Call the bank: new account number, alerts, block ACH debits you didn't authorise |
| Card number | Card issuer: cancel and reissue |
| Selfie holding ID ("verification") | Expect account openings at crypto/fintech; freezes and monitoring |
| Medical insurance number | Insurer: flag the account; review explanation-of-benefits statements |

## Report
identitytheft.gov: personalised recovery plan and an FTC Identity Theft Report (useful for disputes). Police report
if needed by creditors.

## Monitor
Weekly credit reports (annualcreditreport.com), bank alerts, mail for unexpected accounts, IRS transcripts.

## Gotchas
- An SSN can't normally be changed; prevention via freezes is the long-term defence.
- Expect follow-up "recovery" scams from the same crooks; don't trust callers offering help.
