# Fake AI tool sites and apps

**Goal:** use AI tools without installing malware or a $10-a-week subscription you didn't want.

## Common traps
- **Lookalike apps** named "Chat AI", "GPT 5 Pro" or using a famous logo, with weekly subscriptions after a 3-day trial
  (fleeceware).
- **"AI video/image generator" sites** advertised on social media that ask you to upload a file and then download
  the "result": an executable or archive that installs an infostealer.
- **Browser extensions** promising ChatGPT in every tab that hijack Facebook or Google sessions.
- **Desktop downloads** for tools that are web-only; official ChatGPT, Claude and Gemini apps come from the vendor's
  site or the official app stores.
- Ads for "free premium" access to paid models.

## Checks
- Go to the vendor via a bookmark or by typing the domain; check the app store **developer name** (OpenAI,
  Anthropic, Google LLC) and download counts.
- A result file that ends in `.exe`, `.scr`, `.lnk`, `.zip` with password is not an image or video.
- Read subscription terms before the trial; cancel in the App Store/Play Store subscription page, not only by deleting
  the app.
- Install extensions only from well-known publishers, and review their permissions.

## If you installed one
Uninstall, cancel subscriptions, revoke extension access, run a full scan; if you ran an executable, follow the
infostealer response (clean device, password and session reset, OS reinstall).
