# Compare options

## 1. IgnoreExtraneous
Resources that end up tracked by an app but are not in Git (e.g. created by Helm hooks, operators
copying labels, a `ConfigMap` generated by a controller) make the app **OutOfSync**. Mark them:
```yaml
metadata:
  annotations:
    argocd.argoproj.io/compare-options: IgnoreExtraneous
```
- Only affects **sync status**; if the resource's health is degraded the app is still degraded.
  You may combine it with the `Prune=false` sync option (`argocd.argoproj.io/sync-options: Prune=false`).
- Field differences are handled by `ignoreDifferences`, not by this annotation.
- For ConfigMaps generated by Kustomize, set the annotation through `generatorOptions.annotations` (it is added to generated ConfigMaps and Secrets).

## 2. Server-side diff
```yaml
metadata:
  annotations:
    argocd.argoproj.io/compare-options: ServerSideDiff=true      # per app
```
or globally in `argocd-cmd-params-cm`: `controller.diff.server.side: "true"` (restart the application controller). Argo CD runs a
server-side apply in dry-run mode for each resource and diffs the result; admission controllers take part in the diff. Server-Side Diff is stable since v3.1.0 and is used automatically when the Server-Side Apply sync option is on (`ServerSideDiff=false` opts out). Changes made by mutation webhooks are excluded unless you add `IncludeMutationWebhook=true`.
Results are cached; new server-side apply dry-runs are triggered by a refresh or hard refresh, a new target revision, a changed Application spec or a changed live resource version. Server-Side Diff is not performed for resources that do not exist yet.

## 3. Global compare options (`argocd-cm`)
```yaml
data:
  resource.compareoptions: |
    ignoreAggregatedRoles: true
    ignoreResourceStatusField: all       # all (default) | crd | none
```
`ignoreResourceStatusField` disables `status` diffing for CustomResourceDefinitions only (`crd`), for all resources (`all`, the default) or for none; `crd` is suggested over `none` because CRDs often have their status committed to Git.
