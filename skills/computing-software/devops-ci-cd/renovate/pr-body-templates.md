The PR description is assembled from sections that you can adjust:

- `prHeader` is placed first in the PR body; `prFooter` is placed last, after a divider (its default is a "generated by Mend Renovate CLI" line).
- `prBodyNotes` is a list of extra notes or templates, which can be conditional, for example `{{#if isMajor}}...{{/if}}`.
- `prBodyColumns` chooses the columns of the update table (default `Package`, `Type`, `Update`, `Change`, `Pending`), and `prBodyDefinitions` defines how each column is rendered.
- `prBodyHeadingDefinitions` modifies the table header text and may include Markdown.
- `prBodyTemplate` controls which sections are rendered. The default is `{{{header}}}{{{table}}}{{{warnings}}}{{{notes}}}{{{changelogs}}}{{{configDescription}}}{{{controls}}}{{{footer}}}`; the sections are `header`, `table`, `warnings`, `notes`, `changelogs`, `configDescription`, `controls` and `footer`.

```json
{
  "prHeader": "Automated dependency update",
  "prBodyNotes": ["Please check the changelog for breaking changes."],
  "prBodyColumns": ["Package", "Type", "Update", "Change"]
}
```

`prHeader`, `prFooter`, `prBodyNotes` and `prBodyTemplate` support Renovate's template syntax. The options can be set at repository, `packageRules`, manager, update type and group scope, so notes can be limited to matching updates, for example a warning on major bumps.

Related items: `fetchChangeLogs` (`off`, `branch` or `pr`; default `pr`) controls when changelogs are fetched, and `commitBodyTable` (default `false`) appends a table of updates to the commit message body.
