Number prefixes (`01-Intro.md`, `02-Tutorial Easy/01-First Part.md`) order files in both the file system and an autogenerated sidebar. Several prefix patterns are supported, and the prefix is removed by default from the doc ID, title, label and URL paths.

Prefer sidebar metadata instead: renumbering can require updating many Markdown links (`../04-End.mdx` becoming `../05-End.mdx`).

Provide a custom `sidebarItemsGenerator` in the docs plugin or preset config. It receives `defaultSidebarItemsGenerator`, `numberPrefixParser`, `item`, `version`, `docs`, `categoriesMetadata` and `isCategoryIndex`.

Reuse the default generator rather than writing one from scratch, then add, update, filter or reorder:

```js title="docusaurus.config.js"
function reverseSidebarItems(items) {
  const result = items.map((item) =>
    item.type === 'category'
      ? {...item, items: reverseSidebarItems(item.items)}
      : item,
  );
  result.reverse();
  return result;
}

export default {
  plugins: [
    [
      '@docusaurus/plugin-content-docs',
      {
        async sidebarItemsGenerator({defaultSidebarItemsGenerator, ...args}) {
          const sidebarItems = await defaultSidebarItemsGenerator(args);
          return reverseSidebarItems(sidebarItems);
        },
      },
    ],
  ],
};
```
