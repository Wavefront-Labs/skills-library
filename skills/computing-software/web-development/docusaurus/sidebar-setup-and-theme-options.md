Define a sidebars file exporting a dictionary of sidebars and pass its path to the docs plugin (or preset):

```js title="docusaurus.config.js"
presets: [['@docusaurus/preset-classic', {docs: {sidebarPath: './sidebars.js'}}]],
```

The sidebars file runs in Node.js: no browser APIs, React or JSX.

If `sidebarPath` is unspecified, Docusaurus generates a sidebar from the `docs` folder (autogenerated, `dirName: '.'`).

Theme options:

```js title="docusaurus.config.js"
themeConfig: {
  docs: {
    sidebar: {
      hideable: true,               // user can hide the whole sidebar
      autoCollapseCategories: true, // collapse siblings when one expands
    },
  },
},
```

Breadcrumbs render by default from the sidebar path; disable with the docs plugin option `breadcrumbs: false`.

Any item accepts:

- `className` for CSS (`'sidebar-item--highlighted'`)
- `customProps` for data used by swizzled components
- `key`, a unique ID; it is used to generate unique i18n translation keys, and Docusaurus asks for one when translation keys conflict (for example two categories labelled `API`).
