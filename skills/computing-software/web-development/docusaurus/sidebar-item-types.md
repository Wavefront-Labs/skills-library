Item types: doc, link, category, autogenerated, html, ref.

```js title="sidebars.js"
export default {
  mySidebar: [
    {type: 'doc', id: 'doc1', label: 'Getting started'},
    'doc2', // shorthand for a doc ID
    {type: 'link', label: 'Home', href: '/'},       // internal
    {type: 'link', label: 'Facebook', href: 'https://facebook.com'}, // external
    {type: 'html', value: 'Core concepts', className: 'sidebar-title'},
  ],
};
```

Common optional fields: `key`, `className`, `customProps`. `link` also takes `description`; `html` takes `defaultStyle` to use default menu item styling.

Doc items: using the shorthand or autogenerated sidebars loses the `label` key, but `sidebar_label` front matter in the doc has higher precedence than `label`. `sidebar_custom_props` declares custom metadata for a doc, handy for passing data to client-side doc hooks.

A `doc` item creates an implicit sidebar association. Do not assign the same doc to multiple sidebars; use a `ref` item instead.

`html` items render inside the item's existing `<li>`, so for a simple title pass a string and style it with `className`. Useful for dividers, section titles, ads and images.
