In autogenerated sidebars a category links automatically to its index document if a file matches one of:

- named `index` (case-insensitive): `docs/Guides/index.md`
- named `README` (case-insensitive): `docs/Guides/README.mdx`
- same name as the parent folder: `docs/Guides/Guides.md`

This equals a category with `link: {type: 'doc', id: 'Guides/index'}`. A folder with only one index page becomes a plain link, which suits asset collocation (`some-doc/index.md` beside its images).

Customize via `isCategoryIndex` passed to `defaultSidebarItemsGenerator` inside `sidebarItemsGenerator`. The matcher receives `fileName` (no extension, casing preserved), `directories` (lowest level first) and `extension`.

```js title="docusaurus.config.js"
async sidebarItemsGenerator({
  isCategoryIndex: defaultCategoryIndexMatcher,
  defaultSidebarItemsGenerator,
  ...args
}) {
  return defaultSidebarItemsGenerator({
    ...args,
    isCategoryIndex(doc) {
      return (
        doc.fileName.toLowerCase() === 'intro' ||
        defaultCategoryIndexMatcher(doc)
      );
    },
  });
},
```

Return `false` from the matcher to disable the convention entirely.
