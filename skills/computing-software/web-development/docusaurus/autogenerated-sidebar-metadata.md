Autogenerated items read metadata from their files, and are alphabetical unless positioned.

Docs use front matter: `sidebar_position`, `sidebar_label`, `sidebar_class_name`, `sidebar_key`, `sidebar_custom_props`.

```md title="docs/tutorials/tutorial-easy.md"
---
sidebar_position: 2
sidebar_label: Easy
sidebar_class_name: green
---
```

Categories use a `_category_.json` or `_category_.yml` in the folder:

```yml title="docs/tutorials/_category_.yml"
position: 2.5 # floats are supported
label: 'Tutorial'
collapsible: true
collapsed: false
className: red
link:
  type: generated-index
  title: Tutorial overview
customProps:
  description: Usable in a swizzled DocCard
```

`label`, `className`, `key`, `position` and `customProps` default to the linked doc's values if the category has one.

- An explicit `link` disables the default category index conventions.
- A relative doc link in a category generated from `guides` resolves `intro` to `guides/intro` first, then `intro`.
- `link: null` opts out of generating any category index page.
- `position` only orders items within a sidebar slice; other sidebar items are not reordered.
