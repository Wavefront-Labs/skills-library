Doc shorthand: a `doc` item can be its ID string, `'myDoc'` instead of `{type: 'doc', id: 'myDoc'}`.

Category shorthand: an object whose key is the label and whose value is the array of subitems.

```js title="sidebars.js"
export default {
  mySidebar: [
    {'Getting started': ['doc1']},
    {Docusaurus: ['doc2', 'doc3']},
    {type: 'link', label: 'Learn more', href: 'https://example.com'},
  ],
};
```

Consecutive shorthands can merge into one object with several entries:

```js
{
  'Getting started': ['doc1'],
  Docusaurus: ['doc2', 'doc3'],
},
```

That object is a sidebar slice: it is unwrapped, each entry becomes a separate item, and they are spliced with neighbouring items to form the final level. Slices matter for autogenerated sidebars too.

Where an array reduces to a single category shorthand object, omit the enclosing array:

```js
export default {
  sidebar: {
    'Getting started': ['doc1'],
    Docusaurus: {
      'Basic guides': ['doc2', 'doc3'],
      'Advanced guides': ['doc4', 'doc5'],
    },
  },
};
```

Shorthands are for typical items without much customization; use the long form when an item needs options.
