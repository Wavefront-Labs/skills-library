Each folder creates a sidebar category and each file creates a doc link.

```js title="sidebars.js"
export default {
  myAutogeneratedSidebar: [
    {type: 'autogenerated', dirName: '.'}, // '.' = the docs folder
  ],
};
```

`dirName` is the source folder, relative to docs.

An `autogenerated` item becomes a sidebar slice: a list of `doc` or `category` items. The source directory itself does not become a category, only what it contains. So you can use several autogenerated items from different directories, interleaved with regular items in one level:

```js
mySidebar: [
  'intro',
  {
    type: 'category',
    label: 'Tutorials',
    items: [
      'tutorial-intro',
      {type: 'autogenerated', dirName: 'tutorials/easy'},
      'tutorial-medium',
      {type: 'autogenerated', dirName: 'tutorials/advanced'},
      'tutorial-end',
    ],
  },
  {type: 'autogenerated', dirName: 'api'},
],
```

Subfolders of a source directory become categories labelled with the folder name; files become doc items. Items within a slice are alphabetical by file and folder name unless you set positions.
