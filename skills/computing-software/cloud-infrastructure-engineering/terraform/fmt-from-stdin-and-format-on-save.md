# `terraform fmt -` and format-on-save

## stdin mode
```bash
cat main.tf | terraform fmt -          # formatted HCL to stdout
terraform fmt - < snippet.tf > snippet.fmt.tf
echo 'resource "x" "y" {a=1}' | terraform fmt -
```
- Exit code 2 with an `Error:` diagnostic if the input does not parse; output is reformatted
  but single-line blocks stay on one line (`{a=1}` becomes `{ a = 1 }`).
- Use it for text generated by scripts (codegen, templates) before writing files:
  `python gen.py | terraform fmt - > generated.tf`.
- `-check` with `-` returns exit 3 if formatting would change and 0 if it is already formatted
  (`-diff` can be added).

## Editors
**VS Code** (HashiCorp Terraform extension, uses terraform-ls):
```json
"[terraform]": { "editor.defaultFormatter": "hashicorp.terraform", "editor.formatOnSave": true },
"[terraform-vars]": { "editor.defaultFormatter": "hashicorp.terraform", "editor.formatOnSave": true }
```
**Vim/Neovim**: `vim-terraform` with `let g:terraform_fmt_on_save=1`, or
conform.nvim `formatters_by_ft = { terraform = { "terraform_fmt" } }` (conform's `terraform_fmt` runs `terraform fmt -no-color -`).
**JetBrains**: see the Terraform and HCL plugin's own documentation for its format-on-save setting.

## Pitfalls
- terraform-ls formats with the Terraform CLI (its settings doc: the CLI is "used e.g. in
  formatting code via `terraform fmt`"); different Terraform versions format different file
  sets (changelog: `.tfmock.hcl` since 1.7, `.tfquery.hcl` since 1.15), which produces churn
  between developers. Pin via `.terraform-version` + tenv (tenv reads `.terraform-version`).
- Terraform 1.17.0 `fmt` handles `.tf`, `.tfvars`, `.tftest.hcl`, `.tfmock.hcl` and
  `.tfquery.hcl` and skips `.pkr.hcl`, plain `.hcl`, `.tofu`, `.tfvars.json` and `.tf.json`;
  OpenTofu 1.13.2 `tofu fmt` also handles `.tofu` (but not `.tfmock.hcl`/`.tfquery.hcl`
  in the test). Other HCL needs its own formatter: `packer fmt` (Packer docs),
  `terragrunt hcl fmt` (Terragrunt docs).
- Formatting a heredoc does not reformat its JSON/YAML contents.

## Verify
- [ ] Saving a misaligned file realigns `=` signs.
