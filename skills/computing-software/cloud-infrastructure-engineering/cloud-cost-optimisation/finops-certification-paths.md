# FinOps certification paths

Certifications create shared vocabulary across finance, engineering and procurement. Map them to
roles rather than certifying everyone in everything.

## FinOps Foundation (Linux Foundation) catalogue
- **Introduction to FinOps** (free): anyone touching cloud spend.
- **FinOps Certified Practitioner (FOCP)**: foundational exam on the Framework (principles,
  personas, phases, capabilities). Target: FinOps team, champions, finance partners, engineering
  managers.
- **FinOps Certified Engineer**: optimisation techniques for engineers (rightsizing, architecture,
  commitments from an engineering view).
- **FinOps Certified Professional**: advanced, for FinOps practitioners leading a practice;
  requires FOCP and experience (check current prerequisites).
- Role/topic courses: FinOps for Engineering, FinOps for Finance/Procurement, FOCUS analyst,
  FinOps for AI, FinOps Certified FOCUS Analyst. Check learn.finops.org for the current list.
- Cloud provider learning paths complement these (AWS Cloud Financial Management, Microsoft Learn
  Cost Management, Google Cloud billing courses).

## Role mapping
| Role | Path |
|---|---|
| FinOps analyst | Intro -> FOCP -> FOCUS analyst -> Professional |
| Engineer / champion | Intro -> FOCP or Certified Engineer |
| Finance partner | Intro -> FOCP (finance track course) |
| Engineering manager | Intro -> FOCP |
| Executive | Executive briefing, no exam |

## Steps
1. Budget vouchers per role; enterprise training subscriptions are cheaper above ~10 people.
2. Run study groups and practice sessions with internal examples.
3. Track certifications in the skills register; recognise passes publicly.

## Gotchas
- Certification without practice fades; pair with a real task (own a team's monthly review).
- Exam content follows Framework updates; refresh material yearly.

## Verify
- [ ] Each FinOps role has a defined path and budget.
- [ ] Certification counts are tracked against targets.
