Concepts:
- A user environment is a tree of symlinks to activated packages, generated by `nix-env` and stored in the Nix store.
- A generation is a symlink outside the store pointing to a user environment. Each `nix-env` operation creates a new generation from the current one.
- A profile groups generations; its `default` link points to the current generation. Updating it is atomic on Unix, which gives atomic upgrades.

Commands:

```
nix-env --install --attr nixpkgs.subversion
nix-env --list-generations
nix-env --profile /nix/var/nix/profiles/other-profile --install --attr nixpkgs.subversion
```

`--profile` (`-p`) targets a specific profile and does not change the `~/.nix-profile` symlink.

Gotchas:
- Put `~/.nix-profile/bin` on `PATH`, not a profile's own `bin`. `~/.nix-profile` points at the current profile, so switching profiles needs no `PATH` change. `nix.sh` sets this up.
- Changing `PATH` does not affect running processes.
- Store profiles only in the `profiles` directory; elsewhere they may not be GC roots and their packages could be deleted.
