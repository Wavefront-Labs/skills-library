# Microsoft Graph PowerShell SDK

An API wrapper over Microsoft Graph, with cmdlets autogenerated from the Graph API schema. It is
the replacement for the Azure AD PowerShell and MSOnline modules and is recommended for working
with Microsoft Entra ID. It works with PowerShell 7 and later and with Windows PowerShell 5.1, on
Windows, macOS and Linux. Authentication uses MSAL. Permissions are not pre-authorized: users
request the app permissions they need (least privilege). It is published on the PowerShell
Gallery; follow Microsoft's installation instructions.

## Connect
Run `Connect-MgGraph` before any command that reaches Graph. Two authentication types exist:
delegated and app-only.
```powershell
# Delegated: interactive, with the scopes you need for the session
Connect-MgGraph -Scopes "User.Read.All", "Group.ReadWrite.All"
Connect-MgGraph -Scopes "User.Read.All" -UseDeviceAuthentication   # device code flow
Connect-MgGraph -AccessToken $AccessToken                          # your own token

# App-only with a certificate (unattended)
Connect-MgGraph -ClientId "<APP_ID>" -TenantId "<TENANT_ID>" -CertificateThumbprint "<THUMBPRINT>"
Connect-MgGraph -ClientId "<APP_ID>" -TenantId "<TENANT_ID>" -CertificateName "<CERT_SUBJECT>"

# Managed identity
Connect-MgGraph -Identity                                          # system-assigned
Connect-MgGraph -Identity -ClientId "<USER_ASSIGNED_IDENTITY_CLIENT_ID>"
```
- Certificate lookup: the certificate must be in `Cert:\CurrentUser\My\` or
  `Cert:\LocalMachine\My\` for `-CertificateThumbprint` / `-CertificateName`; or pass an object
  with `-Certificate`.
- Client secret: `-ClientSecretCredential` takes a PSCredential (client ID plus secret). Microsoft
  recommends PowerShell 7 or later for it. A managed identity needs no secret provisioning or
  rotation.
- Custom app registration for delegated use (to isolate and limit consent): register a public
  client app, then `Connect-MgGraph -ClientId <APP_ID> -TenantId <TENANT_ID>`. Sovereign clouds
  such as BleuCloud, DelosCloud and GovSGCloud require your own app registration
  (`-Environment`; needs Microsoft.Graph.Authentication v2.36.1 or later). Apps registered
  globally do not replicate to Azure China.
- `Connect-MgGraph -ContextScope Process` limits the context to the current session. By default
  (CurrentUser) the token is cached securely, refreshed automatically, and persists across
  sessions until `Disconnect-MgGraph`, which clears it.
- `-Environment` takes Global (default), China, USGov, USGovDoD, BleuCloud, DelosCloud, GovSGCloud;
  `Get-MgEnvironment` lists them.
- Passwordless methods supported: Windows Hello for Business, FIDO2 (PowerShell 7 and above only),
  Microsoft Authenticator, certificate-based authentication.
- If the sign-in window hangs in a sovereign cloud, disable WAM broker login with
  `Set-MgGraphOption -DisableLoginByWAM $true`.
- `Get-MgContext` shows ClientId, TenantId, Scopes, AuthType (Delegated or app-only), AppName,
  ContextScope and more for the current session.

## Find the cmdlet and permissions
```powershell
Find-MgGraphCommand -Uri '/users/{id}'                 # URI to cmdlets (optional -Method, -ApiVersion v1.0 or beta)
Find-MgGraphCommand -Command Get-MgUser                 # cmdlet to the URI it calls
Find-MgGraphCommand -command Get-MgUser | Select -First 1 -ExpandProperty Permissions
Find-MgGraphCommand -Command .*UserToDo.* -ApiVersion v1.0   # wildcard search
```
Output includes the permissions needed to run the cmdlet, but those do not indicate privilege
levels; check the Graph API reference page to pick the least-privileged permission.
`Find-MgGraphPermission` is the dedicated permission-discovery cmdlet.

## Raw requests
```powershell
Invoke-MgGraphRequest -Method GET -Uri https://graph.microsoft.com/v1.0/me
```
`Invoke-MgGraphRequest` supports all HTTP methods and works for any Graph API when you know the
URI, method and optional body; it is especially useful where no cmdlet exists yet.

## Verify
- [ ] Unattended scripts use a certificate or managed identity, with only the permissions needed.
- [ ] `Get-MgContext` shows the expected AuthType, scopes and tenant.
