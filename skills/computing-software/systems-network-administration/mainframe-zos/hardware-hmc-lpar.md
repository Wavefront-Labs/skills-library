# HMC, LPARs and activation

Goal: understand the platform.
- Hardware Management Console defines LPARs, activation profiles (IPL address, parameters), and handles Load and Reset.
- Weights and capping control CPU shares.
- Restrict HMC access strictly.
Verify: LPAR IPLs with the intended load profile.
