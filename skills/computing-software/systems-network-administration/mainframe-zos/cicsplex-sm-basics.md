Goal: manage a CICSplex.
- CMAS manages CICSplexes; WUI provides web view; BAS defines resources centrally.
- Workload management routes by affinity and load.
- Monitor definitions and real-time analysis (RTA) raise events.
Verify: a resource installed via BAS appears on all target regions.
