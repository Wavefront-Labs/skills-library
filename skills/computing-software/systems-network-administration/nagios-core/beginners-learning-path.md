# Learning Nagios Core in the right order

Goal: avoid the common failure of jumping into advanced features before the basic check/notify loop works.

## Order
1. **Quickstart install.** Follow the quickstart guide for your distribution. It installs Nagios Core and monitors the local system; the page says within 20 minutes you can have Nagios installed and monitoring your local system.
2. **The Basics and Configuring Nagios.** Read the documentation, particularly the sections on Configuring Nagios and The Basics.
3. **Advanced topics last.** Save the advanced topics for when you have a good understanding of the basics.

## Attitude the docs recommend
- Relax: it takes some time, and things will not work exactly as wanted straight away.
- Ask the Nagios community and support staff on the Nagios Support Forum.
