# ISO/IEC 38500 and ISO/IEC 20000
**Goal:** know which standard certifies what.
- ISO/IEC 38500: six principles (responsibility, strategy, acquisition, performance, conformance, human behaviour) and the evaluate-direct-monitor model.
- ISO/IEC 20000-1: certifiable service management system requirements; ITIL is guidance, not certifiable for an organisation.
- ISO/IEC 27001 secures information; COBIT is the enterprise IT governance framework; ITIL implements service practices.

## Self-check
For a given need (board oversight, service quality, security certification) choose the right standard.
