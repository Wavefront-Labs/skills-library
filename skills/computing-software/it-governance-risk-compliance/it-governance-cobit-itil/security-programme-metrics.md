# Security programme metrics and maturity
**Goal:** useful metrics.
- Metric types: operational (patch latency), tactical (control coverage), strategic (risk reduction, cost of incidents).
- Good metrics are defined, owned, repeatable, tied to a decision; avoid vanity counts.
- Maturity models: CSF tiers, COBIT capability 0-5, CMMI levels, SSE-CMM.

## Self-check
Pick a metric and state what decision changes if it moves.
