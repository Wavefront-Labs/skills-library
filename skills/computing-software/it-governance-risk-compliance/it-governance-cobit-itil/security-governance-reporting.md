# Security governance structure and board reporting
**Goal:** a governance cadence.
- Structure: board risk committee, security steering committee (IT, legal, HR, business), CISO with independent reporting line, risk owners.
- Board pack (quarterly): top risks vs appetite, control effectiveness, incidents, audit findings, compliance status, programme delivery, investments.
- Strategy: current vs target state (CSF profile), roadmap with budget and outcome measures.
