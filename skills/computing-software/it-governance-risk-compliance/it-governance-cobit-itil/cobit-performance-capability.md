# Performance management and capability levels
**Goal:** measure and improve processes.
- Capability levels 0 to 5 per process, based on ISO/IEC 33000 series; maturity levels apply to focus areas.
- Steps: select processes, assess activities against level requirements, set target, plan improvement.
- Focus areas include information security, DevOps, risk, small and medium enterprises.

## Self-check
Rate one process and list the activity gaps blocking the next level.
