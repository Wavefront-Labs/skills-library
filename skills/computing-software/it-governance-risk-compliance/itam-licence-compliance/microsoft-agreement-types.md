# Microsoft agreement types (EA, MPSA, CSP)

Goal: pick the vehicle that fits scale and flexibility.

- Enterprise Agreement (EA): 3-year commitment, annual true-up for growth, enterprise-wide enrolment options; check current volume thresholds as Microsoft has been changing eligibility, confirm.
- MPSA: transactional, no true-up commitment.
- CSP: monthly or annual subscriptions via a partner; flexible quantity; term options.
- Software Assurance gives version upgrade, license mobility, Azure Hybrid Benefit and other benefits.

Method: compare 3-year cost under each vehicle, including price-level discounts and Software Assurance value.
Calendar the EA anniversary, true-up deadline and renewal notice.

Gotchas:
- True-up counts peak deployment during the year.
- CSP changes may restrict some benefits; confirm.

Verify: the Microsoft Product Terms checked for each product used.
