# Audit response playbook

Goal: minimise exposure and disruption.

Steps:
1. Form team: legal, ITAM, procurement, IT ops, finance.
2. Freeze changes that destroy evidence; preserve logs.
3. Compute your own ELP before sharing anything; consider legal privilege for the analysis (counsel advice).
4. Provide only what the clause requires, with validated data.
5. Challenge findings: scope, metric interpretation, virtualisation rights, grandfathered terms.
6. Negotiate: seek discounted price, credit for new purchases, release language, and remediation period.
7. Capture lessons into process.

Gotchas:
- Uninstalling software in the middle of an audit may look like spoliation.
- Never accept vendor tool outputs without validation.

Verify: settlement includes release from past claims.
