# Continuous audit readiness

Goal: respond to any notice within days.

Method:
- Keep per vendor: contracts, entitlements, latest ELP, installation data date, assumptions log and decision log.
- Quarterly self-check for top vendors (Microsoft, Oracle, IBM, SAP, Adobe, VMware).
- Track leading indicators: unrecognised software, server mobility events, unmanaged assets.
- Rehearse annually with a tabletop exercise.

Gotchas:
- Evidence rots: refresh at least once a quarter.
- Do not publish exposure figures broadly; restrict circulation.

Verify: time-to-produce an ELP for any top vendor is under 5 working days.
