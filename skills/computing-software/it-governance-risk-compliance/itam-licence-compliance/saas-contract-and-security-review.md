# SaaS contract, exit and security review

Goal: buy SaaS with open eyes.

Checklist:
- Auto-renewal and notice, price uplift caps (e.g. CPI or 3-7%; negotiate).
- Data ownership, export formats, deletion timelines on exit.
- SLA credits, support tiers, and uptime history.
- Security attestations (SOC 2 Type II, ISO 27001), pen test summary, subprocessor list, data residency.
- Liability caps and indemnity, with special attention to data breach.
- Usage rights across affiliates.

Method: run intake through procurement, security and legal; store the outcome in the register.

Gotchas:
- Click-through terms for departmental purchases skip all this; enforce a purchase gate.

Verify: renewal notice dates are calendared.
