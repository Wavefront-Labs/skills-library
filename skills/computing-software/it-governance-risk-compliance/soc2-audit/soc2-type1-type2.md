# Type 1 versus Type 2 reports
**Goal:** pick and time the report.
- Type 1: opinion on description and suitability of design at a point in time. Type 2: also operating effectiveness across a period, commonly 3 to 12 months; first reports are often a 3 or 6 month window.
- Customers mostly want Type 2. Plan observation window start only after controls are operating.
- Bridge or gap letters cover time between report end and today (management assertion, not auditor opinion).

Draft the audit calendar: readiness, window start, fieldwork, report date.
