# SOC 1, SOC 2 and SOC 3
**Goal:** choose the right report.
- SOC 1: controls relevant to user entities' internal control over financial reporting (SSAE 18 / AT-C 320).
- SOC 2: controls relevant to security, availability, processing integrity, confidentiality, privacy (AT-C 105 and 205 with TSP 100).
- SOC 3: general-use report on the same criteria, public seal, no detailed tests.
- SOC 2 reports are restricted-use for user entities, prospects under NDA, auditors.

## Self-check
For three customer requests decide which report type answers each.
