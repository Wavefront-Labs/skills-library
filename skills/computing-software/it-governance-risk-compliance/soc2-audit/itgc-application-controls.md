# Application controls and IPE
**Goal:** reliance on automated controls.
- Types: input validation, edit checks, authorisation, reconciliations, interface controls, output controls, calculation logic.
- Test once in a stable environment if ITGCs are effective (benchmarking); otherwise test more.
- IPE: verify completeness and accuracy of reports used as evidence (query parameters, source, logic).

## Self-check
Re-perform one automated calculation with independent data.
