# System description (DC 200)
**Goal:** a description the auditor can opine on.
- Components: services provided and principal commitments; system components (infrastructure, software, people, procedures, data); boundaries; relevant aspects of control environment, risk assessment, monitoring; subservice organisations; CUECs.
- Include significant system incidents during the period if the description criteria require.
- Management signs an assertion that the description is fairly presented and controls were effective.

## Self-check
Check each control in the matrix maps to a criterion and appears in the description.
