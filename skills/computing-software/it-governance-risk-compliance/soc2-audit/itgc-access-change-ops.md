# ITGC: access, change, operations
**Goal:** a standard ITGC test set.
- Access: user provisioning, privileged access, periodic review, termination. Change: authorisation, testing, approval, segregation of developers from production. Operations: batch jobs, incident handling, backups.
- Tests: inspect samples, re-perform, observe configs; test completeness of population.
- ITGC failure reduces reliance on automated application controls.

## Self-check
Select a system and write the three-test minimum for each ITGC area.
