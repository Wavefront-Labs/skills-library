# Subservice organisations and CUECs
**Goal:** scope the shared responsibility.
- Carve-out: description presents the subservice org's controls separately, with complementary subservice organisation controls (CSOCs) that you monitor. Inclusive: the subservice org's controls are in scope and tested.
- CUECs: controls customers must implement for criteria to be met; list clearly in the description.
- Hyperscale cloud providers are normally carved out; obtain their SOC reports annually.

List the subservice orgs and the date you reviewed each one's report.
