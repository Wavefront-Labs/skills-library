# Readiness assessment and remediation
**Goal:** go into the audit without surprises.
- Define scope (products, systems, categories), map existing controls to criteria, list gaps, fix before the window opens, dry-run evidence collection.
- Typical gap areas: no formal access reviews, no risk assessment, no vendor reviews, undocumented policies, change management bypasses.
- Compliance automation tools can collect evidence continuously, but the auditor still tests the control design and operation.

## Self-check
Run a sample test of three controls before the audit and compare with what the auditor will ask.
