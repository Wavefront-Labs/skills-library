# CC7 system operations and CC8 change management
**Goal:** operations and change evidence.
- CC7.1 detection of vulnerabilities and configuration changes; CC7.2 monitoring for anomalies; CC7.3 evaluate security events; CC7.4 incident response; CC7.5 recovery.
- CC8.1: changes authorised, designed, tested, approved and implemented; evidence a ticket or pull request with reviewer approval, test result and deployment record, plus separation of duties.
- Evidence also: vulnerability scans, alert triage records, incident tickets with post-mortems.

## Gotchas
- Emergency changes need a retrospective approval record.

## Self-check
Sample 25 changes and confirm each has approval before deployment.
