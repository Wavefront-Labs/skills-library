# CC5 control activities and CC6 logical and physical access
**Goal:** access controls evidence for the highest-scrutiny criteria.
- CC5.1-5.3: select and develop control activities, technology general controls, deploy through policies and procedures.
- CC6.1 logical access security; CC6.2 provisioning; CC6.3 role-based access and removal; CC6.4 physical access; CC6.5 disposal; CC6.6 external threats and boundaries; CC6.7 transmission and movement; CC6.8 malicious software prevention.
- Evidence: access lists, joiner-mover-leaver tickets, quarterly access reviews, MFA configs, encryption settings, physical access logs (or cloud provider inheritance).

## Self-check
Sample ten leavers and ten new joiners and confirm timely deprovisioning and approved access.
