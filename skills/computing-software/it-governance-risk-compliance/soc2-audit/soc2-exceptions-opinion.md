# Exceptions and audit opinions
**Goal:** respond to deviations professionally.
- Exception: tested control not operating as described in a sample. Report states it with management's response if provided.
- Opinions: unqualified (clean), qualified (specific control or criterion fails), adverse, disclaimer.
- Fix root cause, document compensating controls, and add management response; many customers accept isolated exceptions with remediation.

## Gotchas
- Do not alter or backdate evidence; it ends the engagement and is misconduct.

## Self-check
For one exception write the root cause, remediation date and compensating control.
