# Risk, threat, vulnerability, likelihood, impact
**Goal:** one shared vocabulary before scoring.
- Risk is a function of likelihood that a threat event exploits a vulnerability and the resulting impact on assets, mission or people.
- Inherent risk = before controls; residual = after existing controls; target = what appetite allows.
- Write risk scenarios as: threat source + event + vulnerability + asset + consequence, not as bare vulnerabilities.

## Gotchas
- Listing "unpatched servers" as a risk is a finding, not a scenario.
