# Vendor due diligence and questionnaires
**Goal:** proportionate vendor assessment.
- Collect evidence before reading answers: SOC 2 Type II report, ISO 27001 certificate with SoA scope, pen-test summary, policies, subprocessor list.
- Questionnaires: Shared Assessments SIG, CSA Cloud Controls Matrix based CAIQ; use the lite versions for low tier.
- Read SOC 2 reports for scope, exceptions, complementary user entity controls (CUECs) and subservice orgs.
- Contract: breach notification time, audit rights, data return and deletion, subprocessor consent, liability.

## Self-check
Take one report and list its exceptions and the CUECs you must implement.
