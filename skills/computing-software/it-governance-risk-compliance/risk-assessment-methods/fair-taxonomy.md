# FAIR taxonomy and factors
**Goal:** a structured, quantified scenario.
- Risk = Loss Event Frequency x Loss Magnitude.
- LEF = Threat Event Frequency x Vulnerability (probability a threat event becomes a loss event, from threat capability versus resistance strength).
- Loss magnitude: primary loss plus secondary loss (response, fines, replacement, productivity, reputation); the six forms of loss: productivity, response, replacement, fines and judgments, competitive advantage, reputation.
- Scope each analysis to one asset, threat community and loss type.

## Gotchas
- Mixing multiple scenarios in one analysis double counts.

## Self-check
Write the scenario statement and fill each taxonomy node with a range and its source.
