# SC, SI, MA, MP families
**Goal:** technical protection families.
- SC: SC-7 boundary protection, SC-8 transmission confidentiality and integrity, SC-12/SC-13 cryptographic key management and use, SC-28 protection of information at rest.
- SI: SI-2 flaw remediation, SI-3 malicious code protection, SI-4 system monitoring, SI-12 information management and retention.
- MA: maintenance tools and personnel; MP: media access, sanitization MP-6.

## Self-check
Document SC-7 with network diagram references and firewall rule review date.
