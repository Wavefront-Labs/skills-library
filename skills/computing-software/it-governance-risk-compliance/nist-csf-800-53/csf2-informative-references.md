# Implementation examples and informative references
**Goal:** one crosswalk, many frameworks.
- NIST publishes implementation examples per subcategory and the CSF Reference Tool (CPRT) with informative references mapping to SP 800-53 Rev 5 and others.
- Build a unified mapping sheet: CSF subcategory, 800-53 control(s), ISO 27001 control, internal control ID.
- Keep references in the machine-readable CSF JSON where tooling consumes it.

## Self-check
Pick ten subcategories and verify each mapped control actually delivers the outcome.
