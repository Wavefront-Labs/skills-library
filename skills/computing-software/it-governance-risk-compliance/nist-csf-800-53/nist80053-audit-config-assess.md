# AU, CM, CA families
**Goal:** audit, baseline and assessment controls.
- AU: AU-2 event logging, AU-6 review and analysis, AU-9 protection of audit information, AU-12 audit record generation.
- CM: CM-2 baseline configuration, CM-6 configuration settings, CM-8 system component inventory, CM-3 change control.
- CA: CA-2 control assessments, CA-5 plan of action and milestones, CA-6 authorization, CA-7 continuous monitoring.

## Self-check
Show a CM-2 baseline, the last drift report and the AU-6 review record.
