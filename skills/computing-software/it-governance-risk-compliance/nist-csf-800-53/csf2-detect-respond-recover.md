# Detect, Respond and Recover functions
**Goal:** map operations to DE, RS, RC outcomes.
- DE.CM continuous monitoring; DE.AE adverse event analysis.
- RS.MA incident management; RS.AN analysis; RS.CO response reporting and communication; RS.MI mitigation.
- RC.RP incident recovery plan execution; RC.CO recovery communication.
- Evidence: detection use cases, runbooks, tabletop results, restore tests, communication templates.

## Self-check
Run a tabletop and map each action taken to a DE/RS/RC subcategory.
