# Current and target profiles and tiers
**Goal:** a profile-driven roadmap.
- Create current profile (what is achieved), target profile (desired), compare gaps, prioritise, implement, repeat. NIST provides Quick Start Guides.
- Tiers describe rigor of governance and risk management: Partial, Risk Informed, Repeatable, Adaptive. Tiers are not maturity levels to be maximised.
- Record per subcategory: status, priority, owner, target date.

## Gotchas
- Scoring everything Tier 4 without business justification.

## Self-check
Produce the top ten gaps ranked by risk reduction per effort.
