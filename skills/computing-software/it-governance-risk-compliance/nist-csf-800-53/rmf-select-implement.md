# RMF Select and Implement steps
**Goal:** documented controls in the SSP.
- Select baseline per 800-53B, tailor, document planned controls and the continuous monitoring strategy; review and approve the plan.
- Implement: implement per plan, update the baseline configuration, document in the system security plan (SSP): inheritance, responsibility, implementation statements.
- OSCAL provides a machine-readable SSP format.

## Self-check
Check every selected control has an implementation statement saying how, by whom.
