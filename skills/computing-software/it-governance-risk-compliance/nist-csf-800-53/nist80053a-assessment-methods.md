# Assessment procedures (800-53A)
**Goal:** assess controls consistently.
- Methods: examine (documents, mechanisms, activities), interview (individuals, groups), test (mechanisms, activities).
- Each control has assessment objectives; record for each: determination (satisfied / other than satisfied), evidence, method.
- Output feeds the security assessment report (SAR) and POA&M items.

## Self-check
Assess one control with all three methods and record objective-level results.
