# RMF Monitor step
**Goal:** sustain the authorization.
- Monitor tasks: track changes to system and environment, ongoing control assessments per the monitoring strategy, ongoing risk response, authorization package updates, reporting, ongoing authorization, system removal.
- SP 800-137 gives the information security continuous monitoring (ISCM) programme guidance.
- Significant change triggers reassessment; define significant change criteria up front.
