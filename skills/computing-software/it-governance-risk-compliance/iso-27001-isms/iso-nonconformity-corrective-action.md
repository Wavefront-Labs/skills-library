# Nonconformity, corrective action, continual improvement (10)
**Goal:** a closed-loop corrective action process.
- 10.2: react (control and correct, deal with consequences); evaluate need to eliminate causes (review, determine causes, check for similar); implement action; review effectiveness; update risks and the ISMS if necessary.
- Record the nature of the nonconformity, actions and results. Use root-cause methods (5 whys, fishbone).
- 10.1 continual improvement of suitability, adequacy and effectiveness.

## Gotchas
- Fixing the instance without root cause or effectiveness check.

## Self-check
Take one closed finding and show the effectiveness check date and outcome.
