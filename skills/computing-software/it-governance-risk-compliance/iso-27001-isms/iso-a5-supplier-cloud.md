# A.5 supplier relationships and cloud
**Goal:** a supplier security lifecycle.
- 5.19 supplier policy; 5.20 security in supplier agreements; 5.21 ICT supply chain; 5.22 monitoring, review and change management of supplier services; 5.23 information security for use of cloud services (new).
- Tier suppliers by data sensitivity and criticality; collect assurance reports (ISO 27001 certificate, SOC 2), review annually, define exit procedure.
- For cloud record the shared-responsibility split and the customer-side controls.

## Self-check
Take your top supplier and show contract security clauses, latest assurance report and review date.
