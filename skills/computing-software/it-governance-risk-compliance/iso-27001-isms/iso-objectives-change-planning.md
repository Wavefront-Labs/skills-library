# Objectives and planning of changes (6.2-6.3)
**Goal:** objectives auditors can measure.
- 6.2: objectives consistent with policy, measurable if practicable, take account of requirements and risk results, monitored, communicated, updated, kept as documented information. Plan what, resources, who, when, how evaluated.
- Examples: phishing click rate below target, critical patches within a defined number of days, supplier reviews completed on schedule.
- 6.3 (new in 2022): when ISMS changes are needed they are carried out in a planned manner.

## Gotchas
- Objectives such as "be secure" are not measurable.

## Self-check
For each objective show metric, target, last measured value and owner.
