# Req 1-2 network controls and secure configuration
**Goal:** firewall and hardening evidence.
- Req 1: network security controls (NSCs) between trusted and untrusted networks; document and review rule sets every six months; restrict inbound/outbound traffic to what is necessary; network diagram and data flow kept current.
- Req 2: change vendor defaults and remove unnecessary accounts; configuration standards for all components (CIS or vendor guides); one primary function per server (or isolated).
- Evidence: rule set review records, diagrams, hardening standards, scan of defaults.

## Self-check
Pick a firewall rule and show owner, business justification and last review.
