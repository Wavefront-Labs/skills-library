# Unified control framework and mapping
**Goal:** one control, many frameworks.
- Define internal controls with IDs, owners, frequency and test procedure; map each to framework requirements; identify the strictest requirement and write to it.
- Sources: NIST OLIR mappings and the CSF informative references, Secure Controls Framework, CSA CCM.
- Maintain mapping as frameworks change (ISO 27001:2022, PCI v4).
- Gap output: requirements with no mapped control.

## Self-check
Take PCI Req 8 and show the internal control and SOC 2 and ISO control mapped to it.
