# Capability-based planning method

Goal: link strategy to delivery via capabilities.

- Define capabilities (what the business can do) with outcomes.
- Assess current maturity and target level per capability.
- Define capability increments, each delivering a measurable improvement through people, process and technology.
- Group increments into releases and fund by capability.
- Map to ADM: capability architecture is the segment level in the Landscape.

Gotchas:
- Capabilities are not org units or systems.
- Include non-technology changes (training, policy).

Verify: each increment lists changes in people, process, information and technology.
