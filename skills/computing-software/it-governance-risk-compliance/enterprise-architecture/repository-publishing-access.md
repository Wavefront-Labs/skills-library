# Publish and provide access to architecture content

Goal: stakeholders use architecture without needing the modelling tool.

- Publish approved views to a web portal or wiki on a schedule.
- Provide search and cross-links between catalogs, capabilities and applications.
- Apply access control: sensitive content restricted.
- Include a landing page that explains where to start.
- Collect feedback and usage metrics.

Gotchas:
- Publishing drafts as if approved harms credibility; mark status.

Verify: usage analytics show regular consumption by non-architects.
