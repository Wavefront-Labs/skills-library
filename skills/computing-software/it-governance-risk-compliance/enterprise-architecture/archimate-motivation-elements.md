# Motivation elements: stakeholder, driver, assessment, goal, outcome, principle, requirement, constraint, meaning, value

Goal: capture intent and its justification.

- Stakeholder holds drivers (conditions that motivate change); an assessment analyses a driver (SWOT-like).
- Goal is a high-level end state; outcome is a result that achieves a goal; principle is a normative property; requirement is needed behaviour or quality; constraint restricts how a requirement can be realized.
- Meaning and value express interpretation and worth.

Gotchas:
- Avoid goal to requirement jumps without outcomes if you want measurable results.

Verify: each goal has a stakeholder and measurable outcome.
