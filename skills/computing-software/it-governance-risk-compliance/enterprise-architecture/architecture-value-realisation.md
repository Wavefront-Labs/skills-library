# Value realisation and architecture performance monitoring

Goal: demonstrate return from the EA practice.

- Define a small KPI set: reuse rate, application count reduction, project compliance rate, time to deliver, cost avoided.
- Baseline before the programme and measure quarterly.
- Link benefits to roadmap items and owners.
- Report to the sponsor using business language.

Gotchas:
- Vanity measures (number of diagrams) hurt credibility.
- Attribute savings carefully; avoid double counting with project benefits.

Verify: a dashboard with trend lines exists and is reviewed by the board.
