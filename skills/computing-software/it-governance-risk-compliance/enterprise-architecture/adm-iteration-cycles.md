# Iteration: cycles, phases and within a phase

Goal: use iteration deliberately.

- Iteration of architecture cycles: repeated full ADM cycles for new scopes or releases.
- Iteration between phases: for example B to C to B when data findings change the business model.
- Iteration within a phase: refine in several passes, increasing detail.
- Pick timeboxes, review criteria and an architecture backlog.
- Combine with Agile by keeping a lightweight architecture runway.

Gotchas:
- Iterating without a definition of done leads to endless modelling.
- Keep versioned baselines.

Verify: the plan names the iteration types used and exit criteria for each.
