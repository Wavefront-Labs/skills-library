# Dispensations, compliance and policy management

Goal: exceptions are visible and temporary.

1. Project submits a dispensation request with reason, risk, cost to comply and remediation plan.
2. Board or delegate decides; record in the Governance Log.
3. Set expiry and an owner for remediation.
4. Review the log quarterly: repeated dispensations show where standards are wrong.
5. Report technical debt created.

Gotchas:
- Perpetual dispensations equal no standard.

Verify: no dispensation lacks an expiry and owner.
