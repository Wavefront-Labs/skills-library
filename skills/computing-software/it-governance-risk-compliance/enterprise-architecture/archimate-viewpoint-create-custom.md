# Create custom viewpoints

Goal: a repeatable specialised view.

- Define name, stakeholders, concerns, purpose (designing, deciding, informing), scope (detail, coherence, overview).
- List the elements and relationships allowed and the notation.
- Provide a template diagram and example.
- Version it with the method.

Gotchas:
- Too many custom viewpoints fragments communication.

Verify: two architects produce consistent views from the definition.
