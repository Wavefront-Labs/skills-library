# Use business scenarios in the ADM

Goal: use scenarios as both input and test.

- Phase A: create scenarios in workshops to find stakeholders, goals and requirements.
- Phases B to D: walk the scenario through the target models to test fit.
- Phase G: use scenarios as acceptance tests of the delivered architecture.
- Keep scenarios in the repository.

Gotchas:
- Limited to a few scenarios; too many dilutes focus.

Verify: each key scenario has a recorded walkthrough result.
