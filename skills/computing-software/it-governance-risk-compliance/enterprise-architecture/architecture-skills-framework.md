# Architecture skills and competency framework

Goal: clear expectations of architects.

- Define skill categories: generic (leadership, teamwork), business, enterprise architecture, programme and project management, IT general knowledge, technical IT, legal.
- Define proficiency levels (awareness, knowledge, hands-on, expert).
- Map roles (domain architect, enterprise architect, solution architect) to required levels.
- Plan development and certification (TOGAF, ArchiMate, vendor).

Gotchas:
- Certification alone does not prove practice ability.

Verify: each architect has a gap plan against their role profile.
