# LeanIX EA management platform

Goal: maintain a living inventory.

- Fact sheets represent applications, IT components, business capabilities, providers and more; relations link them.
- Surveys collect data from owners; lifecycle and TIME fields feed reports.
- Use reports (landscape, matrix, roadmap) and views.
- Integrate with CMDB, cloud and SSO via APIs or connectors (confirm current connector set).
- Set data quality rules and ownership.

Gotchas:
- Tool does not replace governance; define who owns each fact sheet.

Verify: data quality dashboard shows completeness rising over time.
