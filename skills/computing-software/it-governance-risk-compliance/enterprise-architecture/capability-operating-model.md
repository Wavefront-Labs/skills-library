# Architecture capability operating model

Goal: the EA team can repeatedly deliver value.

- Establish architecture organisation: board, central team, federated domain leads.
- Define roles and the skills framework (architecture, business, leadership).
- Define processes: request intake, project engagement, review, repository upkeep.
- Funding model: chargeback, central funding or project-funded.
- Service catalog for the EA team.

Gotchas:
- An ivory-tower central team is bypassed; embed architects in programmes.
- Capacity is always short; prioritise.

Verify: a published engagement model states what the team does and how to ask.
