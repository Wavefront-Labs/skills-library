# Architecture Contracts and implementation oversight

Goal: delivery projects build what the architecture intends.

- Confirm scope and priorities with the programme.
- Define architecture constraints on each project: principles, standards, interfaces, NFRs.
- Sign an Architecture Contract (the agreed deliverables, quality criteria, acceptance and change process).
- Run design reviews at planned points; record findings.
- Handle deviations through dispensation requests.

Gotchas:
- A contract nobody checks is paperwork; schedule reviews.
- Agile teams need lightweight guardrails rather than gate documents.

Verify: each project has a signed contract and review dates.
