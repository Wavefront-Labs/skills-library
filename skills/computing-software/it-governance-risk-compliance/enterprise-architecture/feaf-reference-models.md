# Federal Enterprise Architecture Framework and its reference models

Goal: recognise FEAF vocabulary and relevance.

- FEAF provides a common approach to federal architecture with consolidated reference models: performance, business, data, application and infrastructure (and security) reference models, as set out in the Consolidated Reference Model (confirm the current version).
- Segment architecture focuses on a business area; solution architecture on a single initiative.
- Useful when working with or modelled on US federal agencies; elsewhere use as an alternative taxonomy.

Gotchas:
- Versions and mandates changed over time; check the current OMB guidance.

Verify: you can map FEAF reference models to TOGAF domains.
