# Architecture governance framework and board

Goal: control architecture decisions without blocking delivery.

- Governance framework elements: processes, content (repository), organisation structure.
- The Architecture Board approves principles, standards, dispensations and major designs.
- Define tiers: strategic board, domain councils, project design authority.
- Define thresholds so only significant decisions reach the board.
- Publish a calendar and decision SLAs.

Gotchas:
- A board that takes weeks to decide is bypassed.
- Escalation must be clear.

Verify: a decision matrix lists decision types, level and SLA.
