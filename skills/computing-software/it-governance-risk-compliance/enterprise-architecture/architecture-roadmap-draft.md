# Draft the Architecture Roadmap and Implementation and Migration Strategy

Goal: a draft roadmap the sponsor can react to before detailed planning in Phase F.

- Order work packages by dependency first, then value and risk.
- Show transitions and key milestones on a timeline.
- Include capability and principle compliance impacts.
- Mark assumptions and the readiness factors that gate each step.

Gotchas:
- Roadmaps with exact dates imply false certainty; use quarters or ranges early.
- Include run costs, not only project costs.

Verify: the roadmap can be explained in five minutes to the sponsor.
