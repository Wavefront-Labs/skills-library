# Select open standards for interoperability

Goal: reduce lock-in and integration cost.

- Criteria: openness, maturity, adoption, tooling, licence terms, vendor independence.
- Pilot new standards with a bounded project.
- Register standard, version, profile and lifecycle (emerging, current, retiring).
- Review annually.

Gotchas:
- Optional features in standards break interoperability; profile them.

Verify: the standards register shows owner and review date.
