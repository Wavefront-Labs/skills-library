# Map capabilities to applications, processes and projects

Goal: an integrated view from strategy to systems.

- Keep a matrix: capability x application with support level (primary, secondary).
- Link capability to process and to organisation unit.
- Link initiatives to capabilities they improve.
- Use for portfolio rationalisation and impact analysis.

Gotchas:
- One application mapped to many capabilities may hide a monolith.

Verify: every capability has at least one supporting application or an explicit manual note.
