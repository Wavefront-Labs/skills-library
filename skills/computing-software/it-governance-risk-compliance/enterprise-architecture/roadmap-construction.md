# Construct an architecture roadmap

Goal: show the path and its logic.

1. Start from target capabilities and gap register.
2. List initiatives and their dependencies.
3. Order by dependency, value, risk and funding windows.
4. Show on a timeline by lane (business, application, data, technology) with transition milestones.
5. State assumptions and decision points.

Gotchas:
- Use now/next/later for uncertainty beyond a year.
- Keep to one page for executives.

Verify: each initiative links to a capability outcome and an owner.
