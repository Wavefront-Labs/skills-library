# Stakeholder communication plan

Goal: the right information at the right depth.

- For each group: concern, view or artifact, format (one-pager, workshop, dashboard), frequency, owner.
- Executives get outcomes and decisions needed; engineers get interfaces and constraints.
- Use workshops for validation and short written summaries for record.
- Track feedback and decisions.

Gotchas:
- Sending the full ADD to everyone ensures no one reads it.

Verify: each recipient group confirms the pack answers its concern.
