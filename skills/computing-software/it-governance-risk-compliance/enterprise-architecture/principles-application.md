# Apply and govern principles in decisions

Goal: principles change decisions.

- Reference the relevant principles in each ADR and compliance review.
- When principles conflict, record the trade-off and the chosen priority.
- Include principles in the project start checklist.
- Review annually; retire principles that no longer matter.

Gotchas:
- Unused principles die; keep them visible in templates.

Verify: a sample of reviews cites principles with outcomes.
