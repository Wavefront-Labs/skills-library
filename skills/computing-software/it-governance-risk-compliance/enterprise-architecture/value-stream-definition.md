# Define value streams and stages

Goal: show how the business creates value for stakeholders.

- Identify the stakeholder, the trigger and the value item delivered.
- Name stages with verb-noun phrases ("Acquire Customer", "Fulfil Order").
- Give each stage entry and exit criteria and the value added.
- Keep a stream to 5 to 9 stages.
- Types: external (customer) and internal.

Gotchas:
- A value stream is not a process flow; it does not show decisions.

Verify: each stage has entry and exit criteria and a value statement.
