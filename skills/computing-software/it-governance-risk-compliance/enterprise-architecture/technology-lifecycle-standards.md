# Technology standards and lifecycle status

Goal: control technology sprawl.

- Categories: adopt/current, trial/emerging, contain, retire (names vary; a radar uses adopt, trial, assess, hold).
- Record version, vendor support end, owner, and replacement.
- Review each technology yearly or when end of support is within 18 months.
- Publish for projects to consult before design.

Gotchas:
- Standards without enforcement equal suggestions; link to governance.

Verify: projects can find the standard and the latest status in one lookup.
