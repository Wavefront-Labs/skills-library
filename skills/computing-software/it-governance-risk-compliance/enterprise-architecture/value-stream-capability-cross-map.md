# Cross-map value streams to capabilities

Goal: connect strategy views.

1. List value stages as columns and capabilities as rows.
2. Mark which capabilities are needed in each stage.
3. Combine with the capability heat map to find stages with weak capabilities.
4. Use the result to prioritise improvements and to scope projects.

Gotchas:
- Mapping everything to everything is noise; limit to key enablers.

Verify: each stage has three to seven enabling capabilities.
