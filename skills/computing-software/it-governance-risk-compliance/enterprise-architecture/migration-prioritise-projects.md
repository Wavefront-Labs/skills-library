# Assign business value and prioritise projects

Goal: a defensible order of projects.

1. Estimate cost, benefit and risk per work package with the programme office.
2. Score value with a simple model (value, urgency, risk reduction, dependency enablement).
3. Check against funding envelope and resource availability.
4. Re-sequence for dependencies; do not start a package before its prerequisites.
5. Agree results with the Architecture Board and portfolio owner.

Gotchas:
- Scores should come from the business; architects only facilitate.
- Hidden dependency on shared platforms often reorders the plan.

Verify: priority list reconciles with the project portfolio and budget.
