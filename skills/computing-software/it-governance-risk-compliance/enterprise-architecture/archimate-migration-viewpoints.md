# Project, Migration and Implementation and Migration viewpoints

Goal: present change to portfolio managers.

- Project: work packages, deliverables, assignments to actors, links to goals.
- Migration: plateaus and transitions between them.
- Implementation and Migration: combine work packages, deliverables and plateaus with the core elements they realize.

Gotchas:
- Do not duplicate project plan tool detail; link to it.

Verify: viewpoint shows which plateau each work package contributes to.
