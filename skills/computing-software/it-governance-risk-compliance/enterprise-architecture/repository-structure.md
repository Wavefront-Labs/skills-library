# Architecture Repository structure

Goal: one place for every architecture asset with clear classes.

- Architecture Metamodel: the tailored content definitions.
- Architecture Capability: parameters, structures, processes for governance.
- Architecture Landscape: architectural view of the state of the enterprise (strategic, segment, capability).
- Standards Information Base: standards in force.
- Reference Library: guidelines, templates, patterns.
- Governance Log: decisions, compliance assessments, dispensations, calendar.
- Requirements Repository is related and may be separate.

Gotchas:
- Folder structure should mirror these classes for findability.

Verify: you can locate a standard, a decision and a baseline within one minute.
