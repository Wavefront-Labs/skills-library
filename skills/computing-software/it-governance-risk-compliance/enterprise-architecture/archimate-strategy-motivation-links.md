# Linking strategy, motivation and core elements

Goal: traceability from why to how.

- Capability is realized by core behaviour elements and resources; resource is realized by structure elements.
- Requirement or constraint is realized by core elements.
- Goal is realized by outcome, requirement; principle realized by requirement.
- Use influence to model soft contributions.

Gotchas:
- Realization means fulfils, not merely relates; use association if unsure.

Verify: a requirement-to-element trace can be queried for each requirement.
