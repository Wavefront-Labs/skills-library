# Select viewpoints for stakeholders

Goal: show the right content to the right audience.

- Basic: Organization, Business Process Cooperation, Product, Application Cooperation, Application Usage, Service Realization, Implementation and Deployment, Technology Usage, Information Structure, Layered, Physical.
- Motivation: Stakeholder, Goal Realization, Goal Contribution, Principles, Requirements Realization, Motivation.
- Strategy and change: Strategy, Capability Map, Value Stream, Outcome Realization, Resource Map, Project, Migration, Implementation and Migration.
- Mapping: concern leads to viewpoint, view is a diagram of model content.

Gotchas:
- Viewpoints are guidance; you can create your own.

Verify: each stakeholder concern maps to a named viewpoint.
