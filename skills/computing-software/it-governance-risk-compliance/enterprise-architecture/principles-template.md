# Define principles with the TOGAF template

Goal: a small set of actionable principles.

- Template fields: Name, Statement, Rationale, Implications.
- Quality criteria: understandable, robust, complete, consistent, stable.
- Levels: business, data, application, technology; plus enterprise-wide.
- Example: "Data is a shared asset" with implication that a steward is named and access rules exist.
- Keep to 10 to 20 principles; get business sponsor endorsement.

Gotchas:
- Statements like "use best practice" are not testable.
- Implications must include cost and effort.

Verify: each principle has all four fields and an owner.
