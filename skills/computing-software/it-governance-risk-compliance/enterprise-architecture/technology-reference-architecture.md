# Reference architectures and technology blueprints

Goal: reusable starting designs.

- Define scope, principles, building blocks, quality attributes and deployment options.
- Include diagrams for logical and physical views.
- Provide guardrails and a worked example.
- Version and retire with lifecycle.

Gotchas:
- Reference architectures that cannot be instantiated in code or templates are rarely used.

Verify: at least one project has used it and fed back improvements.
