# DoDAF viewpoints and models

Goal: read and request DoDAF products.

- DoDAF 2.02 is data-centric (DM2) and organised in viewpoints: All Viewpoint, Capability, Data and Information, Operational, Project, Services, Standards, Systems.
- Models carry codes such as OV-1 (high-level operational concept), SV-1 (systems interfaces) and CV-1 (vision).
- Related frameworks: MODAF (UK, now succeeded by NAF), NAF (NATO).
- Many defence tools can model these in UAF or SysML.

Gotchas:
- Producing every model is not required; fit-for-purpose applies.

Verify: the product list lists only the models decision makers need.
