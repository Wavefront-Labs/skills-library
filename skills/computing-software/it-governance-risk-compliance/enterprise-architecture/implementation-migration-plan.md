# Complete the Implementation and Migration Plan

Goal: a plan that delivery and portfolio teams adopt.

- Confirm the management framework (programme, portfolio, change, operations).
- Update the Architecture Definition Document with transitions and final decisions.
- Complete roadmap, schedule, resources and risk register.
- Hand over to implementation teams with the architecture contracts planned.
- Capture lessons learned for the next cycle.

Gotchas:
- A plan owned only by architects will not be maintained.
- Link plan items to benefits so Phase H can measure them.

Verify: the plan is approved and loaded into the portfolio tool.
