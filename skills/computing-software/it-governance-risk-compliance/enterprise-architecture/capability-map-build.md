# Build a business capability map

Goal: a stable vocabulary of what the business does.

1. Gather sources: strategy, value stream, org chart, process models, system lists.
2. Draft level 1 groupings (strategic, core, supporting) then level 2 and 3.
3. Name each as noun phrase ("Customer Onboarding"), definition in one sentence.
4. Test: independent of who, how and where; no overlaps.
5. Review with business leaders.

Gotchas:
- A capability map mirroring the org chart changes with each reorganisation.
- Avoid more than three levels in the first release.

Verify: each capability has a definition and an owner.
