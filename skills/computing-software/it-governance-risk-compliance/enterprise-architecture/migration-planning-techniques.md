# Migration planning techniques

Goal: apply the TOGAF migration techniques properly.

- Implementation Factor Assessment and Deduction Matrix: list factors (risk, urgency, resistance), assess each project, record the deduction of impacts.
- Consolidated Gaps, Solutions and Dependencies Matrix: rows are gaps, columns are solutions, dependencies and actions; use it to group work packages.
- Architecture Definition Increments Table: plan which transitions deliver which parts of the architecture.

Gotchas:
- The matrix is a working tool, not a deliverable for executives.
- Update it whenever scope moves.

Verify: each gap row has a solution, owner and target transition.
