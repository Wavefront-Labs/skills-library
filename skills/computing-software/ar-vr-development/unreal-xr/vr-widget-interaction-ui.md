# Interact with UMG widgets in VR
**Goal:** Click in-world UI with the Widget Interaction component.

- Add a Widget Component (world space) and a Widget Interaction Component on the controller.
- Press/Release Pointer Key to click.
- Set draw size so text is legible at distance.

## Gotchas
- Widget Interaction only works with widgets set to Space: World.

## Self-check
Pointing and trigger press clicks a UMG button.
