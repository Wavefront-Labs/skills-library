# Prepare for store certification
**Goal:** Meet platform store rules before submission.

- Read the current store requirements (technical, comfort, privacy and content) for each platform you ship to; they change often.
- Check minimum frame rate, entry/exit flows, boundary handling, age rating and privacy policy URL.
- Test the release build, not the development build.

## Gotchas
- Requirements differ between stores and revisions; confirm the current documents (not restated here).

## Self-check
Pre-submission checklist built from the store's current documents is fully ticked.
