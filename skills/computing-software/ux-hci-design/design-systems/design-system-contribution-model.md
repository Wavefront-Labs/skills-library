# Governance models
- Centralised (core team), federated (core plus contributors), or hybrid.
- Intake: request template with use cases from at least two products.
- Quality bar: accessible, themed, documented, tested, tokenised.
- Regular review, office hours, roadmap, adoption metrics (usage of components, token coverage).
- Decline ad hoc requests that duplicate existing patterns.

## Verify
- [ ] Contributed components pass the same checklist as core ones.
