# IA workflow
1. Content inventory and audit (what exists, owner, quality).
2. Open/hybrid card sorting for grouping and labels.
3. Draft a hierarchy: broad and shallow beats deep (limit levels, group into 5-9 items where sensible).
4. Validate with tree testing (see ux research).
5. Document sitemap, labelling rules and URL structure.

## Gotchas
- IA is not the navigation UI; it also drives search, URLs and content models.
