# Search UX
- Visible, wide search box with magnifier; keep the query in the box on results.
- Autocomplete suggestions; tolerate typos, synonyms, plurals.
- Results: show total, sort, filters (facets) with counts; applied filters shown as removable chips.
- No-results: suggest alternatives, keep filters visible to remove.
- Mobile: full-screen search overlay; recent searches.
- Accessible: combobox pattern, results count announced via live region.
