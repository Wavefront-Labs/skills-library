# Seven stages of action
Goal, plan, specify, perform (execution); perceive, interpret, compare (evaluation).
- **Gulf of execution**: user cannot work out how to do it (missing signifiers, hidden features).
- **Gulf of evaluation**: user cannot tell what happened (no feedback, ambiguous state).
Use it to categorise observed problems and pick fixes: signifiers and mappings for execution, feedback and system status for evaluation.
