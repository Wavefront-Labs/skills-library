# Norman's concepts
- **Affordance**: relationship between object and user that allows an action. **Signifier**: perceivable cue indicating where the action happens (button shading, underline, cursor change).
- **Mapping**: control layout corresponds to the effect (slider direction, spatial layout of stove knobs).
- **Constraints**: limit wrong actions.
- **Feedback**: immediate, informative.
- Flat design removes signifiers; NN/g eye-tracking found flat clickable elements draw less attention and more uncertainty.
