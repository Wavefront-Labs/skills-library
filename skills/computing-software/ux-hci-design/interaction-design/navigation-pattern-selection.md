# Navigation patterns
- Visible beats hidden: NN/g research finds hidden (hamburger) navigation lowers discoverability and use on desktop; on mobile a bottom tab bar (3-5 destinations) works for primary sections.
- Top bar for few sections; left sidebar for deep app hierarchies; mega menus for large catalogues (keep hover-intent tolerance and keyboard access).
- Highlight current location; breadcrumbs for hierarchical sites.
- Keep labels short and parallel.
