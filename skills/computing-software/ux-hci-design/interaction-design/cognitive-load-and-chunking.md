# Cognitive load
- Chunk information (phone numbers, card numbers shown in groups).
- Remove extraneous load: decorative clutter, unclear labels, inconsistent patterns.
- Offload: defaults, autofill, remembered state, visible context.
- Gestalt principles: proximity, similarity, common region, continuity aid grouping.
- Serial position effect: put key items first and last in lists.

## Verify
- [ ] Think-aloud sessions show fewer pauses and confusion at the redesigned step.
