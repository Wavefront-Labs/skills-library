# JTBD and story mapping
- Job statement: "When [situation], I want to [motivation], so I can [outcome]."
- Capture functional, emotional and social aspects.
- Story map: backbone of user activities left to right, stories beneath by priority; slice horizontally for releases (Jeff Patton).
- Keep acceptance criteria including accessibility.
