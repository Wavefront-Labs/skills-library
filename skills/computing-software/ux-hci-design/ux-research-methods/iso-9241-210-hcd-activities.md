# ISO 9241-210 activities (iterative)
1. Understand and specify the context of use.
2. Specify user requirements.
3. Produce design solutions.
4. Evaluate against requirements; iterate.
Principles: based on explicit understanding of users, tasks, environments; users involved throughout; driven and refined by user-centred evaluation; iterative; addresses the whole user experience; multidisciplinary team.
