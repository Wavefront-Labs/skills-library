# Card sorting
- Open: participants group and name; for creating categories. Closed: sort into given categories; for validating.
- 15-30 participants for quantitative confidence (NN/g suggests about 15); 30-60 cards.
- Cards use user-facing names with short descriptions.
- Analyse: similarity matrix, dendrogram, category-name agreement; look for outliers.
- Tools: OptimalSort, UXtweak, Miro for moderated.
