# Remote testing
- Moderated remote: video call with screen share; same as lab but check tech first.
- Unmoderated: platform delivers tasks and records; needs very clear tasks, shorter sessions, attention checks, and success criteria; weeded out low-quality participants.
- Good for scale and quantitative metrics; weaker for probing.
- Test prototype links in advance, collect permission, handle privacy.
