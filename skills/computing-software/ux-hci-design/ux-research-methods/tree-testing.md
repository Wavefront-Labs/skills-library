# Tree test
- Text-only version of the sitemap; participants pick where they would find an item.
- 8-10 tasks, 50+ participants for stable numbers (common guidance).
- Metrics: success rate, directness (no backtracking), time, first-click location.
- Fix labels or placement for low success; re-test.

## Verify
- [ ] Pass criterion per task set in advance (e.g. above 70 percent success).
