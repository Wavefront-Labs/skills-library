# ISO 9241-11 usability
Usability = extent to which specified users can achieve specified goals with **effectiveness**, **efficiency** and **satisfaction** in a specified context of use.
- Effectiveness: task completion rate, error count.
- Efficiency: time on task, clicks.
- Satisfaction: SUS, SEQ, NPS-like single items.
Set target values before testing (e.g. 90 percent completion).
