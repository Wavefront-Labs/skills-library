# Synthesis
1. Log observations per participant per task (what, where, evidence).
2. Affinity diagram: cluster notes into themes.
3. Count participants affected for each issue; rate severity.
4. Recommend changes; link to clips.
5. Share a short readout (top issues, quotes, clips) soon after testing.

## Verify
- [ ] Each recommendation traces to observations from at least one participant.
