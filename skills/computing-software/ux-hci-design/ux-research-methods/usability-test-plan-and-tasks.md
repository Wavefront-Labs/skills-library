# Test plan
- Goals and questions, participants (representative of users; screeners), 5 per round for qualitative issue-finding (Nielsen: 5 users find about 85 percent of problems; test iteratively with more rounds), methods, metrics, schedule.
- Tasks as scenarios ("You need to move your appointment to next Friday"), not instructions, no UI labels in the wording.
- Pilot to fix tasks.
- Consent forms, recording permission, compensation.

## Verify
- [ ] Pilot participant completes all tasks within the session time.
