# Survey design
- One concept per question (avoid double-barrelled); avoid leading wording and jargon.
- Balanced scales with labelled endpoints; include "not applicable" where needed.
- Order: easy first, sensitive last; keep short.
- Pilot; check mobile display.
- Beware self-selection and acquiescence bias; surveys measure attitudes, not behaviour.
- Open-ended items sparingly; code them for analysis.
