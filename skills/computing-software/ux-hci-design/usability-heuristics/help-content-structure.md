# Task-focused documentation
- Title articles with the user goal ("Export a report to CSV").
- Numbered steps, one action each; screenshots only where they remove ambiguity (with alt text).
- Troubleshooting sections listing symptom, cause, fix.
- Measure: search terms with no results, article ratings, support ticket deflection.

- [ ] Top 10 support questions each have a findable article.
