# Contextual help
- Inline hint text for complex fields; tooltips for secondary info (keyboard/focus reachable, dismissible and hoverable, WCAG 1.4.13).
- Onboarding: teach by doing the first task; avoid long carousels that users skip.
- Link help articles deep to the exact task; keep search in help.
- Do not put essential information only in a tooltip (touch devices lack hover).

## Verify
- [ ] Help is reachable in at most two actions from any screen.
