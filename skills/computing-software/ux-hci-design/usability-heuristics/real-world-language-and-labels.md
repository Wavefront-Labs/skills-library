# User vocabulary
1. Collect the words users actually use: support tickets, search queries, interview transcripts, open card sorts.
2. Replace system terms ("Instantiate", "Entity", "Null value") with task terms.
3. Keep one term per concept across the product (see consistency).
4. Test labels with first-click tests or tree tests.

## Gotchas
- Do not use clever or branded names for core functions.
- Domain experts may genuinely prefer the technical term; segment by audience, don't assume.
- Localisation: translate concepts, not words; idioms and metaphors often fail.

## Verify
- [ ] Five users can describe what each primary label does without help.
