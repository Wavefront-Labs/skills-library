# Jakob's law
Users spend most of their time on other sites, so they expect yours to work like those.
- Logo top-left links home; search is a box with magnifier; cart top-right in e-commerce.
- Use platform controls (native date pickers, system share sheets) before inventing.
- If you break a convention, make the benefit large and test it; provide a migration path when redesigning (opt-in preview).

## Verify
- [ ] First-click test on standard tasks succeeds at conventional locations.
