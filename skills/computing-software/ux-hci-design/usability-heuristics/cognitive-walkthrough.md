# Cognitive walkthrough
For each step in a task sequence ask (Wharton et al. formulation):
1. Will the user try to achieve the right effect?
2. Will they notice the correct action is available?
3. Will they associate the action with the effect?
4. After the action, will they see progress being made?

## Procedure
Define user, task and the correct action sequence; walk each action; record "failure stories" with reasons.
Best for learnability of first-time tasks; run early on prototypes.

## Verify
- [ ] Each failure has a screen, a question number and a proposed fix.
