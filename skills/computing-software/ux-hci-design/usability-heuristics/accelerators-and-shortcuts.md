# Accelerators
- Keyboard shortcuts with a discoverable cheat sheet (commonly `?`), shown in menus.
- Bulk actions, saved filters, templates, command palettes.
- Single-character shortcuts must be turnable off, remappable, or active only on focus (WCAG 2.1.4).
- Avoid clashing with browser, OS and assistive-technology shortcuts.

## Verify
- [ ] Expert task time drops with shortcuts; the novice path is unchanged.
