# Heuristic evaluation procedure
1. Define scope: key tasks and screens; pick the heuristic set (Nielsen's 10, possibly domain-specific).
2. Use 3-5 evaluators (single evaluators find a minority of problems; Nielsen's data shows diminishing returns around 5).
3. Each evaluator reviews independently, in two passes: overview first, then per screen against each heuristic.
4. Record each finding: location, heuristic violated, description, screenshot.
5. Consolidate, deduplicate, rate severity jointly, and report with recommendations.

## Gotchas
- Evaluators with domain and usability expertise find more.
- Heuristic evaluation finds problems, not whether the product works; pair with user testing.
- Do not discuss findings before individual reviews are done.
