# Interface inventory
1. Screenshot every screen/state; group by pattern (buttons, dialogs, tables, forms).
2. Tabulate variants: label wording, button order (primary position), icon for same action, spacing.
3. Rank by frequency x user visibility; fix by consolidating into one design-system component.
4. Check terminology: one name per concept across UI, docs and emails.

## Kinds of consistency
Functional, visual, internal (within product) and external (with platform/industry conventions).

## Verify
- [ ] No pattern has more than one variant without a stated reason.
