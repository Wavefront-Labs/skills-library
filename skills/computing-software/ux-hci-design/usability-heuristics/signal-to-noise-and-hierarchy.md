# Visual hierarchy
- Each screen has one primary action; make it the most prominent.
- Group related items (proximity, common region); whitespace separates.
- Cut: every extra unit of information competes with the relevant ones.
- Check by squint test or blur the screenshot: the important thing should still stand out.

## Gotchas
- Minimalism that hides labels or affordances harms discoverability.
- Aesthetic-usability effect: attractive designs are perceived as more usable, which can mask problems in testing.

## Verify
- [ ] Five-second test: users name the page purpose and main action.
