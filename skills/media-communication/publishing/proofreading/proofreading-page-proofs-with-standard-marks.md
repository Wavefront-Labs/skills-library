# Proofreading page proofs with standard marks

**Goal:** catch every remaining error and layout fault in typeset pages, mark it so the
typesetter can't misread it, and change as little as possible — because every change now
costs money and can cause new errors.

## 1. Know which job you're doing
- **Against copy (comparison proofreading):** checking proofs line by line against the
  edited manuscript to ensure the typesetter followed it. Common in traditional book work.
- **Blind proofreading:** reading the proofs on their own for errors and sense.
- Ask also: which proof round (first proofs allow more; later proofs only essential fixes),
  the style sheet, house style, and whether to query or correct style issues.
**Rule:** at proof stage, correct **errors**, not preferences. Rewriting reflows pages.

## 2. Marking
Two common systems — use whichever the client specifies:
- **Paper / PDF with standard marks:** in the UK the BSI marks (BS 5261) and in North
  America Chicago-style marks. Each correction gets a mark **in the text** and the
  instruction **in the margin**, in order left to right; the classic convention uses
  colours to separate printer's errors from author/editor changes (*check the client's
  convention; many no longer use colours*).
- **PDF annotation (now the most common):** Acrobat/Reader comment tools — Insert Text,
  Replace Text, Strikethrough, sticky notes for instructions. Keep one annotation per
  correction; don't overlap comments; describe the action, not just the error ("delete
  comma" not "comma?").
Mark so the change is **unambiguous**: write out ambiguous characters (e.g. "en dash",
"capital O, not zero").

## 3. What to look for (beyond spelling)
**Text:** typos, missing/doubled words, punctuation, consistency with the style sheet,
wrong fonts (italic/bold/small caps) where the manuscript had them, special characters
dropped in conversion (diacritics, symbols, ligatures).

**Layout:**
- **Bad breaks:** wrong word division at line ends, more than ~2-3 consecutive hyphenated
  lines (house rules vary), broken URLs or numbers split from units.
- **Widows and orphans:** a single line of a paragraph stranded at the top or bottom of a
  page (definitions of which is which vary between houses — follow the client's terms).
- **Rivers and loose lines** in justified text.
- **Headings** stranded at a page foot; heading levels consistent.
- **Running heads and folios** (page numbers): correct chapter, sequence unbroken, absent on
  chapter openers or blank pages where house style says so.
- **Figures/tables** near their call-outs, captions matched and numbered in sequence.
- **Contents page** entries and page numbers match the actual pages; cross-references
  ("see p. 112") correct.

## 4. Method
- Read in **multiple passes**: one for text, one for layout and sequence checks (folios,
  running heads, contents, figure numbering). Doing both at once misses things.
- Read slowly; read numbers and names letter by letter. Some proofreaders read
  backwards or aloud for spelling.
- Check the start and end of every page and spread — errors cluster at page turns.
- **Count the cost:** if fixing something requires rewriting, suggest a solution that
  fits the same space (same line length) to avoid reflow.

## 5. Collation and later rounds
When an author and a proofreader both mark proofs, someone **collates** them into one set,
resolving conflicts. On revised proofs, **check every correction was made** and that no new
errors appeared around it (the whole line and paragraph, sometimes the following pages).

## Verify
- [ ] Brief, round, style sheet and marking system confirmed.
- [ ] Every mark is unambiguous and has a margin instruction or clear comment.
- [ ] Separate pass done for running heads, folios, contents and figure numbering.
- [ ] No preference-only changes on late proofs.
- [ ] On revised proofs, every earlier correction checked as made.
