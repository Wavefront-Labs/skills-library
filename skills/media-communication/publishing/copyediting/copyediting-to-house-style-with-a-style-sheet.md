# Copyediting to house style with a style sheet

**Goal:** a manuscript that is correct and consistent, in the author's voice, with every
non-obvious change explained and a style sheet the proofreader can work from.

## 1. Before you start
- Get the **brief**: level of edit (light/medium/heavy), house style guide (Chicago,
  New Hart's Rules, AP, APA, or a house guide that overrides one of them), preferred
  dictionary (e.g. Merriam-Webster, Oxford), deadline, how queries are delivered.
- Save an **untouched copy** of the manuscript. Turn on **Track Changes** in Word and set
  your user name so changes are attributed.
- Skim the whole thing first. Note the author's patterns before you impose any.

## 2. Passes (don't try to catch everything at once)
1. **Mechanical clean-up:** double spaces, straight vs curly quotes, en/em dashes, ellipses,
   stray formatting. Use Find & Replace carefully — **never "Replace All" without
   checking a sample**, and be aware it acts on hidden text and notes too.
2. **Main read:** grammar, spelling, punctuation, usage, clarity, consistency, facts that
   look wrong (dates, names, arithmetic). This is the big pass.
3. **Elements:** headings hierarchy, numbered lists, tables, figure/table call-outs and
   captions, notes and references (format and matching citations to the reference list).
4. **Consistency check:** run through the style sheet; optionally use a consistency tool
   (e.g. PerfectIt) to find variants you missed.

## 3. The style sheet
A living document you send with the edited manuscript. Sections usually include:
- **Spelling and word list:** alphabetical — "e-mail → email", "website", proper nouns,
  coined terms, the author's preferred variants.
- **Hyphenation and capitalisation** decisions ("decision-making" as noun and adjective).
- **Numbers:** spelled out vs numerals, dates, times, currency, percentages.
- **Punctuation:** serial comma yes/no, quotation mark style, possessives (James's / James').
- **Abbreviations**, italics (titles, foreign words), and citation style.
- **Characters/places/timeline** for fiction: names, ages, eye colour, which day it is.
Record each decision the **first time** you make it, with the page reference.

## 4. Edit without rewriting
- Change what is **wrong or inconsistent**; query what is merely **different from how
  you'd write it.** The author's rhythm and word choice are theirs.
- If a sentence is unclear, propose a fix in a query instead of silently restructuring it.
- Don't "correct" deliberate dialect, dialogue or voice. In fiction, dialogue is allowed to
  be ungrammatical.

## 5. Author queries
- Use Word comments (or the publisher's AQ format). Be **specific, brief, polite**, and
  give an option: "AQ: Chapter 2 gives 1987 and chapter 9 1989 for the move — which is
  correct?" "AQ: OK to change to 'fewer' per house style?"
- Explain changes that might surprise the author with a short rationale, citing the style
  guide rule if useful.
- Don't query every routine style change — explain them once in a cover note instead.

## 6. Hand-off
Deliver: tracked manuscript, style sheet, cover note (level of edit, global changes made,
key queries, anything unresolved). After author review, a clean-up pass accepts/rejects
changes and resolves answers.

## Common gotchas
- Global Find & Replace that changes "US" inside "USED" or alters quoted material.
- Fixing a reference in the text but not in the reference list (or vice versa).
- Imposing UK spelling on a US book (or reverse) without checking the brief.
- Losing track of what you decided in chapter 1 by chapter 20 — the style sheet prevents this.

## Verify
- [ ] Brief, style guide and dictionary confirmed; original saved.
- [ ] All changes tracked under your name.
- [ ] Style sheet complete enough for a proofreader to work from.
- [ ] Every query is specific and answerable.
- [ ] Citations match the reference list in both directions.
